## 已确认无需改动（记录结论，避免重复讨论）

| 项 | 结论 |
|---|---|
| ✅ 持续性速率修正 | `StatKey` 已含 `gauge_rate` / `gauge_threshold`，`modify_stat(gauge_rate, +8, duration: N)` 直接可行。**不需要**给 `modify_resource` 加 duration |
| ✅ 开局载荷清单化 | `StatusDef.payload` 已是 `TermNode[]`，A23 已完成，无需再改 |
| ✅ 术语算子够用 | Sequence / Repeat / If 三个已能覆盖本稿全部技能；跨效果传值类（吸血、按目标攻击力加成）按 A17 走独立 EffectDef，不进术语 |
| ✅ INV-S5 未挡路 | 「命运操纵」「平衡感」改的是 `gauge.current` / `gauge_rate` 源属性，不是派生的行动周期，合规 |
