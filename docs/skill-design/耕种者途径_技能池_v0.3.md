# 耕种者途径（母亲）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按母巢系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入母巢系核心机制 **「月相」节拍器**（满/血/银/红/缺，5 相轮转串四轴）；
> ③ 新增 **跨系 combo 卡**（母巢↔暗影世界 荒芜净化污秽→丰饶、母巢↔永暗之河 恶灵化读奴役）；
> ④ 补 1 张主题界域牌（创造世界·自然世界）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《母巢系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做「轴=钩子」与跨系联动两层。核心主轴是「生长 ↔ 荒芜」双面体，靠【枯荣循环】耦合两轴。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁「技能效果 + 轴引擎 + 跨系接口」，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **生命** ★核心 | `生命`(vitality, 友方) | 治疗 / 给予生命 / 生命炼成 → 产 `生命` | 缝合灵魂免死；触碰痊愈全清；枯荣循环以 DOT 反哺 | 万物母巢 |
| ② **大地** | `大地`(earth, 自身/区域) | 催化种子 / 驱使虫豸 / 化身巨熊 → 挂 `大地` | 藤蔓纠缠 / 地底潜行 / 自然憎恶引仇；橡树之子强化 | 自然之子 |
| ③ **炼成** | `炼成`(forged, 召唤物) | 生命炼成 / 人偶制造 → 产 `炼成` | 魔像/人偶材质递进；杂交造物赌变异 | 人偶制造 |
| ④ **荒芜** ★跨系 | `荒芜`(blight_mark, 敌方/区域) | 恶灵化 / 剥夺生命 / 荒芜 → 挂 `荒芜` | 范围内生命流逝至死；死者化恶灵；净化污秽→丰饶 | 荒芜 |

> **月相 节拍器（母巢系签名机制，母巢系 §2.2 / 总览 §1 咬合器⑤）**：母巢系的签名机制挂在**药师**途径（月相轮转串其四轴）。耕种者作为同系相邻途径，**借用月相区间**获得增益——当友方药师处于某月相时，耕种者的「生命/大地/荒芜」对应轴获得协同加成（详见各卡 payoff）。本途径自身不轮转月相，而是通过【丰饶反哺】【秽土净化】等跨系卡与药师月相、罪犯污秽互动，形成母巢双途径的耦合。
>
> **本途径主轴：生长 ↔ 荒芜 双面体**。【枯荣循环】把敌方身上的每一道 DOT 直接换算成己方治疗——这是生命轴与荒芜轴唯一的**直接耦合件**，没有它两轴只是平行线。
