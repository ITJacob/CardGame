### 本途径的三条辨识度机制

**① 卷轴（预存—燃烧）**
原著「念咒后卷轴燃烧释放能力」「冰冻、麻痹等卷轴极大节约施法时间」。落地规则：
- 卷轴 = 一个 `charges: 1`（C6，已实现）的**预存状态**，挂在施法者（或友军）身上；
- 咒在挂载时已念完 → 卷轴状态带 `silent_immune`（本稿新增项 SS1，🔴）：持有者即便处于「沉默」，卷轴仍会照常燃烧；
- 触发条件写在状态触发器上（**下次被攻击** / **下次攻击**），触发即 `charges` 归零卸载（C6）；
- 载荷 = 卷轴上预先写好的法术（冰冻 = `shackle` F7；麻痹 = 「眩晕」）。

**② 隐秘知识（知识越少人知道，法术越强大）**
原著序列 4 明写"知识越少人知道法术越强大"。落地为计数状态 `hidden_knowledge`（本稿新增项 SS3，🔴）：
- 自身计数，初始 **3 层**，`maxStacks: 5`，`damage_mul = 1 + 0.1 × 层数`；
- **消耗**：你每次造成伤害 → 层数 −1（招式被看穿，下限 0）；
- **回充**：每当你释放「知识类」技能（法术解析 / 神秘再现 / 删除 / 修改 / 知识攻击）→ 层数 +1。
- 玩法体感：**先解析、先删改，再输出**；连续用同一张输出卡会越打越软。
- 零新依赖版即主方案（层数回充写在技能效果里，不需要引擎统计"是否首次释放"）；增强版（"本场首次释放的技能 +1 层"）列为新增项 SS3 的可选分支。

**③ 童话魔法**
原著序列 4「神秘学家」的核心招牌，点名三个具名法术——**卖火柴的小女孩（幻觉）、灰姑娘（变形）、朗基努斯之枪（强攻）**。本稿三张全部落地为独立技能，并统一 flavor：它们都是"把童话搬进现实"，因此都可以被驱散（与序列 4 的"知识越少人知道越强大"形成反差——童话是**人人都知道**的故事，所以强度高但易被针对）。

## 一、技能池

图例：⚠️ = 需要框架扩展（通用项引 `_GENERATION_BRIEF.md` §7 编号，本途径特有项引文末 **SS** 编号）；★ = 该轴的旗舰技能。

### 普通（序列 9–8）

#### 【被动】窥秘之眼 🜁
- **原著** 序列9 窥秘人 —— "『窥秘之眼』：观察星灵体 / 以太体 / 心智体状态"
- **文案** 你的眼睛能看见别人的"三体"：星灵体的光、以太体的流、心智体的结。藏起来的瞒不过你，身上带着门道的，也瞒不过你。
- **序列** 9 窥秘人 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `scrying_eye`（整场，`duration: null`）：
  - 敌方 `stealth` / `shadow_veil` / 不可选中类状态**对你无效**（依赖 C8 候选池过滤，🔴 未实现）
  - 你的伤害对**携带任意状态**的目标 ×1.15（`If(target_has_status: any)`，依赖 F52 谓词 🟡）
- **翻译/语义** 原著"观察三体状态"在卡牌里唯一的出口就是**状态可见性**——没有隐藏信息，但有"是否被隐匿遮挡"与"是否带状态"两件事。故拆成两条：识破隐匿 + 对"身上有门道"的目标加成。本途径的反隐匿地基，与愚者【灵体之线】同族。
- ⚠️ 依赖 C8（🔴）+ F52（🟡）。数值 ⚠️D。

#### 【主动】快速仪式 🜁
- **原著** 序列9 窥秘人 —— "快速仪式：无需大多数仪式物品"
- **文案** 你省去了那些瓶瓶罐罐与繁琐步骤——咒文脱口而出，手上的功夫也快了半拍。
- **序列** 9 窥秘人 · **能量 1 / cd 3 / 吟唱 0** · `targetSpec: SELF`
- **效果** `modify_resource(energy, +3, delta)`（自身）+ `mount_status(免吟唱, duration: 2)`
- **翻译/语义** 原著"无需大多数仪式物品"= **施法门槛降低**。引擎里"门槛"只有两个维度：能量与前摇，故给 +3 能量（净 +2）与 2 tick 免吟唱（复用既有 `免吟唱` 状态，零新机制）。1 能量换净 +2 能量看着像永动，实际被 cd 3 与"占用一个主动槽"卡住；若验证脚本判超模则降到净 +1（⚠️D）。
- **与相邻途径的分野** 阅读者（白塔）的「省略步骤」是**永久性**被动，本条是**一次性**主动——窥秘人的"快"来自临场省事，不是体系化的精简。

#### 【主动】占星术 🜄
- **原著** 序列9 窥秘人 —— "魔法、巫术、**占星术**等神秘知识全面掌握"
- **文案** 你从星象里读出下一步。被你点到的同伴，脚步会比对手先落下。
- **序列** 9 窥秘人 · **能量 2 / cd 3 / 吟唱 0** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: gauge_asc }`
- **效果** `modify_resource(gauge.current, +20, delta)` 目标**友军**
- **翻译/语义** 占卜/占星 = 提前量。**⚠️ G5 铁律**：绝不能写成 `SELF` 自推条——主动技能在自己回合释放时行动条已清零，自推后立刻重填，等于没加。推友军是本途径"预知"主题唯一正确的出口。🜄 轴的低费骨架。
- ⚠️ `gauge.current` 类技能的定价无既有锚点（沿用 **D2**）。数值 ⚠️D。

#### 【被动】神秘知识 🜃
- **原著** 序列9 窥秘人 —— "**魔法、巫术、占星术等神秘知识全面掌握**"
- **文案** 那些别人要翻遍典籍才找得到的条目，你早就烂熟于心——你的灵感来得更密，也更早。
- **序列** 9 窥秘人 · **hook** `on_battle_start`（A1）
- **效果** 自身 `modify_stat(energy_max, +5, duration: null)` + `modify_stat(energy_regen, +0.2, duration: null)`
- **翻译/语义** 原著是本途径最基础的一条，落在资源层最干净：知识广 = 能量池更大 + 恢复更快。⚠️ **契约注意**：引擎 `StatKey` 无「智力」，v0.1 写的 `modify_stat(int, +2)` 属无效键，本版改回 `energy_max` / `energy_regen`。零新依赖，🜃 轴与全途径的能量地基。
- ⚠️D：`energy_regen +0.2` 相当于每 tick 多 0.2 能量，需与通识者 / 阅读者的同类被动一起定档。

#### 【主动】格斗术·因敌施技 🜂 ★
- **原著** 序列8 格斗学者 —— "**掌握许多流派格斗术**"
- **文案** 你学过的流派太多，多到身体会自己挑：对方立了架势，你就用刚劲砸开；对方抢了先手，你就卸力推回；对方躲在后面，你就把它拽出来。
- **序列** 8 格斗学者 · **能量 3 / cd 3 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `index_asc`）
- **效果** `If` 三分支（确定性，无随机）：
  - 目标带「护盾」或「坚守」→ **刚**：`damage(element: physical, 7)`（破架势）
  - 目标行动条最高（即将出手，`gauge_desc`）→ **柔**：`damage(element: physical, 3)` + `modify_resource(gauge.current, -20, delta)`
  - 其余 → **擒**：`damage(element: physical, 4)` + `move(pull_forward)`（在**其自己队列内**前拉 1 格，C1 锁定 `from.faction`，**G8 合规**）
- **翻译/语义** 原著"许多流派"最贴的引擎表达不是随机轮换（R5 只允许概率用于非伤害维度，伤害不能掷骰子），而是**条件化选招**——这正是"学者"打法的味道：看情况换流派。三分支分别对应破防/卸力/拉人，且都是原著格斗术的常识动作。
- **与 v0.1 的差异** v0.1 的「学者格斗术」是 `damage 6 (physical)` 一张白板卡，把"许多流派"这个原著核心词完全丢了。
- ⚠️ 依赖 F52 `target_has_status`（🟡）+ `gauge_desc` 排序（已有）。近战溢价无锚点（沿用 v0.1 遗留）。数值 ⚠️D。

#### 【被动】学者体魄 🜂
- **原著** 序列8 格斗学者 —— "**身体素质提升**"
- **文案** 常年浸淫各家流派的身体，比看上去结实得多。
- **序列** 8 格斗学者 · **hook** `on_battle_start`（A1）
- **效果** 自身 `modify_stat(hp_max, +8, duration: null)` + `modify_stat(defense, +1, duration: null)`
- **翻译/语义** 原著白纸黑字"身体素质提升"，直译成生命上限与防御。单卡纪律内（防御 ±1），🜂 轴必须站前排，这条是对冲贴身代价的地基。零新依赖。⚠️D（`hp_max +8` 约合 13% 最大生命，与"生命上限 = 30 + 10×力量"锚点对齐）。

#### 【主动】照明术 🜃
- **原著** 序列7 巫师 —— "常见法术：**照明术**、闪电术、造风术、力场之手等"
- **文案** 一团光在你掌心炸开，黑暗里藏不住任何东西——包括它身上那些见不得光的门道。
- **序列** 7 巫师 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `index_asc`）
- **效果** `damage(element: fire, 3)` + `dispel(target, category: ['buff'], count: 1)`（C2 已支持数组）
- **翻译/语义** 原著点名的基础法术。照明在卡牌里的收益不是"看得见"（无隐藏信息），而是**破除依附于黑暗的东西**：隐匿类与增益类状态都是 `category: 'buff'`，一次驱散正好落在这两个方向。本途径最便宜的驱散件，也是【窥秘之眼】的战术搭档。
- **与 v0.1 的差异** v0.1 完全没有照明术，是原著点名法术的重大遗漏。⚠️D。

#### 【主动】闪电术 🜃

- **文案** 一道电光自你指尖窜出，在它身上炸开一片焦痕。
- **序列** 7 巫师 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: shock, 5)`
- **翻译/语义** 火球锚点（3 能量 = 5 伤害）的直译，🜃 轴的伤害基准件。元素取 `shock`（原著是"闪电术"，引擎既有 `shock`，**不新立项元素**——参照 F63 对 `lightning` 的否决结论）。与【格斗术】构成"远 5 / 近 3+位移"的成对锚点，方便验证脚本对齐 `reach` 溢价。零新依赖。⚠️D。

#### 【主动】造风术 🜃
- **原著** 序列7 巫师 —— "常见法术：照明术、闪电术、**造风术**、力场之手等"
- **文案** 你挥手掀起一阵风，把它连同它的节奏一起往后推去。

#### 【主动】力场之手 🜃
- **原著** 序列7 巫师 —— "常见法术：照明术、闪电术、造风术、**力场之手**等"

- **文案** 你的一部分始终留在知识荒野的雾里。敌人找不到你——除非你自己走出来。
- **序列** 0 隐者 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `concealment_authority`（整场，`duration: null`）：
  - 自身 `target_exclusion`（敌方单体技能难以选中，依赖 **C8**，🔴）
  - `damage_taken_mul: 0.9`
  - 触发器 `on_deal_damage` → 显形 2 tick（期间上述两条失效）
- **翻译/语义** 原著序列 0 的三大权柄之一。做成常驻但**攻击即破**的半隐匿，避免"全程不可选中"在 4+4 槽位环境里失衡。与 F4 `shadow_veil` / F11 `stealth` 同族，**建议并入潜行母版**（F 组合并候选 1），本稿只填参数。
- ⚠️ 依赖 C8（🔴）+ 潜行母版（**SS17**，🟡）。数值 ⚠️D。

#### 【主动】数字象征·零与一 🜄 ★
- **原著** 序列0 隐者 —— "『神秘知识』权柄：**赋予数字象征力量（0 = 混沌，1 = 造物主）**"
- **文案** 「一」是造物主，从混沌里立起秩序；「零」是混沌，把秩序推回原初。你摊开手掌，看自己更需要哪一个。
- **序列** 0 隐者 · **能量 6 / cd 8 / 吟唱 ⚠️D** · 自身条件分支
- **效果** `If(自身生命值 < 50%)` → **「一」·造物主**（0 → 1，从混沌中创造）：
  - 全体友军 `mount_status(shield, +6, duration: 4)` + `modify_stat(attack, +2, duration: 4)`
  `else` → **「零」·混沌**（1 → 0，把秩序打回混沌）：
  - 全体敌人 `dispel(category: ['buff'], count: all)` + `damage(element: none, 5)`
- **翻译/语义** **原著序列 0 最具辨识度的一条，v0.1 完全漏掉**。原著点名"0 = 混沌，1 = 造物主"，最贴的双模式卡就是"创造 vs 归零"：造物主给秩序与护佑，混沌抹掉一切既有秩序。分支条件用自身血量（濒死时自保、健康时进攻），谓词集内已有，**零新依赖**。
- **与相邻途径的分野** 通识者（完美者）的「文明」权柄是"让混沌沉淀出秩序"，与本条的「一」半边同源——这正是知识荒野双途径在「秩序/混沌」上的共同语言，已在「跨途径共享」里标注。
- ⚠️ 依赖：条件谓词 `SelfHpBelow`（**SS19**，🟡）。数值 ⚠️D：护盾 6（超"5 一档"）由传说档权重与 cd 8 兜住，需过验证脚本。

#### 【被动】备份 🜄
- **原著** 序列0 隐者 —— 下位权柄"**备份**"
- **文案** 你把自己复制了一份，存在没人找得到的地方。第一次真正死去时，那份拷贝会把你拼回来——连同你本该有的样子。
- **序列** 0 隐者 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `backup`（自身，`charges: 1`，`duration: null`）：
  - 挂载时**记录自身当前状态快照**（`status_snapshot`，**SS6**，🔴）
  - 触发器 `on_death` → 中断死亡，恢复至 25% 最大生命，`dispel(self, category: ['debuff','dot'], count: all)`，并**还原快照中的增益**（保留其剩余 duration）
  - `charges` 归零后不再触发（C6）
- **翻译/语义** 原著下位四权柄（备份 / 复制 / 删除 / 修改）里最"隐者"的一条：不是复活（那是愚者「奇迹」与灵之虫的领域），而是**从备份还原**——所以还原的是**状态**，不是生命。删除、修改已单独立卡（序列 2），「复制」的语义（复制敌人或自己的状态给别人）暂未独立立项，见「本稿遗留」。
- **与愚者【灵之虫】的差异** 灵之虫是 `on_death` → `spawn`（死后召回，4 次）；本条是**中断死亡**（不进死亡结算），且只有 1 次、附带状态还原。
- ⚠️ 依赖：状态快照/还原（**SS6**，🔴）+ 致死保护 `lethal_protect`（**与愚者稿新增项 1 同源，建议并入同一母版**，🔴）。**退化方案**：不做状态还原，只做"中断死亡 + 回到 25% 血 + 清负面"，即退化为愚者 `lethal_protect` 的一个实例，仍可用。数值 ⚠️D。

## 四、本稿遗留

- **数值全档待标**：37 个技能的能量 / 伤害 / 时长 / 层数 / 抗性均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中 `gauge.current` / `gauge_rate` 类技能（占星术 / 造风术 / 星之巨柱 / 星海穿梭 / 星桥 / 本我星象 / 预言）**仍无既有锚点**（沿用 **D2**），是本稿最大的定价风险集中区。
- **`reach: melee` 的溢价系数无锚点**：本稿按"近战 +1 伤害"量级给（格斗术 3 能量：刚 7 / 柔 3+推条 / 擒 4+位移），沿用 v0.1 遗留，需一次实测贴身承受反击 / 嘲讽的 TTK 代价。
- **元素归属**：星象 / 星光 / 信息类伤害本稿统一用 `element: none`（不再新申请元素，参照 F63 对 `lightning` 的否决结论）。若后续要给星象开独立抗性维度，需按 F63 的路径单独立项，并同步 `ResistanceMap` / `zeroResistances()`。
- **原著点名但未单独立卡的**：
  - 序列 2「同化」→ 列为【知识攻击】的 B6 变体（用 F50 `drain category:'buff'`，不再独立占槽）
  - 序列 0 下位「复制」→ 与【备份】的 `status_snapshot` 语义重叠，本稿只做了"备份（自身快照）"这一半；"复制敌人状态给自己 / 复制自身状态给全队"两个方向**未立项**，列为后续
  - 序列 1「能影响七光」→ 原著未说明七光是什么，引擎也无对应维度，仅做 flavor
  - 序列 6「卷轴极大节约施法时间」→ 已落进卷轴机制的 `silent_immune`，若 SS1 不批则该条原著描述无处安放
- **童话魔法只落地原著点名的三个**（卖火柴的小女孩 / 灰姑娘 / 朗基努斯之枪）。其余童话典故（**睡美人** = 沉睡/眩晕、**皇帝的新装** = 虚假信息/驱散增益、**小红帽** = 不可选中 + 潜伏爆发）**均为本稿推演、原著未点名**，列为后续扩展，不在本版立卡。
- **命名重叠待裁定**：本途径【预言】与阅读者（白塔）【预言】同名（原著两条途径都有"预言"），【占星术】与通识者的星象类技能概念相邻。建议汇总阶段统一加限定词（如「星占」「大预言」）。
- **【信息化】与 F4 `shadow_veil` 同族**：本稿未新立项状态语义，只填参数。是否并入 F 组合并候选 1 的潜行母版，需汇总阶段拍板。
- **C8（候选池过滤）未实现**是本稿最大的外部依赖：窥秘之眼 / 信息化 / 隐匿权柄 / 照明术 的"识破 / 不可选中"部分**当前全部不生效**。若 C8 长期不落地，这四张卡需要整体重做（改为"对隐匿目标伤害加成""受击减伤"等不依赖候选池的替代收益）。

  3. 序列 5 的「星海穿梭」「星桥」只给了名字、**没有效果描述**，本稿按字面推演（位移闪现 / 架桥调度），已在各条「原著」行标注。
  4. 序列 0 下位权柄「备份 / 复制 / 删除 / 修改」同样**只有词、无描述**，本稿按信息隐喻推演为对状态的操作。
