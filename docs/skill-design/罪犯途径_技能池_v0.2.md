> ① 逐序列比对原著能力表（序列 9→0），把漏掉的招牌全部补回；
> ② 剔除 v0.1 中凭空发明、原著无据的设计（`dark` 元素、暗影步、恶魔领域光环、鲜血领域吸血光环、污秽君王全体挂 dot）；

> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数 / 抗性 / 属性增减）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 每技能五行：**「原著」** = 原著能力依据（引用自上述对照表）；**「文案」** = 玩家视角描述，肉鸽派发展示用；**「序列」** = 序列位阶 + 触发点 / 能量消耗 / 目标规格；**「效果」** = 引擎落地表达；**「翻译/语义」** = 为什么这么映射、绑定了哪个锚点、依赖哪条框架改动。

> **三领域分工**（🜃 轴内部）：`fire` = 直伤与爆发（岩浆之剑、硫磺火球、地狱之火）；`poison` = 持续与削弱（毒火、强酸沼泽、腐蚀毒雾）；`physical` = 低费骨架与武器增伤（犯罪能力、武器上手）。**污秽**在引擎里没有独立元素，按语境分别落 `poison`（腐蚀肉体）与 `mental`（污染心灵）——序列3 及以上一律走 `mental`。
>
> **轴间协同**：🜄 的恶魔化给 🜁 的精神冲击提供"燃烧的恶魔角"增幅、给 🜃 提供攻击力与硫磺中毒；🜂 的腐蚀剥掉护甲后，🜃 的火与毒才打得动；🜁 挂上的 `lust` / `charm` 又是 🜂 的【侵蚀者】【深渊即我】的乘区前置。
>
> 技能总量 **36 个**（主动 25 / 被动 11）。罪犯途径在原著里每两个序列就换一整套机制（人 → 折翼天使 → 连环杀手 → 恶魔 → 欲望使徒 → 魔鬼 → 呓语者 → 鲜血大公 → 污秽君王 → 深渊），要"遵照原著"就必须给足覆盖；单局构筑密度由派发权重控制，池子大小不影响 4+4 槽位。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或文末「本途径框架改动」条目号）；★ = 该轴旗舰 / 高序列招牌技能；⚠️D = 数值占位待标。

### 普通（序列 9–8）

#### 【被动】强壮身体 🜄
- **原著** 序列9 罪犯 —— "**强壮身体**和敏锐直觉，身心处于恶欲统治下"
- **文案** 你的身体比看上去结实得多。战斗开始时，生命上限 +15、护甲 +2。
- **序列** 9 罪犯 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(hp_max, +15, duration: null)` + `modify_stat(armor, +2, duration: null)`
- **翻译/语义** 原著序列9 第一个词就是"强壮身体"，直译无歧义。生命上限按「30 + 10×力量」的量级取约 25% 一档（⚠️D），护甲按「5 一档」取半档偏上。这是【恶魔化】与【身体权柄】的数值地基——本途径的变身是"把本来就强壮的身体再撑大"，不是凭空加数值。⚠️D

#### 【被动】敏锐直觉 🜄
- **原著** 序列9 罪犯 —— "强壮身体和**敏锐直觉**"
- **文案** 你总比别人先半步察觉到刀锋的方向。战斗开始时，行动条速率 +6；而冲着你脑子来的东西，也伤不到你多少——精神抗性 +10%。
- **序列** 9 罪犯 · **hook** `on_battle_start`
- **效果** `modify_stat(gauge_rate, +6, duration: null)` + `modify_stat(resist:mental, +10%, duration: null)`
- **翻译/语义** 卡牌里没有隐藏信息可"直觉"，唯一能落地的维度是**节奏**：先察觉 = 先出手。**注意与 G5/G6 的边界**：G5/G6 禁的是「主动技能给自己 `gauge.current +N`」（自己回合释放时条已清零，等于没加）；本条是**被动**且改的是 `gauge_rate` 源属性，不是派生的行动周期（**INV-S5 合规**）。后半段"直觉"的防御面取精神抗性（直觉预警 → 不易被精神打击）。⚠️D（沿用 D2 待标）

#### 【主动】犯罪能力 🜁 ★
- **原著** 序列9 罪犯 —— "**掌握各种犯罪能力**，各类武器熟练上手"
- **文案** 下毒、勒颈、背后那一下——你太熟这些了。造成 4 点物理伤害，并在它身上留下三成机会补一道易于下手的破绽。
- **序列** 9 罪犯 · **能量 2 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 4)` + `{ ref: 'mount_vulnerable_2t', condition: { kind: 'chance', p: 0.3 } }`
- **翻译/语义** **本稿最重要的补漏**。v0.1 把序列9 译成了"街头犯罪 = 4 伤 + 必挂易伤"的开乘区套路，本条保留其"输出地基"定位（原著序列9 唯一明确的攻击手段就是"各种犯罪能力"），但把"必挂易伤"改成**概率附加**：概率只作用于**是否附加状态**这一非伤害维度（**R5 合规**），写法是 EffectRef 的 `condition`，**不是**不存在的 `Chance()` 算子（**G1**），需在 `RandomUsageRegistry` 登记（R3）。4 伤 / 2 能 = 2.0 汇率，高于基准 1.2，理由同愚者·飞牌、囚犯·随手物品——它要撑起整条途径的输出骨架。⚠️D
- **升级阶梯**（B6）伤害 4 → 6 → 8；或解锁「惯犯」：改为必定附加 `vulnerable` 2t，伤害降为 3。

#### 【被动】武器上手 🜃
- **原著** 序列9 罪犯 —— "掌握各种犯罪能力，**各类武器熟练上手**"
- **文案** 刀、枪、绞索、随手抄起的铁棍——到了你手里都一样趁手。整场战斗中，你造成的物理伤害提升 15%。
- **序列** 9 罪犯 · **hook** `on_battle_start`
- **效果** 挂载 `weapon_mastery`（整场）：自身造成的 `physical` 伤害 ×1.15
- **翻译/语义** "各类武器熟练上手"在引擎里没有"武器"维度，最干净的落点是**按元素过滤的伤害乘区**（只吃 `physical`）。它与【犯罪能力】是同一句原著拆出的两条：一条给手段（技能），一条给熟练度（乘区）。⚠️D
- ⚠️ 依赖"按伤害元素过滤的 `damage_mul`"（本稿新增项 15）；**与愚者途径 v0.2「本途径框架改动」第 14 项同源**（愚者是按 pathway 标签过滤，本条是按 element 过滤），建议并入同一个可过滤乘区母版。**退化方案**：改为 `modify_stat(attack, +2, duration: null)`，代价是火 / 毒也一起吃加成，失去"武器"的语义。

#### 【被动】失去良知 🜁
- **原著** 序列8 折翼天使 —— "**失去良知，与恶欲同流**"
- **文案** 你已经不记得良知是什么东西了，所以没人能用它来刺痛你。整场战斗中精神抗性 +20%；而那些被欲望与污秽沾过的人，在你眼里格外好下手——你对身上带着负面状态的目标造成的伤害提高 15%。
- **序列** 8 折翼天使 · **hook** `on_battle_start`
- **效果** 挂载 `lost_conscience`（整场）：`modify_stat(resist:mental, +20%, duration: null)` + 触发器 `on_deal_damage`（`target_has_category: ['debuff','dot']`）→ 该次伤害 ×1.15
- **翻译/语义** 原著两个半句分别落地：① 失去良知 = 不再有心理弱点 = 精神抗性（良知是心理战的抓手）；② 与恶欲同流 = 你与堕落者天然亲近 = 对已堕落者加伤。**与【精神交锋】的分界**：本条是"我不受良心谴责"（抗性 + 广谱加伤），序列4 那条是"我精于此道"（抗性 + 对本途径污染状态的定向加伤）。⚠️D
- ⚠️ `target_has_category`（✅ 新增项 20，已落 ddd：共享内核参数 §三 `has_category`）。**退化方案**（F52 枚举具体 id）仍备。

#### 【主动】迟缓 🜂
- **原著** 序列8 折翼天使 —— "**共通能力『迟缓』**"
- **文案** 你伸手按住了它的影子。它慢了下来——接下来的 3 个 tick，它连抬手都比别人慢半拍，行动条速率只剩七成五。
- **序列** 8 折翼天使 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: physical, 2)` + `mount_status(slow, duration: 3)`
- **语义** `slow`：`gauge_rate ×0.75`（**乘算，INV-S5 合规** —— 改的是源属性不是派生行动周期）、`category: ['debuff']`、`dispelable: true`。
- **翻译/语义** 原著白纸黑字把「迟缓」标为折翼天使的**共通**能力（即所有折翼天使都有，不是"因人而异"的三分支之一），所以它理应是本途径低序列最廉价的节奏工具。直伤压到 2，预算全给减速。⚠️D（推条 / 减速定价无既有锚点，沿用 D2）
- ⚠️ `slow`（✅ 新增项 11，H24 减速族纯数据——与 F7 `shackle` 同母版，本条取 0.75 且不带禁位移档）。

#### 【主动】恶魔类法术 🜃
- **原著** 序列8 折翼天使 —— "获得**恶魔类法术能力（因人而异）：毒火 / 诅咒 / 黑烟**"
- **文案** 深渊给你的那份礼物，和给别人的都不一样。你张开手——是灼人的毒火、是一句短促的诅咒、还是一团呛人的黑烟，全看你自己是谁。
- **序列** 8 折翼天使 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）· **三选一变体**
- **效果**（释放时由玩家三选一）
  - **毒火**：`damage(element: fire, 3)` + `mount_status(poison, 2t)` —— 火里带毒
  - **诅咒**：`mount_status(vulnerable, 3t)` + `damage(element: mental, 2)` —— 短促的恶毒咒言
  - **黑烟**：`mount_status(hallucination, charges: 1, duration: 2)` + `damage(element: poison, 2)` —— 呛得看不清，下一击挥空
- **翻译/语义** **原著明确写了"因人而异"**，所以三个分支不该拆成三张独立卡（那样每个玩家都会拿到全部三种，就"因人而异"不起来了），而应是**一张卡、三选一**：构筑时选定分支，或释放时临时选。这是本途径第一个"复合骨架"，也是三领域（🜃 火 / 毒）与污秽（🜂 诅咒）在低序列的第一次分野。三分支预算刻意做成等价：火偏直伤、诅咒偏乘区、黑烟偏控制，直伤都压在 2–3。
  - **黑烟分支**完全复用 **C7 已端到端验证**的 `target_override → anchor:'first_empty'`（状态 `hallucination` 与愚者途径 v0.2「制造幻觉」同名同机制，**建议直接共用**，不另立状态）。⚠️D
- ⚠️ 依赖 `SkillDef.modes`（🟡 新增项 21，**ddd 无落点，保持待拍**——可走数据层 B6 同族路径）。**退化方案**：拆成三张独立普通卡，代价是失去"因人而异"的原著语义，且普通卡池膨胀 2 张。

- **文案** 战场上所有脏的东西都认得你，也听你的。全体敌人受到 3 点毒素伤害；它们身上原本就在溃烂、灼烧、被呓语侵蚀的伤口，全都在你手里重新发酵了一遍（各叠加 1 层、持续时间刷新至 3 个 tick）；而每有一个人在你面前溃烂，你就从那股污秽里汲取 2 点生命。
- **序列** 1 污秽君王 · **能量 6 / cd 8 / 吟唱 ⚠️D** · 全体敌人
- **效果** 全体敌人 `Sequence[`
  - `damage(element: poison, 3)`,
  - `If(target_has_status: ['poison','burn','whisper'])` → 该状态 `stacks + 1` 且 `duration` 刷新至 3（**F51**）,
  - 每命中一个带 `dot` 的敌方单位 → `heal(self, 2)`（**A22**：治疗必须用 `heal` 原语）`]`
- **翻译/语义** "**掌控者**"三个字在引擎里最贴的翻译是**接管别人身上已有的污秽**——不是再挂一层新的，而是把场上所有正在溃烂的伤口重新收拢到自己手里（叠层 + 刷新），并从中汲取养分（回血）。这与"再放一个大 AOE dot"有本质区别，也是它区别于【腐蚀毒雾】的地方。**回血与 A22**：必须用 `heal` 原语，不能用 `modify_resource(hp, +N)`。⚠️D
- ⚠️ 依赖均已落：F51 `stacks`（✅ 编队上下文 §六）+ 刷新 duration 并叠层（✅ 新增项 23，§六 挂载流程含叠加——重复挂载刷新 duration、maxStacks 内叠层）+ F52（✅ §三）。**退化方案**仍备。

#### 【主动】侵蚀者 🜂 ★
- **原著** 序列1 污秽君王 —— "『**侵蚀者**』：**再坚固的壁垒持续腐蚀也会穿透**"
- **文案** 你把手贴在那面墙上。5 个 tick 内，它每时每刻都被腐蚀掉 3 点生命——**这腐蚀无视它的一切护甲、护盾与抗性**；而那面墙本身，也在一点点变薄（护甲 -2）。
- **序列** 1 污秽君王 · **能量 4 / cd 6 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `armor_desc`）
- **效果** `mount_status(erosion, duration: 5)`：
  - `modify_stat(armor, -2, duration: 5)` —— 壁垒被腐蚀变薄
  - 触发器 `on_tick` → `damage(element: poison, 3, pierce: ['armor','shield','resist'])` —— 腐蚀穿透一切防护
  - `category: ['dot','debuff']`；`dispelable: true`（**可以被驱散**——这 5 个 tick 是它的唯一弱点）
- **翻译/语义** **本途径的招牌攻坚技能，v0.1 完全没有**。原著这句话是一个**承诺**：不管多厚的甲，持续腐蚀总能穿透。引擎里最干净的表达就是 `pierce`（忽略减伤层）+ 持续多 tick。它刻意**可被驱散**：原著说的是"持续腐蚀**会**穿透"，前提是腐蚀得**持续下去**——被打断就穿透不了，这是它与"直接无视防御的一次性伤害"的分界。⚠️D
- ⚠️ 依赖均已落：`erosion`（✅ 新增项 6，H2 + H16）+ `damage.pierce`（✅ 新增项 2，效果参数 §1.1，与囚犯 21 同源同落点）。**退化方案**仍备。

#### 【主动】深渊之火 🜃 ★
- **原著** 序列1 污秽君王 —— "『**深渊之火**』：**兼具燃烧 / 腐蚀 / 毒素 / 污染**"
- **文案** 你张开嘴，吐出的火是黑色的。它烧灼（5 点火焰伤害）、它腐蚀（护甲 -2，持续 4 个 tick）、它带毒（中毒 3 个 tick）、它还污染（1 层呓语，3 个 tick）——四种恶在里头烧成一团，落在每一个人身上。
- **序列** 1 污秽君王 · **能量 7 / cd 9 / 吟唱 ⚠️D** · 全体敌人
- **效果** 全体敌人 `Sequence[`
  - `damage(element: fire, 5)`（**燃烧**）,
  - `modify_stat(armor, -2, duration: 4)`（**腐蚀**）,
  - `mount_status(poison, duration: 3)`（**毒素**）,
  - `mount_status(whisper, stacks: 1, duration: 3)`（**污染**，F16 + F51）`]`
- **翻译/语义** 原著白纸黑字列了四个词，本稿四条**全部落地**——这是三领域（🜃）轴的顶点，也是全稿唯一一张把 `fire` / `poison` / `mental` 三个元素同时打出去的卡。"兼具"二字在引擎里最贴的翻译就是**一次施放、四种载荷**，而不是"随机挑一种"。⚠️ **AOE 定价无既有锚点**，且传说档刻意超预算（派发权重极低、一局最多 1 张），超标系数上限 ⚠️D。
- ⚠️ F16 / F51（✅ H2 + H11 / StatusGrant.stacks，编队上下文 §六）。

#### 【被动】深渊即我 🜄 ★
- **原著** 序列0 深渊 —— "**『深渊即我，我即深渊』**"；下位："**腐蚀**"、"**恶意**"、**部分"毒素"**、**部分"火焰"**、部分"身体"
- **文案** 深渊不在别处，深渊就是站在这里的你。整场战斗中火焰与毒素抗性各 +30%；你施加的一切污秽与恶意，无人能洗；而凡是已经沾上污秽的东西，本来就已经在深渊里了——你对身上带着任何负面状态的目标造成的伤害提高三成。
- **序列** 0 深渊 · **hook** `on_battle_start`
- **效果** 挂载 `abyss_is_me`（整场）：
  - ① `modify_stat(resist:fire, +30%, duration: null)` + `modify_stat(resist:poison, +30%, duration: null)` —— **下位权柄：部分毒素、部分火焰**
  - ② 自身施加的 `debuff` / `dot` 类状态运行时覆写为 `dispelable: false` —— **恶意 + 污染权柄的顶点**
  - ③ 触发器 `on_deal_damage`（`target_has_category: ['debuff','dot']`）→ 该次伤害 ×1.3 —— **深渊即我：堕落者本就在深渊之中**
- **翻译/语义** 序列0 的三个部分分头落地：下位权柄（抗性与支配）、深渊即我（乘区）。第 ③ 条是"我即深渊"的语义核心——**深渊不是一个地方，是一种状态**，凡是已经堕落的东西都归你支配，所以你打它们格外狠。它同时是 🜁（恶欲）与 🜂（污秽）两轴的共同回报：你挂的每一个 debuff 都在给这一击加码。⚠️D
- ⚠️ 依赖均已落：② 覆写 `dispelable`（✅ 新增项 3，H8）；③ `target_has_category`（✅ 新增项 20，§三 `has_category`）。**退化方案**（F52 枚举 id）仍备。

#### 【主动】堕落 🜁 ★
- **原著** 序列0 深渊 —— "部分『**堕落**』权柄"
- **文案** 你把手按在它肩上，说了一句"你也一样"。6 个 tick 内，它彻底堕落了——**它的每一次攻击都落在自己身上**，它的血肉每时每刻被腐蚀 2 点（无视一切防护），而它再也不配被任何治疗拯救（受到的治疗减半）。**这份堕落不可逆。**
- **序列** 0 深渊 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `reach: melee` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(fallen, duration: 6)`：
  - `behaviorModifiers: [{ op: 'target_override', anchor: 'self' }]` —— 攻击打向自己
  - 触发器 `on_tick` → `damage(element: poison, 2, pierce: ['armor','shield','resist'])`
  - `heal_received_mul: 0.5`
  - `dispelable: false`；`category: ['control','debuff','dot']`
- **翻译/语义** **本途径的终极单点控制，v0.1 完全没有**。"堕落"权柄在卡牌里的最强表达不是"变成我方单位"（那是囚犯途径【转化】的语义，本途径不能借用），而是**让它自己毁灭自己**：打自己、烂掉、且治不好。三条载荷分别对应"堕落"的三个侧面——行为堕落 / 肉体堕落 / 灵魂堕落。
  - **与【迷幻】的分界**：迷幻是"看见不存在的东西"（打向空处，`charges` 型、可驱散、短）；堕落是"你自己就是那个东西"（打向自己，duration 型、不可驱散、6 tick）。⚠️D
- ⚠️ 依赖均已落：① `target_override → self`（✅ 新增项 4，H12 + §一 anchor `self` 在列）；② `damage.pierce`（✅ 新增项 2，H16）；③ `heal_received_mul`（✅ H21，与 F20 同字段）。
- **退化方案**：若 `self` 锚点短期无法实现，改为 `target_override → anchor: 'first_empty'`（打空）+ 加倍的自伤 dot，仍能表达"它已经废了"，但丢了"自己打自己"这一最有味道的语义。

#### 【主动】深渊之咒 🜂
- **原著** 序列0 深渊 —— "部分『**诅咒**』权柄"（序列8 恶魔类法术分支亦有"诅咒"）
- **文案** 你说出那个从深渊底下捞起来的词。5 个 tick 内，它每时每刻被啃掉 2 点精神；它的攻击与防御各被削去 2 点；而在这段时间里，**它得不到任何祝福**。
- **序列** 0 深渊 · **能量 5 / cd 7 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(abyss_curse, duration: 5)`：
  - 触发器 `on_tick` → `damage(element: mental, 2)`
  - `modify_stat(attack, -2, duration: 5)` + `modify_stat(defense, -2, duration: 5)`
  - `block_buff_gain: true`（期间无法获得任何 `buff` 类状态）
  - `category: ['debuff','dot']`；`dispelable: true`
- **翻译/语义** 序列0 明列"部分**诅咒**权柄"，本稿给它一个具体形态：一个**全能衰减**的持续性诅咒（掉血 + 削攻防 + 断增益）。它是【污秽之语·诅咒】变体与【恶魔类法术·诅咒】分支的共同上位——**这条原著主线从序列8 一路长到序列0**，三处用同一个"诅咒"语义、三种不同量级，是本途径少有的跨序列连贯设计。⚠️D
- ⚠️ `abyss_curse`（✅ 新增项 24，H2 + H38 `buffBlocked`——与 F17「禁护盾」同族，粒度由 `{ categories }` 参数控制）。

## 四、本稿遗留

- **数值全档待标**：36 个技能的能量 / 伤害 / 时长 / 层数 / 抗性 / 属性增减一律 ⚠️D，需过验证脚本重定（沿用 D4）。其中三类**定价无既有锚点**，是本稿最大盲区：① `gauge` 推拉与减速类（迟缓 / 污秽之语·缓慢 / 敏锐直觉 / 恶意感知）；② AOE 类（腐蚀毒雾 / 污秽之王 / 深渊之火）；③ 变身类（恶魔化：4 能量换 5 tick 的四项属性 + 一个触发器，无同类卡可参照）。
- ~~**复活优先级链未定**~~（✅ 2026-09-08 销项）：已落 ddd——编队上下文 §十 复活优先级链（H23）：反复活标记 > 阻止死亡（H7 `lethalProtect`）> 死后召回（C4 / G4 `reviveOf`），与本条建议的次序一致；【恶意化身】【深渊即我】与愚者 `spirit_worm` / `miracle` 同链结算。
- **`on_remove` 的到期 / 被驱散语义未分**：【欲望爆炸】写在 `on_remove` 上，若被驱散也爆炸，则这张卡变成不可拆的定时炸弹（反而更强、也更难 counter）。需引擎确认能否传入 `reason`（`'expired'` / `'dispel'`）。
- **状态内触发器的防循环规则**：【恶魔化】的 `on_deal_damage → poison`、`desire_avatar` 的 `on_deal_damage → lust` 这类"由状态触发器产生的伤害"是否会**再次**触发同一个 `on_deal_damage`（无限递归）？必须规定"由状态触发器产生的伤害不再触发同一状态的触发器"。**与囚犯途径 v0.2 遗留的 `curse_link` 防循环是同一族问题**，建议一起定。
- **变身状态共存规则**：【恶魔化】与 **F10** `beast_form`（若跨途径抽到）同时挂载时，属性是叠加还是互斥？建议"同源形态类状态互斥，后挂载者覆盖前者"，需拍板。
- **`drain` 的不等量回复**：【鲜血主宰】写 `drain(hp, 7)` 回复 5。需确认 `drain` 是否支持 `healRatio`（既有先例只有 v0.1 文档里的写法，未见代码）。若不支持，退化为"7 伤回 7"（偏强）或"5 伤回 5"（偏弱）。
- **`SkillDef.modes` 的取舍**：【恶魔类法术】【污秽之语】【呓语】三张卡用了"多选一变体"，其体感（构筑时锁定 vs 释放时临时选）未定。若 `modes` 不实现，需拆成 3+3+4 张独立卡，全稿技能数将从 36 涨到 43。
- **未完全落地的原著能力**（有意省略，记录以免漏项）：
  - 序列9「**身心处于恶欲统治下**」：只以【失去良知】的精神抗性与【恶魔化】的 `resist:mental -15%` 代价表达，未做"理智值 / 失控值"系统（引擎无对应维度）。
  - 序列7「掌握涉及恶魔的**知识**」：只以【恶魔仪式】表达"仪式"，"知识"维度（识别恶魔弱点、破除他人仪式）未落地。
  - 序列6「恶魔化」的**巨大化 3 米**：引擎无体型 / 占位维度，译为 attack + hp_max + armor 三件套；"山羊角"只作为【精神冲击】的叙事载体，未单独立机制。
  - 序列5「欲望化身」的"**影响**"：只做成 `lust` 感染，未做"黑色液体渗入地面影响环境"（引擎无环境物件维度）。
  - 序列4「**高智商**」：只以【精神交锋】的"对本途径污染状态定向加伤"表达，未做反制 / 识破类机制（避免与愚者、阅读者途径重名）。
  - 序列3「掌握**一定**污染权柄」："一定"的程度未量化，本稿取"duration +1 + 自家 `whisper` 不可驱散"两档。
  - 序列2「一滴未泯即可**重组**」：与【恶意化身】合并为一条复活，未做"自身肢体 / 血滴重组"的回位与豁免（与【身体权柄】的 `immune_stat_reduction` 部分重叠）。
  - 序列1「污秽之王：**不净物的掌控者**」：未做"操控环境污物"，只做"接管敌方已有的 dot"（引擎无环境物件维度）。
  - 序列0「**异类**」权柄：未单独立技能（与【深渊召唤】的恶魔召唤重叠），仅列入【深渊即我】的下位 flavor。
- **召唤物基线未定**：`unit_demon`（**F45**）的 `hpRatio` / `atkRatio` 需与愚者稿 `unit_marionette`、囚犯稿 `unit_ghoul` 一起定召唤物基线（F 组合并候选 7）。另 **F45 的 ID 未加 `unit_` 前缀**，建议在合并时统一。
