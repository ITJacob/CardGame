# 通识者途径（完美者）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按知识荒野系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入本系签名维度：**规律/信息（无独立量表）**——靠 **造物入规则槽**（↔失序之国）与 **信息删除**（↔光之钥，由窥秘人承载）两条跨系桥落地；
> ③ 新增 **跨系 combo 卡**（通识者造物 ↔ 失序之国规则槽 / 通识者规律 ↔ 混沌海阅读者规律）；
> ④ 补 1 张主题界域牌（文明/造物类）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《知识荒野系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类为 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

知识荒野系**无独立战场量表**——其签名是「规律/信息」。通识者以四轴**身份状态**做自包含 enabler→payoff 引擎；跨系价值通过两张 combo 卡（造物入规则槽 / 规律同源）外溢，不另立自 gauge。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **知识** | `知识`(knowledge, 自身计数) | 唤醒记忆/遗迹禁忌/仪式魔法 → 累积 `知识` | 若\[`知识`≥2\] 鉴定揭示物品、解析看穿本质、规避负面 | 鉴定师 |
| ② **造物** ★核心 | `造物`(construct, 自身计数：已产造物/在场造物) | 硝酸甘油/王水/齿轮/机械奇物/考古发掘/炼成 → 产出 `造物` | 若\[`造物`≥N\] 造物强化（注入灵魂/机械维修覆盖、灵魂熔炉回收加成） | 炼金术士 |
| ③ **星象** | `星象`(astral, 敌方/区域标记) | 虚假星象/星之祝福/星之诅咒 → 挂 `星象` | 若\[目标带 星象\] 干扰其占星、改变其重力/节律 | 天文学家 |
| ④ **规律** | `规律`(law, 友方光环) | 规律权柄/现实规律 → 挂 `规律` 改写物理法则 | 若\[`规律` 生效\] 指定元素伤害减半、看穿天使本质 | 知识导师 |

> **知识荒野系签名维度（依据《九大源质总览》§5）**：本系**无独立量表**，靠两类跨系桥获得全网价值：
> - **造物入规则槽**（↔失序之国）：通识者「造物」产出实体物件，是最该被规则槽 `Rules[3]` 约束的对象——造物一旦违规，正好落在仲裁人审判范围；律师可为其争豁免。见 §三 / 稀有档【造物入规则槽】combo 卡。
> - **信息删除**（↔光之钥）：由同系窥秘人承载，见窥秘人稿。
> 本稿另将 `知识`/`造物`/`星象`/`规律` 四状态做成enabler→payoff 自循环，使本途径在无独立量表时仍有完整构筑引擎。

## 一、技能池

图例：⚠️ = 需框架扩展（注编号或本稿新增项）；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）。

#### 【被动】唤醒记忆 🜁 知识 · **E**
- **原著** 序列9 通识者 —— "'唤醒记忆'：记起看过的所有知识"
- **文案** 你合上眼，把读过的每一页重新翻开——那些知识一直都在，只是需要被叫醒。

## 三、跨途径共享（知识荒野 + 跨系 combo）

通识者与窥秘人同属源质「知识荒野」；跨系 combo 通过 **`StatusDef.crossPathway:true`** 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 鉴定 / 仪式魔法 / 遗迹禁忌知识 / 解析权柄 | 窥秘人 | 知识域同源（同言"知识"但产出不同） |
| 虚假星象 / 星之祝福 / 星之诅咒 | 窥秘人（星象同族） | 知识荒野星象分支；窥秘人有星象师同源 |
| **造物入规则槽** | **失序之国（律师/仲裁人）** | 跨系 combo：读友方 `规则槽`/`豁免` 升级造物（枢纽 `规则槽`） |
| **规律共振**（见下，史诗增补位） | **阅读者（混沌海）** | 跨系 combo：读友方 `规律` 叠加（枢纽 `规律`） |

> **枢纽状态（落地优先级最高）**：`规则槽(Rules[3])`、`规律(law)`、`星象(astral)`、`知识(knowledge)`、`造物(construct)` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单。其中 `规则槽` 为失序之国共享棋盘，`规律`/`星象` 为跨源质同源状态。
