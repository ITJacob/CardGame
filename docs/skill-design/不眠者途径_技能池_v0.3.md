# 不眠者途径（序列0：黑暗）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入永暗之河系核心机制 **「隐秘值」战场维度**（secrecy 0–10，主消费方）；
> ③ 新增 **跨系 combo 卡**（永暗之河↔源堡 提线木偶、隐秘值联动）；
> ④ 补 1 张主题界域牌（黑夜领域）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；序列映射依据《永暗之河系技能设定》《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

> **v2 修订要点**：战士已移入永暗之河系，不眠者/收尸人/战士聚齐为「死亡·黑暗·灵体」承接组；本系是源堡系 `提线木偶 / 灵体之线 / 隐秘` 的天然宿主。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **暗夜** 🌑 | `夜幕`(nightfall, 黑暗值) | 夜视 / 夜色渐浓 → 累积 `夜幕` | 若\[夜幕≥3\] 力量/敏捷/防御提升、侵蚀敌人、黑夜领域增益 | 黑夜领域 |
| ② **梦魇** 🌙 | `灵梦`(slumber, 灵体·梦魇) | 入梦 / 塑梦 / 强制入梦 → 挂 `灵梦`(slumber) | 若\[灵梦\] 拉入梦境击溃精神 / 梦魇世界 / 恐惧灵光 | 梦魇世界 |
| ③ **安魂** 🕯 | `安宁`(pacified) | 安魂 → 挂 `安宁`(抹平欲望情绪) | 若\[安宁\] 敌灵体减速 / 灵群增伤 / 灵之统帅统御 | 灵之统帅 |
| ④ **隐秘** 🗝 ★核心·跨组 | `隐秘`(conceal, secrecy) | 隐秘化 / 无迹之影 → 挂 `隐秘` +1 战场隐秘值 | 隐秘之地封印 / 隐秘权柄显形；隐秘值维度受益 | 隐秘权柄 |

> **隐秘值维度（永暗之河系 §2.3，主消费方）**：战场级属性 0–10，独立于力/敏/智/灵/体/魅。不眠者经"隐秘化/隐秘之地/无迹之影/隐秘权柄"等 +1/次。层级（照搬总览，与源堡同源）：
> - **≥4**：场上所有 `提线木偶` 每回合 +1 层（暗夜/梦魇轴经收尸人·奴役间接受益）
> - **≥7**：友方「隐秘 / conceal / 愚弄」类技能 **+50%**
> - **=10**：触发「**源堡共鸣**」——本回合所有带 `提线木偶` 的目标可被任意友方（含跨源质）操控一次
>
> **跨源质写入方**：源堡（占卜家·愚弄/隐秘）、永暗之河（不眠者·隐秘 / 收尸人·灵体之线 / 战士·隐蔽）三方共用同一 `secrecy` 维度，不眠者是主消费方之一。

## 一、技能池

图例：⚠️ = 需框架扩展（注编号或本稿新增项）；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）。

### 普通（序列 9–8）

#### 【被动】不眠之躯 🌑 暗夜 · **E**
- **原著** 序列9 不眠者 —— "每天只需 3-4 小时休息"
- **文案** 你的身体早已习惯不眠，别人睡一整夜才攒下的精力，你在片刻的假寐里就能补回。
- **序列** 9 不眠者 · **hook** `on_battle_start`
- **效果** `modify_stat(energy_max, +5, duration: null)` + `modify_stat(energy_regen, +0.2, duration: null)`（每 tick）
- **翻译/语义** 原著"休息需求少"折为能量骨架被动（暗夜轴起手资源）。⚠️D。

#### 【被动】夜视 🌑 暗夜 · **E**
- **原著** 序列9 不眠者 —— "无需光照具备卓越视力"；"敏锐察觉黑暗里的危险"
- **文案** 黑暗于你并非阻碍——藏在暗处的身形瞒不过你，而它们自以为得手的偷袭，也总是慢了半步。
- **序列** 9 不眠者 · **hook** `on_battle_start`
- **效果** 挂载 `dark_sight`（整场）：① 敌方 `concealed` / `shadow_veil` / `stealth` 对你无效；② `on_take_damage` → `If(攻击者处于隐匿类状态)` → 该次伤害 ×0.75
- **翻译/语义** 识破隐匿（依赖 C8「识破」，与愚者【灵视】同源）。⚠️D。

#### 【被动】夜色渐浓 🌑 暗夜 · **E**
- **原著** 序列9 不眠者 —— "夜越深精力越充沛，力量/敏捷/思维超越常人"
- **文案** 夜色每浓一分，你的力量、身手与思绪便更清明一分——黎明之前，不会有人的锋芒比你更盛。
- **序列** 9 不眠者 · **hook** `on_tick`
- **效果** `mount_status(nightfall, stacks: +1, maxStacks: 5)`（整场）；每层 `attack +1` / `gauge_rate +2` / `energy_regen +0.04`
- **翻译/语义** 「越黑暗越强」主判据：暗夜轴身份状态 `夜幕` 累积源。⚠️D。

#### 【被动】午夜武艺 🌑 暗夜 · **E**
- **原著** 序列8 午夜诗人 —— "擅长格斗、射击、攀爬和感应"
- **文案** 你在午夜里练就的身手从不需要灯火照明——拳脚、准头与攀爬的本能，早已刻进骨子里。
- **序列** 8 午夜诗人 · **hook** `on_battle_start`
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(defense, +1, duration: null)`
- **翻译/语义** 暗夜轴属性地板。⚠️D。

#### 【主动】午夜诗篇·恍惚 🌙 梦魇 · **E**
- **原著** 序列8 午夜诗人 —— "用不同风格的诗篇影响生灵：使敌人精神恍惚"
- **文案** 你念起一支节拍错乱的诗——它的思绪散了，挥出的拳也失了准头。
- **序列** 8 午夜诗人 · **能量 2 / cd 2 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `damage(element: mental, 2)` + `mount_status(daze, duration: 3)`：`damage_mul: 0.8` + `modify_stat(gauge_rate, ×0.9, duration: 3)`
- **翻译/语义** 诗篇三分支之一（敌人恍惚）。⚠️D。

#### 【主动】安眠谣 🕯 安魂 · **E**
- **原著** 序列8 午夜诗人 —— "用不同风格的诗篇影响生灵：使队友安静"
- **文案** 你低声哼起一支安眠的调子——同伴急促的呼吸平复下来，身上的诅咒也松动了几分。
- **序列** 8 午夜诗人 · **能量 2 / cd 3 / 吟唱 0** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: hp_asc }`
- **效果** `heal(5)` + `dispel(target, category: ['control','debuff'], count: 1)`
- **翻译/语义** 安魂轴友军向预演（增益向），与序列6【安魂】削弱向区分。⚠️D。

#### 【主动】惊惧诗 🌙 梦魇 · **E**
- **原著** 序列8 午夜诗人 —— "用不同风格的诗篇影响生灵：使目标恐惧"
- **文案** 你吟出一行不该被听见的句子——它的瞳孔骤然收缩，握武器的手开始发抖。
- **序列** 8 午夜诗人 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `damage(element: mental, 3)` + `mount_status(dread, duration: 2)`（`modify_stat(attack, -3)` + `damage_mul: 0.8`）
- **翻译/语义** 恐惧链最下环（惊惧诗→恐惧灵光→恐惧权柄），同状态 `dread` 三级复用。⚠️D。

## 三、跨途径共享（永暗之河三途径 + 跨系 combo）

相邻（收尸人 / 战士）用 `sharedAcross`；跨系 combo 卡通过 **`StatusDef.crossPathway:true`** 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 通灵之眼 / 安魂 | 收尸人 / 战士 | 同源"看见灵体""安抚"骨架 |
| 隐秘化（concealed） / 无迹之影 | 收尸人 / 战士 | 隐秘(conceal) 组内核，白名单内 |
| 黑夜领域 | 战士 | 暗夜↔晨曦对冲，已定规则 |
| 秘偶协奏 | **占卜家（源堡）** | 跨系 combo：读取友方 `puppet_string` 升级为完全秘偶（提线木偶枢纽） |
| 隐秘共鸣 | **占卜家（源堡）** | 跨系 combo：吃共享 `secrecy` 维度，≥4/≥7 放大隐秘类 |

> **枢纽状态（落地优先级最高）**：`提线木偶(puppet_string)`、`寄生(flesh_parasite)`、`替身`、`混乱`、`恶欲值`、`命运` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单。本途径接入 **`puppet_string`（占卜家/收尸人/不眠者/囚犯）** 与 **`conceal/secrecy`（占卜家/不眠者/战士）** 两条枢纽，白名单见 §六。
