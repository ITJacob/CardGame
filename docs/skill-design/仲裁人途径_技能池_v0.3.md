# 仲裁人途径（审判者）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入失序之国系核心机制 **「规则槽 Rules[3] 共享棋盘」** + **「秩序度 Order」战场维度**（0–10）；
> ③ 新增 **跨系 combo 卡**（失序之国↔永暗之河 安魂审判 / 失序之国↔知识荒野 违规造物·审判）；
> ④ 补 3 张主题界域牌（满月 / 废止 / 底层规则）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《失序之国系技能设定》。
>
> **本版定位**：v0.2/v0.3 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。规则表达由 v0.2 的 `decree`（单体禁令）升级为**战场级公共棋盘「规则槽」**——仲裁人立规写入，律师改规读取，两途径首次共享同一可读写物件。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

| 序列 | 稀有度 | 派发权重 | 定位 |

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **辖区** | `辖区` | 展开 `zone_jurisdiction`（Ⅰ/Ⅱ/Ⅲ 档）→ 挂 `辖区` | 区域内己方加成、敌方减速；辖区档位越高惩戒越强 | **辖区** |
| ② **惩戒** | `惩戒` | 选定惩戒目标 → 挂 `惩戒` | 对该目标攻击增幅；违背规则时以必定命中姿态攻击 | **惩戒 / 审判之剑** |
| ③ **审讯** | `过目标记` | 过目不忘 / 察觉异常 → 挂 `过目标记` | 破隐匿、优先选敌、追猎标记；所有 `惩戒` 只对被标记目标生效（改后闸门） | **过目不忘 / 混乱感应** |
| ④ **律令** ★核心 | `律令（规则）` | 立规 → 写入**规则槽** | 违背触发惩戒；槽位数量决定审判强度；秩序度每立规 +1 | **立规 / 底层规则** |

> **律令轴 = 规则槽发动机**：仲裁人经「立规 / 秩序领域 / 废止」写入规则槽；敌方（或友方律师）违背 `trigger` 时自动执行 `punishment`。规则槽是失序之国两途径**唯一共享棋盘**（详见本节「本系咬合器维度」）。

### 本系咬合器维度说明（失序之国系 §2.2 / §2.3）

**① 规则槽 Rules[3]**（战场级共享棋盘，上限 3 具名规则位 `rule_a / rule_b / rule_c`）：

| 操作 | 归属 | 语义 |
|---|---|---|
| **立规** | 仲裁人 | 写入一条规则到空槽（`{trigger, punishment, exemptions:[]}`） |
| **惩戒** | 仲裁人 | 任一单位触发 `trigger` → 自动执行 `punishment` |
| **废止 / 底层规则** | 仲裁人 | 清场重写（终局态 `秩序度=10` 才可用） |

> 律师不在本稿立规，但改规（扭曲/独享规则/重定义/定义·替身）——见《律师途径 v0.3》。**本系共享棋盘优先于共享状态**（P2）。

**② 秩序度 Order（0–10，初始 5）**——战场量表，与「隐秘值」同族：

| 秩序度 | 阈值效果 |
|---|---|
| **≥7 铁序** | 所有 `律令` 惩戒伤害 +50%；律师 `扭曲/重定义` 的成功判定 −30% |
| **≤3 失序** | 所有 `混乱` 类状态持续 +1 tick；`熵蚀` 每回合自动 +1 层；仲裁人 `辖区` 区域效果 −30% |
| **=10 / =0** | 终局态：`底层规则`（仲裁人）/ `秩序崩坏`（律师）才可用的门槛 |

- 仲裁人侧：每次成功立规 +1，每次成功惩戒 +1（写入 / 执法都推高秩序度）。
- 律师侧：每次扭曲 / 利用成功 −1，`熵蚀` 每层 −0.5（压低 / 扭曲秩序度）。
- 这是本系与全局的接口：秩序度（失序之国）、隐秘值（源堡）、命运值（光之钥）构成「战场量表族」。

## 一、技能池

图例：⚠️ = 需框架扩展（注编号或本稿新增项）；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）。

### 普通（序列 9–8）

#### 【被动】信服与权威 🜁 辖区 · **E**
- **原著** 序列9 仲裁人 —— "让人信服的魅力和权威"
- **文案** 你往那儿一站，就是规矩本身——敌人面对你时难免自惭形秽，出手也软了三分。
- **序列** 9 仲裁人 · **hook** `on_battle_start`
- **效果** `modify_stat(attack, -1, duration: null)` 敌方全体（整场）+ 自身挂 `辖区(1)`（辖区轴起手标记）
- **翻译/语义** 权威=削弱对手攻击意志（非减伤）。并挂 `辖区` 身份状态让辖区轴起手。⚠️D。

#### 【主动】屈服 🜃 审讯 · **E**
- **原著** 序列9 仲裁人 —— "让冲突方不自觉想要屈服"
- **文案** 你抬眼看了它一眼，它的刀便偏了——那一击挥向了你身侧的空处。
- **序列** 9 仲裁人 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(overawed, charges:1, duration:3)`；`behaviorModifiers:[{op:'target_override', anchor:'first_empty'}]`
- **翻译/语义** "不自觉屈服"=下一次攻击打向空处（C7 已验证）。审讯轴起手标记（打空本身即"让对方放弃这一击"）。⚠️D。

#### 【主动】格斗术 🜂 惩戒
- **原著** 序列9 仲裁人 —— "出色格斗能力"
- **文案** 你近身上前，一记利落的直拳砸在它脸上——仲裁人的拳头，从来先于判决到达。
- **序列** 9 仲裁人 · **能量 3 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 5)`
- **翻译/语义** 本途径「火球术」锚点：3 能 5 伤。G8 合规（`reach: melee` 不调 move）。⚠️D。

#### 【被动】过目不忘 🜃 审讯 · **E** ★
- **原著** 序列8 治安官 —— "见过就能牢牢记住目标样子，获得额外感应"
- **文案** 你只要看过一眼，那张脸就再也抹不掉了——记住的东西，藏不起来，也逃不掉。
- **序列** 8 治安官 · **hook** `on_battle_start` + `on_spawn`（第三方监听）
- **效果** `mount_status(过目标记, duration:null)` 敌方全体（整场）：你对被标记单位伤害 +1；其隐匿/潜行/不可锁定对你无效（C8 识破）；单体技能候选池优先命中（C8 加权）
- **翻译/语义** 审讯轴旗舰 enabler：体系入口，让后续所有"针对"有根。⚠️D。

#### 【主动】辖区 🜁 辖区 · **E** ★
- **原著** 序列8 治安官 —— "『辖区』：指定区域获得超凡实力和环境帮助"
- **文案** 这里是你的辖区。踏进来的外人，寸步难行。
- **序列** 8 治安官 · **能量 3 / cd 5 / 吟唱 0** · `consumption: 'zone'` · 落点：己方半场
- **效果** `spawn_zone(zone_jurisdiction)`（Ⅰ 档，持续 6t ⚠️D）：区域内己方 `attack+2`、受伤害 ×0.9；区域内敌方 `gauge_rate×0.9`；同时 `modify_resource(order, +1)`（立主场推秩序度）
- **翻译/语义** 辖区轴核心 enabler：区域增益+干扰双向。写入秩序度 +1 接通战场量表族。⚠️D。

#### 【被动】察觉异常 🜃 审讯 · **E**
- **原著** 序列8 治安官 —— "能察觉不正常因素、邪恶混乱相关事物"
- **文案** 你总能先一步闻到不对劲——那些正在溃烂的、正在失控的，都瞒不过你。
- **序列** 8 治安官 · **hook** `on_battle_start`
- **效果** 挂载 `evil_sense`（整场）：敌方隐匿/潜行/不可锁定对你无效；你对带 `debuff/dot/control` 目标伤害 +1
- **翻译/语义** 审讯轴 enabler：被动常驻+对任何异常目标加成。与【混乱感应】差异：本条全体、被动。⚠️D。

#### 【主动】立规 🜄 律令 · **E** ★
- **原著** 序列6 法官 —— "对一定区域立下新规则，违背则受束缚"
- **文案** 你当着它的面宣判了一条规矩。它当然可以不听——但违背的代价，它付不起。
- **序列** 6 法官 · **能量 3 / cd 4 / 吟唱 0** · Manual（fallbackSort: `atk_desc`）
- **效果** `write_rule_slot(空位, {trigger:'no_skill'|'no_attack', punishment: damage(mental,3)+shackle(2t), exemptions:[]})` + `mount_status(律令（规则）, stacks:+1)` + `modify_resource(order, +1)`
- **翻译/语义** **本途径灵魂 enabler**：把 v0.2 的单体 `decree` 升级为**写入规则槽**（战场级共享棋盘）。立规同时挂 `律令（规则）` 身份状态、推秩序度 +1。律师可改此槽（见《律师 v0.3》）。⚠️ `规则槽 Rules[3]` 为新增战场物件（本稿框架改动 #1）。退化方案：单 `decree` 状态，代价失"共享棋盘"辨识度。
- **规则档位** `no_skill`（不得发动主动技能）/ `no_attack`（不得攻击）。

## 四、轴引擎 / 规则槽 / 跨系 自检

- **enabler→payoff 闭环**：辖区（挂辖区→区域增益）、惩戒（挂惩戒→×1.4）、审讯（挂过目标记→破隐匿+闸门）、律令（写规则槽→违背触发）四轴均显式成链。

- **跨系 combo（非复刻）**：【安魂审判】读收尸人 `亡灵` 升级超度，符合 P3。
