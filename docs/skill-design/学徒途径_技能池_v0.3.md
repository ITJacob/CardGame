# 学徒途径（门）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入源堡系核心机制 **「隐秘值」战场维度**（secrecy 0–10）；
> ③ 新增 **跨系 / 源堡内部 combo 卡**（源堡↔混沌海·学徒读占卜家提线 / 学徒读偷盗者误判赃物 / 学徒读秘祈人血肉寄生由对应途径落地）；
> ④ 补 1–2 张主题界域牌。
> 框架依据 `../meta/GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《源堡系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

## 〇、肉鸽化前提

| 约定 | 内容 |
|---|---|
| 槽位 | 每英雄 **4 主动 + 4 被动** |
| 派发 | 爬塔随机派发，逐步构筑 |
| 共享 | 部分技能带 `sharedAcross`，可被相邻途径（占卜家 / 偷盗者）重复抽到 |
| 稀有度 | 由序列位阶直接映射（下表） |

### 稀有度 = 序列位阶

| 序列 | 稀有度 | 派发权重 | 定位 |
|---|---|---|---|
| 9–8 | 普通 Common | 高 | 骨架，开局即可得 |
| 7–6 | 精良 Uncommon | 中 | 成型件 |
| 5–4 | 稀有 Rare | 低 | 构筑核心 |
| 3–2 | 史诗 Epic | 很低 | 大招 / 转折点 |
| 1–0 | 传说 Legendary | 极低 | 一局最多 1 张 |

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **门扉** ★核心 | `门扉`(坐标) | 开门 / 仪式·门 → 标记 `门扉` 坐标 | 若\[有门扉\] 位移 / 闪现 / 传送零耗 | 旅行家之门 |
| ② **戏法** | `戏法标记` | 闪光 / 造雾 / 冰冻 / 摔倒术 → 自身挂 `戏法标记` | 若\[戏法标记\] 行动条 +20 / 控场 | 戏法大师 |
| ③ **记录** | `记录槽` | 记录 → 存储目标技能入 `记录槽` | 若\[记录槽非空\] 重现 / 再现该技能 | 再现·改 |
| ④ **星界** | `星界锚` | 占星术 / 星相学 → 挂 `星界锚` | 若\[星界锚\] 远程摄物 / 空间隐藏 / 放逐 | 漫游者（顶点：时空迷宫） |

> **隐秘值维度（源堡系 §2.2）**：战场级属性 0–10，独立于力/敏/智/灵/体/魅。学徒经"门扉 / 星界"类效果 +1/次（开门、仪式·门、干扰占卜、星相学、门之概念、空间牢笼、无处不在、门·权柄 等）。层级：
> - **≥4**：场上所有 `提线木偶` 每回合 +1 层（源堡系共享收益；学徒经【提线接门·改】读取占卜家 `puppet_string` 同享）
> - **≥7**：友方「愚弄 / 隐秘 / conceal」类技能 **+50%**（学徒的 空间隐藏 / 幻化 / 自我符号 等 conceal 类受益）
> - **=10**：触发「**源堡共鸣**」——本回合所有带 `提线木偶` 的目标可被任意友方（含跨源质）操控一次
>
> **跨源质写入方**：占卜家（愚弄/观诡）、学徒（星界/门）、偷盗者（欺诈/寄生）、永暗之河（不眠者/收尸人/战士）、暗影世界（囚犯/罪犯）、混沌海（秘祈人）也写入同一 `secrecy` 维度。

## 一、技能池

图例：⚠️ = 需框架扩展（注编号或本稿新增项）；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）。

### 普通（序列 9–8）

#### 【主动】开门 🜁 开门 · **E**
- **原著** 序列9 学徒 —— "「开门」：穿墙而过，手掌按住墙壁出现幽蓝大门"
- **文案** 你按住虚空，一道幽蓝的门扉在墙上浮现——你穿门而过，出现在战场的另一处，门扉闭合时的气流掀动了近旁的敌人。
- **序列** 9 学徒 · **能量 2 / cd 3 / 吟唱 瞬发**
- **效果** `move(param→己方半场内指定空位)`（自身，**G8 合规**）+ `damage(element:physical, 2)` 对 `{faction:ENEMY, anchor:front_line}` + `mount_status(door_coord, stacks:+1)`（标记门扉坐标）+ `modify_resource(secrecy,+1)`（门扉写入隐秘值）
- **翻译/语义** 门扉轴 enabler：穿门位移的同时挂 `门扉(坐标)` 状态，供后续传送零耗 payoff 读取；并写入 +1 隐秘值（源堡系 §2.2 学徒门扉写入方）。落点用空位锚点表达，不越中线。数值 ⚠️D。

#### 【被动】仪式·门 🜁 开门 · **E**
- **原著** 序列9 学徒 —— "能使用仪式魔法"
- **文案** 开战前你便布下了一道仪式——三息之后，那道门会在敌阵前方自行洞开。
- **序列** 9 学徒 · **hook** `on_battle_start`
- **效果** `mount_status(ritual_gate, duration:4)`；触发器 `on_remove`→`damage(element:none, 4)` 对 `{faction:ENEMY, anchor:front_line}`；同时在门扉坐标集追加 1 个 `door_coord` 标记 + `modify_resource(secrecy,+1)`
- **翻译/语义** 延时生效的仪式魔法，先布置后爆发；落点门扉坐标供门扉轴 payoff 使用，并写入隐秘值。数值 ⚠️D。

#### 【主动】戏法·闪光 🜂 戏法 · **E**
- **原著** 序列8 戏法大师 —— "掌握各种奇怪法术：闪光、黑幕、转移气体、巨响、冰冻、电击、造雾、刮风、点火、摔倒术、驱物、逃脱戏法"
- **文案** 一道刺目的强光在它眼前炸开，紧接着是一声贯耳的巨响——它挥出的下一击，砍在了空处。
- **序列** 8 戏法大师 · **能量 2 / cd 3 / 吟唱 瞬发**
- **效果** `mount_status(flash, charges:1, duration:3)`（`behaviorModifiers:[{op:'target_override', anchor:'first_empty'}]`，C7 ✅）+ `modify_resource(gauge.current,-20)` + 自身 `mount_status(trick_mark, stacks:+1)`（戏法标记 enabler）
- **翻译/语义** 闪光=致盲(打空)+巨响=推条；同时自身挂 `戏法标记` 供戏法轴 payoff 读取。复用 C7 已验证。⚠️D。

#### 【主动】戏法·三元素 🜂 戏法 · **E**
- **原著** 序列8 戏法大师 —— "…冰冻、电击、…点火…"
- **文案** 你打出一串细碎的手势——一点火苗、一层白霜、一缕电光，接连落在它身上。
- **序列** 8 戏法大师 · **能量 3 / cd 3 / 吟唱 瞬发**
- **效果** `Sequence[ damage(element:fire,2), damage(element:ice,2), damage(element:lightning,2) ]` + 自身 `mount_status(trick_mark, stacks:+1)`
- **翻译/语义** 点火/冰冻/电击合成"三元素连击"，挂 `戏法标记`。三段独立结算吃三次护甲。⚠️D。

#### 【主动】戏法·摔倒术 🜂 戏法 · **E**
- **原著** 序列8 戏法大师 —— "…刮风、…摔倒术、驱物…"
- **文案** 它脚下一绊莫名踉跄，你顺手卷起一阵风，把它推得更远。
- **序列** 8 戏法大师 · **能量 2 / cd 3 / 吟唱 瞬发**
- **效果** `damage(element:physical,2)` + `move(push_back)`（目标在自己队列内后移 1 格，C1 ✅）+ 自身 `mount_status(trick_mark, stacks:+1)`
- **翻译/语义** 摔倒+刮风+驱物=推挤；挂 `戏法标记`。与【无形之手】构成门扉轴调度对。⚠️D。

#### 【被动】逃脱戏法 🜁 开门 · **P ★**
- **原著** 序列8 戏法大师 —— 一整套奇术法师的戏法体系（闪光/造雾/冰冻/摔倒术…）
- **文案** 你把所有小花招揉成了一套章法——每一个标记的戏法，都让下一次出手快上半拍。
- **序列** 8 戏法大师 · **hook** `on_battle_start`
- **效果** 挂载 `trick_master`（整场）：每当你拥有 `戏法标记`≥1，你的主动技能 `modify_resource(gauge.current,+20)` 前置加成（行动条 +20）；`戏法标记` 每存在 1 层，本场你施加的 control 类状态 `duration+1`
- **翻译/语义** 戏法轴旗舰 payoff：把零散 `戏法标记` 收束为"行动条 +20 / 控制延长"。⚠️ 依赖 G5/G6 自检（被动整场型，非自推条）。数值 ⚠️D。

## 四、轴引擎 / 隐秘值 / 跨系 自检
