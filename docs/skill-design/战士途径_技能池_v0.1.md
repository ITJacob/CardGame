# 战士途径 · 技能池 v0.1

灵感源：ima 知识库《诡秘之主-途径数据》→ 战士途径（aka 黄昏巨人途径，源质「永暗之河」，相邻途径=不眠者、收尸人）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5，并已核对 `src/catalog/model.ts` 的实际 schema。

> 本稿是**设计约定**，不是终稿数值。所有数值标注了推导依据，最终需过验证脚本（见改动记录 D 组）。
> 「文案」为玩家视角的效果描述，用于肉鸽派发时展示；「效果」为引擎落地表达。
> 翻译基调：战士是「直伤 / 坦克 / 守护」型，**最贴合现有九原语**（`damage` / `mount_status(护盾/坚守/守护)` / `heal` / `drain`）。优先复用既有状态，少发明新状态；「守护领域」借「守护 + 护盾 + 坚守」组合表达，不新造状态。序列 0/1 位格碾压 → 只做高费大招或 flavor。

## 〇、肉鸽化前提（本版新增的设计约束）

| 约定 | 内容 |
|---|---|
| 槽位 | 每英雄 **4 主动 + 4 被动** |
| 派发 | 爬塔随机派发，逐步构筑 |
| 共享 | 部分技能带 `sharedAcross`，可被相邻途径（不眠者/收尸人）的职业重复抽到 |
| 稀有度 | 由序列位阶直接映射（见下表） |

### 稀有度 = 序列位阶（自然映射，无需另设维度）

| 序列 | 稀有度 | 派发权重 | 定位 |
|---|---|---|---|
| 9–8 | 普通 Common | 高 | 骨架，开局即可得 |
| 7–6 | 精良 Uncommon | 中 | 成型件 |
| 5–4 | 稀有 Rare | 低 | 构筑核心 |
| 3–2 | 史诗 Epic | 很低 | 大招 / 转折点 |
| 1–0 | 传说 Legendary | 极低 | 一局最多 1 张 |

### 四条构筑轴（肉鸽要保证技能能成体系，不能是散装）

| 轴 | 关键词 | 玩法 |
|---|---|---|
| ⚔ **近战猛攻** | 力量 / 直伤 | 贴脸高费直伤，近战高效，处决与爆发 |
| 🗡 **兵器精通** | 武器 / 多段 | 感知武器特性，多段打击，削甲与克制 |
| 🛡 **守护壁垒** | 护盾 / 坚守 / 替伤 | 吸收、减伤（乘区）、替友军挡，磨血不死 |
| ☀ **圣洁裁决** | 圣光 / 易伤 / 净化 | 神圣伤害、挂易伤乘区、驱散增益、治疗续航 |

> 四轴覆盖 10 序列：9–7 偏近战/兵器，6–5 偏守护，4–3 偏猎魔/圣裁，2–0 偏战斗领域与终极权柄。

## 一、技能池

图例：⚠️ = 需要框架扩展（已登记改动记录或待立项）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【主动】猛击 ⚔
- **文案** 抡起拳头或兵刃，一记结实的近身重击砸在敌人脸上。
- **序列** 9 战士 · **能量 2 / cd 2** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `damage 4 (physical)`
- **推导/语义** 近战高效：基准 2 能量↔2.4 伤，取 4（每能 2.0）体现「体能、力量大幅增强」。高于火球术锚点(3能5伤=1.67/能)下限，属近战专精溢价，数值待标（D 组）。

#### 【被动】强健体魄 🛡
- **文案** 如同铁铸的身躯，战斗开始时你的最大生命永久提升。
- **序列** 9 战士 · **hook** `on_battle_start`（⚠️ A1 新增触发点）
- **效果** `modify_stat(max_hp, +20, duration: null)`
- **推导/语义** 生命锚点 `30 + 10×力量`，+20 HP ≈ +2 力量等价；力量3 时(60血)≈+33% 最大生命。用**固定值**提升，非百分比杠杆（D3 后防御不再写 ±1=∓X%）。

#### 【主动】精准突刺 🗡
- **文案** 一记精准的突刺，直取要害，干净利落。
- **序列** 8 格斗家 · **能量 2 / cd 2** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `damage 3 (physical)`
- **推导/语义** 2 能量↔2.4 基准，取 3，单段精准打击，兵器轴基线。"掌握格斗技巧与搏击术" → 稳定的单体物理输出。

#### 【主动】格挡架势 🛡
- **文案** 举盾横在身前，短促的格挡为你挡下即将到来的伤害。
- **序列** 8 格斗家 · **能量 1 / cd 2** · `targetSpec: SELF`
- **效果** `mount_status(shield, +5, 3t)`
- **推导/语义** 护盾吸收伤害（既有状态）。护甲 5 一档等价吸收量；1 能量极低门槛，是守护轴的润滑剂。"强健体魄与近身格斗" → 防御姿态。

#### 【主动】圣光拂拭 ☀
- **文案** 一缕温和的圣光拂过伤口，为你疗愈些许。
- **序列** 8 格斗家 · **能量 1 / cd 3** · `targetSpec: SELF`
- **效果** `heal 3`
- **推导/语义** 1 能量↔1.2 基准，取 3 偏低但治疗自带生存价值，圣洁轴入门。用 `heal` 原语（A22 裁定：治疗必须用 `heal` 而非 `modify_resource`）。

### 精良（序列 7–6）

#### 【主动】武器共鸣 🗡 ★
- **文案** 你与手中的武器心意相通，三连斩将敌人劈得节节后退，自身也因「感知特性」而更稳。
- **序列** 7 武器大师 · **能量 3 / cd 3** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `TermRef(repeat, body:[damage 2 (physical)], count:3)` + `modify_resource(armor, +2, delta)`（自身）
- **推导/语义** 兵器轴旗舰。"精通各类武器、将威力发挥至极致" → 多段打击（3×2=6）。3 能量/6 伤=2.0，略超基准但多段只触发一次受击/反击、只撞一次（B8 裁定），且附 +2 护甲（≈0.4 档）。Repeat 算子落地（A17 后首个实战之一）。

#### 【主动】破甲重击 ⚔
- **文案** 蓄力一击狠狠砸碎对手的护甲，让他再扛不住接下来的痛。
- **序列** 7 武器大师 · **能量 3 / cd 3** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `damage 4 (physical)` + `modify_resource(armor, -3, delta)`（目标）
- **推导/语义** 4 直伤 + 削甲 3（护甲 5 一档≈0.6 档削弱）。近战破防，为后续输出铺路；用固定值改护甲，非百分比杠杆。

#### 【被动】狂战之血 ⚔
- **文案** 受伤反而让你更亢奋，被击中的瞬间反弹出一阵血性反伤。
- **序列** 7 武器大师 · **hook** `on_take_damage`
- **效果** `mount_status(反伤, 2t)`
- **推导/语义** 反伤为既有状态（受击反弹）。"强健体魄与近身战斗" → 换血型近战。反伤数值沿用既有定义。

#### 【主动】守护壁垒 🛡
- **文案** 你架起一面光盾，护住身旁的一名同伴。
- **序列** 6 黎明骑士 · **能量 2 / cd 3** · `targetSpec: ALLY`
- **效果** `mount_status(shield, +6, 3t)`（目标友军）
- **推导/语义** 护盾 6 ≈ 1.2 档。2 能量给队友，守护轴成型件。"掌握光明与守护之力" → 守护他人。

#### 【主动】黎明之辉 ☀
- **文案** 黎明的光辉洒落，治愈同伴的伤痕。
- **序列** 6 黎明骑士 · **能量 3 / cd 4** · `targetSpec: SELF_OR_ALLY`
- **效果** `heal 6`
- **推导/语义** 3 能量↔3.6 基准，取 6（每能 2）偏高因治疗即时且不可驱散（参照 `regen` 总回 12 但可驱散）。光明=治疗，直接 `heal` 原语。

#### 【被动】圣光庇佑 ☀
- **文案** 圣光自你降临起便笼罩周身，开局便镀上一层薄盾。
- **序列** 6 黎明骑士 · **hook** `on_battle_start`（⚠️ A1）
- **效果** `mount_status(shield, +3, 3t)`（自身）
- **推导/语义** 开局 3 护盾 ≈ 0.6 档。圣洁被动，借 `on_battle_start` 表达"开局"（⚠️ A1，全稿统一引用，不重复立项）。

### 稀有（序列 5–4）

#### 【主动】守护领域 🛡 ★
- **文案** 你张开骑士的守护领域，为全体同伴镀上护盾，自身更立于坚不可摧的坚守之中。
- **序列** 5 守护者 · **能量 3 / cd 4** · `targetSpec: ALL_ALLIES`
- **效果** 全体友军 `mount_status(shield, +4, 3t)` + 自身 `mount_status(坚守, 3t)`
- **推导/语义** 守护轴旗舰。"展开守护领域，在领域内保护他人" → 群体护盾 4（≈0.8 档）+ 自身 `坚守`（`damage_taken_mul: 0.7`，固定乘区，非百分比杠杆）。**借「护盾 + 坚守」组合表达"领域"，不新造状态**。⚠️ `targetSpec: ALL_ALLIES`（全体友军）需确认引擎支持——现有多单/SELF_OR_ALLY，待立项。

#### 【主动】致死打击 ⚔
- **文案** 看准破绽的致命一击，几乎要将敌人当场劈碎。
- **序列** 4 猎魔者 · **能量 4 / cd 4** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `damage 8 (physical)`
- **推导/语义** 4 能量↔4.8 基准，取 8（每能 2）= 处决级直伤，体现猎魔者"猎杀"语义。若后续要加法处决，`If(目标生命 < 50%)` 算子可展开，先控预算做单发 8。

#### 【主动】猎魔标记 🗡
- **文案** 你为猎物刻下猎魔标记，使它受到的伤害加剧，并补上一记重击。
- **序列** 4 猎魔者 · **能量 3 / cd 3** · `reach: ranged` · `targetSpec: ENEMY`
- **效果** `mount_status(vulnerable, 4t)` + `damage 2 (physical)`
- **推导/语义** "克制异类"在引擎无怪物类型，翻译成 `vulnerable`（×1.3 乘区，A14 裁定）。2 直伤压低因核心在 debuff：挂易伤乘区让后续所有伤害 +30%。

#### 【主动】驱邪 ☀
- **文案** 神圣之力驱散敌人身上被污染的增益，并灼以圣焰。
- **序列** 4 猎魔者 · **能量 3 / cd 4** · `reach: ranged` · `targetSpec: ENEMY`
- **效果** `dispel(unit, dispelable:true, category:'buff', count:1)` + `damage 3 (holy)`
- **推导/语义** "净化/克制" → `dispel` 敌方增益 + 3 圣伤。复用 `dispel`（C2 数组扩展待登记，此处单 buff 可接受）。

#### 【被动】浴血 ⚔
- **文案** 你越战越勇，每一击都从敌人身上汲取鲜血反哺自身。
- **序列** 5 守护者 · **hook** `on_deal_damage`
- **效果** `drain 1`（自身）
- **推导/语义** 吸血 1，近战续航。`drain` 原语直接承载，零新机制，最干净的映射。

### 史诗（序列 3–2）

#### 【主动】银色裁决 ☀ ★
- **文案** 银色的圣光化作裁决之剑，劈下时令目标破绽尽露。
- **序列** 3 银骑士 · **能量 4 / cd 5** · `reach: ranged` · `targetSpec: ENEMY`
- **效果** `damage 6 (holy)` + `mount_status(vulnerable, 3t)`
- **推导/语义** 圣洁裁决轴旗舰。"掌握圣洁与裁决之力" → 6 圣伤（每能 1.5）+ 易伤乘区（×1.3），神圣领域能力的浓缩表达。

#### 【被动】神圣守护 🛡
- **文案** 同伴受袭时，你身上的神圣守护会替他挡下这一击。
- **序列** 3 银骑士 · **hook** `on_take_damage`（友军受击触发）
- **效果** `mount_status(守护)`（自身，替友军挡）
- **推导/语义** "神圣领域保护他人" → 复用既有 `守护` 状态（替友军挡），与 `坚守` 组合成完整守护链。⚠️ 需确认 `守护` 状态的触发实现（替友军挡的具体规则）。

#### 【主动】荣耀冲锋 ⚔
- **文案** 你踏着荣耀的步法突进猛击，一记重撞将敌人砸退（冲锋为 flavor，不越中线、不改站位）。
- **序列** 2 荣耀者 · **能量 4 / cd 5** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `damage 5 (physical)`
- **推导/语义** 「突进/冲锋」仅为 flavor 近战攻击进程（不调站位、不越中线，遵循 G8 铁律），故直伤压到 5；原 `move.op: param` 落点会越中线，已移除。

#### 【主动】万械归一 🗡
- **文案** 你将周身万械之力倾泻于一击，连绵不绝的兵刃风暴撕裂目标。
- **序列** 2 荣耀者 · **能量 5 / cd 6** · `reach: melee` · `targetSpec: ENEMY`
- **效果** `TermRef(repeat, body:[damage 2 (physical)], count:4)`
- **推导/语义** 兵器轴大招：4×2=8 / 5 能 = 1.6，略低于基准，溢价在多段（只触发一次受击/反击，B8）。"战斗领域权柄" → 武器之力的极致。

#### 【主动】神圣干涉 ☀
- **文案** 圣光降下干涉，既治愈同伴，又为其罩上护盾。
- **序列** 3 银骑士 · **能量 3 / cd 4** · `targetSpec: ALLY`
- **效果** `heal 8` + `mount_status(shield, +4, 3t)`（目标友军）
- **推导/语义** 瞬发 8 治疗（不可驱散，A22 / INV-D5）+ 4 护盾。圣光干预，即时救场。

## 三、跨途径共享（永暗之河三途径）

战士与「不眠者」「收尸人」同属源质永暗之河相邻途径，共享技能用 `sharedAcross` 声明：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 强健体魄 / 格挡架势 / 守护壁垒 / 守护领域 | 不眠者、收尸人 | 防御/生存是永暗之河相邻途径的通用需求，临近途径同源质，护盾/坚守互通 |
| 破甲重击 / 精准突刺 | 不眠者 | 不眠者亦重近身战斗与武器，削甲/精准打击可直接复用 |
| 黎明之辉 / 圣光拂拭 | 收尸人 | 收尸人通灵复活线需要治疗续航，圣光治疗可互通 |
