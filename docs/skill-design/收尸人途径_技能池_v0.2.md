> **本稿主轴：死亡的三种形态**。原著里「死亡」在本途径不是一个动作，而是三层递进——
> **① 侵蚀**（死神使者 / 左手触碰：把血条往下推）→ **② 处决**（摆渡·对视 / 死亡宣告 / 死亡之国：越过阈值就带走）→ **③ 收编**（唤起亡者 / 死亡之国 / 灵魂掌控：死了的东西归我）。
> 三层由【一切的归宿】的阈值乘区串成一条链：越残血推得越快，越快越过阈值，越过后变成我的兵。这是本途径区别于其他"召唤流"的唯一辨识度。
>
> 技能总量 **34 个**（主动 20 / 被动 14，v0.1 为 24 个）。收尸人途径十个序列里，序列 5 / 4 / 3 / 2 / 1 / 0 各有 2–3 个原著明写的独立招牌（冥界、不死者、摆渡、死亡执政官、苍白皇帝、五大权柄），要"遵照原著"就必须给足覆盖；单局构筑密度由派发权重控制，池子大小不影响 4+4 槽位。

### 普通（序列 9–8）

#### 【被动】尸体特质 🜂
- **原著** 序列9 收尸人 —— "具备尸体特质，体温低，**避免亡灵袭击** / **能承受腐烂、寒冷、死亡气息**"
- **文案** 你的体温比尸体高不了多少，腐烂与寒冷都伤不到你；而那些游荡的亡灵，也从不把你当成活人。
- **序列** 9 收尸人 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `corpse_nature`（整场）：`modify_stat(resist:poison, +20, duration: null)` + `modify_stat(resist:ice, +20, duration: null)` + 受到来源为 `unitType: UNDEAD` 单位的伤害 ×0.7
- **翻译/语义** 原著三条一比一落地：体温低 / 承受寒冷 = 抗 `ice`；承受腐烂 = 抗 `poison`；"避免亡灵袭击" = 对**亡灵来源**伤害减免。抗性走 `resist:<元素>` StatKey（已存在，仅需数据）。"死亡气息"沿用 poison/ice 两条承载，不另设维度。**v0.1 的对应物是"尸嗅"回能**——原著序列9 没有任何"从尸体获取能量"的表述，本版删除。
- ⚠️ 第三条依赖 `unitType: UNDEAD` 判定（✅ 已落 ddd：编队参数 §1.2b 单位类型标签体系，与不眠者同源并入同一母版，本稿不另立）。数值 ⚠️D。

#### 【被动】天然灵视 🜁
- **原著** 序列9 收尸人 —— "**天然灵视，看见部分恶灵**"
- **文案** 你天生能看见那些本不该被看见的东西——藏起来的身形瞒不过你，飘在半空的恶灵更瞒不过你。
- **序列** 9 收尸人 · **hook** `on_battle_start`
- **效果** 挂载 `spirit_sight`（整场）：① 敌方 `concealed` / `shadow_veil` / `stealth` 类状态**对你无效**；② 你对 `unitType: SPIRIT` 单位造成的伤害 ×1.3
- **翻译/语义** 原著"看见部分恶灵" = 识破不可见之物。卡牌里对应两件事：识破隐匿（依赖 C8 的「识破」分支，与愚者【灵视】【灵体之线】、不眠者【夜视】三稿同源）与对灵体特化。注意"**部分**"是原著的限定 —— 故只给 `SPIRIT`，不给 `UNDEAD`（骷髅行尸没有灵，原著说的是"恶灵"）。
- ⚠️ 依赖 C8（🟢 已登记未实现）+ `unitType` 判定（同源不另立）。⚠️D

#### 【主动】腐息 🜂
- **原著** 序列9 收尸人 —— "具备尸体特质……能承受**腐烂**……气息"（主动化引申：你自己即是腐烂的来源）
- **文案** 你张口吐出一口尸腐之气——它躲不开，也吐不掉。
- **序列** 9 收尸人 · **能量 2 / cd 2 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: poison, 2)` + `mount_status(中毒, duration: 2)`（既有 dot，穿透护甲）
- **翻译/语义** **本稿唯一的推断项**。对照表给序列9 的只有特质与感知，**没有任何攻击手段**，但卡牌需要一条低费输出地基（同愚者稿为序列8 补【飞牌】的处理）。取"腐烂气息"主动化，元素 `poison` 与【尸体特质】的抗性同源，形成"我抗腐、我放腐"的闭环。已在「四、本稿遗留」登记为推断项，若汇总阶段认定越界可整条删除。⚠️D

#### 【被动】掘墓人体魄 🜂
- **原著** 序列8 掘墓人 —— "**体魄更强壮**"
- **文案** 整日挥铲掘土练就的身板，比看上去结实得多。
- **序列** 8 掘墓人 · **hook** `on_battle_start`
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(defense, +1, duration: null)` + `modify_stat(hp_max, +8, duration: null)`
- **翻译/语义** 原著白纸黑字的身体素养，直接落成常量。这是本途径的属性地板，让低序列也有站场能力。攻防按单卡纪律 ±1~±2；`hp_max` 是"体魄"的第三落点（brief：生命上限 = 30 + 10×力量，+8 ≈ 力量3 时 13%）。
- **升级阶梯**（B6）+1 / +1 / +4。⚠️D

#### 【主动】死亡之眼 🜁 ★
- **原著** 序列8 掘墓人 —— "'死亡之眼'：**进入灵性世界，从更高层次俯视敌人找弱点**"；"灵视更厉害"
- **文案** 你的魂魄离体半寸，从灵性世界里俯下身——它的要害、它的破绽，一下子全浮了出来。
- **序列** 8 掘墓人 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `Sequence[` `damage(element: mental, 3)`（进入灵性世界）, `mount_status(vulnerable, duration: 3)`（**找弱点**：既有状态 `damage_taken_mul: 1.3`）, `dispel(target, category: ['conceal'], count: 1)`（**俯视**） `]`
  附加：若目标处于隐匿类状态，本次伤害 ×1.5
- **翻译/语义** **原著招牌能力，v0.1 完全漏掉**。原著三个动作都落地：进入灵性世界 = 精神属性伤害；找弱点 = `易伤`；俯视 = 破隐匿。"灵视更厉害"与序列9【天然灵视】是同一能力的进阶，两者共用 `spirit_sight` 族群（本卡是序列9 那条的应用端）。
- ⚠️ 依赖 `dispel` 的 `'conceal'` category（✅ 已落 ddd：H40 StatusCategory 增补，与不眠者同源）+ C8（✅ 共享内核参数 §四 + H5）+ `Sequence`（✅ G3，编目参数 §一，运行时已确认展开）。⚠️D

#### 【主动】灵之耳语 🜁
- **原著** 序列8 掘墓人 —— "能**初步沟通**附近少量灵"
- **文案** 你向附近的游灵低声问了句话——它凑到你耳边，把即将落下的那一击提前告诉了你。

### 精良（序列 7–6）

#### 【主动】通灵 🜃 ★
- **原著** 序列7 通灵者 —— "'通灵'（核心）：**直接与自然灵和亡魂沟通，借灵实现魔法**"
- **文案** 你向着空处开口，一缕亡魂应声而来——它替你把这道咒文推了出去，然后留在了这里。
- **序列** 7 通灵者 · **能量 4 / cd 5 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）

- **翻译/语义** **本途径的核心机制，也是亡者轴旗舰**。原著"通灵"有两个宾语（自然灵 **和** 亡魂）与两个动作（沟通 / 借灵实现魔法），本卡一次落地：借灵实现魔法 = 一张即时法术；沟通 = 灵留下成为召唤物。这是本途径召唤体系的源头，序列6 的【唤起骷髅】【唤起活尸】都由它分蘖。
- ⚠️ `unit_wraith`（**F25**，✅ 已落 H1 召唤物基线）与不眠者稿的 **ID 冲突已裁决**（brief §7 F25 行：`unit_wraith` 归收尸人亡灵线，不眠者自然灵另立 `unit_nature_spirit`）。按裁决口径：hp 16 / atk 4，`unitType: UNDEAD`。⚠️D

#### 【被动】灵之同类 🜃
- **原著** 序列7 通灵者 —— "**对亡魂、自然灵而言像同类，危险性低**"
- **文案** 在它们眼里，你闻起来和它们是一路的——亡魂不会先扑向你，自然灵也不会。
- **序列** 7 通灵者 · **hook** `on_battle_start`
- **效果** 挂载 `kin_of_spirits`（整场）：① 你受到来源为 `unitType: SPIRIT / UNDEAD` 单位的伤害 ×0.7；② 敌方 `SPIRIT / UNDEAD` 单位选择攻击目标时，**你的优先级权重最低**（嘲讽 / 守护仍可覆盖）
- **翻译/语义** 原著写的是"危险性低"——**是对方对你的危险感知低，不是你的防御力高**，所以落点必须是"来源类型过滤"，不能写成通用减伤（v0.1 的"地下感知"就是无来源的通用护甲，本版删除）。第②条是"不会被优先攻击"语义，依赖 C8 的候选池**加权**分支（不是排除 —— 排除会变成不可选中，过强）。
- ⚠️ 依赖 `unitType`（同源不另立）+ C8 加权分支（🟢 未实现）。若只落地一条，优先保留①。**叠乘风险见「四、本稿遗留」**。⚠️D

- **文案** 你在地上画完最后一笔，站进圈里的亡者们同时抬起了头。

### 史诗（序列 3–2）

#### 【主动】摆渡·对视 🜄 ★
- **原著** 序列3 摆渡人 —— "**死亡权柄：与其对视的生灵直接死亡，神性者遭受重创**"
- **文案** 你抬起眼，与它对上了目光——它僵在那里，然后倒了下去。而那些更强一些的，只是踉跄着退开，身上多了一道深可见骨的口子。
- **序列** 3 摆渡人 · **能量 5 / cd 6 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `hp_asc`）
- **效果** `If(target_hp_percent ≤ 0.25)` → `then: execute`（直接致死）
  `else:` `Sequence[ damage(element: none, 6)`, `mount_status(vulnerable, duration: 3)` `]`
- **翻译/语义** **本途径最锋利的招牌，也是全稿最重要的一次平衡取舍**。原著写的是"**直接死亡**，**神性者遭受重创**"——请注意原著自己就给了分岔：**不够强大的直接死，足够强大的（神性者）只受重创**。所以"条件处决"不是妥协，而是原著原文的一比一落地：阈值 = "是否神性者"的可判定替身。卡牌里无条件即死会破坏平衡（一张 5 费牌换掉任何单位），阈值处决则把它变成一张**收割牌**：先用 dot / 亡语把它磨到 25% 以下，再用对视收掉——这正是本途径"死亡三层递进"的第二层。
- ⚠️ 依赖 `execute`（✅ 新增项 1，已落 ddd：效果参数 §1.1 `damage.lethal`）+ 条件谓词 `target_hp_percent`（✅ 新增项 2，共享内核参数 §三 `hp_percent`）。**退化方案**：`damage(element: none, 9999)` 走正常伤害结算——会被护甲 / 减伤 / `lethal_protect` 拦截，其实是可接受的平衡口径。⚠️D

#### 【主动】左手触碰 🜄
- **原著** 序列3 摆渡人 —— "**左手触碰：目标几乎不可逆地走向死亡**"
- **文案** 你的左手按在它肩上——从这一刻起，它已经在往下走了，而且没有什么能让它停下来。
- **序列** 3 摆渡人 · **能量 4 / cd 5 / 吟唱 ⚠️D** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(doomed, duration: 8)`：`dispelable: false`（**不可逆**）+ `on_tick → damage(element: none, 2)` + `heal_received_mul: 0.5`（治愈也拉不回来）+ `damage_taken_mul: 1.15`
- **翻译/语义** 原著"**几乎**不可逆"三个字是本卡的命门：它必须**不可被 `dispel` 驱散**（否则任何一张净化牌就废掉了整条终末轴），同时必须留一个后门——那就是【右手触碰】。所以本稿把 `doomed` 设为 `dispelable: false`，并规定**只能由【右手触碰】按状态 ID 精确解除**，两张卡互为唯一的钥匙与锁。8 tick × 2 无属性伤 ≈ 16 点，是本途径最重的单体输出，也是把对手推进【摆渡·对视】阈值的主力。
- ⚠️ 依赖：① 新状态 `doomed`（✅ 新增项 6，纯数据 H2 母版）；② `dispel` 按 **statusId** 过滤（✅ 新增项 12，效果参数 §一 dispel.filter）；③ `heal_received_mul`（✅ H21，与 F20 `petrify` 同型）。⚠️D

#### 【主动】右手触碰 🜂
- **原著** 序列3 摆渡人 —— "**右手触碰：解除此状态**"
- **文案** 你的右手覆上去，那道正在往深处走的痕迹停住了——它喘过一口气，活了回来。
- **序列** 3 摆渡人 · **能量 3 / cd 4 / 吟唱 ⚠️D** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: hp_asc }`
- **效果** `dispel(target, statusId: ['doomed'], count: all)` + `dispel(target, category: ['dot','debuff'], count: 1)`（**C2** ✅）+ `heal(6)`（**A22**）
- **翻译/语义** 原著给右手触碰的宾语只有一个字："**此**状态"——它存在的全部意义就是解左手。所以本卡**必须**能解 `doomed`，且是全场唯一的解；其余（清 1 个 dot/debuff + 治疗）只是让它不至于在没有 `doomed` 可解时成为废牌。这是本途径唯一一张**防守牌**，也是终末轴能自洽的关键：你既能给出去，也能收回来。注意它可以**给友军**用——因为 `doomed` 一旦挂错人（比如被反弹/转移）就需要这条退路。
- ⚠️ 依赖 `dispel` 按 statusId 过滤（✅ 新增项 12，效果参数 §一 dispel.filter.statusId 精确点名）。⚠️D

#### 【被动】摆渡人之躯 🜂
- **原著** 序列3 摆渡人 —— "**不会自然死亡**，**净化外大部分攻击无效**"
- **文案** 你已经死过一次了——那些慢慢侵蚀你的东西，只能把你拖到门口，推不进去；而死亡的气息，对你来说只是故乡的风。
- **序列** 3 摆渡人 · **hook** `on_battle_start`
- **效果** 挂载 `ferryman_shroud`（整场）：① **持续伤害（dot）不会使你死亡** —— dot 致死结算时保留 1 点生命（`dot_cannot_kill: true`）；② 受到 `poison` / `ice` 元素的伤害 ×0.6；③ 自身 `on_death` 触发的效果优先级最高（先于【不死者】结算，避免时序歧义）
- **翻译/语义** 原著两个分句分开处理。**"不会自然死亡"** 精确对应引擎里的 dot 致死结算——自然死亡 = 慢慢耗尽，而被打死不算，所以只挡 dot 致死（保留 1 血），不挡伤害致死。**"净化外大部分攻击无效"** 属位格碾压语义（位格维度 v0.3 已解禁，brief §11）；但被动载体不适合引入位格判定，本稿仍取折损方案：折为对死亡系元素（`poison` / `ice`）的 60% 减免。"净化"指代的净化类 / 神圣类攻击在本作无对应元素维度，故取"除净化外"的反面近似，已在「四、本稿遗留」登记此取舍。
- ⚠️ 依赖 `dot_cannot_kill`（✅ 新增项 5，已落 ddd：编队参数 §1.1b 死亡结算行，`trigger: 'dot'` 分支；与愚者 `lethal_protect` 同插桩同批落地）+ 复活优先级链（✅ 编队上下文 §十）。⚠️D

#### 【主动】完全的死亡 🜄 ★
- **原著** 序列2 死亡执政官 —— "'完全的死亡'：**剥夺区域内所有生命力**，**复活 / 替身能力无效**"
- **文案** 你抬手画下边界——那一块地方里不再有生命这回事：流干的血补不回来，准备好的替身，也只是又一具尸体。
- **序列** 2 死亡执政官 · **能量 6 / cd 7 / 吟唱 ⚠️D** · `consumption: 'zone'`
- **效果** `spawn_zone(zone_true_death)`：区域内敌方单位每 tick → `Sequence[` `damage(element: none, 2)`（**剥夺生命力**）, `mount_status(lifeless, duration: 2)`（`heal_received_mul: 0`，**生命被剥夺，补不回来**）, `mount_status(revive_blocked, duration: 2)`（**复活 / 替身无效**） `]`
- **翻译/语义** **原著招牌，v0.1 完全没有**。三个要素：区域（Zone）、剥夺生命力（无属性 dot，不走元素抗性）、禁疗 + 禁复活（后两者才是"**完全**"的所在——死得不留余地）。`revive_blocked` 与愚者 v0.2 新增项 11、不眠者 v0.2 新增项 13 `eternal_sleep` **同名同源**，是本作复活机制密集语境下的稀缺解；本途径自己是复活大户（【不死者】），由本卡来提供反面，设定上也自洽。
- ⚠️ 依赖 Zone 母版（✅ 新增项 10，H9）+ `revive_blocked`（✅ 已落 ddd：编队参数 §1.1b，与愚者 11 / 不眠者 13 同源同母版）+ `heal_received_mul`（✅ H21）+ `Sequence`（✅ G3）。⚠️D

#### 【被动】亡者之王 🜃 ★
- **原著** 序列2 死亡执政官 —— "'亡者之王'：**小型冥界容纳不死生物大军**"
- **文案** 你体内的冥界向外撑开了一圈——它不再只装得下三个魂，而站在你身后的，也不再只是一小队亡者。
- **序列** 2 死亡执政官 · **hook** `on_battle_start`

- **翻译/语义** 原著这句是序列5「小型冥界」的**直接升级**：同一个容器，从"容纳魂体"变成"容纳**大军**"。所以本卡的第一件事是**扩容【小型冥界】的计数上限**（3 → 6），而不是另开一个容器——这是本途径唯一的**跨档联动**设计，两卡合成一套，且升级路径可读（玩家能看懂"我变强了"）。第二、三件事（召唤位 + 召唤物强化）是"大军"的落地。

- **文案** 你看了它一眼，抬起手，指了过去——它还有两个呼吸的时间，而那已经是它全部的未来。

- **文案** 你摊开手掌，颜色从这片世界里退了出去——随之退去的，还有它们身上那些自以为是的本事。
- **序列** 1 苍白皇帝 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `consumption: 'zone'`

- **翻译/语义** 原著"**颜色**死亡的国度"+"**非凡能力**凋零"——在引擎里，"非凡能力"最贴的对应物就是**增益状态**（buff 是卡牌里"能力"的载体），所以"凋零" = 每 tick 自动剥一层 buff + 攻势衰减。"颜色"无维度可落，已并入"凋零"的 flavor。区域内己方亡灵减伤是"苍白世界"的归属面（这是**你的**国度）。与【冥界之门】的差异：冥界之门是**亡者变强 + 生灵变慢**（双向节奏），苍白世界是**敌人被剥夺能力**（单向瓦解）。
- ⚠️ 依赖 Zone 母版（✅ 新增项 10，H9——载荷含 `dispel` / `modify_stat`，按 unitType 分派）+ `Sequence`（✅ G3）。⚠️D

- **效果** `Sequence[`
  - `damage(element: none, 6)`（**生命死亡**）,
  - `dispel(target, category: ['buff'], count: 2)`（**记忆死亡**：忘掉被赋予的能力——"记忆"在卡牌里的载体是增益状态）,
  - `dispel(target, category: ['link','contract'], count: all)`（**联系死亡**：守护 / 链接 / 契约类状态一并断绝）,
  - `mount_status(revive_blocked, duration: 6)`（**烙印死亡**：灵魂上的烙印失效，复活 / 替身不再生效）,
  - `modify_stat(attack, -4, duration: 4)`（**非凡特性短暂死亡**：能力被抹除一段时间） `]`
- **翻译/语义** **序列0 的核心权柄，本途径的顶点大招**。原著这句是**五个宾语的排比**，本卡五个落点一比一对应，一个都不省——这是本稿唯一一张敢把原著一整句话铺满的卡。其中「记忆」「联系」在卡牌里必须找载体：记忆 = buff（被赋予的能力即"被给予的记忆"），联系 = 守护 / 链接 / 契约类状态（需要一个 `'link'` category）。7 能量 / cd 8 / 一局至多 1 张。
- ⚠️ 依赖：① `dispel.category` 新增 `'link'`（✅ 新增项 13，H40 StatusCategory 增补）；② `revive_blocked`（✅ §1.1b）；③ `Sequence` 算子（✅ G3，编目参数 §一）。⚠️D

#### 【被动】一切的归宿 🜄
- **原著** 序列0 死神 —— "'**终点**'权柄"；"**一切的归宿，所有生命共同的终点**"
- **文案** 万物都有终点，而你就是那个终点——离它越近的人，被你拉过去时越轻；而凡是走进终点的，都回不来。
- **序列** 0 死神 · **hook** `on_battle_start`
- **效果** 挂载 `journeys_end`（整场）：① 你对生命值 ≤ 50% 的目标造成的伤害 ×1.3，≤ 25% 时 ×1.6（**越靠近终点，越容易被拉过去**；两档不叠乘，取高值）；② 你击杀的敌方单位获得 `revive_blocked`（**回不来**）
- **翻译/语义** 原著"终点"的体感是**单向不可逆的加速度**——所以落点不是"打高血目标更疼"，而是"**越残血越致命**"，与【摆渡·对视】【死亡宣告】【死亡之国】的阈值机制合成一套完整的"处决体系"：本卡负责让"把对手推向阈值"这个过程本身越来越快，阈值类技能负责收掉。第②条与愚者【命运锚点】、不眠者【永眠】分流同一机制。
- ⚠️ 依赖按目标生命阈值的条件乘区（✅ 新增项 17，已落 ddd：H4 `{filter, dynamic}` 条件乘区，血量过滤在列）+ `revive_blocked`（✅ §1.1b）。⚠️D

#### 【被动】亡灵权柄 🜃
- **原著** 序列0 死神 —— "'**亡灵**'权柄"
- **文案** 死亡不是终点，而是一种兵役——凡是在你面前倒下的，最终都会在你的队伍里报到。
- **序列** 0 死神 · **hook** `on_battle_start`
- **效果** 挂载 `undead_authority`（整场）：① 你控制的 `UNDEAD` 单位受到伤害 ×0.85；② 你控制的 `UNDEAD` 单位死亡时 `underworld_cage.stacks + 1`（**不计原上限** —— 权柄级对"小型"的豁免）；③ 你的 `UNDEAD` 单位攻击附带 `damage(element: none, 1)`
- **翻译/语义** 序列0 的五大权柄里，「死亡」「苍白」「奴役」已分别由【死亡权柄】【苍白世界】【灵之主宰】承载，本卡补上「**亡灵**」——它是亡灵大军的终极形态：**更耐打、死后归队、自带死亡气息**。第②条让【小型冥界】在权柄层面不再受"小型"二字限制（序列5 的上限被序列0 覆盖），是本途径最长的一条成长线的收口。
- ⚠️ 依赖 `unitType` 判定（✅ §1.2b）+ 计数状态（✅ F51 + H11）+ 全局 `on_death` 监听（✅ 执行参数 §2.1）+ 第③条召唤物伤害链附加 `damage`（✅ 新增项 19，F54 `companionBuff` 携带 `on_deal_damage` 附加段）。⚠️D

## 四、本稿遗留

- **数值全档待标**：34 个技能的能量 / 伤害 / 时长 / 层数均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中**大部分伤害走 `element: none`**（死亡本身不属于七元素），绕过了所有 `resist:X` 抗性乘区，定价无既有锚点，**是本次最大的数值盲区**（沿用 **D2**）。召唤物基线数值（F34 / F35 / F25 的 hp / atk 量级）同为盲区。
- **未单独成技能的原著能力**（有意省略或合并，留待后续）：
  - 序列6「可**提前**控制、驱使亡者和自然灵战斗」里的"提前"（预先布置）—— 引擎无"预先 / 预备"维度，折为【亡灵驱使】的推条，未做预备机制。
  - 序列4「每 **60 年**死去一次复活一次」—— 折为 `oncePerBattle`；「漫长生命」折为 `hp_max` / 【不死者】，未单独立卡。
  - 序列4「冥界之门」与序列5「感应冥界入口」—— 前者立为 Zone 卡，后者的"感应"无信息维度可落，并入【亡灵驱使】。
  - 序列3「**净化**外大部分攻击无效」—— 位格碾压（brief §3 不搬），折为对 `poison` / `ice` 的 60% 减免 + dot 不致死，**"净化"指代何种能力在表中未定义**，需拍板。
  - 序列2「复活 / 替身能力无效」与序列0「烙印死亡」—— 合并为 `revive_blocked` 一处，未重复立项。
  - 序列1「苍白世界」的"**颜色**死亡"—— 无颜色维度，折为"能力凋零"。
  - 序列0 五权柄中的「**奴役**权柄」—— 由【灵之主宰】承载（原著上"奴役"与"灵之主宰"是同一能力的两处提及），未单独立卡。
  - 序列0「一切的归宿，所有生命共同的终点」—— 由【一切的归宿】承载，未另立"终点"卡。
- **推断项登记**：【腐息】是本稿**唯一**没有原著直接依据的技能（由序列9"腐烂气息"主动化引申而来，用于补低费输出地基）。若汇总阶段认定越界，可整条删除，不影响其余 33 个技能的体系完整性。
- **未决机制优先级**：`revive_blocked`（本稿 3 处：完全的死亡 / 死亡权柄 / 一切的归宿）与 `lethal_protect`（愚者 / 不眠者 / 歌颂者 / 秘祈人四稿）、C4 `miracle`、G4 `reviveOf`、本稿【不死者】正面对冲。**需先定「致死 → 复活 → 反复活」的结算优先级链**，否则这三条强度不可控。
- **阈值档位需统一**：本稿出现 4 个阈值（对视 25% / 宣告 40% / 死亡之国 20% / 归宿 50%·25%）。建议汇总阶段收敛为**同一套档位**（如 25% / 50% 两档），否则玩家记不住、平衡也难标。
- **叠乘风险**：【尸体特质】×0.7（UNDEAD 来源）+【灵之同类】×0.7（SPIRIT/UNDEAD 来源）+【灵之主宰】×0.7（SPIRIT/UNDEAD 来源）三处"按来源类型过滤的减伤"会叠乘至 0.343。建议改为**加法合成并设下限**（如 `1 - (0.3 + 0.3 + 0.3)` 下限 0.5），或规定同族状态只取最高值。
- **G8**：本稿**零 `move` 使用**（原著收尸人途径没有任何位移能力，与 G9 审计结论一致：收尸人属"未使用 move 原语"的 10 份文档之一）。唯一需要留意的是【唤起亡者】【死亡之国】的**跨阵营 `spawn`** —— 它们是"新建单位落己方队尾"，不是 relocate，G8 合规，但需实现侧确认 `handleSpawn` 未硬编码死者阵营。
- **`on_turn_start` 零使用**：本稿全部周期性效果挂 `on_tick` / `on_battle_start` / `on_death` / `on_kill`，**完全规避 G15 与 G15-b**（同不眠者 v0.2 口径）。唯一一处涉及"目标自身回合"的是【驱使亡者】的 `puppet_string`，已按 G15-b 把 duration 提到 6t。
- **A2 严守**：本途径召唤物极多，所有"开局"语义一律走 `on_battle_start`（**A1** ✅）；召唤物增益一律走 **F54** `spawn.companionBuff`，**不挂 `on_spawn` 自触发**——避免"召唤物每登场一次就白嫖一次"。
- **概率使用**：全稿**仅 1 处**（【灵魂掌控】`p: 0.3`，抽取灵体），严格满足 R5（非伤害维度）、R3（须登记）、R4（单次抽样）。其余全部为确定性效果。
- **v0.1 遗留的错处已在本版订正**（不另设变更对照）：删除"尸体→能量"这条原著不存在的续航轴（尸嗅 / 尸体解读 / 死亡预感 / 苍白视界的回能部分）、删除"墓园结界""死亡法则""永暗之河"等非原著卡、把纯正面的"不死者"补回"遗忘记忆"的代价、把"守门 / 守护"归还其应有的序列位。
