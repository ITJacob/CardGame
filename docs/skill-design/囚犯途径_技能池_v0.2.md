# 囚犯途径（被缚者）· 技能池 v0.3


> **版本**：v0.3（2026-09-06）—— 在 v0.2 原著校准版基础上增量升级，补入**界域 / 位格 / 性别 / 吟唱**四个维度（依据 `_GENERATION_BRIEF.md` v0.3 §10–§13）。v0.2 的原著校准成果全部保留。
> 文件名沿用 `v0.2`，内容已升级至 v0.3。
灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **囚犯途径**（源质「暗影世界」，旧日：欲望母树，序列0 被缚者）。
框架：`docs/ddd/`（战斗内核 DDD 终版）+ `_GENERATION_BRIEF.md`；旧框架编号（A/C/D/E/F/G 组）的现落点见 brief §7（v1.5 旧档、原《框架改动记录》与 `src/` 实现均已删除，原文可在 git 历史查阅）

> **本版定位**：v0.2 是**原著校准版**。v0.1 的问题是"借用了一堆不属于本途径的机制"（沉默封技、全体精神污染、易伤开乘区、复活不死），而原著真正写在囚犯途径里的招牌能力——**诅咒之源（伤害反映到另一方）、变形诅咒、转化异种、灵体化、操纵无生命物品、牺牲理智换力量**——一个都没落地。本版做三件事：
> ① 逐序列比对原著能力表（序列 9→0），把漏掉的招牌全部补回；
> ② 剔除 v0.1 中凭空发明、原著无据的设计；
> ③ 把本途径的灵魂机制「诅咒」做出**层次**（序列4 伤敌也伤己 → 序列3 伤敌不再伤己 → 序列0 完成所有类型诅咒且自身极难被诅咒）。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数 / 抗性）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 每技能五行：**「原著」** = 原著能力依据（引用自上述对照表）；**「文案」** = 玩家视角描述，肉鸽派发展示用；**「序列」** = 序列位阶 + 触发点 / 能量消耗 / 目标规格；**「效果」** = 引擎落地表达；**「翻译/语义」** = 为什么这么映射、绑定了哪个锚点、依赖哪条框架改动。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或文末「本途径框架改动」条目号）；★ = 该轴旗舰 / 高序列招牌技能；⚠️D = 数值占位待标。

### 普通（序列 9–8）

#### 【被动】体魄强化 🜏
- **原著** 序列9 囚犯 —— "体魄强化，强壮"
- **文案** 长年囚禁没能压垮你的肉身，反倒把它磨得更硬。战斗开始时，攻击力 +2，护甲 +1。
- **序列** 9 囚犯 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(armor, +1, duration: null)`
- **翻译/语义** 原著序列9 的第一条就是"体魄强化、强壮"，直译无歧义。护甲按「5 一档」取半档 +1，攻击按单卡纪律 ±1~±2 取上限。⚠️D
- **升级阶梯**（B6）：+2/+1 → +3/+2 → +4/+3

#### 【被动】知觉敏锐 🜐
- **原著** 序列9 囚犯 —— "知觉敏锐"
- **文案** 你比别人先看见、先听见、先摸到那件能要人命的东西。战斗开始时，行动条速率 +6。
- **序列** 9 囚犯 · **hook** `on_battle_start`
- **效果** `modify_stat(gauge_rate, +6, duration: null)`
- **翻译/语义** 卡牌里没有隐藏信息可"察觉"，唯一能落地的维度是节奏：先察觉 = 先出手。**注意与 G5/G6 的边界**：G5/G6 禁的是「主动技能给自己 `gauge.current +N`」（自己回合释放时条已清零，等于没加）；本条是**被动**、改的是 `gauge_rate` 源属性，且**不是**派生的行动周期（INV-S5 合规）。⚠️D（沿用 D2 待标）

#### 【主动】随手物品 🜐 ★
- **原著** 序列9 囚犯 —— "掌握诸多犯罪技巧，**擅长用随手物品杀人**"
- **文案** 你的手边永远有东西能要人命。抄起手边之物砸过去，造成 4 点物理伤害；要是顺手抄到的是锁链，还能把它缠住。
- **序列** 9 囚犯 · **能量 2 / cd 2 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 4)` + `{ ref: 'mount_shackle_1t', condition: { kind: 'chance', p: 0.3 } }`（F7）
- **翻译/语义** **本稿最重要的补漏**。v0.1 把序列9 译成了"护甲 + 精神抗性"，导致本途径前四个序列完全没有输出地基。原著序列9 唯一明确的攻击手段就是"用随手物品杀人"，所以它必须是本途径的「火球术」：低费、无前置、纯直伤。4 伤 / 2 能 = 2.0 汇率，高于基准 1.2，理由同愚者·飞牌——它要撑起整条途径的输出骨架。"随手"的不确定性用概率表达，但只作用于**是否附加状态**这一非伤害维度（R5 合规），写法是 EffectRef 的 `condition`，**不是**不存在的 `Chance()` 算子（G1）。⚠️D
- **升级阶梯**（B6）伤害 4 → 6 → 8；或解锁「镣铐变体」：改为必定附加 `shackle` 1t，伤害降为 3（锁链缠绕的 flavor 落在升级分支里，不单独占技能位）

#### 【主动】犯罪技巧 🜐
- **原著** 序列9 囚犯 —— "**掌握诸多犯罪技巧**"
- **文案** 下绊、迷眼、背后那一下——你太熟这些了。造成 2 点物理伤害，并把目标的行动条向后拨 25。
- **序列** 9 囚犯 · **能量 2 / cd 3 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: physical, 2)` + `modify_resource(gauge.current, -25, delta)`（作用于目标）
- **翻译/语义** "犯罪技巧"是阴招合集，卡牌里落不成"撬锁 / 扒窃"，唯一有玩法价值的是**节奏破坏**：让目标晚出手。直伤压到 2，把预算让给推条。⚠️D（推条定价无既有锚点，沿用 D2）

#### 【主动】爆发欲望 🜎 ★
- **原著** 序列8 疯子 —— "**牺牲理智换力量：爆发欲望换取全方面提高**"
- **文案** 你把理智松开了一道口子。3 回合内攻击力 +3、行动条速率 +8、护甲 +2——代价是防御 -2、精神抗性 -20%，而且没人能让你中途冷静下来。
- **序列** 8 疯子 · **能量 2 / cd 4 / 吟唱 0** · `targetSpec: SELF`
- **效果** `mount_status(frenzy, duration: 3)`：`attack +3` / `gauge_rate +8` / `armor +2`（全方面提高）；`defense -2` / `resist:mental -20%`（牺牲理智）；`dispelable: false`（爆发期间无法被"劝冷静"）
- **翻译/语义** 原著这条的机制骨架是**自身代价**——用理智（防御与精神抗性）换力量。引擎里最干净的表达就是"正负两段同时挂在同一个可计时的状态里"，到期自动回滚（欲望退潮、理智回来）。**与【狼人化】的分界**：疯子是**放开欲望**（不可驱散、有代价、序列8），狼人是**改变形态**（可驱散、无代价、序列7）。⚠️D
- ⚠️ 依赖新状态 `frenzy`（本稿新增项 10）；**与 F10 `beast_form` 同族**（自身形态增益），建议并入同一「形态增益」母版，差异只在代价段与可否驱散。

#### 【被动】疯癫抗性 🜎
- **原著** 序列8 疯子 —— "**对干扰思绪 / 影响精神的强大抵抗力**"
- **文案** 你早就疯了，没人能再把你逼疯。战斗开始时精神抗性 +20%；而每一次冲着你来的精神冲击，都让你的疯狂更兴奋一点——受到精神伤害时获得 1 点能量。
- **序列** 8 疯子 · **hook** `on_battle_start`
- **效果** `modify_stat(resist:mental, +20%, duration: null)` + 挂载 `unhinged_mind`（整场）：触发器 `on_take_damage`（`sourceFilter: element = mental`）→ `modify_resource(energy, +1, delta)`
- **翻译/语义** 原著两条语义一起落地：抗性（抵抗力）+ 越被冲击越精神（疯子的正反馈）。`sourceFilter` 按元素过滤已在 `EffectCondition` 谓词集内，无新依赖。⚠️D

### 精良（序列 7–6）

#### 【主动】狼人化 🜏 ★
- **原著** 序列7 狼人 —— "**恐怖的力量、敏捷、速度和自愈，狼人化后手爪牙齿带毒**"
- **文案** 骨骼错位、毛发暴长。4 回合内攻击力 +3、行动条速率 +8；你的爪牙带毒，每次命中都让对方溃烂；而你的伤口在每一个瞬间自行合拢。
- **序列** 7 狼人 · **能量 3 / cd 6 / 吟唱 0** · `targetSpec: SELF`
- **效果** `mount_status(beast_form, duration: 4)`（**F10** 已登记：`atk +3` / `gauge_rate +8`），并追加两条触发器：
  - `on_deal_damage` → 给被击中的目标 `mount_status(poison, 2t)`（爪牙带毒，复用既有「中毒」）
  - `on_tick` → `heal(self, 1)`（恐怖自愈，**A22** 必须用 `heal` 原语）
  - `dispelable: true`（保留被对手 `dispel(category:'buff')` 打断的窗口）
- **翻译/语义** 原著序列7 的四个要素（力量 / 敏捷速度 / 自愈 / 带毒）在原著里本就是"**狼人化之后**"的同一套能力，本稿合并进同一个变身状态——拆成四个技能反而是凭空发明。载体直接复用 F10 `beast_form`，只追加两条触发器。自愈走 `on_tick`（每 tick 1 点），不写成"每回合"（G14：tick ≠ 回合）。⚠️D

#### 【主动】黑暗恐惧 🜎
- **原著** 序列7 狼人 —— "『**驱光**』、『**黑暗恐惧**』"
- **文案** 你伸手把战场上的光掐灭了。全体敌人失去 1 个增益，并在无边的黑里受到 2 点精神伤害。
- **序列** 7 狼人 · **能量 3 / cd 4 / 吟唱 0** · 全体敌人
- **效果** 全体敌人 `Sequence[ dispel(target, category: ['buff'], count: 1)（驱光）, damage(element: mental, 2)（黑暗恐惧）]`
- **翻译/语义** 原著"驱光"= 熄灭光线（驱散光明类增益，**C2** 已支持数组形式）；"黑暗恐惧"= 在黑暗里施加恐惧（精神伤害）。两条同属一个动作（先灭光、再恐惧），合成一张卡。都是非直伤维度，故直伤压到 2。这片黑暗同时是【初步反占卜】的叙事前提（黑里只看得见一团黑毛）。⚠️D

#### 【主动】毒性傀儡 🜏
- **原著** 序列7 狼人 —— "**控制被毒性浸入目标转化为傀儡**"
- **文案** 毒液浸透它的四肢百骸，你这才牵起线来。目标中毒 4 回合；若它体内已经有你的毒，它便不再属于自己——接下来它的攻击由你指定打向谁。
- **序列** 7 狼人 · **能量 4 / cd 5 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `Sequence[ mount_status(poison, 4t), If(target_has_status: ['poison']) → mount_status(puppet_string, duration: 6) ]`（`puppet_string` = **F9**）
- **翻译/语义** 原著白纸黑字是"**被毒性浸入**的目标"——控制不是无条件的，**前置是毒**。这条前置正是它与序列5【怨魂附身】的分界：狼人靠毒浸透做**持续型**控制（duration），怨魂靠附体做**次数型**控制（charges）。是"转化傀儡"这条原著主线的第一级。
- ⚠️ **G15-b 修正**：v0.1 的 `puppet_string` 是 `duration: 3t` + `on_turn_start` 触发，而敏捷 0 的单位 5 tick 才行动一次 → 大概率一次都碰不到就过期。本稿统一改为**「单位发动攻击」即时节点**（本稿新增项 20），并把 duration 提到 6t 兜底，两处都取稳。
- ⚠️ 依赖均已落：F9 `puppet_string`（✅ H12 `target_override` 族）+ F52（✅ §三 `has_status`）+ 攻击即时节点（✅ `on_attack`，执行参数 §2.1）。

#### 【被动】初步反占卜 🜎
- **原著** 序列7 狼人 —— "**初步反占卜（只能看到黑毛身影）**"
- **文案** 占卜与通灵落在你身上，只捞得到一团模糊的黑毛。战斗开始的刹那，敌方指向你的第一个单体技能注定落空。
- **序列** 7 狼人 · **hook** `on_battle_start`

囚犯与**罪犯**同属源质「暗影世界」，互为相邻途径（对照表：囚犯 ↔ 罪犯），高序列能力可混合。共享用 `sharedAcross: ['criminal']` 声明：

| 诅咒之源 / 无反噬之咒 | 罪犯 | 罪犯途径序列0 深渊含"部分**诅咒**权柄"，序列2 鲜血大公起即有诅咒类手段，`curse_link` 一次实现两边复用 |
| 邪物 | 罪犯 | 罪犯的「呓语污染」（**F16** `whisper`）与本条的 `mind_taint`（**F8**）同属精神污染叠层，共用 F8 + F51，建议纳入同一「叠层 debuff」母版 |

## 四、本稿遗留

- **数值全档待标**：35 个技能的能量 / 伤害 / 时长 / 层数 / 抗性一律 ⚠️D，需过验证脚本重定（沿用 D4）。其中 `gauge.current` 推拉类（犯罪技巧 / 怨魂尖啸 / 幽影之躯）与 AOE 类（怨魂尖啸 / 邪物之眼 / 万咒加身）**定价无既有锚点**，是本稿最大盲区。
- ~~**`curse_link` 的连锁规则未定义**~~（✅ 2026-09-08 销项）：H28 母版已**内置防循环**——由链接/转嫁产生的伤害不再触发任何 `curse_link`，无限循环不可构造（编队参数 §1.1b 伤害转嫁行）。
- **状态内 `on_tick` 能否作用于敌方单位**：【邪物】的光环要求状态挂在施法者身上、`on_tick` 的载荷却要打到敌方全体。当前 `StatusDef.payload` 默认作用于宿主，需确认能否用 `target` 覆盖到敌方全体（与 **F56** `casterId` 寻址是同一族问题）。
- **`convert` 的残留细节**：被转化单位身上已挂载的状态如何处理（保留 / 清空 / 反向）？转化后其原始技能组是否要留一个"挣脱"窗口？落位是否受 G8 约束（本稿按"移除 + 己方队尾 spawn"绕开）。
- **`transmute_curse` 的 `disable_skills` 边界**：是否覆盖「免吟唱」这类可挣脱禁技的既有状态？建议明确"变形诅咒 > 免吟唱"（变形成野兽后不存在吟唱）。
- **「弱序列4 基准值」未定**：【演出】的 `to_at_least` 需要一个具体的 attack / defense 数值，本稿只能标记为 ⚠️D，需与参数层一起定。
- **F25 `unit_wraith` 的 ID 冲突未解决**：不眠者稿与收尸人稿同 ID 两套属性（改动记录「合并候选 10」列为**必须先解决**项）。因此本稿序列6「**控制幽魂**」只能挂在【唤醒死尸】的升级阶梯（B6）上，不能正式落地。
- **未完全落地的原著能力**（有意省略，记录以免漏项）：
  - 序列6「**操纵活尸**」的"操纵"语义只以【操纵活尸】的"培养"表达，未做"夺取敌方尸体控制权"；「**控制幽魂**」见上一条。
  - 序列5「**镜面闪现**」的位移并入【灵体化】释放时的 `push_back`（G8 只允许己方半场内位移，无法表达"闪现到镜子位置"）；「**自由出入灵界**」在单战场里无对应维度，仅作 flavor。
  - 序列4「操纵全部无生命物品」未设数量上限（原著未给），本稿按"一次唤起一具古物傀儡"处理，是设计选择而非原著原文。
  - 序列3「沉默门徒」原著未列"沉默"的具体形式，本稿把"沉默"推导为【长久沉默】的"免疫沉默 + 对被沉默者加伤"。
- **`mind_taint` 层数上限未拍板**（F8 建议 3 层）：直接影响【邪物】的强度上限，需与 F8 / F16 / F51 一起定。
- **`spawn` 与 `on_spawn` 的时序**：【操纵活尸】要求 `on_spawn` fire 时新单位已完成落位（否则 `modify_stat` 可能打在错误目标上），需引擎确认。
- **与刺客 / 通识者的状态命名冲突**：`transmute_curse` / `petrification` / `petrify` 三者中文都接近"变成别的东西"，需在汇总阶段统一命名并确认三者不合并。
