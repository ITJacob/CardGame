# 律师途径（黑皇帝）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.2 原著校准版基础上，**按 9 大源质新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入失序之国系核心机制 **「规则槽 Rules[3] 共享棋盘」** + **「秩序度 Order」战场维度**（0–10）；律师侧是规则槽的**改规方**（不立法，只夺取/扭曲/利用），并把秩序度往下压；
> ③ 落实 **拆轴 reform**：原「讼辩 + 贿腐」合并为 ① 寻隙，原「失序」18 张拆出 ③ 熵蚀 与 ④ 僭越（新规核心轴）；
> ④ 新增 **跨系 combo 卡**（失序之国↔光之钥 混乱共鸣 / ↔源堡 定义·替身·改 / ↔知识荒野 造物豁免）；保留 1 张主题界域牌「扭曲秩序」。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；轴定义依据《失序之国系技能设定》§4.1/§4.2；跨系依据《九大源质总览》《失序之国系技能设定》§6。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做「轴=钩子」与「规则槽/秩序度/跨系」两层。规则表达由 v0.2 的「单体 debuff / 单卡扭曲」升级为**读写仲裁人立下的共享棋盘**——律师首次成为规则槽的「法律掮客」。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁「技能效果 + 轴引擎 + 跨系接口」，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

> 拆轴依据《失序之国系技能设定》§4.1：原「讼辩 + 贿腐」合并为 ① 寻隙，原「失序」18 张拆出 ③ 熵蚀（混乱/熵/狂乱）与 ④ 僭越（扭曲/利用/放大/独享规则/阶层/重定义/定义·替身/独裁者）。每轴一个身份状态；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **寻隙** | `寻隙` | 诡辩 / 薄弱处 / 贿赂(削·魅·狂·关联) / 寻隙 / 滔滔不绝 → 挂 `寻隙` 系列 | 对手每带 1 个 debuff 我的伤害递增；标记回扣反哺能量 | **薄弱处 / 腐化回扣** |
| ② **蛮力** | `蛮力` | 野蛮体魄 / 力量解决 / 冲撞 / 赠予 → 挂 `蛮力` | 生命上限/护甲/双抗堆叠；「不能靠法律的就用力量解决」 | **力量解决** |
| ③ **熵蚀** | `熵蚀` | 混乱 / 熵 / 狂乱 / 踏月 → 挂 `熵蚀` 叠层 | 战斗越久敌人越乱；层数越高自身越强；失序态自动 +1 层 | **熵 / 狂乱适应** |
| ④ **僭越** ★核心 | `僭越` | 扭曲 / 腐蚀 / 利用 / 放大 / 独享规则 / 阶层 / 重定义 / 定义·替身 → **改写规则槽** | 操作场上已存在的规则（改 trigger / 转 punish / 加 exempt / 换对象 / 互换本体替身） | **定义·替身 / 独裁者** |

> **僭越轴 = 规则槽的改规发动机**：律师不立规（立规归仲裁人），但**改规**——`扭曲` 改写 trigger、`利用` 加倍/转向 punish、`独享规则` 把自己加进 exempt、`重定义` 改写作用对象、`定义·替身` 互换身份。规则槽是失序之国两途径**唯一共享棋盘**（详见本节「本系咬合器维度」）。

### 本系咬合器维度说明（失序之国系 §2.2 / §2.3）

**① 规则槽 Rules[3]**（战场级共享棋盘，上限 3 具名规则位 `rule_a / rule_b / rule_c`）：

| 操作 | 归属 | 语义（律师侧） |
|---|---|---|
| **立规 / 惩戒 / 废止** | 仲裁人 | 写入规则、触发惩罚、清场重写 |
| **扭曲** | 律师 | 改写已存在槽位的 `trigger`（原「扭曲」能力落地） |
| **利用** | 律师 | 把某条规则的 `punishment` 转向 / 加倍（原「利用 / 放大」落地） |
| **独享规则** | 律师 | 把自己加入 `exemptions`（同一条规则只打敌人不打我） |
| **重定义** | 律师 | 重定义作用对象：把「全体」改写成「友方律师侧除外」 |
| **定义·替身** | 律师 | 把某单位的「本体/替身」身份互换（规则作用目标瞬间错乱） |
| **秩序崩坏** | 律师 | 清空 / 打乱全部槽位并重排（原「秩序崩坏」落地） |

> 仲裁人 = **立法者**（造法、执法）；律师 = **法律掮客**（不废法，而是让法为自己服务）。两途径强度都取决于**槽里有几条规则**——仲裁人希望槽满且严苛，律师希望槽满且被自己改写。**利益一致在「槽要满」，冲突在「归谁解释」**。

**② 秩序度 Order（0–10，初始 5）**——战场量表，与「隐秘值」同族：

| 秩序度 | 阈值效果 |
|---|---|
| **≥7 铁序** | 所有 `律令` 惩戒伤害 +50%；律师 `扭曲 / 重定义` 的成功判定 −30% |
| **≤3 失序** | 所有 `混乱` 类状态持续 +1 tick；`熵蚀` 每回合自动 +1 层；仲裁人 `辖区` 区域效果 −30% |
| **=10 / =0** | 终局态：`底层规则`（仲裁人）/ `秩序崩坏`（律师）才可用的门槛 |

- 仲裁人侧：每次成功立规 +1，每次成功惩戒 +1（写入 / 执法都推高秩序度）。
- **律师侧**：每次 `扭曲 / 利用 / 重定义` 成功 −1，`熵蚀` 每层（或每 tick）−0.5（压低 / 扭曲秩序度）；`秩序崩坏` 把秩序度拉向 0 解锁终局。
- 这是本系与全局的接口：秩序度（失序之国）、隐秘值（源堡）、命运值（光之钥）构成「战场量表族」。

- **效果** **若\[友方 通识者 的 `造物` 已挂 规则槽\]** → `modify_rule_slot(该造物所在槽位, {field:'exemptions', add:'该造物'})` + `mount_status(造物豁免, duration:5)` 给该造物
- **翻译/语义** 跨系 combo：读通识者 `造物`（跨系枢纽），为其争取规则豁免，免受仲裁人审判。依赖 `造物`/`规则槽` `crossPathway:true`。⚠️D。

## 三、跨途径共享（失序之国相邻：仲裁人）

源质同源（失序之国），仲裁人与律师唯一互为相邻。共享用 `sharedAcross: ['arbiter']`。

**规则槽共享棋盘联动**（P2，强于状态共享）：

| 仲裁人（立法/执法） | 律师（改规/逃脱） | 介质 |
|---|---|---|
| 立规 → 写空槽 | 扭曲 trigger / 利用 punish / 独享规则 exempt / 重定义 scope | `规则槽 Rules[3]`（双方可读写） |
| 惩戒 → 触发惩罚 +1 秩序度 | 放大把惩罚变处决；扭曲让敌人更易违背（帮仲裁人刷秩序度） | `规则槽` + `秩序度` |
| 底层规则（秩序度=10） | 秩序崩坏（秩序度=0 拉满） | 终局态对位 |

**共享/联动（落地优先级）**：

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 诡辩 / 薄弱处 / 贿赂·削弱·魅惑 | 仲裁人 | 心智影响执行层互通（寻隙轴） |
| 混乱 / 熵 | 仲裁人 | 同属「混乱」语义，利于互相 counter（熵蚀轴） |
| 扭曲 / 利用 / 放大 / 独享规则 / 重定义 / 定义·替身 / 秩序崩坏 | 仲裁人（只读不共） | 规则槽操作权是两条途径唯一分界线，**双向都不共享**（仅共享棋盘） |

> **枢纽状态（标 `crossPathway:true`，一等公民）**：`混乱` / `替身` / `规则槽` / `秩序度` 在 `StatusDef` 标 `crossPathway:true` + 途径白名单。其中 `规则槽`（白名单：仲裁人、律师）、`秩序度`（白名单：仲裁人、律师）为失序之国共享介质；`混乱`（白名单：律师、怪物）、`替身`（白名单：律师、占卜家、刺客）为 5 枢纽状态。本稿登记的跨系 combo：`混乱共鸣·改`（↔怪物）、`定义·替身·改`（↔占卜家，读 `秘偶`）、`造物豁免`（↔通识者，读 `造物`）。全部走 combo（P3），无复刻卡。

## 四、轴引擎 / 规则槽 / 跨系 自检

- **enabler→payoff 闭环**：寻隙（挂 `寻隙`→按 debuff 数加伤/回扣）、蛮力（挂 `蛮力`→堆叠生存）、熵蚀（挂 `熵蚀`→越久越强/压秩序度）、僭越（操作规则槽→改 trigger/加倍 punish/加 exempt/换对象）四轴均显式成链。
- **规则槽维度**：律师经【扭曲】【利用】【独享规则】【重定义】改写规则槽，【放大】把 punish 变处决（需槽非空），【秩序崩坏】清槽；与仲裁人立规共享同一棋盘成立。
- **秩序度维度**：扭曲/利用/重定义 −1、熵蚀每 tick −0.5、秩序崩坏拉向 0；失序≤3 时混乱+1tick、熵蚀自动+1层（已 weave 进卡面）。仲裁人立规/惩戒推高（见其稿）。
- **跨系 combo（非复刻）**：【混乱共鸣·改】读怪物 `混乱`、【定义·替身·改】读占卜家 `秘偶`、【造物豁免】读通识者 `造物`，均符合 P3。
- **界域牌**：【扭曲秩序】共 1 张，占总量内。

## 五、本稿遗留

- **数值全档待标**：所有能量/伤害/时长/层数 ⚠️D，需过验证脚本。`规则槽` 惩罚定价、`秩序度` 乘区挂钩无既有锚点。
- **拆轴后轴分布**：本稿实落 **寻隙 9 / 蛮力 4 / 熵蚀 8 / 僭越 13**（共 34）。蛮力轴天然只覆盖序列8/4 物理维度（原 v0.2 亦仅 4 张），且 `放大` 已按 §4.2 归入僭越，故偏薄；僭越为新建核心轴，承载原「失序」18 张拆出的神卡，故最厚。与 reform 目标 ~8/6/8/11 的偏差（蛮力偏少、僭越偏多）是系设定 §4.1 轴定义的直接结果，非遗漏。
- **复活优先级链未定（重要）**：`九座陵寝`/`defined_substitute` 与愚者 `spirit_worm`/`miracle`/`revive_blocked` 纠缠。建议链：`revive_blocked` > `defined_substitute` 压制 > `lethal_protect` > `on_death` 复活。未拍板前【九座陵寝】【定义·替身】强度不可标定。
- **【狂乱】方差**是全稿唯一概率来源（R5 边界）。若平衡不接受 4 次独立伯努利，改用退化方案（固定得 1 项增益+1 项减益）。
- **规则槽数据结构**：需内核新增战场级数组型物件（退化为 3 具名规则位 rule_a/b/c）。`modify_rule_slot` 算子需 `field∈{trigger,punish,exemptions,scope}` 的可配置写入。
- **未单独成卡的原著能力**（有意合并）：序列4「篡改规则/增加规则」并入【利用】；序列0「能让世界底层规则扭曲混乱」并入【秩序崩坏】；序列1「重新定义距离/位置」未单列（与重定义同源）。
- **【赠予】`on_tick` 自伤**会高频触发 `on_take_damage`，需确认是否污染【对半承担】转移、是否计入【狂乱适应】debuff（不应计）。
