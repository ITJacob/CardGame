# 怪物途径（命运之轮）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入光之钥系核心机制 **「命运值」战场双极维度**（fate −10↔+10，怪物专用、他人可触发）；
> ③ 新增 **跨系 combo 卡**（光之钥↔源堡 / 永暗之河 / 失序之国，枢纽状态 `crossPathway:true`）；
> ④ 补 2 张主题界域牌（厄运领域 / 命运之轮领域）。
>
> 框架依据 `../meta/GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《光之钥系技能设定》。v0.2 原著校准成果全部保留，只重做"轴=钩子"与跨系联动两层。
>
> **本版定位**：光之钥是 9 源质中**唯一单途径源质**（怪物无相邻途径），故怪物被设计成 **「命运总线」**——其余途径（占卜家 / 偷盗者 / 刺客 / 不眠者 / 律师 / 仲裁人）的命运类操作都读写同一组枢纽状态，怪物是放大器与调度器。这是单途径源质唯一的、也是最优的破局方式。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

本途径为单途径源质，四轴必须**自洽成环**（幸运↔厄运经命运值双向转换、混乱打乱既定命运→循环重启回某一命运片段）。★核心轴为 **命运**，由「命运值」双极维度驱动；循环（水银之蛇）归入命运轴 payoff。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| 🜂 **幸运** | `幸运`(fortune, 计数资源) | 幸运者 / 命运潮汐 / 引发灾祸 / 福祸之言 → 累积 `幸运` | 若\[幸运≥N\] 化解致命危机（赢家）、消耗运气为友方赐福 | **赢家** |
| 🜃 **厄运** | `厄运`(misfortune, 叠层 debuff) | 厄运领域 / 给予厄运 / 厄运诅咒 / 预见灾祸 → 对敌挂 `厄运` | 若\[厄运\] 目标判定恶化、接连遭遇灾祸（行动条衰减 + 叠满打空） | **厄运法师（厄运领域）** |
| 🜁 **混乱** | `混乱`(fate_chaos, 目标改写) | 混乱 / 混乱导演 → 挂 `混乱` | 若\[混乱\] 目标既定命运 / 行动序列被打乱（清零进度 + 打向最近单位） | **混乱行者（混乱）** |
| 🜄 **命运** ★核心 | `命运值`(fate_value, 战场维度 −10↔+10) | 预知 / 厄运施放 / 循环重启 → push 命运值 +（怪物为总线，他人可触发读取） | 阈值档：≥+5 我方好运类放大 / 敌厄运加速；≤−5 反噬；=±10 终焉 | **命运之轮 / 水银之蛇** |

> **命运值维度（光之钥系 §2.2 / 总览 §1 咬合器③）**：战场双极量表 **−10↔+10**，怪物专用写入，他人（占卜家 / 偷盗者 / 刺客 / 不眠者）可触发读取。怪物经「预知 / 厄运 / 循环」类效果写入：我方好运类 enabler 命运值 **+1/次**；施加敌方厄运 **+1/次**（从敌方抽取运气）；消耗类（赢家免死 / 赐福）**−N**。阈值档（全部 ⚠️D）：
> - **≥ +5**：我方「幸运 / 好运」类 payoff 放大（赐福 ×1.3、赢家免死阈值 4→3）；敌方「厄运」叠层速度 ×2（每 tick +1 而非 +0.5）。
> - **≥ +8**：命运总线满载——怪物可远端调度一次命运（命运之轮减费 / 强制判定生效）。
> - **≤ −5**：反噬风险——怪物施放技能后自身 `mount_status(厄运, stacks:1)`（确定性 debuff，非伤害，R5 合规），或敌人从总线抽头获利。
> - **= +10 / −10**：命运洪流 / 命运债务——终焉卡触发全屏改写。
>
> **跨源质写入方**：占卜家（命运干扰 / 锚点）、偷盗者（嫁接命运 / 命运木马）、刺客（命运诅咒）、不眠者（厄难）也读写同一组枢纽状态；怪物是主调度方（见 §三 枢纽白名单）。

## 一、技能池

图例：⚠️ = 需框架扩展；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）；★★ = 跨系 combo；★★★ = 终焉。

### 普通（序列 9–8）

#### 【被动】灵感超高 🜁 灵感 · **E**
- **原著** 序列9 怪物 —— "灵感超高：听见／看到别人感知不到的事物"
- **文案** 你的灵感高到能听见不该听见的声音——藏起来的东西瞒不过你，而战局一开始，你已比旁人多看了一步。
- **序列** 9 怪物 · **hook** `on_battle_start`
- **效果** `modify_resource(energy, +⚠️D)` + 挂载 `inspiration_sense`（整场）：敌方隐匿／不可锁定类状态**对你无效**；你对隐匿单位伤害 ×1.2 + `modify_resource(fate_value, +⚠️D)`（命运轴起手）
- **翻译/语义** 感知优势拆两条：① 超前感知 = 开局能量；② 看穿遮蔽 = 识破隐匿。同时轻推命运值，让命运轴有起手层数。⚠️ 依赖 C8 识破分支。数值 ⚠️D。

#### 【被动】危险预感 🜁 灵感 · **E**
- **原著** 序列9 怪物 —— "对危险有敏锐直觉预感"
- **文案** 危险降临前的一瞬，你的身体先于意识动了——这一击只擦着你过去。
- **序列** 9 怪物 · **hook** `on_battle_start`
- **效果** `danger_sense`：`on_take_damage`→该次 ×0.6，`charges-1`；`on_remove`→`mount_status(danger_sense, charges:1, duration:⚠️D)`（自续链）
- **翻译/语义** "直觉预感"=提前规避=减伤。charges 一次性减伤 + `on_remove` 自续链（规避 G15）。⚠️ 依赖自续链合法化。数值 ⚠️D。

#### 【主动】未来画面 🜁 灵感 · **E**
- **原著** 序列9 怪物 —— "偶尔窥见未来画面"
- **文案** 你眼前闪过一幅尚未发生的画面——于是一名同伴抢在敌人之前动了手。
- **序列** 9 怪物 · **能量 2 / cd 3 / 吟唱 瞬发**
- **效果** `modify_resource(gauge.current, +⚠️D)` 友军 + `modify_resource(fate_value, +⚠️D)`（命运轴 enabler：预知即调度命运）
- **翻译/语义** 预知=提前量，受益者必为友军（G5 铁律：自推条=没加）。并 push 命运值，命运轴起手。数值 ⚠️D。

#### 【主动】精准射击 🜁 灵感 · 输出地基
- **原著** 序列8 机器 —— "格斗射击天赋者"
- **文案** 没有多余的瞄准动作，你抬手便是必中的一枪。

#### 【被动】恐怖计算 🜁 灵感 · **E**

- **文案** 你像一台精密的机器推演战局：出手更快，而任何想让你的枪口偏一点的把戏都落了空。

## 三、跨途径共享（枢纽状态 `crossPathway:true`）

光之钥为单途径源质，**无相邻途径**，故本途径技能一律 `sharedAcross: []`。跨系联动改走 **枢纽状态 `crossPathway:true`**（非复刻卡），怪物作为「命运总线」被其余途径从两侧抽头。

| 枢纽状态 | `crossPathway:true` | 参与途径白名单 | 本稿落点 |
|---|---|---|---|
| **命运** | ✅ | 怪物 / 占卜家 / 偷盗者 / 刺客 | 【命运共鸣·源堡】【命运之轮】【命运之轮领域】读取友方源堡命运状态再放大；占卜家/偷盗者/刺客从两侧抽头 |
| **混乱** | ✅ | 怪物 / 律师 / 仲裁人 | 【混乱导演】读取友方失序之国「秩序度≤3」双系加成；怪物产噪→律师导演 |
| **厄运**（扩展共享） | ✅ | 怪物 / 不眠者 / 刺客 | 【厄难共鸣】读取友方不眠者「厄难」继承层数；刺客命运诅咒借用 |

| 技能 | 跨系联动给 | 介质 / 理由 |
|---|---|---|
| 厄难共鸣 | 不眠者（永暗之河） | 读取 `厄运`/`厄难` 升级为完全厄难（厄运组合） |
| 命运共鸣·源堡 | 占卜家 / 偷盗者（源堡） | 读取 `命运` 类状态升级为命运接管（命运总线） |

> **枢纽状态落地优先级**：`命运`/`混乱`/`厄运` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单（源自《九大源质总览》§3）。这是跨系联动的地基，避免旧方案"复刻卡塞两池"的病。

## 四、轴引擎 / 命运值 / 跨系 自检

- **enabler→payoff 闭环**：幸运（幸运者攒→赢家免死/赐福花）、厄运（厄运领域/诅咒挂→叠满打空/衰退）、混乱（混乱挂→清零+错乱）、命运（预知/厄运 push 命运值→阈值放大）。四轴均显式成链。
- **命运值维度**：怪物经 未来画面/福祸之言/厄运施放/循环重启 push `fate_value`；≥+5 放大赐福与敌厄运叠层、≤−5 反噬自挂厄运、≥+8 二次调度、=+10 命运洪流。维度阈值照搬总览 §1（双极 −10↔+10），不另立标准。
- **跨系 combo（非复刻）**：【厄难共鸣】读不眠者厄难、【命运共鸣·源堡】读源堡命运状态、【混乱导演】读失序之国秩序度——均为"读取友方别家招牌状态再升级"，符合新方案 P3。
- **界域牌**：【厄运领域】（序列4 上层 overlay）、【命运之轮领域】（序列0 上层 overlay，★★★终焉）共 2 张，占总量内；均付迷失租金 `modify_resource(lost,+⚠️D)`。
- **自洽闭环**：幸运↔厄运经命运值双向转换、混乱打乱既定命运→循环重启回某一命运片段，无需组内第二途径。
