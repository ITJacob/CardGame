# 愚者途径（占卜家）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入源堡系核心机制 **「隐秘值」战场维度**（secrecy 0–10）；
> ③ 新增 **跨系 combo 卡**（源堡↔永暗之河 提线木偶、源堡↔混沌海 寄生）；
> ④ 补 2–3 张主题界域牌。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《源堡系技能设定》。
>
> **本版定位**：v0.2/v0.3 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **观诡** | `预兆`(omen, 敌方标记, 可叠层) | 灵视 / 占星 / 占卜 → 给目标挂 `预兆` | 若\[某敌 `预兆`≥3\] → 命运干扰 + 先手 / 额外伤害 | 占卜家·启 |
| ② **变形** | `拟态`(mimic, 自身, charges) | 变形 / 制造幻觉 / 伤害转移 → 自身挂 `拟态` | 若\[`拟态`\] → 复制敌方上一个技能 / 替身承伤 | 无面人 |
| ③ **提线** ★核心 | `提线木偶`(puppet_string, 敌方, duration) | 秘偶 → 对敌挂 `提线木偶` | 若\[`提线木偶`\] → 远端操控其行动 / 调位 / 替死 | 诡法师 |
| ④ **命运** | `隐秘值`(secrecy, 战场维度 0–10) | 愚弄 / 命运干扰 / 愿望 → +1 隐秘值 | 若\[隐秘值≥7\] → 弄假成真（判定制胜）/ 隐秘类 +50% | 愚者·权柄 |

> **隐秘值维度（源堡系 §2.2）**：战场级属性 0–10，独立于力/敏/智/灵/体/魅。占卜家经"愚弄/隐秘"类效果 +1/次。层级：
> - **≥4**：场上所有 `提线木偶` 每回合 +1 层（提线轴直接受益）
> - **≥7**：友方「愚弄 / 隐秘 / conceal」类技能 **+50%**
> - **=10**：触发「**源堡共鸣**」——本回合所有带 `提线木偶` 的目标可被任意友方（含跨源质）操控一次
>
> **跨源质写入方**：永暗之河（不眠者·隐秘 / 收尸人·灵之线 / 战士·隐蔽）、暗影世界（囚犯·诅咒之源 / 罪犯·污秽）、混沌海（秘祈人·阴影血肉）也写入同一 `secrecy` 维度，故占卜家是主消费方之一。

#### 【被动】灵视 🜁 观诡 · **E**

- **文案** 你的灵视洞穿遮蔽，开局便窥见战局走向，立即获得 5 点能量；藏起来的敌人也瞒不过你。

## 四、轴引擎 / 隐秘值 / 跨系 自检

- **enabler→payoff 闭环**：每条轴均有 enabler 卡（挂身份状态）与 payoff 卡（读取放大）；观诡=预兆、变形=拟态、提线=提线木偶、命运=隐秘值，四轴均显式成链。

- **跨系 combo（非复刻）**：【秘偶大师·改】读收尸人线、【寄生者·改】读秘祈人线，均为"读取友方别家招牌状态再升级"，符合新方案 P3。
- **界域牌**：【幻境】（序列7 上层 overlay）、【诡秘之境】（序列1 zone）、【愚者·权柄】（序列0 上层 overlay）共 3 张，占总量内。
