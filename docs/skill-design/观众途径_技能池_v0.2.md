# 观众途径（空想家）· 技能池 v0.2

灵感源：`docs/诡秘之主职业路径与能力对照表.md` → **观众途径**（源质「混沌海」，相邻途径：歌颂者 / 阅读者，序列0 空想家）。**本稿唯一灵感源，不引用 ima 二手数据、不借用其他途径的招式名。**
框架：`docs/ddd/`（战斗内核 DDD 终版）+ `_GENERATION_BRIEF.md`；旧框架编号（A/C/D/E/F/G 组）的现落点见 brief §7（v1.5 旧档、原《框架改动记录》与 `src/` 实现均已删除，原文可在 git 历史查阅）

> **本版定位**：v0.2 是**原著校准版**。v0.1 把这条途径翻译成了一套"通用控制 + 通用治疗 + 通用召唤"的模板技能，与原著差距大。本版做三件事——
> ① 逐序列比对原著能力表，**补回全部被漏掉的招牌能力**（虚拟人格、龙鳞、龙化、巨龙、身份分离、瘟疫风暴、精神瘟疫、心智剥夺、心灵风暴、书写成真、凡有言必被知、质变的心理暗示、梦境穿梭、心理学隐身、特性分离）；
> ② **删除 v0.1 凭空发明的原著外技能**（记忆回响、弱点辨识、记忆回溯、记忆抹除、潜意识探索、因果窥视、混沌海、认知重塑）——原著观众途径没有"记忆操作"，那是阅读者/偷盗者的地盘；
> ③ 把原著的具体手段还原成可落地机制，而不是抽象成"信息 → 资源前置"了事。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / tick / 层数）**一律为占位建议值，统一归类 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达；「翻译/语义」= 为什么这么映射。

>
> **普通档天然偏向 🜁 洞察轴**——这不是失衡，是原著设定：序列9 明写「间接影响，**缺乏直接克敌手段**」，序列8 只有观察能力。本稿普通档**零伤害技能**，第一个伤害技能出现在序列7【狂乱】。这条途径的低序列就该没输出。

### 本途径的核心循环：洞察 → 暗示

原著观众途径的能力结构是有顺序的：**先看清楚（序列9–8）**，**再动手（序列7 起）**。本稿把它落成一个计数资源：

- 状态 **`insight`（心象）**：整场、上限 5 层（【洞察权柄】提到 7 层），作用于自身，**本身不提供任何属性**，只作为消耗品。
- 进：①【观众·细微观察】每次造成精神伤害 +1；②【引导】命中 +1；③【操纵】施放时 +2（"读取想法"）。
- 出：【读心】（消耗 2 层换爆发伤害）、【编织梦境】（消耗 3 层延长封印）。

> 这样"读心者"在卡牌里才真的有玩法：不是"看到隐藏信息"（引擎没有隐藏信息），而是**把看穿的东西换成一次性爆发**。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项编号）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】观众·细微观察 🜁
- **原著** 序列9 观众 —— "出众的精神和敏锐的观察力：从表情举止窥见真实想法"
- **文案** 你看着它的肩膀、它的呼吸、它眨眼的方式——每读懂一次，你心里就多记下一笔。
- **序列** 9 观众 · **hook** `on_deal_damage`（自身对敌方造成 `mental` 伤害时）
- **效果** 自身计数状态 `insight` 层数 +1（上限 5，`duration: null`）
- **翻译/语义** 原著"从表情举止窥见真实想法"在卡牌里没有隐藏信息可看，唯一能留下来的语义是"**看懂了就能用**"。故做成计数燃料，驱动全途径的爆发点。
- ⚠️ 依赖本稿新增项 1（`insight` 计数状态，与 F1 `inscription` 同源）；触发需按伤害元素过滤（🟡，见新增项 17 附注）。数值 ⚠️D。

#### 【被动】出众精神 🜂
- **原著** 序列9 观众 —— "**出众的精神**和敏锐的观察力"
- **文案** 这条途径的低序列之所以能在非凡者环绕中活下来，靠的就是这副精神。
- **序列** 9 观众 · **hook** `on_battle_start`
- **效果** `modify_stat(resist:mental, +20%, duration: null)`（自身常驻）
- **翻译/语义** 原著只给了"出众的精神"四个字，本稿**不发明额外效果**，诚实落地为常驻精神抗性。
- ⚠️ 单抗性是否撑得起一个被动槽存疑，⚠️D；若 D 组判定偏弱，再考虑叠加"自身受到的 control 状态 duration −1 tick"（需新字段，届时代为新增项）。

#### 【主动】间接影响 🜁
- **原著** 序列9 观众 —— "**间接影响**，缺乏直接克敌手段"
- **文案** 你从不亲手伤人——你只是让同伴的脚步，比对手快了半拍。
- **序列** 9 观众 · **能量 1 / cd 2** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: gauge_asc }`
- **效果** `modify_resource(gauge.current, +20, delta)` → 指定的一名**友军**
- **翻译/语义** 原著"间接影响"+"缺乏直接克敌手段"是本稿**最该守住的一条纪律**：序列9 的技能不该有伤害。故做成纯节奏辅助，且是全场最便宜的推条技能（1 能量）。
- ⚠️ **G5 铁律**：绝不能写成 `SELF` 自推条——主动技能在自己回合释放时行动条已清零，自推等于没加。本技能只推**友军**。数值 ⚠️D。

#### 【主动】读心 🜁
- **原著** 序列8 读心者 —— "观察深入气场、以太体，**异常准确地掌握人心**"
- **文案** 你读完了它。接下来的一击，你确切知道该落在哪儿。
- **序列** 8 读心者 · **能量 2 / cd 2** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `Sequence[`
  - `damage(mental, 2)`,
  - `If(self.insight >= 2)` → `status.consume(insight, 2)` + `damage(mental, 6)` + `mount_status(vulnerable, 2t)` 目标`]`
- **翻译/语义** 序列8 是"掌握人心"而非"攻击"。低费、低底伤，**价值全在消耗洞察层后的爆发**——这就是"读心"在卡牌里的体感：先观察，再一击命中要害。不消耗层数时它只是一发亏本的 2 伤，逼玩家真的去走"观察 → 读心"的循环。
- ⚠️ 依赖本稿新增项 1（`insight`）+ 新增项 15（主动技能链中调用 `status.consume`，复用 F48）。数值 ⚠️D。

#### 【被动】气场感知 🜁
- **原著** 序列8 读心者 —— "观察深入**气场、以太体**……在其面前**很难有秘密**"
- **文案** 气场和以太体瞒不了你——藏起来的东西，在你眼里只是颜色深了一点。
- **序列** 8 读心者 · **hook** `on_battle_start`
- **效果** 挂载 `aura_sight`（整场）：敌方 `stealth` / 不可选中类状态**对你无效**；你对处于隐匿 / 不可选中状态的目标造成的伤害 ×1.25
- **翻译/语义** "很难有秘密"在卡牌里唯一可落地的语义是**反隐匿**。与本途径序列1【凡有言必被知】、序列2【洞察权柄】构成三级反隐匿链，本条是最廉价的一级。
- ⚠️ 依赖 C8 候选池过滤（🔴 未实现，已登记，本稿不重立）。与愚者·灵体之线（识破）同源，建议并入同一"识破"分支。数值 ⚠️D。

### 精良（序列 7–6）

#### 【主动】震慑 🜂
- **原著** 序列7 心理医生 —— "『震慑』：使目标**瞬间惊慌混乱**"
- **文案** 你只看了它一眼。它慌了，手上的动作乱了半拍。
- **序列** 7 心理医生 · **能量 2 / cd 3** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `mount_status(眩晕, 2t)` + `modify_resource(gauge.current, -20, delta)`（目标）
- **翻译/语义** "瞬间惊慌混乱" = 短硬控 + 节奏被打断。与【战斗催眠】的区别：震慑是**惊出来的**（便宜、短、附带拖条），催眠是**哄进去的**（贵、长、纯控）。
- 数值 ⚠️D；`gauge.current` 类效果无既有定价锚点（沿用 D2）。

#### 【主动】狂乱 🜂
- **原著** 序列7 心理医生 —— "『狂乱』：**引爆情绪**，精神伤害"
- **文案** 你伸手在它心里那堆乱麻上点了一下——炸开的全是它自己的情绪。
- **序列** 7 心理医生 · **能量 3 / cd 3** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(mental, 4)` + `If(target_has_status: ['debuff','dot','control'])` → `damage(mental, 2)`
- **翻译/语义** **本途径第一个伤害技能，也是唯一符合原著"序列9 无直伤"纪律的位置**。"引爆情绪"= 目标心里越乱炸得越狠，故做成**追击型**：前面挂的 debuff/dot/control 越多，这一下越痛。它是全途径伤害链的收尾键。
- ⚠️ 依赖 F52 `target_has_status`（🟡 已登记，不重立）。数值 ⚠️D。

#### 【主动】心理暗示 🜂
- **原著** 序列7 心理医生 —— "『心理暗示』"
- **文案** 你轻声告诉它：你很弱，你的刀也很钝。它就真的信了。
- **序列** 7 心理医生 · **能量 2 / cd 3** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `dispel(target, category: ['buff'], count: 1)` + `modify_stat(attack, -3, duration: 4)`
- **翻译/语义** 低阶暗示 = **削弱对方的自我认知**：先剥掉它对自己的信心（驱散增益），再压低它的攻击。"降攻"而非"驱增益二选一"，是因为原著暗示的落点是**意识**，而攻击力是意识最直接的产物。
- ⚠️ 依赖 C2 `dispel.category` 数组（✅ 已落地）。数值 ⚠️D。

#### 【主动】安抚 🜂
- **原著** 序列7 心理医生 —— "『安抚（**精神分析**）』"
- **文案** 你把那些压着它的东西一件件拿出来看了一遍——看完，就不疼了。
- **序列** 7 心理医生 · **能量 2 / cd 3** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: hp_asc }`（含自身）
- **效果** `heal 5` + `dispel(target, category: ['debuff','dot'], count: 1)`
- **翻译/语义** 原著把"安抚"和"精神分析"写在同一条里，两段语义都落地：**安抚** = `heal`（**A22 铁律：治疗必须用 `heal` 原语**）；**精神分析** = 把压在潜意识里的东西拿出来 = 驱散负面。这是本途径唯一的治疗技能，也是它"低序列不伤人但能救人"的人设锚点。
- ⚠️ 依赖 C2（✅）。治疗量 ⚠️D。

#### 【主动】战斗催眠 🜃
- **原著** 序列6 催眠师 —— "『**战斗催眠**』"
- **文案** 战阵之上，你的声音低了下去。它也跟着低了下去，然后就不动了。
- **序列** 6 催眠师 · **能量 3 / cd 4** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(眩晕, 3t)`
- **翻译/语义** 纯硬控、无附加。比【震慑】贵 1 能量、长 1 tick，但没有拖条——**控得久，伤不到节奏**。控场轴的骨架件。
- 数值 ⚠️D。

#### 【主动】心理学隐身 🜂
- **原著** 序列6 催眠师 —— "『**心理学隐身**』"
- **文案** 你没有消失。你只是从所有人的意识里，被轻轻地漏掉了。
- **序列** 6 催眠师 · **能量 2 / cd 4** · `targetSpec: SELF`
- **效果** `mount_status(psych_invisibility, duration: 2t)`：`target_exclusion: true`（敌方单体技能无法选中你）；触发器 `on_deal_damage` → 立即卸载（一出手就暴露）
- **翻译/语义** 原著这条是**心理学**隐身，不是光学隐身——所以破除条件是"你主动出手"而不是"被打中"。这条区分让它与潜行类状态有明确辨识度。
- ⚠️ 依赖本稿新增项 4（与 F11 `stealth` / F4 `shadow_veil` 同源，建议并入统一潜行母版）+ C8（🔴）。数值 ⚠️D。

#### 【主动】心理暗示·质变 🜂
- **原著** 序列6 催眠师 —— "『心理暗示』**质变：直接修改意识、影响潜意识**"
- **文案** 你没跟它讲道理。你直接走进去，把"谁是敌人"那一栏改掉了。
- **序列** 6 催眠师 · **能量 4 / cd 5** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(subconscious_edit, duration: 5t)` + `damage(mental, 2)`
- **机制** 持有者发动攻击时，`target` 被强制改写为**其同阵营存活友军**（`hp_desc`，`index_asc` 破平）；`subconscious_edit` 优先于嘲讽 / 守护。
- **翻译/语义** 原著序列7 的暗示只是"劝"，序列6 是"**改**"。卡牌里能表达"直接修改意识"的最强手段就是**改写它的攻击对象**——不是拉仇恨（它仍然在打，只是打错了人）。这是本途径与愚者·秘偶 / F9 `puppet_string` 的同源点，但落点不同：愚者是**牵灵体之线**（物理层面的牵引），本途径是**改潜意识里的敌我认定**（认知层面），所以本稿命名为 `subconscious_edit` 而非复用 `puppet_string`，并让它可以被【心灵权柄】加固为不可驱散。
- ⚠️ **G15-b 合规**：触发器走**「单位发动攻击」即时节点**（本稿新增项 3），**不用 `on_turn_start`**，因此不受"duration 必须 ≥ 目标行动周期"约束，`duration: 5t` 只是存续上限而非触发窗口。依赖 C7（✅ 已验证）扩展到"指向己方阵营内单位"。数值 ⚠️D。

- ⚠️ 依赖新增项 17（**"按另一状态层数给伤害乘区"是新的乘区表达方式**，🔴/🟡 待定）。数值 ⚠️D。

#### 【主动】巨龙 🜄
- **原著** 序列2 洞察者 —— "『**巨龙**』（可化为真正巨龙）"
- **文案** 这一次不是像了。这一次，你自己就是那条龙。
- **序列** 2 洞察者 · **能量 5 / cd 6** · `targetSpec: SELF`
- **效果** `mount_status(dragon_true_form, duration: 5t)`：`modify_stat(attack, +6)` + `modify_stat(armor, +10)` + `modify_stat(gauge_rate, +8)`；攻击附带 `spread: splash_adjacent`（对目标相邻单位追加 50% 伤害）
- **翻译/语义** 空想轴三级龙链的**第三级**。原著特意写"**真正**巨龙"以区别于序列4 的龙化，故本稿让它带溅射——"巨"的体感来自一次攻击扫到一片。龙鳞（常驻护甲）/ 龙化（攻+甲+速率）/ 巨龙（翻倍 + 溅射）构成一条完整的成长链。
- ⚠️ 依赖新增项 9 + 溅射参数（需确认 `spread: splash_adjacent` 已存在，若否则列为新增项）。数值 ⚠️D（+6 攻 / +10 甲远超单卡纪律，靠 5 能量 + cd 6 + 5t 存续 + 史诗稀缺性平衡）。

### 传说（序列 1–0）

#### 【主动】书写成真 🜄 ★
- **原著** 序列1 作家 —— "『**书写成真**』：书写的故事变成现实"
- **文案** 你写下："三息之后，它会睡着。"然后合上本子——这件事就已经发生完了，只是还没走到那一步。
- **序列** 1 作家 · **能量 5 / cd 7** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(written_truth, duration: 3, dispelable: false)`；触发器 `on_remove`（**自然到期**）→ 执行已记录的载荷，例如：
  - 变体·沉睡：`mount_status(眩晕, 3t)`
  - 变体·终章：`damage(mental, 12)`
  - 变体·痊愈（对友军）：`heal 12`
- **翻译/语义** 「书写成真」是本途径**机制自由度最高**的一条权柄，本稿把它落成一个可复用的引擎模式：**记录一段文字，若干 tick 后强制生效**。三个设计要点让它在引擎里成立且可控：
  1. `dispelable: false` —— 写下的东西不能被擦掉，**唯一的出口是时间到**（所以 `on_remove` 只会被"自然到期"触发）；
  2. 用 `on_remove` 而非 `on_tick` 计数——不新增任何计时机制；
  3. 载荷是数据（变体表），不进引擎。
  这是"言出法随"在确定性引擎里最干净的表达：不是掷骰子，是**已经写好了，只是还没翻到那一页**。
- ⚠️ 依赖新增项 10；需确认 `on_remove` 在 duration 自然到期时 fire（与 G10 的 `charges` 消耗卸载是不同 reason，需区分）。数值 ⚠️D（**本稿定价最难的一项**：延迟伤害的贴现率无既有锚点）。

#### 【主动】空想具现 🜄
- **原著** 序列1 作家 —— "『**空想**』权柄：**将概念拉入现实变成真实事物**"
- **文案** 你想到了"一个能挡在我前面、并且很生气的东西"。于是它就站在那儿了。
- **序列** 1 作家 · **能量 6 / cd 8** · `targetSpec: SELF`
- **效果** `spawn(unit_imagined, hpRatio: 0.6, atkRatio: 0.8, position: 'tail')`
- **翻译/语义** 原著写的是"**概念**拉入现实"，所以这个召唤物不是分身、不是亡灵、不是幻影——它是一个被想出来的东西，本稿取名 `unit_imagined`。与【身份分离】的区别：身份分离体**会你的技能**（来自你的过去），空想造物**只有很高的属性**（来自你的想象）。
- ⚠️ 依赖新增项 14；复用 C5（✅）。⚠️ **A2**：召唤物登场 fire `on_spawn`，禁挂开局语义。与 F 组合并候选 7 同源。数值 ⚠️D。

#### 【被动】凡有言必被知 🜁
- **原著** 序列1 作家 —— "『**凡有言必被知**』：知道『作家』者，作家也知道他"
- **文案** 它一开口，你就知道了它是谁；它一出手，你就知道了它所有的底细。藏是藏不住的。
- **序列** 1 作家 · **hook** `on_battle_start`
- **效果** 挂载 `all_spoken_known`（整场）：
  - 敌方 `stealth` / 不可选中类状态**对你无效**
  - 你对处于隐匿 / 不可选中状态的目标造成的伤害 **×1.3**
  - 触发器 `on_take_damage`（自身）→ `modify_resource(energy, +1, delta)`（"它一出手，你就读到了它"）
- **翻译/语义** 原著是一条**双向**的知晓律：你被知道 = 它被知道。卡牌里"知道"没有价值，故落为三件事：**反隐匿**（它藏不住）+ **反制隐匿者的增伤**（藏反而更亏）+ **受击读心**（它一出手就泄露信息 → 你回能量）。最后一条让它在被动槽里真正产生收益，而不只是一条静态过滤器。
- ⚠️ 依赖新增项 12 + C8（🔴）。与【气场感知】是同族三级链的两端（本条为最高级）。数值 ⚠️D。

#### 【主动】宣告未来 🜄
- **原著** 序列0 空想家 —— "『空想』权柄：……**所宣称的未来必将上演**"
- **文案** 你没有祈祷，也没有攻击。你只是当着所有人的面说了出来："四息之后，你们都会倒下。"——那就一定会倒下。
- **序列** 0 空想家 · **能量 8 / cd 10** · `targetSpec: ALL_ENEMIES`
- **效果** `mount_status(declared_fate, duration: 4, dispelable: false)`（全体敌方）；触发器 `on_remove`（自然到期）→ `damage(mental, 8)`（全体敌方）
  - 期间：己方全体获得 `mount_status(fortify, 4t)`（"我宣称我们会赢"——先让未来在场上有迹可循）
- **翻译/语义** 【书写成真】的权柄级放大版：单体 → 群体，且**宣告期间友军先获得守护**，让"未来必将上演"在视觉上先有预兆。与【书写成真】共用同一套"延迟强制生效"底层（新增项 10），是本途径的终局牌。能量 8 / cd 10 + 传说稀缺性（一局 ≤1）是唯一的平衡手段。
- ⚠️ 依赖新增项 10。数值 ⚠️D（**本稿最高风险数值项**，建议先用最保守值上线并单独观察）。

#### 【被动】心灵权柄 🜂
- **原著** 序列0 空想家 —— "『**心灵**』权柄：**心灵世界之主**"
- **文案** 在心灵的世界里，你写下的东西没有人有资格擦掉。
- **序列** 0 空想家 · **hook** `on_battle_start`
- **效果** 挂载 `lord_of_mind`（整场）：
  - 你施加的 `control` 类状态（`subconscious_edit` / `眩晕` / `沉默` / `drawn_in`）**不可被驱散**（运行时覆写 `dispelable: false`）
  - 你对处于 `control` 状态的目标造成的 `mental` 伤害 ×1.25
- **翻译/语义** "心灵世界之主"= 对你施加的东西有绝对支配权。落地为两条：**你的控制解不掉**（绝对性）+ **被你控住的人更脆**（支配）。后者同时给【狂乱】的追击分支提供了稳定的触发面，让高序列被动真正盘活低序列技能。
- ⚠️ 依赖新增项 11（运行时覆写 `dispelable`，与愚者途径 v0.2 新增项 9 同源，**建议并入同一母版**）。数值 ⚠️D。

#### 【被动】特性分离 🜄
- **原著** 序列0 空想家 —— "可分离两份序列1特性，**空想出特性代替，保持位格不降**"
- **文案** 你撕下自己一半的特性丢在原地，让它替你碎掉。真正的你在三步之外，睁开了眼睛。
- **序列** 0 空想家 · **hook** `on_death`（自身）
- **效果** `mount_status(sealed_identity, charges: 1, duration: null)`；触发器 `on_death` → `spawn(reviveOf: self, hpRatio: 0.4, position: '原坐标')`，`charges - 1`；归零后不再触发
- **翻译/语义** 原著这条是空想家的**保位格**机制：丢掉一份特性、凭空想出一份顶上，所以位格不掉。卡牌里最贴的表达就是**用一次死亡换一次归来**，而且 flavor 上"碎片留在原地"正好对应 `position: '原坐标'`。

## 四、本稿遗留

1. **数值全档待标**：35 个技能的能量 / 伤害 / tick / 层数均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中 `gauge.current`（震慑 / 间接影响 / 梦境迷宫）与 `gauge_rate`（龙化 / 巨龙）类技能无既有定价锚点，是最大盲区（沿用 D2）。
2. **AoE 精神伤害的三处高风险点**：【心灵风暴】（AoE 3 伤 + 群体眩晕 1t）、【修改】（满层 12 伤 / 2 能量）、【瘟疫风暴】（AoE 传染）。**这三条是优先标定项**，滚雪球风险最高。
3. **【书写成真】/【宣告未来】的延迟贴现率**无既有锚点：3 tick 后的 12 伤与当下的 12 伤不是一回事，需先定延迟效果的折扣曲线，否则这两张牌会长期失衡。
4. **洞察层数的经济未标定**：进账（细微观察 / 引导 / 操纵）与出账（读心 / 编织梦境）的速度比需要实测，否则会出现"层永远用不完"或"层永远攒不够"两个极端。
5. **未单独成技能的原著能力**（有意合并，附理由）：
   - 序列4「**心灵吐息**」→ 并入【心灵风暴】的升级阶梯（B6 变体：直线 / 前排双目标高伤 + 沉默）。
   - 序列7「**读心**」与序列8 读心者同义 → 由【读心】（序列8）统一承载，不重复占位。
   - 序列0「**洞察**」权柄与序列2「洞察」权柄同名 → 由【洞察权柄】（序列2）统一承载，不重复占位。
   - 序列6「**龙鳞**」/ 序列4「**龙化**」/ 序列2「**巨龙**」→ 对照表未标明是否同一能力的递进，本稿按**递进**处理，三级各自入池（一级被动 + 两级主动）。
   - 序列5「**引导**」的"说出秘密"信息维度 → 卡牌无隐藏信息，语义并入【读心】的洞察层获取与【引导】的降防。
6. **【出众精神】强度存疑**：单条 20% 精神抗性可能撑不起一个被动槽，待 D 组判定是否需补效果（补则需新字段，届时代为新增项）。
7. **【虚拟人格】层数待决**：原著 13 个人格，本稿先锁 3 层占位，需按"一局平均吃到几次控制"反推。
8. **【特性分离】次数待决**：原著未给次数，本稿按 1 次占位；原著"分离**两份**序列1特性"字面上暗示 2 次，待拍板。
