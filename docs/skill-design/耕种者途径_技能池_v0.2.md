灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **耕种者途径**（源质：母巢，旧日「堕落母神」，序列0 母亲，相邻：药师）。

> **本版定位**：v0.2 是**原著校准版**。相比 v0.1 主要做三件事——
> ① 逐序列比对原著能力表，把 v0.1 完全没做的招牌能力（力气、预测天气、分辨培育种子、外科手术 / 缝合灵魂 / 给予生命、催化种子、驱使植物和虫豸、祈雨祈晴仪式、杂交造物、自身剧毒、化身巨熊、地底潜行 / 沼泽 / 自然憎恶 / 橡树之子、生命炼成、恶灵化、剥夺生命、回归大地、荒芜、人偶制造材质五档、自然之子、创造世界、母亲 / 大地 / 自然三权柄）全部落地；
> ② 剔除 v0.1 里凭空发明的原著外能力（「丰饶直觉」开局能量、「大地恩赐 / 母巢降生」的 `max_hp` 堆叠、「净化药剂 / 贤者之药」两张三清卡、「生命转化」吸血、「自然之怒」全体眩晕等，在原著对照表里均无出处；且「沃土」「医者本能」挂在 `on_turn_start` 上，是 **G15** 死触发点，当前完全不生效）；
> ③ 把 v0.1 里被抽象掉的「**生长 ↔ 荒芜**」双面体还原成本途径真正的骨架——这是耕种者途径区别于其他治疗途径的根本，v0.1 只做了一层薄薄的 DOT。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 治疗量 / 时长 / 层数 / 召唤物属性）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是「技能效果」**，不是数值。

> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。

> **本途径的设计主轴：生长与荒芜是同一件事的两面。**
> 原著里序列7「丰收祭司」与序列2「荒芜主母」是同一条途径的两站，序列0 的下位权柄更是把「荒芜」与「丰收」并列写在一起。所以本稿刻意让 🌾 丰饶与 ☠ 荒芜**互相咬合**而不是各走各的：
> - 【催化种子】长出的藤蔓缠住敌人，【荒芜】让敌人的生命流逝；
> - 【枯荣循环】把敌方身上的每一道 DOT 直接换算成己方的治疗 —— 这是两轴唯一的**直接耦合件**，没有它，丰饶与荒芜只是两条平行线；
> - 【最后回归之地】一张卡同时做两件事：让敌人的生命回归大地、让己方的死者从大地里爬回来。
>
> 技能总量 **34 个**（主动 24 / 被动 10）。耕种者途径在原著里的能力密度极高——单是序列5 德鲁伊就有「化身巨熊 + 四个大地系法术」五项、序列7 有四项、序列2 有四项，要「遵照原著」就必须给足覆盖；单局构筑密度由派发权重控制，池子大小不影响 4+4 槽位。

### 核心机制：材质阶梯（【人偶制造】专用）

原著序列2「荒芜主母」白纸黑字把人偶制造的材质写成了 **泥土 / 植物 / 岩浆 / 矿石 / 金属** 五档递进。这是本途径最有味道的造物机制，做成**随施放次数自动升档**的阶梯，而不是让玩家手动选（手动选会退化成「永远带金属」，递进的味道全丢）。

载体是计数型状态 `matter_ladder`（初始 1 档，每施放一次【人偶制造】+1，上限 5，同场战斗内不重置）：

| 档 | 材质 | 属性建议（⚠️D） | 元素 | 自带特性 |
|---|---|---|---|---|
| 1 | **泥土** | hp 18 / atk 3 | `physical` | 亡语 → 相邻敌方 `gauge_rate ×0.85`（2t，泥泞拖足） |
| 2 | **植物** | hp 20 / atk 4 | `poison` | 自带 `再生`（1/tick，整场） |
| 3 | **岩浆** | hp 22 / atk 5 | `fire` | 自带 `反伤 2` |
| 4 | **矿石** | hp 26 / atk 5 | `physical` | 自带 `armor +8` |
| 5 | **金属** | hp 24 / atk 7 | `shock` | 自带 `gauge_rate +8`（锋利迅捷） |

**规则三条**

| 规则 | 说明 |
|---|---|
| ① 自动升档 | 每次施放【人偶制造】推进 `matter_ladder` 一档；到 5 档后保持金属档不再升 |
| ② 未持阶梯则取泥土 | 若施法者身上没有 `matter_ladder`（例如退化方案下只做一档），固定召唤泥土人偶 —— 保证单卡可成立，不成为升级件的专属配件 |
| ③ 旧人偶不换材质 | 阶梯只影响**新召唤**的那一只；场上已有的人偶保持召唤时的材质。这条是刻意的：场上同时出现泥土人与金属人，才有「造物谱系」的画面感 |

> ⚠️ 本机制依赖 `spawn.variant`（按状态选择单位变体）+ 计数型状态（本稿新增项 3 / 19，🔴）。**退化方案见【人偶制造】条目**：先上「固定一档 + 其余四档列为 B6 升级阶梯分叉」验证手感，是推荐路径。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；⚠️D = 数值为占位建议值；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【主动】力气 🌾
- **原著** 序列9 耕种者 —— 「力气变得很大」
- **文案** 你握惯了锄头的手攥紧拳头——这一下，和抡了十年镐头没什么两样。
- **序列** 9 耕种者 · **能量 2 / cd 2** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 4)` + `modify_stat(attack, +2, duration: 3)`（自身，「活动开了」）
- **翻译/语义** 原著低序列唯一的攻击手段就是「力气大」，故做成纯物理直伤，定位本途径的「火球术」。4 伤 / 2 能 = 2.0 汇率，高于 1.2 基准——这是刻意的：本途径前四个序列除「力气」外**再无任何攻击手段**，这张卡要独自撑起输出骨架（同愚者【飞牌】的处理逻辑）。自带一段小加攻表现「越抡越有力」。⚠️D。
- **升级阶梯**（B6）伤害 4 → 6 → 8；或解锁「连枷」（两段 `damage(physical, 3)`）。

#### 【被动】预测天气 🌾 ★
- **原著** 序列9 耕种者 —— 「能通过自然现象预测天气」
- **文案** 你抬头看了一眼云——它们比你更早知道接下来会发生什么。
- **序列** 9 耕种者 · **hook** `on_battle_start`（**A1 已落地 ✅**）
- **效果** `modify_resource(gauge.current, +15, delta)` → `{ faction: ALLY, spread: all_allies }`；并挂载 `weather_omen`（整场）：己方全体 `modify_stat(gauge_rate, +4, duration: null)`
- **翻译/语义** 预测 = 提前量 → 译成节奏（brief §3：信息类能力在卡牌里不值钱，真正的收益是「提前」）。
- **为什么这里可以推条（G5 / G6 的边界）**：G5/G6 禁的是「主动技能在自己回合给自己推条」——此时行动条刚刚清零，自推后立刻重填，等于没加。本条是 `on_battle_start` **被动**，fire 在调度开始之前、所有单位的行动条尚未推进，推条真实有效。且推的是**全体友军**而非仅自身，双重规避 G5/G6。这是本途径唯一一条「先手」类效果，其余一律不做自推条。⚠️D。

#### 【主动】分辨种子 🌾
- **原著** 序列9 耕种者 —— 「擅于分辨培育种子」
- **文案** 你在掌心挑出一粒最饱满的种子，把它按进同伴的伤口里——三天后它会自己长成一棵树。
- **序列** 9 耕种者 · **能量 2 / cd 3** · `targetSpec: { faction: ALLY }`（Manual，fallbackSort: `hp_asc`）
- **效果** `mount_status(cultivated, duration: 3)`；触发器 **`on_remove`**（种子成熟）→ `modify_stat(attack, +3, duration: 4)` + `heal(4)`
- **翻译/语义** 「分辨 + 培育」= 选中一个对象、延时后兑现收益。用 `on_remove` 表达「种子成熟」是本稿翻译得最干净的一条：挂载即埋下，到期卸载即破土。`on_remove` ✅ `combat.ts:320` 已 fire。
- ⚠️ 需确认 **duration 自然到期**时同样走 `on_remove` 分支（本稿新增项 14，🟡）。⚠️D。

#### 【主动】治疗 ✚
- **原著** 序列8 医师 —— 「『治疗』（核心）：灵视判断病情，出色外科手术」
- **文案** 你的灵视一眼看穿病根在何处，刀口随之落下——该切的切掉，该缝的缝上。
- **序列** 8 医师 · **能量 2 / cd 2** · `targetSpec: { faction: ALLY }`（Manual，fallbackSort: `hp_asc`）
- **效果** `Sequence[ heal(4), dispel(target, category: ['dot','debuff'], count: 1) ]`（**C2 数组已落地 ✅**）
- **翻译/语义** 原著两条语义一并落地：① 灵视判断病情 → 治疗顺带摘掉一处病根（驱散 1 个负面）；② 出色外科手术 → 精准（用 `Sequence` 保证治疗与清创在同一次施法内完成，不是两件事）。
- **A22**：治疗必须走 `heal` 原语，不得用 `modify_resource(hp, +N)` 顶替——本途径是治疗大户，此条全稿适用。
- **刻意留档**：本卡只清 `dot` / `debuff`，**不清 `control`**（眩晕 / 沉默）。清控制要等序列4 的【触碰痊愈】。⚠️D。

#### 【主动】外科手术 ✚
- **原著** 序列8 医师 —— 「出色外科手术」
- **文案** 你的刀比谁都清楚该往哪里切——伤口开得精准，之后的每一次打击都会更深。
- **序列** 8 医师 · **能量 3 / cd 3** · `reach: melee` · Manual（fallbackSort: `atk_desc`）
- **效果** `damage(element: physical, 3)` + `mount_status(易伤, duration: 3)`
- **翻译/语义** 同一句原著在**敌方**身上的那一面：外科手术 = 精准切开 → 易伤（复用既有状态，不新立）。与【力气】的区分是刻意的：**力气**是纯直伤 + 自身加攻（自用），**外科手术**是直伤 + 易伤（为全队铺增伤）。两卡构成低序列「自己打」与「帮队友打」的选择。⚠️D。

#### 【被动】缝合灵魂 ✚ ★
- **原著** 序列8 医师 —— 「缝合灵魂」
- **文案** 灵魂裂开的那一瞬，你伸手把它缝了回去——线是用麦秆搓的，很土，但很牢。
- **序列** 8 医师 · **hook** 挂载于自身，触发器监听**任意友军**的 `on_take_damage`
- **效果** 挂载 `soul_stitch`（`charges: 1`（**C6 已落地 ✅**），`duration: null`）：触发器 `on_take_damage`（目标为任一友军）→ `If(该次伤害将致其死亡)` → **中断死亡**、保留 1 血 + `heal(3)`，随后 `charges - 1` 归零卸载（每场一次）
- **翻译/语义** 「缝合灵魂」是把**已经碎掉**的灵魂缝回去，所以语义是**阻止死亡**，不是死后召回——这与 C4 `miracle`（死后 `spawn` 召回）方向相反，二者不可互换。用 C6 `charges: 1` 表达「只缝得了一次」。这是治疗轴的旗舰保命件，也是本途径在普通档唯一的硬保命。
- ⚠️ 依赖 `lethal_protect`（🔴，本稿新增项 2）——**与愚者途径 v0.2 新增项 1（纸人替身 / 秘偶不死）、药师途径 v0.2 新增项 7（月光化 / 月亮纸人 / 蝙蝠分解 / 生命之权）需求完全一致，务必并入同一母版**，否则跨途径会出现三套致死保护实现。⚠️D。

#### 【主动】给予生命 ✚
- **原著** 序列8 医师 —— 「给予生命」
- **文案** 你把一口气吹进同伴的胸膛——那口气在它体内生了根，开始自己长。
- **序列** 8 医师 · **能量 3 / cd 4** · `targetSpec: { faction: ALLY }`（Manual，fallbackSort: `hp_asc`）
- **效果** `Sequence[ heal(3), mount_status(再生, duration: 3) ]`（既有 `再生`：2/tick × 3t = 6）
- **翻译/语义** 「给予生命」≠「治疗伤口」——原著把两者分开列，语义是**灌入生命力**而非修补破损。故做成「即时小治 + 持续再生」两段，与【治疗】的「瞬发 + 清一处负面」形成对照：前者救急，后者养人。⚠️D。

### 精良（序列 7–6）

#### 【主动】催化种子 🌾 ★
- **原著** 序列7 丰收祭司 —— 「『催化种子』：30 米范围植物加速生长 / 制造藤蔓纠缠」
- **文案** 你往地里丢了一把种子——它们疯长成藤，缠住了敌人的脚踝；而藤蔓的荫凉下，同伴的伤正在愈合。
- **序列** 7 丰收祭司 · **能量 3 / cd 4** · 双目标（己方召唤位 + 敌方 Manual fallbackSort: `gauge_desc`）
- **效果** `Sequence[ spawn(unit_vine, position: 'tail')（己方）, mount_status(vine_snare, duration: 3)（敌方单体） ]`
- **翻译/语义** 原著这一条其实是**两件事**：① 植物加速生长（造物/生长）→ 己方召唤一株藤蔓；② 制造藤蔓纠缠（控制）→ 敌方被定住。v0.1 只做了「催熟 = 坚守 + 小治」，把原著的两面全丢了；本稿一张卡同时落地两面，不做取舍。
- **机制** `vine_snare`（藤蔓纠缠）：无法被任何 `move` 影响 + `gauge_rate ×0.75`（**乘算，INV-S5 合规**——改的是速率源属性，不是派生的行动周期）+ `attack -2`；`duration: 3`；`category: ['debuff','control']`；`dispelable: true`。
- ⚠️ 依赖：新单位 `unit_vine`（本稿新增项 11）+ `move_immune` 字段（**与 F7 `shackle` / 愚者稿新增项 6 同源**）。**与 F7 的关系**：F7 是单体 2t 强控（`gauge_rate ×0.7`），本条是单体 3t 中档（×0.75 + 减攻），建议并入同一「参数化地形控制」母版。⚠️D。

#### 【主动】驱使虫豸 🌾
- **原著** 序列7 丰收祭司 —— 「驱使植物和虫豸」
- **文案** 你蹲下来和它们说了几句话。然后它们就从地缝里涌出去了，密密麻麻。
- **序列** 7 丰收祭司 · **能量 3 / cd 4** · `consumption: summon`
- **效果** `spawn(unit_vermin, position: 'tail')`

- **翻译/语义** 原著是「死者变恶灵」，本途径的恶灵来源必须是**敌方死者**。这与收尸人途径的死灵召唤是**根本不同的两件事**，必须划清：收尸人的 `unit_skeleton` / `unit_zombie` 是从己方「存量」里拉起来的部队（F34 / F35），本条的 `unit_wraith` 是战斗中**现杀现转**的增量。二者不可互换，也不应共享 `sharedAcross`——否则两条途径的亡灵线会糊成一条。
- ⚠️ 两点：① 复用 **F25 `unit_wraith`**（不眠者 / 收尸人已登记），但该条目本身挂着「两稿属性冲突（hp 8/atk 3 vs hp 16/atk 4）」的警示，**汇总时必须定档**；② 原著是「10 公里范围内**所有**死者」，本稿退化为「**你击杀的**单位」（走 `on_kill`）。完整版需要全局 `on_death` 第三方监听（本稿新增项 1，🔴）——见「四、本稿遗留」。⚠️D。

#### 【主动】剥夺生命 ☠
- **原著** 序列3 抬棺人 —— 「『剥夺生命』：击中目标使其接受死亡考验」
- **文案** 你的手落在它肩上，它的生命开始倒数。通不过这场考验的，就不必再留着了。
- **序列** 3 抬棺人 · **能量 4 / cd 5** · Manual（fallbackSort: `hp_asc`）
- **效果** `Sequence[ damage(element: none, 3), mount_status(death_trial, duration: 3) ]`
- **机制** `death_trial`（死亡考验）：`on_tick` → `damage(element: none, 1)`（生命流逝）；另带条件触发器 `on_tick` → `If(目标生命% < 25%)` → `damage(element: none, 6)`（考验失败）并卸载自身，**每场对同一目标只结算一次**
- **翻译/语义** 原著「接受死亡考验」= 一次**判定**：撑得住就活，撑不住就死。用既有的 `If` 算子 + `TargetHpBelow` 条件谓词（谓词集已存在，愚者稿【灵界掌控者】用过）落地，**不新造「处决」机制**——这一点是刻意的：新造 execute 会引入一整套优先级与免疫规则，收益却只服务于这一张卡。「考验」本体做成 3 tick 的持续流逝 + 一次阈值爆发，让对手有 3 个 tick 的时间去治疗、去驱散，这才是「考验」该有的样子。
- **元素取 `none`**：荒芜 / 死亡不是任何一种元素伤害，用 `none` 可避免与既有抗性维度（`resist:*`）耦合，也让【大地权柄】的 none 增伤能覆盖它。⚠️D。

#### 【主动】回归大地 ☠
- **原著** 序列3 抬棺人 —— 「『回归大地』：死灵类生物迅速消散」
- **文案** 你敲了敲地面。那些本该躺在土里的东西，忽然记起了自己该在哪儿。
- **序列** 3 抬棺人 · **能量 3 / cd 4** · Manual（fallbackSort: `hp_desc`）
- **效果** `If(目标 unitClass ∈ { undead, spirit, death_construct })` → `Sequence[ damage(element: none, 10), dispel(target, category: ['buff'], count: all), mount_status(revive_blocked, duration: null) ]`；`else` → `damage(element: none, 3)`
- **翻译/语义** 原著明写是**对死灵类的特化克制**，故做成「条件式巨额伤害 + 不许再起来」。它的价值不在真空强度，而在**环境定位**：对收尸人 / 不眠者 / 秘祈人这类亡灵铺场途径是定向 counter。非亡灵目标只有 3 点伤害（远低于 3 能量的 6 伤基准）——这是刻意的低效率，强迫玩家在出牌前先判断「它是不是死灵」。
- ⚠️ 依赖：① 按单位类别过滤 `unitClass`（本稿新增项 10，与药师稿同源）；② `revive_blocked` 标记（**与愚者稿新增项 11 同源**，建议并入同一实现）。⚠️D。

#### 【主动】荒芜 ☠ ★
- **原著** 序列2 荒芜主母 —— 「『荒芜』：30 公里范围所有生命飞快流逝至死」
- **文案** 你不再催生任何东西。于是这片土地上的一切，都开始往回走。
- **序列** 2 荒芜主母 · **能量 5 / cd 6** · `targetSpec: { faction: ENEMY, spread: all_enemies }`
- **效果** `mount_status(blight, duration: 4)`（敌方全体）
- **机制** `blight`（荒芜）：`on_tick` → `damage(element: none, 2)`（4t × 2 = 8，全体）；`heal_received_mul: 0.5`（连治愈都在流逝）；`category: ['dot','debuff']`；`dispelable: true`；**刷新 duration 不叠层**
- **翻译/语义** 「生长 ↔ 荒芜」双面体的另一面：【催化种子】【繁衍生长】让生命变多，本条让生命飞快流逝。原著强调「**所有**生命」→ 敌方全体（30 公里的折算见「四、本稿遗留」）；「**流逝至死**」是**过程**而不是结果，故做成 DOT 而非一次性 AOE——一次性 AOE 就没有「流逝」的体感了。
- ⚠️ `heal_received_mul: 0.5` **与 F20 `petrify`（通识者·结晶，已登记 0.5）同源，直接复用同一字段，不另立**。⚠️D。

#### 【被动】大地权柄 ☠
- **原著** 序列2 荒芜主母 —— 「部分『大地』『荒芜』『丰收』『生命』权柄」
- **文案** 你脚下踩着的不只是土——是起源，也是终点。你的枯萎比别人的更久，你的收成比别人的更多。
- **序列** 2 荒芜主母 · **hook** `on_battle_start`
- **效果** 挂载 `earth_authority`（整场）：① 你施加的 **`dot` 类状态** `duration +1`（荒芜得更久）；② 你造成的 **`none` 元素**伤害 ×1.15（大地 / 荒芜不属任何元素，自成一路）
- **翻译/语义** 原著把四条「部分权柄」（大地 / 荒芜 / 丰收 / 生命）写在同一行。本稿按两面切分：**大地 + 荒芜**落在这条（枯萎强化），**丰收 + 生命**落在【生命充盈】【万物母巢】（生长强化）。这是荒芜轴的**乘区引擎**——没有它，【荒芜】【剥夺生命】【回归大地】在后期会因为数值不涨而被淘汰。
- ⚠️ 依赖：① `status_duration_bonus`（施法者侧，**与药师途径 v0.2 新增项 2 同源**）；② 按元素过滤的伤害乘区（**与愚者途径 v0.2 新增项 14 同源**；退化方案：改为「你的全部伤害 ×1.08」，代价是失去元素区分、且会误伤非荒芜技能）。⚠️D。

#### 【主动】人偶制造 🧪 ★
- **原著** 序列2 荒芜主母 —— 「人偶制造扩展至泥土 / 植物 / 岩浆 / 矿石 / 金属」
- **文案** 泥土捏的人偶还在往下掉渣，而你已经在想下一个该换什么材质了。
- **序列** 2 荒芜主母 · **能量 5 / cd 6** · `consumption: summon`
- **效果** `Sequence[ spawn(unit_doll, variant: <`matter_ladder` 当前档位>, position: 'tail'), advance(matter_ladder, +1) ]`；材质按「核心机制：材质阶梯」表取值
- **翻译/语义** 原著序列2 把材质**明写**为「泥土 / 植物 / 岩浆 / 矿石 / 金属」五档递进。这是本途径最有味道的造物机制，做成随施放次数**自动升档**的阶梯，而不是让玩家手动选——手动选会退化成「永远带金属档」，递进的味道全丢。自动升档则让每一次施放都有「这次会出什么」的期待，且天然形成「前期泥人拖住、后期金属收割」的节奏曲线。
- **与【生命炼成】的分工**：生命炼成是「**生命**的炼成」（血肉造物：人类 / 魔像，会死、有亡语），人偶制造是「**材质**的制造」（无机造物：泥土→金属，属性由材质决定）。原著把它们放在序列4 与序列2 两站，本稿据此分开。
- ⚠️ 依赖 `spawn.variant`（按状态选择单位变体）+ 计数型状态 `matter_ladder`（🔴，本稿新增项 3 / 19）。**两条退化方案（推荐先走 ②）**：① 不新增 `spawn.variant`，把五档写成 5 个固定 `spawn` + `If(matter_ladder >= n)` 串联（引擎侧零改动，代价是配置冗长）；② **只做一档固定材质（泥土）**，把其余四档列为 **B6 升级阶梯分叉**——先用最小成本验证「造物流」的手感，材质阶梯留到下个里程碑。⚠️D。

#### 【被动】枯荣循环 ☠🌾 ★
- **原著** 序列2 荒芜主母「部分『丰收』『生命』权柄」+ 序列0 下位「荒芜」「丰收」并列
- **文案** 它们枯萎的地方，你们的种子正破土而出——同一片土地，只换了一只看它的眼睛。
- **序列** 2 荒芜主母 · **hook** `on_tick`
- **效果** `on_tick` → `If(场上存在处于 `dot` 状态的敌方单位)` → `heal(1)` → `targetSpec: ally_lowest_hp`（**F60 已登记 🟢**）
- **翻译/语义** 本途径「生长与荒芜」双面体的**机制化出口**：敌人身上每有一个正在流逝的生命，己方最虚弱者就回一点血。这条是四轴之间**唯一的直接耦合件**——没有它，🌾 丰饶与 ☠ 荒芜就只是两条互不相干的平行线，本途径也就退化成「一个会加血也会放毒的普通治疗职业」。有了它，【荒芜】从纯输出卡变成「输出即治疗」的引擎，玩家会主动去铺 DOT。
- ⚠️ **本稿最大的数值盲区**：`on_tick` 是每 tick fire（敏捷 0 的单位约 5 tick 才行动一次），「每 tick 回 1」换算成「每个自身回合回 5」，量级可能远超预期。需按 `on_tick` 频率重标，或改为「每 2 tick」/「每 tick 回 0.4（取整累积）」。⚠️D，见「四、本稿遗留」。

- **翻译/语义** 原著序列0 的两条权柄各拆一半：「孕育万物」= 每一次登场都被包裹（①）；「最后回归之地」= 每一次死亡都反哺生者（②）；「生命起源」= 开局全体厚血（③）。这是治疗轴与丰饶轴的共同顶点，也是本途径**唯一一条同时踩住「生」与「死」两端**的被动——有了 ②，【枯荣循环】的「以死养生」才从技能层面的技巧升格为途径层面的主题。

## 四、本稿遗留

**数值**

- 34 个技能的能量 / 伤害 / 治疗量 / 时长 / 层数 / 召唤物属性**全档为占位建议值，统一 ⚠️D**，需过验证脚本重定。
- **最大盲区是【枯荣循环】的 `on_tick` 频率**：`on_tick` 每 tick fire（敏捷 0 的单位约 5 tick 才行动一次），「每 tick 回 1」≈「每个自身回合回 5」。必须按 tick 频率重标（见该条）。
- **`gauge_rate` 类修正的定价无锚点**：预测天气 +4 / 沼泽 ×0.75 / 祈晴 +8 / 化身巨熊（无）/ 人偶金属档 +8。沿用 **D2**。
- **治疗侧无统一锚点**：brief §2 只给了「伤害 = 1.2 × 能量」。本稿统一按「治疗 = 1.0 × 能量」粗定（低于直伤汇率，因为治疗不会被打断 / 不会被闪避），但【触碰痊愈】4 能 / 8 治 + 全清三类、【最后回归之地】6 能双段超出了这个口径，需单独标定。
- **召唤物属性全档待标**：`unit_vine` / `unit_vermin` / `unit_oak_child` / `unit_golem` / `unit_homunculus` / `unit_doll`（5 材质档）共 9 个单位模板的血 / 攻 / 速 / 亡语值，需纳入「召唤物基线模板」统一重定（F 组合并候选 7）。

**原著能力的折算与省略（有意，非遗漏）**

| 原著能力 | 处置 | 理由 |

**原著存疑 / 需回查（5 条）**

1. **「自然憎恶」原著未解释是什么。** 对照表只在序列5 的大地系法术里列了名字（地底潜行 / 沼泽 / 自然憎恶 / 橡树之子），没有任何描述。本稿按字面推为「让自然本身敌视目标 → 受伤加深 + 己方攻击被引向它」，这是**设计推演而非原著原文**。若后续查到原著对该法术有明确描述，需按原著回改。
2. **「剥夺生命」的「死亡考验」判定标准原著未给。** 本稿取 25% 生命阈值，纯属设计取值。
3. **序列3「恶灵化」的范围来源被弱化了。** 原著是「10 公里范围内**所有**死者变恶灵」，本稿退化为「**你击杀的**单位」（走已落地的 `on_kill` A4）。完整版需要全局 `on_death` 第三方监听（本稿新增项 1，🔴）。这不是设计取舍，是引擎受限的妥协，**监听落地后建议回改**。
4. **序列8「治疗恶疾」未单独成卡。** 对照表序列8 写的是「治疗恶疾 / 创伤」并列的短语，本稿把它并入【治疗】的 `dispel(['dot','debuff'], 1)` 分支（「恶疾」≈ dot/debuff）。若后续认为「恶疾」应特指 poison 类，可拆出独立的解毒卡。
5. **序列9「力气变得很大」是本途径低序列唯一的攻击描述。** 对照表在序列9–6 之间**完全没有给出任何攻击性非凡能力**（只有「力气大」「自身产生剧毒」）。本稿的【力气】【外科手术】【生物洞悉】三条输出卡中，只有【力气】有逐字依据，**另两条是从「出色外科手术」「深刻了解生物特性」推演而来**。这是本稿原著依据最薄的部分，若汇总时认为推演过度，【外科手术】与【生物洞悉】可合并为一张。

**机制未决项**

- **本稿未使用 `on_turn_start`**：全部 34 个技能的触发点落在 `on_battle_start` / `on_tick` / `on_kill` / `on_death` / `on_spawn` / `on_take_damage` / `on_deal_damage` / `on_apply` / `on_remove` 九个**已确认会 fire** 的节点上，从设计源头规避了 **G15**（`on_turn_start` 是死触发点，当前会导致跨途径 36 个被动完全不生效）。v0.1 的【沃土】【医者本能】正是挂在这个死触发点上，本稿已全部改掉。
- **本稿仅 1 处引入概率**（【杂交造物】的 4 选 1 变异），且落在**附加哪种增益**这一非伤害维度，符合 **R5**；需 **R3** 登记进 `RandomUsageRegistry`。
- **致死保护优先级链未定**：本稿的 `lethal_protect`（【缝合灵魂】）与 C4 `miracle`、G4 `reviveOf`、以及愚者稿 `spirit_worm` / 药师稿 `eternal_life` 跨途径共存时谁先结算，需框架层统一裁定（沿用愚者稿【命运锚点】与药师稿提出的同一问题）。
- **【荒芜】的 `heal_received_mul: 0.5` 与治疗途径的对冲**：若环境中治疗密集，本条强度会剧烈波动。建议验证脚本按「敌方治疗量」而非固定值标定。
- **【创造世界】的 Zone 落位是否受 G8 约束**（G8 原文只约束单位位移），需与愚者稿【诡秘之境】一起统一拍板。
