# 愚者途径（占卜家）· 技能池 v0.2

灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **占卜家途径**（源堡，旧日「诡秘之主」，序列0 愚者）。
框架：`docs/ddd/`（战斗内核 DDD 终版）+ `_GENERATION_BRIEF.md`；旧框架编号（A/C/D/E/F/G 组）的现落点见 brief §7（v1.5 旧档、原《框架改动记录》与 `src/` 实现均已删除，原文可在 git 历史查阅）

> **本版定位**：v0.2 是**原著校准版**。相比 v0.1 主要做三件事——
> ① 逐序列比对原著能力表，补回全部遗漏的原著招牌能力；
> ② 剔除误入本途径的其他途径能力；
> ③ 把 v0.1 中被"抽象翻译"丢掉的原著具体手段（飞牌、纸人替身、伤害转移、变形、愿望、纸人部位…）还原成可落地的机制。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】灵视 🜁
- **原著** 序列9 占卜家 —— "能『看』到被遮挡事物、『听』到微弱脚步声，提前判断"
- **文案** 你的灵视洞穿遮蔽，战斗一开始便窥见战局走向，立即获得 5 点能量；而藏起来的敌人也瞒不过你。
- **序列** 9 占卜家 · **hook** `on_battle_start`（A1）
- **效果** `modify_resource(energy, +5)` + `modify_stat(energy_max, +5, duration: null)` + 挂载 `clairvoyance`（整场：敌方隐匿 / 潜行类状态**对你无效**）
- **翻译/语义** 原著灵视是感知能力。卡牌里无隐藏信息，故拆成两条：① "提前判断" = 开局能量（沿用 v0.1，D 组待标）；② "看到被遮挡事物" = 识破隐匿。
- ⚠️ 识破依赖 C8 候选池过滤的「识破」分支（🔴 未实现）。数值 ⚠️D。

#### 【被动】占卜 🜁
- **原著** 序列9 占卜家 —— "掌握占星术、卡牌占卜、灵摆、灵视等占卜能力"
- **文案** 你以卡牌与灵摆窥探天机，每回合开始时，有三成机会得到一丝启示，获得 2 点能量。
- **序列** 9 占卜家 · **hook** `on_turn_start`
- **效果** `{ ref: 'gain_energy_2', condition: { kind: 'chance', p: 0.3 } }`
- **翻译/语义** 具体的占卜手段（卡牌、灵摆）在引擎里只能落成"随机获得资源"。概率写法依 **G1 更正**用 EffectRef 的 `condition`（不是不存在的 `Chance()` 算子），R3 登记、R5 限非伤害维度。
- ⚠️ **G15**：`on_turn_start` 引擎从未 fire，当前完全不生效；修 G15 后自动闭环。

#### 【主动】占星术 🜁
- **原著** 序列9 占卜家 —— 占星术，"提前判断"
- **文案** 你从星象中读出一丝先机，指定一名同伴被向前拨动行动条，抢在对手之前出手。
- **序列** 9 占卜家 · **能量 2 / cd 3** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: gauge_asc }`
- **效果** `modify_resource(gauge.current, +25, delta)` 目标友军
- **翻译/语义** 占卜 = 提前量。⚠️ **G5 铁律**：绝不能写成 `SELF` 自推条——主动技能在自己回合释放时行动条已清零，自推后立刻重填，等于没加。

#### 【主动】飞牌 🜂 ★
- **原著** 序列8 小丑 —— "『飞牌』：将纸张掷出，使其锋利如刀刃"
- **文案** 一张薄纸在你指尖化作利刃，破空钉入敌人的身体。
- **序列** 8 小丑 · **能量 2 / cd 2** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 4)`
- **翻译/语义** **本稿最重要的补漏**。原著占卜家途径低序列"缺乏直接对敌手段"，飞牌与空气弹是仅有的两个例外，原稿却一个都没做，导致这条途径前 4 个序列完全没有输出地基。定位 = 本途径的「火球术」：低费、无附加、纯直伤。4 伤 / 2 能 = 2.0 汇率，高于基准 1.2，因为它要撑起整条途径的输出骨架。⚠️D 待标。
- **升级阶梯**（B6）伤害 4 → 6 → 8；或解锁「抽纸为兵」（序列7 同源能力）：对目标相邻单位追加 2 点物理伤害（`spread: splash_adjacent`）。

#### 【被动】直觉预感 🜂
- **原著** 序列8 小丑 —— "可凭直觉预感目标下一步行动"
- **文案** 你直觉地预感到对手的下一步，每回合开始凝成一层「预感」；受到攻击时它替你挡下半数力道。
- **序列** 8 小丑 · **hook** `on_turn_start` → `mount_status(premonition, stacks: +1, maxStacks: 3)`
- **效果** 状态 `premonition`：`category: buff`、`maxStacks: 3`、`charges: 1`；触发器 `on_take_damage` → 该次伤害 ×0.6，随后 `charges - 1` 消耗一层
- **翻译/语义** 原著"预感下一步行动"= 提前规避 = 减伤。用 C6 `charges`（已实现）表达"一次性的预感"，每回合补 1 层、上限 3 层防无限堆叠。
- ⚠️ 依赖 F50/F51 `mount_status.stacks`（🟡）+ **G15**（`on_turn_start` 未 fire）。

#### 【被动】完美协调 🜂
- **原著** 序列8 小丑 —— "技巧型格斗大师：极大提高身体协调性，几乎不会跌倒"
- **文案** 你的身体协调到近乎不可能失衡——任何推挤、拖拽与击倒都拿你无可奈何。
- **序列** 8 小丑 · **hook** `on_battle_start`
- **效果** 挂载 `poise`（整场）：`immune_to_move: true` + `immune: [control]`（依 G12 的 `immune` 字段）
- **翻译/语义** 原著"几乎不会跌倒"正好对应两件事：① 不被位移（击退 / 拖拽）；② 不被击倒（眩晕）。v0.1 把它译成"行动速率 +8"（平衡感）是凭空发明，本版改回原著语义。
- ⚠️ 依赖 G12 `immune`（🔴）+ 新增 `immune_to_move`（本稿新增项 6）。与 F7 `shackle`（禁位移 + 减速）是同一机制的正反两面，**建议统一为一个 `move_immune` 布尔字段**。

### 精良（序列 7–6）

#### 【主动】空气弹 🜂
- **原著** 序列7 魔术师 —— "『空气弹』：打响指制造堪比左轮手枪的空气弹"
- **文案** 你打了个响指，压缩空气如子弹般迸射，将敌人打得踉跄后退。
- **序列** 7 魔术师 · **能量 3 / cd 3** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: physical, 3)` + `modify_resource(gauge.current, -50, delta)`（击退，`KNOCKBACK_DISTANCE`，D1 已拍板）
- **翻译/语义** 原著明确"堪比左轮手枪"→ 远程直伤 + 冲击力。比飞牌贵 1 能量、少 1 伤害，换来一次击退（推后 2/3 行动周期）。与飞牌构成"纯输出 vs 输出+节奏"的选择。
- **更名说明** v0.1 叫「空气弹跳」，语义偏成了位移技能；原著就是「空气弹」，本版改回。

#### 【主动】火焰跳跃 🜂
- **原著** 序列7 魔术师 —— "『火焰跳跃』：30 米范围内在火种间闪现"；"操纵火焰"
- **文案** 你在跃动的火光间一闪而逝，灼伤身前的敌人后退回己方后排。
- **序列** 7 魔术师 · **能量 3 / cd 4** · `reach: melee` · `targetSpec: { faction: ENEMY, anchor: front_line }`
- **效果** `damage(element: fire, 4)` 对目标（**近战攻击进程，不调 move**）+ `move(push_back, distance: 99)`（自身退回己方半场最后位）
- **翻译/语义** 原著是位移闪现，但 **G8 铁律**禁止越中线，故按 **G7 先例**处理：突进 = 近战攻击进程（表现层），真实位移只有"闪回己方后排"（己方半场内，合规）。元素从 v0.1 的 `physical` 改为 `fire` —— 原著魔术师明确会"操纵火焰"。
- **与飞牌的差异** 飞牌远程物理；火焰跳跃近战、火元素、附带自身脱离前排。

#### 【主动】纸人替身 🜂 ★
- **原著** 序列7 魔术师 —— "『纸人替身』：纸人变自身挡致命一击，削弱诅咒"
- **文案** 剪好的纸人在你受致命一击的刹那替你碎裂——你活了下来，而附着在你身上的诅咒也随之被削弱。
- **序列** 7 魔术师 · **能量 3 / cd 5** · `targetSpec: SELF`
- **效果** `mount_status(paper_substitute, charges: 1, duration: 4)`；状态触发器 `on_death` → **阻止死亡**（保留 1 血）+ `dispel(self, category: ['debuff','dot'], count: all)`，随后 `charges - 1` 归零卸载
- **翻译/语义** 原著两条语义都落地：① "挡致命一击" = 致死保护；② "削弱诅咒" = 触发时驱散自身全部负面。用 C6 `charges: 1` 表达一次性。
- ⚠️ 引擎缺口：「阻止死亡」当前无原生表达。两条路：① 用 C4 `miracle`（`on_death` → `spawn` hpRatio）近似，但走 spawn 流程、丢"保留原格"与"驱散"的时序；② 新增 `lethal_protect` 标志（本稿新增项 1）。**建议走 ②**，`miracle` 仍留给【奇迹】做友军复活。

#### 【主动】伤害转移 🜃
- **原著** 序列7 魔术师 —— "『伤害转移』：将要害伤口转移至手臂等不重要部位"
- **文案** 你把即将落在要害的伤口挪到了无关紧要的地方——接下来几次打击，都只伤到皮肉。
- **序列** 7 魔术师 · **能量 2 / cd 4** · `targetSpec: SELF`
- **效果** `mount_status(wound_transfer, charges: 3, duration: 4)`；触发器 `on_take_damage` → 该次伤害 ×0.5，`charges - 1`
- **翻译/语义** **原著核心能力，v0.1 完全漏掉**。注意原著序列7 是转移到**自己**不重要的部位（伤害降级），转移到**别人**身上是序列4 诡法师的能力（见【秽物转移】）。用 charges 型单次减伤表达"把 N 次伤口挪走"。
- **与直觉预感的差异** 直觉预感 = 被动、每回合补 1 层、上限 3；伤害转移 = 主动、一次性给 3 层、可 preemptive 释放。

#### 【主动】制造幻觉 🜃
- **原著** 序列7 魔术师 —— "『制造幻觉』"
- **文案** 你让敌人看见并不存在的景象——它的下一击挥向幻影，落在空处。
- **序列** 7 魔术师 · **能量 3 / cd 4** · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(hallucination, charges: 1, duration: 3)`；`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`
- **翻译/语义** 幻觉 = 让对手打空。复用 **C7 已验证**的 `target_override → first_empty`。
- **与【愚弄】的关系** 幻觉是愚弄的低阶版（单体 / 1 次 / 短）；愚弄是权柄级（多段 + 反噬 + 时间愚弄）。v0.1 把"打空"直接放在传说档，导致序列7 的幻觉无处安放，本版下移。

#### 【主动】变形 🜄 ★
- **原著** 序列6 无面人 —— "『变形』：永久变化容貌（拔高 / 变矮 10cm），模拟声音"
- **文案** 你把自己的面容与身形揉成另一个人的模样——敌人的攻击认不出你，而你的利刃已经贴上它的后背。
- **序列** 6 无面人 · **能量 3 / cd 5** · `targetSpec: SELF`
- **效果** `mount_status(disguise_form, duration: 3)`：
  - `untargetable_by_targeted: true`（敌方单体技能无法选中你，依赖 C8）
  - 触发器 `on_deal_damage` → 该次伤害 ×1.5（对方认不出你、被近身一击），`charges: 1`
- **翻译/语义** 原著变形是**伪装潜入**。卡牌里"换脸"本身不产生收益，收益在"不可被选中"（潜入）与"近身必杀"（对方认不出）。
- **与 v0.1 的差异** v0.1 的【易容】做成"期间免疫 debuff/dot/control"（G12），**这是凭空发明的原著外能力**；本版改回伪装语义，"免疫负面"交由【秽物转移】处理。
- ⚠️ 依赖 C8 候选池过滤（🔴）。与 F4 `shadow_veil`、F11 `stealth` 是同一底层，建议并入统一潜行母版。

#### 【被动】细微观察 🜁
- **原著** 序列6 无面人 —— "对他人外貌和细微动作的极强观察力和记忆力"
- **文案** 你记下对手的每一个细微动作，它的招式在你眼里越来越慢、破绽越来越多。
- **序列** 6 无面人 · **hook** `on_deal_damage`
- **效果** 自身计数状态 `observe` 层数 +1（上限 3，整场）；`damage_mul = 1 + 0.1 × 层数`
- **翻译/语义** 原著"观察力 + 记忆力"→ 越打越了解对手 → 伤害递增。
- ⚠️ 依赖 F50/F51 `stacks`（🟡）。与 F1 `inscription`（学徒·默记）是同一计数型状态，**建议共用母版**。

#### 【被动】能力精进 🜄
- **原著** 序列6 无面人 —— "火焰跳跃、空气弹等能力变强约 30%"
- **文案** 成为无面人后，你对身体与火焰的掌控更上一层——本途径的所有攻击技能，威力提升三成。
- **序列** 6 无面人 · **hook** `on_battle_start`
- **效果** 自身 `damage_mul: 1.3`，**仅对 `pathway: 'fool'` 的技能生效**
- **翻译/语义** 原著白纸黑字"变强约 30%"，直接落地为途径内增伤。这是本途径的**协同引擎**，让飞牌 / 空气弹 / 火焰跳跃在后期仍值得占槽。
- ⚠️ 依赖 B2 `SkillDef.pathway`（🔴）+ "按技能标签过滤的伤害乘区"（本稿新增项 14）。**退化方案**：改为"自身 fire + physical 伤害 ×1.15"，不依赖标签，代价是吃不到途径区分。

### 稀有（序列 5–4）

#### 【主动】秘偶 🜃 ★
- **原著** 序列5 秘偶大师 —— "看见并操纵『灵体之线』，通过灵体之线控制目标的灵体、心智体、以太体和身躯……可将目标彻底变成秘偶"
- **文案** 你牵住那条看不见的灵体之线，敌人的身躯不再属于它——它转身，扑向自己的同伴。
- **序列** 5 秘偶大师 · **能量 4 / cd 5** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(puppet_string, duration: 6)` + `damage(element: mental, 2)`
- **机制** 持有者发动攻击时，`target` 被强制改写为**其同阵营存活友军**（`index_asc` 破平），`puppet_string` 优先于嘲讽 / 守护。

- **原著** 序列0 愚者 —— "『灵界掌控者』：操纵灵体之线和唤起灵性之线"
- **文案** 你是灵界的主宰——所有灵体之线都在你掌心，敌人的灵魂越虚弱，你牵动它们越轻易。
- **序列** 0 愚者 · **hook** `on_battle_start`
- **效果** 挂载 `lord_of_spirits`（整场）：
  - 你施加的**控制类**状态（`puppet_string` / `hallucination` / `fooled` / `taunt`）**不可被驱散**（运行时覆写 `dispelable: false`）
  - 你对生命值低于 50% 的目标造成的伤害 ×1.3（"灵性之线"松动）
- **翻译/语义** 原著"掌控灵界"= 对灵体之线的绝对支配。落地为两条：① 控制不可解（操纵的绝对性）；② 残血目标易控（灵性之线松动）。
- ⚠️ 依赖：① 运行时覆写状态 `dispelable`（本稿新增项 9，🔴）；② `TargetHpBelow` 条件谓词（已存在于 EffectCondition 谓词集）。

#### 【被动】命运锚点 🜁
- **原著** 序列0 愚者 —— "『命运锚点』权柄"
- **文案** 你把自己的命运钉死在此处——没有人能把你从这条线上推开；而凡是被你钉住命运的敌人，连死亡都收不走它。
- **序列** 0 愚者 · **hook** `on_battle_start`
- **效果** 挂载 `fate_anchor`（整场）：
  - 自身**免疫一切 `gauge.current` 减少**（击退、拖慢对你无效）
  - 你击杀的敌方单位**无法以任何方式复活**（`revive_blocked`）
- **翻译/语义** 原著"命运锚点"是锚定命运的权柄。落地为：锚定自己（不被推动）+ 锚定敌人（死了就是死了）。后者是**唯一的反复活手段**，在本作复活机制密集的语境下有明确价值。
- ⚠️ 依赖：① 免疫 `gauge.current` 减少（本稿新增项 10，🔴）；② 反复活标记 `revive_blocked`（本稿新增项 11，🔴，与【灵之虫】【奇迹】正面对冲，需先定复活机制的优先级）。
