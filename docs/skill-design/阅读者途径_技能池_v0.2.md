### 本途径的两条辨识度机制

**① 解析 → 模仿（本稿的灵魂，也是原著最招牌的因果链）**

原著序列6 的白纸黑字是「**模仿解析过的能力**」——两个能力不是并列的，**先解析、后模仿**。引擎里最贴的落地是「**记录 → 重放**」两步：

- **记录**：状态 `observed`（已解析）挂在敌方单位上，挂载瞬间快照该单位**最近一次施放过的技能**。记录的途径有三条（全部走既有触发点，`on_deal_damage` / `on_take_damage` / `on_battle_start`，零新增触发点依赖）：
  - 【观察】（被动）：你打到它、或它打到你，就解析它一层；
  - 【解析】【逻辑推演】【仪式魔法】等主动技能：命中即刷新其 `observed` 快照；
  - 【白塔·全知】（序列0 被动）：全场敌人常驻 `observed`，且你每次造成伤害都自动刷新——**全知 = 不需要额外动作去观察**。
- **重放**：`mimic(potency)` 是一个**参数化的一次性乘区状态**，唯一参数是 `potency`。展开时调用 `echo_last_skill(target, potency)` 重放快照里的技能：伤害类效果 ×potency，附加效果按 potency 门槛决定保留多少。
- **梯度**：potency 由**技能所在的序列位阶固定**（0.2 → 0.5 → 0.6 → 0.8 → 0.9 → 1.0），**不是掷骰子**。原著的"百分比成功率"在本稿被翻译成"**按序列位阶固定的效果强度**"——这符合 **R5**（概率只用于非伤害维度），也避免了"一张卡的收益靠运气"这种糟糕的肉鸽体感。

> **关于序列6 的"有几率"**：原著只在序列6 写了"**有几率**模仿"，序列5 起就只写"效果达 X%"、不再提几率。本稿据此处理：**只有序列6 档带 `condition: { kind: 'chance', p: 0.5 }`**（决定"这次是否成功模仿"，属 R5 允许的添头维度），序列5 及以后**必定成功**、只涨强度。退化方案：去掉概率，改为固定 potency 0.2 但要求目标必须处于 `observed`——即把"有几率"解释成"必须先解析成功"，零随机、零 `RandomUsageRegistry` 登记。

> **关于"模仿"占几个槽**：5 个档位是**同一条技能线**，用 **B6 升级阶梯**实现（`duplicatePolicy: 'upgrade'`），重复抽到即升级到下一档，**不额外占槽**。这样既做出原著 20%→100% 的完整梯度感，又不会把 4 个主动槽塞满同一张卡。

**② 中序列的物理战斗力（v0.1 完全丢失的东西）**

原著序列7「守知者」明写："偏知识掌握和推理，**附带格斗和器械能力** / **武器精通、格斗大师**、推理大师、仪式魔法大师"。这条途径**不是纯辅助**——从序列7 起它就是"拿着武器、精通格斗的学者"。本稿把这条落为 🜂 秘术轴的直伤骨架（【武器精通】【格斗大师】【仪式魔法】【仪式魔法大师】），让它在低中序列就能站上前排打输出，而不是躲在后面挂易伤。

#### 【被动】理解力 🜁

- **原著** 序列9 阅读者 —— "能使用**仪式魔法**，大量阅读获得知识储备"

#### 【主动】逻辑推演 🜁
- **原著** 序列8 推理学员 —— "观察力、**逻辑思维能力**提升"

#### 【被动】观察 🜃 ★
- **原著** 序列8 推理学员 —— "**观察力**、逻辑思维能力提升"（并作为序列6「模仿**解析过**的能力」的前置）

  - `on_take_damage` → 打你的单位被解析（挨打也是一种观察，且是本途径低序列唯一的"被动积累"途径）
- **翻译/语义** **模仿轴的起点与整条链的素材来源**。原著序列6 明确是"模仿**解析过**的能力"——没有解析就没有模仿，这条被动就是那条因果线的入口。挂载时快照目标最近一次施放的技能（依赖本稿新增项 1 的 `lastSkillRef`）。

## 四、本稿遗留

- **数值全档待标**：33 个技能的能量 / 伤害 / tick / 层数 / 时长 / 模仿倍率均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中 `gauge.current` / `gauge_rate` 类技能的定价无既有锚点，是本稿最大盲区（沿用 **D2**）。
- **模仿线的 potency 经济未标定**：模仿的收益**完全取决于对手用了什么技能**——对手开大招时模仿价值极高、对手普攻时几乎为零。这使它无法按常规"能量 → 伤害"定价，**必须按期望值下限定价**（即假设模仿到的是一个 3 能级别的中等技能）。这是本稿最难定价的一条线，建议按 `potency × 3 能技能的期望伤害` 反推，⚠️D。
- **乘区规则已裁定（2026-09-07 销项）**：同向乘区**取最高、不叠乘**（H42，编队参数 §2.4 母版表）。本稿 `vulnerable`(×1.3)、`omniscience_mark`(×1.2)、`tutelage`(×1.2)、`wisdom`(×1.15)、`ritual_expertise`(×1.2)、`推理大师`(×1.2)、`optimal_choice`(×1.4)、`白塔·全知`(×1.15) 八个乘区同向不叠，取最高者生效——×3 以上的叠乘爆炸不存在了；各卡数值按此口径过 D4 重标即可。
- **`resist:all` 的裁定点**：负值抗性如何与 `damage_mul` 乘区交互、是否被 `pierce_shield` 影响，需与 **D3「防御杠杆重标」** 一并裁定。
- **`echo_last_skill` 的重放边界未定义**：被模仿技能若包含 `spawn` / `move` / 指向性 `target_override`，重放时的目标归属（施法者还是原主）与阵营判定需明确。建议**先上保守版：只重放 `damage` / `mount_status` / `dispel` / `modify_resource` 四类，其余条目一律跳过**，列为后续增强。
- **【秘术传授】的原著依据存疑**：见下方存疑 3。若判定不成立，本条应删除，`tutelage`（F14）改由其他途径承载。
- **全稿零 `heal`**（原著阅读者途径没有治疗能力），因此 **A22 对本稿无约束**；这是刻意的，不是遗漏。
- **仅 1 处随机**：全稿只有【模仿·初解】的 `condition: { kind: 'chance', p: 0.5 }` 引入随机，且是"是否触发"的添头维度，符合 **R5**；需按 **R3** 登记进 `RandomUsageRegistry`。序列5 及以后的模仿档**全无随机**（严格照原著：序列5 起不再提"有几率"）。
- **未单独成技能的原著能力**（有意省略或并入，留待后续）：
  - 序列6「**无使用次数限制**」—— 是修饰模仿的，已并入【模仿·初解】（cd 压到 2、能量 2），不单独成技能
