# 药师途径（月亮）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按母巢系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入母巢系核心机制 **「月相」节拍器**（满/血/银/红/缺，5 相轮转串四轴）；
> ③ 新增 **跨系 combo 卡**（母巢↔灾祸之城 兽群入集众、母巢↔永暗之河 黑暗凝视读夜幕）；
> ④ 补 1 张主题界域牌（血月当空）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《母巢系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做「轴=钩子」与「月相节拍器」两层。母巢系设定明确指出药师是「四轴平铺」最典型案例，故本版把月相做成驱动其余三轴的节拍器。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁「技能效果 + 轴引擎 + 跨系接口」，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **药剂** | `药剂`(draught, 自身/友方) | 药剂调配 / 草药敷贴 / 隐身·无味 → 产 `药剂` | 若\[银月\] 药剂×2；预服药水超强；健康灵视对低血×1.5 | 健康灵视 |
| ② **兽群** | `兽群`(beast_pack, 自身/召唤) | 驯兽哨 / 动物感官 → 挂 `兽群` | 兽群属性增益 + 分享感官；兽群指挥·改入集众 | 动物感官 |
| ③ **月相** ★核心 | `月相`(moon_phase, 自身 5 相轮转) | 满月 / 银月切相 / 月相·轮转 → 推进/设定 `月相` | 各相驱动其余三轴（见 §〇 月相维度） | 月相·轮转 |
| ④ **召唤** | `召唤`(summon_mark, 召唤物) | 召唤之门 / 灵界契印 → 产 `召唤` | 若\[满月\] 召唤生物强度提升；满月下契约超量 | 召唤之门 |

> **月相 节拍器（母巢系签名机制，母巢系 §2.2 / 总览 §1 咬合器⑤）**：`月相` 为自身 5 相轮转状态 `moon_phase`（formGroup，同组互斥）：满 / 血 / 银 / 红 / 缺。
> 轮转序：**满 → 血 → 银 → 红 → 缺 → 满**（每 ⚠️D tick 自动进一相，由传说【月相·轮转】挂载；【满月】【银月切相】可强制设定某相）。
> 各相加成（⚠️D 全档待标）：
> - **满月**：治疗与恢复 +100%（heal 输出/接收 ×2）；`召唤` 生物强度提升
> - **血月**：drain/腐蚀类攻击 ×1.2；`兽群` 获得嗜血（攻击 +⚠️D）
> - **银月**：`药剂` 类效果 ×2；闪现距离提升
> - **红月**：黑暗领域法术 ×1.3；蝙蝠分解重组判定更松（重组更快）
> - **缺月**：自身受伤 ×0.8；敌方单体治疗 ×0.5
>
> **enabler→payoff 闭环**：enabler 卡（满月 / 银月切相 / 月相·轮转）推进或设定月相；payoff 卡读取当前月相放大对应轴——腐蚀之爪读血月、预服药水读银月、召唤之门/创生读满月、黑暗凝视/蝙蝠分解读红月、月光化读缺月。四轴被同一节拍器串成 combo。

## 一、技能池

图例：⚠️ = 需框架扩展；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）；**性别** = 女 见 brief §12.1。

### 普通（序列 9–8）

#### 【主动】药剂调配 🜄 药剂 · **E**
- **原著** 序列9 药师 —— 「擅长调配药剂」
- **文案** 你随手把几味药材捣碎调匀灌了下去，苦涩的暖流立刻淌遍全身，药力在血里慢慢铺开。
- **序列** 9 药师 · **能量 2 / cd 2 / 吟唱 0** · `targetSpec:{faction:ALLY}`（Manual，fallbackSort:`hp_asc`）
- **效果** `Sequence[ heal(4), mount_status(药剂, stacks:+1) 目标友军 ]`
- **翻译/语义** 药剂轴 enabler：产 `药剂` 状态为后续 payoff 叠层数。治疗汇率压到 1.0/能量（低于直伤 1.2，治疗不白嫖直伤）。严格 A22 走 `heal`。⚠️D。

#### 【主动】草药敷贴 🜄 药剂 · **E**
- **原著** 序列9 药师 —— 「驯化使用植物治病」
- **文案** 你嚼碎一把活着的苔草敷上伤口，叶片仍在微微抽动，把生机一点点渡进血肉里。
- **序列** 9 药师 · **能量 3 / cd 3 / 吟唱 0** · `targetSpec:{faction:ALLY}`（Manual，fallbackSort:`hp_asc`）
- **效果** `Sequence[ heal(3), mount_status(再生, duration:3), mount_status(药剂, stacks:+1) 目标友军 ]`
- **翻译/语义** 用植物治病→即时小治+持续恢复+产 `药剂`。与【药剂调配】差异：本卡叠 `再生` 持续段。⚠️D。

#### 【被动】毒素抗性 🜄 药剂
- **原著** 序列9 药师 —— 「毒素抗性强」
- **文案** 你常年与毒草为伴，寻常的毒已经毒不倒你；每次中毒身体都自己把它解掉。
- **序列** 9 药师 · **hook** `on_battle_start`
- **效果** `modify_stat(resist:poison, +20, duration:null)` + 挂载 `antivenom`（整场）：`on_take_damage`→若 element=poison 则 `heal(1)`
- **翻译/语义** 直接落 `resist:poison` + 小额自愈解毒。⚠️D。

#### 【被动】健康灵视 🜄 药剂 · **P** ★
- **原著** 序列9 药师 —— 「健康领域『灵视』」
- **文案** 你能看见别人身上的病气与裂口在哪里——伤得越重，你越知道该怎么救。
- **序列** 9 药师 · **hook** `on_battle_start`
- **效果** 挂载 `health_sight`（整场）：你施放的 `heal`/`药剂` 若目标当前生命<50%，效果 ×1.5
- **翻译/语义** 药剂轴 payoff：读低血目标放大治疗。v0.2 仅作用于 heal，本版扩到 `药剂` 状态族，串起药剂轴。⚠️D。

#### 【主动】驯兽哨 🐾 兽群 · **E**
- **原著** 序列8 驯兽师 —— 「驯化使用活着的动物（含超凡生物）」
- **文案** 你吹响骨哨，林子里那头被你驯过的狼循声而来，龇着牙站到你身前。
- **序列** 8 驯兽师 · **能量 3 / cd 4 / 吟唱 0** · `consumption:summon`
- **效果** `spawn(unit_beast, position:'tail')` + 自身 `mount_status(兽群, stacks:+1)`
- **翻译/语义** 兽群轴 enabler：召唤动物并挂 `兽群` 身份状态。动物类非构装。⚠️D；A2：禁给召唤物挂开局语义。

#### 【被动】动物感官 🐾 兽群 · **E** ★
- **原著** 序列8 驯兽师 —— 「『动物感官』：读懂野兽想法，沟通/驱使/分享感官」
- **文案** 你与它们共享着同一副感官——谁咬住了你，你的兽群就先一步知道。

- **翻译/语义** 兽群轴 payoff：读 `兽群` 增益。推友军非自推条（G5/G6 合规）。⚠️D。
