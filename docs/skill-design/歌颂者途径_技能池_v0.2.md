### 本途径的两条辨识度机制

**① 阵营克制（原著反复强调的招牌）**

原著在三个序列反复加码这条途径的定位：序列8「克制死尸鬼魂」、序列5「**污秽和死灵的克星**」、序列4「净化堕落 / 污秽 / 黑暗 / 疾病力量」。这是本途径区别于"另一个光系奶妈"的**唯一硬资产**，必须做成可感知的玩法：

- **主方案 A**（已落 ddd：编队参数 §1.2b，新增项 2）：`UnitDef` 增加标签 `undead` / `foul` / `dark`，配套条件谓词 `target_has_tag` 与"按标签的伤害 / 受伤乘区"。服务于【邪秽克星】【日照】【神圣之光】【白昼】【太阳光环】【神圣之国】。
- **退化方案 B**（✅ 零新字段，**本稿默认按 B 落地**）：数据层给不死 / 污秽 / 黑暗单位预置 **负的 `resist:holy`**（如 `-25`）。`resist:<元素>` 已是合法 `StatKey`，无需任何引擎改动——光对不死的天然克制直接由抗性表表达，且只有本途径大量产出 `holy` 伤害，辨识度不丢。
- 建议：先按 B 上量验证数值，A 待出现"检索 / 指定不死单位"类技能时再补。

**② 公证与契约（原著最独特的机制）**

原著序列6「公证人」的核心是：**对非凡能力的真实性做出公证，有效的增强、无效的削弱**。引擎里技能没有"真假"维度，故本稿把语义核心保留为「**由公证人做出权威裁定**」——玩家选择强化友军的下一击、或削弱敌军的下一击（落到 `charges: 1` 的一次性乘区上）。契约同理：原著"序列5 也无法违背、序列4 违约付出代价"，卡牌里"禁止行动"= 沉默（太强且无契约味），真正的契约味是**允许你做，但每次做都要付代价**。

> 这两条是本途径 v0.1 完全丢失的东西，也是本稿投入最多新增项的地方。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能；⚠️D = 数值占位待标

> **元素口径**：本稿全部光属性伤害写作 `damage(element: holy, N)`。`holy` 是本稿立项的新元素（**新增项 1**，已落 ddd：共享内核参数 §一 ResistanceSet 行含 holy）；**未批准前的退化方案**为全量改 `fire`——太阳 / 烈阳 / 阳炎 / 光明之火本就是火焰意象，退化代价可接受，但会失去「抗光」这个 counter 维度，并与水手（雷火）、猎人（火）途径的伤害类型混同。

### 普通（序列 9–8）

#### 【主动】歌颂 🜁 ★
- **原著** 序列9 歌颂者 —— "通过歌声带来勇气、力量、虔诚和服从"
- **文案** 你唱起颂歌，勇气与力量随音符一起灌进同伴的身体——他握刀的手，稳了。
- **序列** 9 歌颂者 · **能量 2 / cd 2 / 吟唱 0** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: atk_desc }`
- **效果** `mount_status(blessing, duration: 3)` → `modify_stat(attack, +2)` + `modify_stat(defense, +1)`（到期回滚）
- **翻译/语义** 原著"带来勇气、力量"= 攻防增益。这是本途径的**节奏起点**：低费、可反复刷、给核心输出位叠起来。注意原著一句里其实有四个词（勇气 / 力量 / 虔诚 / 服从），本稿拆成四条技能分别承载——力量与勇气在【歌颂】，服从在【服从之音】，虔诚在【信仰之仆】，不做成一张四合一的怪卡。⚠️D

#### 【主动】勇气赞歌 🜁
- **原著** 序列9 歌颂者 —— "消除恐惧……附带灵性恢复"
- **文案** 一句高昂的赞歌驱散了同伴心头的寒意，也让他重新感到力量在身体里流淌。
- **序列** 9 歌颂者 · **能量 1 / cd 2 / 吟唱 0** · `targetSpec: { faction: ALLY, fallbackSort: hp_asc }`
- **效果** `Sequence[ dispel(target, category: ['control','debuff'], count: 1), modify_resource(energy, +2, delta) ]`
- **翻译/语义** 原著"消除恐惧"在引擎里最贴的是**驱散 control / debuff**（恐惧 = 控制与负面）；"灵性恢复"没有对应资源，译为能量（灵性即施法燃料）。两条语义同属一次赞歌，用 `Sequence` 串起来（**G3**：需确认运行时已实现 `Sequence`）。C2 `category` 数组 ✅。⚠️D

#### 【被动】灵性恢复 🜁
- **原著** 序列9 歌颂者 —— "消除恐惧、提升力量，**附带灵性恢复**"
- **文案** 你的灵性在歌声中自行回补——每当轮到你行动时，圣力便又盈满一分。
- **序列** 9 歌颂者 · **hook** `on_turn_start`
- **效果** `modify_resource(energy, +2, delta)`（自身）
- **翻译/语义** 同【勇气赞歌】的"灵性 → 能量"，本条是这条途径的**能量引擎**。
- ⚠️ **G15**：`on_turn_start` 引擎**从未 fire**，当前完全不生效；修 G15 后自动闭环。
- **退化方案** 改为 `on_battle_start` → `modify_stat(energy_regen, +0.2, duration: null)`（整场每 tick 回能，零触发点依赖），代价是失去"轮到自己时回补"的节奏感、且强度需重标 ⚠️D（每 tick 与每回合差约 5 倍，**G14** 时间尺度）。

#### 【主动】白昼 🜂
- **原著** 序列8 祈光人 —— "『白昼』：周围10米获得光照"
- **文案** 你点亮一圈白昼——在这圈光里，黑暗再也藏不住任何东西。
- **序列** 8 祈光人 · **能量 2 / cd 3 / 吟唱 0** · `targetSpec: ALL`（全场）
- **效果** 全场（敌我）挂载 `daylight`（duration: 4）：① 敌方隐匿 / 不可选中类状态**对己方无效**（识破分支）；② 己方对带 `undead` / `foul` / `dark` 标签的单位伤害 ×1.15
- **翻译/语义** 原著"10 米光照"是照明。卡牌里没有隐藏信息、照明本身不值钱，值钱的是两件衍生事实：**黑暗与隐匿失效**、**光对不死更狠**。两条都直接取自原著"祈光人克制死尸鬼魂"的定位，不做第三件。
- ⚠️ 依赖 C8 识破分支（已落 ddd：共享内核参数 §四，与愚者【灵视】同源）+ 本稿新增项 2（§1.2b）/ 14（§四 识破 + 按 tag 乘区）。**退化**：只保留①。

#### 【主动】日照 🜂
- **原著** 序列8 祈光人 —— "『日照』：创造烈阳光芒**伤害不死生物**"
- **文案** 你召来一道烈阳的光芒——凡是不洁的东西，在它下面都会燃烧起来。
- **序列** 8 祈光人 · **能量 2 / cd 2 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `index_asc`，默认打最前排）
- **效果** `damage(element: holy, 3)`；对带 `undead` / `foul` / `dark` 标签的目标 ×1.5
- **翻译/语义** 原著明确写了"伤害不死生物"，这是本途径**最早的直伤**，也是阵营克制（新增项 2，已落 §1.2b）的入门件。3 伤 / 2 能 = 1.5 汇率，高于基准 1.2，溢价买的是"克制不死"的条件性与 `holy` 独占维度。⚠️D
- **退化** `element` 改 `fire`；克制改由数据层负 `resist:holy` 自然生效。

#### 【主动】祝福 🜂
- **原著** 序列8 祈光人 —— "『祝福』"
- **文案** 你把圣光按在同伴肩上——一层暖意裹住他，伤口也跟着收敛了。
- **序列** 8 祈光人 · **能量 2 / cd 3 / 吟唱 0** · `targetSpec: { faction: ALLY, fallbackSort: hp_asc }`
- **效果** `Sequence[ mount_status(shield, +4, duration: 3), heal(2) ]`
- **翻译/语义** 原著只给了"祝福"两个字、未定义形式。按途径主题（光 / 神圣 / 守护）译为**护盾 + 小治疗**，是本途径最廉价的续航件。**A22 合规**：治疗一律走 `heal` 原语。⚠️D

#### 【主动】服从之音 🜄
- **原著** 序列9 歌颂者 —— "通过歌声带来勇气、力量、虔诚和**服从**"
- **文案** 你的歌声落进敌人耳中，化作一句无法违拗的低语——它举刀的手，慢了下来。
- **序列** 9 歌颂者 · **能量 1 / cd 2 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(obedience, duration: 3)` → `modify_stat(attack, -2)` + `modify_stat(gauge_rate, ×0.9)`
- **翻译/语义** "服从"= 压制。译为降攻 + 拖慢。**INV-S5 合规**：改的是 `gauge_rate` 源属性，不碰派生的行动周期。**G5/G6 合规**：这是给敌人的减益，不是自推条。这是序列9 唯一的对敌手段，也是 🜄 审判轴的起点。⚠️D

### 精良（序列 7–6）

#### 【主动】召唤圣光 🜂 ★
- **原著** 序列7 太阳神官 —— "『召唤圣光』"
- **文案** 你举起手掌，一束圣光自虚空中降临，笔直地落在敌人的身上。
- **序列** 7 太阳神官 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: holy, 5)`
- **翻译/语义** **本途径的"火球术"**——低费、无附加、纯直伤，撑起整条途径的输出骨架（v0.1 完全没有这张牌，导致本途径前 5 个序列没有输出地基）。5 伤 / 3 能 = 1.67 汇率，高于基准 1.2，溢价理由：`holy` 是本途径独占维度且吃阵营克制乘区。⚠️D
- **升级阶梯**（B6）伤害 5 → 7 → 9；或解锁「纯白射线」（序列4 同源能力，见稀有档）。

#### 【主动】制造圣水 🜂
- **原著** 序列7 太阳神官 —— "『制造圣水』"
- **文案** 你倒出一小瓶圣水——它洗去同伴身上的污秽，也把他的伤口缝合起来。
- **序列** 7 太阳神官 · **能量 2 / cd 3 / 吟唱 0** · `targetSpec: { faction: ALLY }`
- **效果** `Sequence[ dispel(target, category: ['debuff','dot'], count: 2), heal(3) ]`

- **效果** `If(目标带 guilty)` → `Sequence[ damage(element: holy, 8), dispel(target, category: ['buff'], count: all), modify_stat(attack, -5, duration: 5) ]`
  `Else` → `damage(element: holy, 3)`（判决仍要执行，但力度大减）

- ⚠️ 依赖：① `If` 算子 + `target_has_status` 谓词（**F52** 已落 ddd：§三 `has_status`）；② 新增项 6 `guilty`（H2）。
- **关于"连天使都受影响"** 若做成 `dispelable: false` 的降攻会过强，本稿改为 duration 内正常可驱散，把"连天使"的味留给 flavor 与【秩序权柄】。

#### 【被动】正义光环 🜃

## 三、跨途径共享（混沌海相邻途径：观众 / 水手）

## 四、本稿遗留

- **数值全档待标**：35 个技能的能量 / 伤害 / tick / 层数 / 时长均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中**群体 `heal` / 群体护盾**（净化光环、祝福、太阳光环）与**区域类技能**（无暗之域、神圣之国）的定价**完全没有既有锚点**，是本次最大盲区（沿用 D3）。
- **乘区规则已裁定（2026-09-07 销项）**：同向乘区**取最高、不叠乘**（H42，编队参数 §2.4 母版表）——【太阳光环】（受伤 ×0.9）与【正义光环】（×0.9）同向取 ×0.9，【邪秽克星】（×1.5）与【光之权柄】（×1.25）同向取 ×1.5，0.81 / 1.875 的极端组合不存在了；各卡按此口径过 D3 重标即可。
- **【神圣权柄】的驱散节奏**：`on_deal_damage` 每次造成伤害都触发，群体技能（纯白射线、太阳使者）可能一回合扒光多个目标的多层增益。建议限定"同一目标每 tick 最多触发 1 次"，需引擎侧确认是否有现成的节流手段。

  - 序列7「体质增强」—— 并入【免疫恐惧】的 `resist:poison` / `resist:mental`

  - 序列8「施展太阳领域法术和仪式」—— "仪式"在单局战斗中无维度，取其"法术"面
- **全稿零概率**：本途径没有任何技能引入随机（原著能力里没有掷骰成分），符合 R5 精神，无需 `RandomUsageRegistry` 登记。
- **原著对照表的存疑 / 缺漏项**（供回补对照表时参考，共 8 条）：
  1. 序列7「太阳光环」、序列6「擅制契约」**只有名字、没有机制描述** —— 本稿按途径主题（常驻范围增益 / 立约与违约代价）补全，属推断。
  2. 序列5「净化光环：金色光辉外扩，精准操纵」未说明是治疗还是伤害 —— 本稿按"外扩 + 精准"译为**清友军负面 + 灼敌**双侧。
  3. 序列7「神圣誓约」与序列4「太阳誓约」同名机制（誓约），对照表未给出二者差异 —— 本稿按序列差做**单体 2 伤 / 群体 3 伤**区分。
  4. 序列3「正义审判」说"不符合准则的力量被极大削弱，连天使都受影响"，但**「准则」由谁定、内容是什么**未说明（原著是正义导师自身的"秩序"）—— 本稿落为玩家可选的变体档。
  5. 序列2「太阳使者：化身微缩太阳洒下光热净化」与序列1「神圣之国」**语义重叠**（都是区域净化）—— 本稿用"状态 vs 区域"两种载体区分，但重叠客观存在。
  6. 序列0「秩序权柄：偏正面、自我、排它」是**抽象形容词、无具体招式** —— 本稿按字面三词译为三条（自身增益不可驱散 = 自我 / 己方受益敌方受损 = 偏正面 / 规则不可被解除 = 排它）。
  7. 序列6「公证」的对象是"非凡能力的真实性"，卡牌里**没有"能力真假"这一维度** —— 本稿退化为"由公证人裁定下一次技能的强弱"，是本稿对原著最大的一处妥协，需确认可接受。
  8. 全途径**没有任何位移 / 潜行 / 复活他人的能力**，治疗也只在序列7「制造圣水」与序列8「祝福」中间接存在 —— 本稿所有 `heal` 均挂在这两条与序列1「神圣之国 / 纯白之光」上，属合理推断；另注意对照表把**相邻途径**记为"观众、水手"，而 v0.1 稿写的是"秘祈人 / 观众 / 水手 / 阅读者"（按源质混沌海全组），本稿以对照表为准。
