# 偷盗者途径（错误）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入源堡系核心机制 **「隐秘值」战场维度**（secrecy 0–10）；
> ③ 新增 **跨系 / 源堡内部 combo 卡**（偷盗者寄生 ↔ 混沌海秘祈人血肉寄生；偷盗者读占卜家提线 / 读学徒门扉坐标）；
> ④ 补 1–2 张主题界域牌。
> 框架依据 `../meta/GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《源堡系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

## 〇、肉鸽化前提

| 约定 | 内容 |
|---|---|
| 槽位 | 每英雄 **4 主动 + 4 被动** |
| 派发 | 爬塔随机派发，逐步构筑 |
| 共享 | 部分技能带 `sharedAcross`，可被相邻途径（占卜家 / 学徒）重复抽到 |
| 稀有度 | 由序列位阶直接映射（下表） |

### 稀有度 = 序列位阶

| 序列 | 稀有度 | 派发权重 | 定位 |
|---|---|---|---|
| 9–8 | 普通 Common | 高 | 骨架，开局即可得 |
| 7–6 | 精良 Uncommon | 中 | 成型件 |
| 5–4 | 稀有 Rare | 低 | 构筑核心 |
| 3–2 | 史诗 Epic | 很低 | 大招 / 转折点 |
| 1–0 | 传说 Legendary | 极低 | 一局最多 1 张 |

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **窃物** | `赃物` | 窃取 / 卓越观察 → 累积 `赃物` | 若\[赃物≥3\] 窃取其一项能力/属性 | 盗火人 |
| ② **欺诈** | `误判` | 思维误导 / 精神干扰 / 骗取 → 敌挂 `误判` | 若\[误判\] 以假代真（伪装/欺诈规则生效） | 欺瞒导师 |
| ③ **寄生** ★核心 | `寄生` | 寄生 → 对敌挂 `寄生` | 若\[寄生\] 接管身体 + 窃取概念(位置/距离) | 寄生者 |
| ④ **时间** | `时差` | 嫁接命运 / 衰老 / 分身替换 → +1 `时差` | 若\[时差≥2\] 分身替换/重启 | 时之虫（顶点：错误） |

> **隐秘值维度（源堡系 §2.2）**：战场级属性 0–10，独立于力/敏/智/灵/体/魅。偷盗者经"欺诈 / 寄生"类效果 +1/次（思维误导、精神干扰、栽赃、寄生、窃取距离、寄生·血肉共生、欺诈规则、窃取身份、错误 等）。层级：
> - **≥4**：场上所有 `提线木偶` 每回合 +1 层（源堡系共享；偷盗者经【提线接管·改】【寄生·血肉共生·改】同享）
> - **≥7**：友方「愚弄 / 隐秘 / conceal」类技能 **+50%**（偷盗者的 误判 / 伪装·盗天机 / 寄生 等 conceal 类受益）
> - **=10**：触发「**源堡共鸣**」——本回合所有带 `提线木偶` 的目标可被任意友方（含跨源质）操控一次
>
> **跨源质写入方**：占卜家（愚弄/观诡）、学徒（星界/门）、偷盗者（欺诈/寄生）、永暗之河（不眠者/收尸人/战士）、暗影世界（囚犯/罪犯）、混沌海（秘祈人）也写入同一 `secrecy` 维度。

## 一、技能池

图例：⚠️ = 需框架扩展（注编号或本稿新增项）；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）。

### 普通（序列 9–8）

#### 【主动】窃取 🜁 窃取 · **E**
- **原著** 序列9 偷盗者 —— "「窃取」：轻松窃取目标口袋内物品"
- **文案** 你的手从它的口袋里掠过——钱袋没了，而你连它什么时候被划开的都没让它察觉。
- **序列** 9 偷盗者 · **能量 2 / cd 3 / 吟唱 瞬发**
- **效果** `drain(resource:energy, 3)` + `damage(element:physical,1)` + `mount_status(赃物, stacks:+1)`
- **翻译/语义** 窃物轴 enabler：偷能量+累积 `赃物`。用 `drain`（搬运语义=偷）。⚠️D。

#### 【被动】敏捷之手 🜁 窃取 · **E**
- **原著** 序列9 偷盗者 —— "「敏捷之手」：提升手腕指头灵活度"
- **文案** 你的手腕与十指灵活得不像人手——同样的时间里，你总能比别人多摸一次、多出一手。
- **序列** 9 偷盗者 · **hook** `on_battle_start`
- **效果** `modify_stat(gauge_rate,+8, duration:null)`（整场）+ 每有 1 层 `赃物` 自身 `drain` 量 +⚠️D
- **翻译/语义** 频率提升=出手更快；与赃物协同（赃物越多摸得越多）。INV-S5 合规（改源属性）。⚠️D。

#### 【被动】卓越观察 🜁 窃取 · **E**
- **原著** 序列9 偷盗者 —— "「卓越观察」：感应 10 米内贵重物品"
- **文案** 你一眼就看出谁身上带着值钱的东西——躲起来的没用，揣得深的也没用。
- **序列** 9 偷盗者 · **hook** `on_battle_start`
- **效果** 挂载 `keen_eye`（整场）：敌方 `stealth`/`shadow_veil`/`untargetable` 对你无效（C8）+ 对携带≥1 个 buff/shield 目标伤害 ×1.25；`mount_status(赃物, stacks:+1)`
- **翻译/语义** 识破隐匿+对带增益增伤+累积赃物。⚠️D。

#### 【主动】思维误导 🜂 欺诈 · **E**
- **原著** 序列8 诈骗师 —— "「思维误导」+「精神干扰」"
- **文案** 你在它脑子里轻轻拨了一下——它挥出的那一击，砍在了它自己以为你站着的地方。
- **序列** 8 诈骗师 · **能量 2 / cd 3 / 吟唱 瞬发**
- **效果** `mount_status(misdirect, charges:1, duration:3)`（`behaviorModifiers:[{op:'target_override', anchor:'first_empty'}]`，C7 ✅）+ 敌方 `mount_status(误判, stacks:+1)` + `modify_resource(secrecy,+1)`（欺诈写入隐秘值）
- **翻译/语义** 误导=打空+挂 `误判`（欺诈轴 enabler）+写隐秘值。⚠️D。

#### 【主动】精神干扰 🜂 欺诈 · **E**
- **原著** 序列8 诈骗师 —— "「思维误导」+「精神干扰」"
- **文案** 一串细碎的噪声钻进它的脑袋，它的动作慢了半拍，而那半拍足够你做很多事。
- **序列** 8 诈骗师 · **能量 3 / cd 3 / 吟唱 瞬发**
- **效果** `damage(element:mental,2)` + `modify_resource(gauge.current,-20)` + 敌方 `mount_status(误判, stacks:+1)` + `modify_resource(secrecy,+1)`
- **翻译/语义** 干扰=推条+挂误判+写隐秘值。⚠️D。

#### 【被动】微表情 🜂 欺诈 · **E**
- **原著** 序列8 诈骗师 —— "「卓越观察」质变：观察微表情、小动作"
- **文案** 它肩膀一动你就知道拳要往哪儿落——你侧了半寸，那一击擦着你的衣角过去了。
- **序列** 8 诈骗师 · **hook** `on_battle_start`
- **效果** 挂载 `micro_read`（`charges:3`，整场，C6 ✅）；`on_take_damage`→该次 ×0.75，`charges-1`；`mount_status(误判, stacks:+1)`（自身读心挂误判）
- **翻译/语义** 读身体语言=减伤+自身挂误判。并入参数化减伤母版(H3)。⚠️D。

#### 【被动】魅力口才 🜂 欺诈 · **E**
- **原著** 序列8 诈骗师 —— "「魅力」+「口才」：话术提升+超凡说服力"
- **文案** 你说出口的谎，连命运都愿意多信一会儿——它们在你身上留得比别人久。
- **序列** 8 诈骗师 · **hook** `on_battle_start`
- **效果** 挂载 `silver_tongue`（整场）：你施加的减益/控制类状态 `duration+1`；每施加 1 个 `误判` 额外 `modify_resource(secrecy,+1)`
- **翻译/语义** 说服力=你的谎更持久+持续写隐秘值。依赖 durationModifier(H14)。⚠️D。
