灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **秘祈人途径**（**源堡**，旧日「诡秘之主」，序列0 倒吊人；相邻途径：**占卜家**）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5 / 技能池生成规范 brief，并已逐条核对 `框架改动记录.md`（A–G 组、F1–F63）与已实现契约（`on_battle_start` / `on_kill` / `charges` / `spawn.hpRatio` / `target_override→first_empty`）。

> **本版定位**：v0.2 是**原著校准版**。相比 v0.1 做三件事——
> ① 逐序列比对原著能力表，把 v0.1 抽象的"祈祷神力 / 隐匿潜行 / 牧养灵体 / 堕落诅咒"四条轴拆掉重划，改按原著能力谱系重划为**阴影 / 血肉 / 牧魂 / 秽堕**；
> ② 补回 v0.1 完全没做的原著招牌：序列8 的疯癫代价、序列6 的「必须经常补充血肉」、序列5「放牧灵魂」的吞噬语义、序列4「灵肉之刃」、序列3「血肉不灭」、序列2「秽语」的言灵 / 诅咒 / 诱使堕落、序列1「黑暗海洋」「堕落眷属」、序列0「异变」「替罪」；
> ③ 剔除无原著依据的"神术 / 神恩 / 圣堂 / 混沌海"系列（原著秘祈人途径属**源堡**，不走神圣路线）。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数 / 乘区）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能；⚠️D = 数值待标（占位建议值）

### 普通（序列 9–8）

#### 【被动】灵感 🜁
- **原著** 序列9 秘祈人 —— "灵感极大提升：察觉神秘恐怖存在"
- **文案** 你的灵感远超常人，战局尚未展开，你就已经嗅到了"不该存在之物"的气息。
- **序列** 9 秘祈人 · **hook** `on_battle_start`（A1 ✅）
- **效果** `modify_resource(energy, +5, delta)` + `modify_stat(gauge_rate, +4, duration: null)`（整场）
- **翻译/语义** 卡牌里没有隐藏信息，"察觉神秘恐怖存在"只能落成资源与节奏两条：开局能量（沿用通用锚点）+ 危险预感（行动条速率↑）。⚠️ **G5/G6 铁律**：本条是 `on_battle_start` **被动**，合规；若有人把它改成主动技能自推 `gauge.current`，则等于没加。`gauge_rate` 定价无既有锚点 ⚠️D（D2）。

#### 【主动】祭祀仪式 🜂
- **原著** 序列9 秘祈人 —— "掌握祭祀知识和少量仪式魔法"
- **文案** 你划开自己的皮肉，把血与痛摆上祭坛：仪式完成，力量涌了上来。
- **序列** 9 秘祈人 · **能量 0 / cd 3** · `targetSpec: SELF`
- **效果** `modify_resource(hp, -3, delta)`（自身支付）→ `Sequence[ modify_resource(energy, +5, delta), modify_stat(attack, +2, duration: 3) ]`
- **翻译/语义** 原著"仪式魔法"的通用结构就是"付出代价 → 换取力量"，本途径的代价是**血肉**（与序列6「必须经常补充血肉」闭环）。0 能量、只吃血量，是本途径的费用引擎。
- ⚠️ **自身扣血不能走伤害链**：若 `modify_resource(hp, -3)` 会 fire `on_take_damage` / 反伤 / 亡语 / 致死判定，本卡会自杀或无限触发，需新增 `pay_hp` 语义（本稿新增项 8，🔴）。数值 ⚠️D。

#### 【被动】倾听 🜄 ★
- **原著** 序列8 倾听者 —— "'倾听'：直接听到隐秘存在的耳语，**获得强大但扭曲的能力**"；"**难以存活超过五年，都是隐藏的疯子**"
- **文案** 你日夜聆听那些不该被听见的耳语：力量源源不断地涌来，而你的理智正被它们一点点啃空。
- **序列** 8 倾听者 · **hook** `on_battle_start`（A1 ✅）
- **效果** 挂载 `listener`（整场，`duration: null`，不可驱散）：
  - `modify_stat(energy_regen, +0.4, duration: null)` —— **强大**
  - `modify_stat(hp_max, -8, duration: null)` —— **扭曲**（理智被侵蚀）
  - 触发器 `on_tick` → `{ ref: 'madness_gain_1', condition: { kind: 'chance', p: 0.25 } }` —— **隐藏的疯子**
- **翻译/语义** **本途径的核心风险机制，v0.1 完全没有**。原著一句话里同时给了收益与代价，本稿一字不改拆成三条：能量恢复↑（强）、生命上限↓（扭曲）、疯癫随时间累积（活不过五年）。概率只用于"是否叠 1 层疯癫"这一非伤害判定，符合 R5；写法用 EffectRef 的 `condition`（**G1 更正**），不用不存在的 `Chance()` 算子。
- ⚠️ 依赖新状态 `madness`（新增项 10）+ F50/F51 `stacks`（🟡）。数值 ⚠️D。

#### 【主动】耳语 🜄
- **原著** 序列8 倾听者 —— "直接听到隐秘存在的耳语"（把听到的东西塞进别人脑子里）
- **文案** 你把耳中那句不可名状的低语送进了它的脑袋——它的眼睛开始失焦。
- **序列** 8 倾听者 · **能量 2 / cd 2** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: mental, 3)` + `{ ref: 'mount_madness_1', condition: { kind: 'chance', p: 0.4 } }`
- **翻译/语义** 定位 = 本途径的「火球术」：低费、远程、纯直伤 + 概率附加状态。3 伤 / 2 能 = 1.5 汇率，高于 1.2 基准，因为它是本途径前四个序列**唯一的输出地基**（原著秘祈人低序列同样缺乏直接对敌手段）。⚠️D。
- **升级阶梯**（B6）伤害 3 → 5 → 7；或解锁「群低语」：对目标相邻单位各 1 点精神伤害（`spread: splash_adjacent`，新增项 15）。

#### 【被动】扭曲之力 🜄
- **原著** 序列8 倾听者 —— "获得**强大但扭曲**的能力"；"都是隐藏的疯子"
- **文案** 疯癫也是一种力量：你越被耳语侵蚀，出手就越狠，也越不在乎自己会碎在哪里。
- **序列** 8 倾听者 · **hook** `on_battle_start`（A1 ✅）
- **效果** 挂载 `twisted_power`（整场）：自身 `damage_mul = 1 + 0.08 × 自身 madness 层数`（上限 5 层 → ×1.4）
- **翻译/语义** "强大但扭曲"的另一半：疯癫不只是代价，也是力量来源。与【倾听】构成完整闭环——【倾听】产出 `madness`，【扭曲之力】把 `madness` 兑换成输出，这是本途径疯癫 Build 的引擎。
- ⚠️ 依赖 `madness`（新增项 10）+ **按其它状态层数计算的动态乘区**（新增项 2，🔴）。**退化方案**：改固定 `damage_mul: 1.15`，代价是丢掉疯癫联动。

### 精良（序列 7–6）

#### 【主动】藏入阴影 🜁 ★
- **原著** 序列7 隐修士 —— "'藏入阴影'：躲藏、跟踪、运用阴影力量"
- **文案** 你沉进脚下的阴影里，气息随之消失——敌人只看到一片会动的暗。
- **序列** 7 隐修士 · **能量 2 / cd 4** · `targetSpec: SELF`
- **效果** `mount_status(shadow_dwell, duration: 3)`：
  - `untargetable_by_targeted: true`（依赖 C8 候选池过滤）
  - `damage_taken_mul: 0.85`
  - 触发器 `on_deal_damage` / `on_take_damage` → 移除（出手或挨打即现形）
- **翻译/语义** **阴影轴旗舰**。原著"躲藏、跟踪"在卡牌里的唯一出口就是"不可被选中"（C8）。v0.1 已抓到这点（S1 `stealth` → 已登记 F11），本版保留，并补上原著语义必然要求的"出手即现形"。**不做位移**——原著"跟踪"是修辞，且 G8 禁止越中线。
- ⚠️ 状态名改用 `shadow_dwell` 以区别于不眠者 F4 `shadow_veil` 与本途径 v0.1 的 F11 `stealth`——**三者同一机制，建议并入统一潜行母版**（新增项 11）。依赖 C8（🟢 未实现）。

#### 【主动】召唤阴影 🜁
- **原著** 序列7 隐修士 —— "'召唤阴影'：召唤阴影世界生物"
- **文案** 阴影里伸出一只不属于此世的手——你把它整个拽了出来。
- **序列** 7 隐修士 · **能量 3 / cd 4** · `consumption: 'summon'`
- **效果** `spawn(unit_shadow_spawn, hpRatio: 0.35, atkRatio: 0.5, position: 'tail')`
- **机制** 阴影生物：中低血量、近战、`element: mental`；自带亡语 `on_death` → 对相邻敌方单位 `damage(mental, 2)`。⚠️ **A2**：亡语可挂，**禁止**挂 `on_spawn` 的"登场光环"。
- **翻译/语义** 原著白纸黑字的召唤能力，是本途径召唤体系的起点。属性按比例继承施法者：复用 C5 的 `hpRatio` / `position`（✅ 已实现），`atkRatio` 未见实现（🟡）。
- ⚠️ 新单位 `unit_shadow_spawn` 纳入召唤物基线模板（新增项 19）。

#### 【主动】阴影诅咒 🜄
- **原著** 序列7 隐修士 —— "'阴影诅咒'"；序列6 蔷薇主教 —— "'血肉诅咒'"
- **文案** 阴影像一件湿透的裹尸布贴上它的身体，血肉从底下开始腐烂。
- **序列** 7 隐修士 · **能量 3 / cd 3** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(flesh_corrode, duration: 3)`：`on_tick` → `damage(element: poison, 2)`；`category: ['dot','debuff']`；`dispelable: true`
- **翻译/语义** 序列7「阴影诅咒」与序列6「血肉诅咒」在原著里分列两行、语义高度重合（都是"持续侵蚀肉体"），本版**合为一张卡**，避免两张卡只有名字差别。元素取 `poison`（腐蚀 / 腐烂），与已登记的 `burn`（火）、F16 `whisper`（精神）区分开。3t × 2 = 6 总伤 ≈ 3 能量预算，⚠️D。
- ⚠️ 与 F6 `despair` / F12 `defile` / F13 `drowning` / F16 `whisper` / F18 `entropy_decay` 同为"复合 debuff"族，建议并入参数化母版（新增项 13）。

#### 【主动】操纵阴影 🜁
- **原著** 序列7 隐修士 —— "'操纵阴影'"、"'阴影塑形'"
- **文案** 脚下的影子托着你滑向队列另一侧，顺手凝出一面影盾挡在身前。
- **序列** 7 隐修士 · **能量 2 / cd 3** · `targetSpec: SELF`
- **效果** `Sequence[ move(push_back, distance: 99), mount_status(shield, +5, duration: 3) ]`
- **翻译/语义** 原著"操纵阴影 + 阴影塑形"合并：真实位移只有"退到己方半场队尾"（**C1 ✅ 已落地，且已锁定 `from.faction`；G8 合规**——只在己方队列内、不越中线），塑形落地为影盾。⚠️ **F53 `charge_forward`（v0.1 提出的冲锋 op）本版不再需要**，建议撤销，见「四、本稿遗留」。
- **升级阶梯**（B6）解锁前压版：`move(pull_forward)` + `modify_stat(attack, +2, duration: 3)`（影刃）。

#### 【主动】血肉治愈 🜂 ★
- **原著** 序列6 蔷薇主教 —— "血肉魔法专家：深层掌控细胞，**极擅长治疗**"
- **文案** 你伸手按在伤口上，肌肉与皮肤在你掌心重新长好。
- **序列** 6 蔷薇主教 · **能量 3 / cd 3** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: hp_asc }`
- **效果** `heal(8)` 指定友军（可含自身）
- **翻译/语义** **血肉轴旗舰，也是本途径唯一的正经治疗**。原著白纸黑字"极擅长治疗"，本途径的续航定位由此确立；必须用 `heal` 原语（**A22 / INV-D5**）。8 点 ≈ 力量3 单位 13% 最大生命，高于 3 能量预算（≈6 伤害当量），因它要撑起整条治疗轴，⚠️D。
- **升级阶梯**（B6）治疗 8 → 11 → 14；或解锁「细胞重构」：同时 `dispel(目标, category: ['dot','debuff'], count: 1)`（C2 ✅），对应原著"深层掌控细胞"。

#### 【主动】血肉披风 🜂
- **原著** 序列6 蔷薇主教 —— "'血肉披风'"
- **文案** 你把一层仍在蠕动的血肉披在身上——它替你吃下大部分力道。
- **序列** 6 蔷薇主教 · **能量 3 / cd 4** · `targetSpec: SELF`
- **效果** `mount_status(flesh_cloak, duration: 4)`：`damage_taken_mul: 0.85`；`category: ['buff']`；`dispelable: true`
- **翻译/语义** 原著血肉披风是"额外的一层身体"，用参数化减伤比 `shield` 更贴"披风"的持续吸伤语义，且不吃"禁获护盾"类克制（F17 `lust`）。
- ⚠️ 与 C3 `glibness`(0.75/2t) / F22 `sanctuary`(0.8/3t) / F4 `shadow_veil`(0.7) 同族，建议并入「参数化减伤状态」母版（新增项 12）。数值 ⚠️D。

#### 【主动】血肉炸弹 🜂
- **原著** 序列6 蔷薇主教 —— "'血肉炸弹'"
- **文案** 你把一块还在跳动的血肉塞进它的伤口——两秒后，那块肉炸了，连它身边的同伴一起。
- **序列** 6 蔷薇主教 · **能量 3 / cd 4** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 4)` + `mount_status(flesh_bomb, duration: 2)`；触发器 `on_remove` → 对目标**及其相邻单位** `damage(element: physical, 3)`
- **翻译/语义** 原著"血肉炸弹"= 植入 + 延时爆炸。延时用状态 `duration` + `on_remove` 表达（**不引入第十个原语**）；被驱散也会炸（`on_remove` 语义），这是刻意的——想拆弹就得付代价。总伤 4 + 3×(1~3 目标)，⚠️D。

- **文案** 你吐出一串污秽的音节。它的伤口开始发黑，而它心里有什么东西，正一点点松动。
- **序列** 2 秽语长老 · **能量 4 / cd 5** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `Sequence[ damage(element: mental, 3), mount_status(fallen, duration: 4) ]`
  - `fallen`（诱使堕落）：`heal_received_mul: 0.5`（堕落者受不到神恩）+ `on_tick` → `damage(element: mental, 1)` + `on_remove` → `mount_status(defile, duration: 3)`（**堕落完成**，复用 F12）
- **翻译/语义** 原著把"直接诅咒"与"诱使堕落"写在同一句里，本稿拆成即时（诅咒伤害）与延时（堕落进程）两段，并用"到期转为 `defile`"表达**堕落是个过程，不是瞬间状态**。"精神上的灵肉之刃"= 这条 debuff 走 `mental` 元素、专治灵魂。
- ⚠️ 依赖 `fallen`（新增项 14，🟡，建议并入参数化复合 debuff 母版）+ F12 `defile`（🟡）+ `on_remove`（✅ 已有事件）。

### 传说（序列 1–0）

#### 【主动】黑暗海洋 🜄 ★
- **原著** 序列1 暗天使 —— "'黑暗'权柄：**制造黑暗海洋吞噬攻击**"
- **文案** 黑暗像海水一样漫过战场——打进来的东西沉了下去，而你在水里看得一清二楚。
- **序列** 1 暗天使 · **能量 6 / cd 8** · `consumption: 'zone'`
- **效果** `spawn_zone(zone_dark_sea, duration: 4)`：
  - 区域内**敌方**单位 `damage_mul ×0.75`（攻击被黑暗吞噬）+ `modify_stat(gauge_rate, ×0.85, duration: 场内)`
  - 区域内**己方**单位获得 `concealed`（难以被单体技能选中，依赖 C8）
- **翻译/语义** **秽堕轴的顶点**。原著"吞噬攻击"= 削弱输出（作用在**攻击方**的 `damage_mul` 上，而不是给自己加护盾——"吞噬"发生在攻击落进来之前）；"黑暗"同时给我方隐蔽。
- ⚠️ ZoneDef 机制已存在（A23 已把区域载荷清单化），**只缺这一条数据**（新增项 20，🟢，与 F47 `zone_astral_field` 同型）。另需确认：① Zone 能否落在敌方半场（G8 只约束单位位移，同愚者稿【诡秘之境】的存疑点）；② 区域载荷能否承载 `modify_stat`。

#### 【主动】秽语·流逝 🜄
- **原著** 序列1 暗天使 —— "'秽语'进阶：敌人**生命流逝**、**疯狂加强**"
- **文案** 你每说一句，它们的血肉就淡一分，眼里的疯狂就浓一分。
- **序列** 1 暗天使 · **能量 5 / cd 7** · `targetSpec: ALL_ENEMIES`
- **效果** 对**全体敌方** `mount_status(wasting, duration: 4)`：`on_tick` → `damage(element: none, 2)`（生命流逝）+ `mount_status(madness, stacks: +1)`（疯狂加强）
- **翻译/语义** "生命流逝"= 无属性持续流失（用 `element: none` 规避抗性维度，正合"流逝"的不可抵抗感）；"疯狂加强"= 直接给敌人叠 `madness`（新增项 10），与本途径疯癫体系打通——**敌人越疯狂，就越容易被【耳语】【秽语·言灵】这类精神手段击穿**。
- ⚠️ 依赖 `ALL_ENEMIES`（新增项 17）+ `madness`（新增项 10）+ `stacks`（F50/F51）。数值 ⚠️D。

#### 【被动】阴影统治者 🜁
- **原著** 序列1 暗天使 —— "'阴影统治者'"；序列0 倒吊人 —— "权柄：阴影之主……"
- **文案** 所有阴影都听你的——你藏在里面时，出手比任何时候都狠；而它们生出来的东西，也更强。
- **序列** 1 暗天使 · **hook** `on_battle_start`（A1 ✅）
- **效果** 挂载 `shadow_sovereign`（整场，不可驱散）：
  - 自身处于 `shadow_dwell` / `stealth` / `shadow_veil` 时 `damage_mul ×1.3`
  - 己方**阴影 / 灵体类召唤物**（`tags` 含 `shadow` 或 `spirit`：`unit_shadow_spawn` / `unit_grazed_wraith` / `unit_flesh_servant` / `unit_fallen_kin` / `unit_abomination`）`attack +2`
- **翻译/语义** 原著"统治者 / 之主"= 对阴影及其造物的支配权，落地为两条：自身在阴影中的爆发 + 全召唤物加攻。这是**阴影轴与牧魂轴的汇合点**，也是召唤 Build 的放大器。
- ⚠️ 依赖：① 按"自身是否持有某状态"的条件乘区（与新增项 2 的动态乘区同族，🔴）；② **按单位 `tags` 筛选己方单位**（新增项 18，🟡）；③ C8。

#### 【主动】堕落眷属 🜃 ★
- **原著** 序列1 暗天使 —— "'堕落眷属'：**22 个灵魂全部外放**为眷属"
- **文案** 你把体内所有被吞下的灵魂一起放了出来——二十二道扭曲的身影，黑压压地站满了半个战场。
- **序列** 1 暗天使 · **能量 7 / cd 9** · `consumption: 'summon'`
- **效果** `status.consume(grazed_soul, all)` → `Repeat`：每 **2 层** `grazed_soul` → `spawn(unit_fallen_kin, hpRatio: 0.25, atkRatio: 0.3, position: 'tail')`（上限 11 个）
- **机制** 眷属：低血量、低攻击、`element: mental`、`tags: ['shadow','spirit']`；**不占用"同时驱使上限"**——本条是一次性全部外放，与【驱使灵魂】的常态上限是两条独立约束。
- **翻译/语义** **牧魂轴的顶点**。原著"22 个全部外放"是数量碾压，卡牌里只能落成"用全部存量换一批单位"——所以它的强度**完全取决于玩家前中期攒了多少 `grazed_soul`**，这让【放牧灵魂】的每一次击杀都有复利。
- ⚠️ 依赖 `grazed_soul`（新增项 1）+ **批量 `spawn` + `status.consume(all)`**（新增项 9，🔴）+ 场上单位数上限（新增项 7）。数值 ⚠️D。

#### 【主动】异变 🜄
- **原著** 序列0 倒吊人 —— "'异变'：**黑暗中凭空制造怪物**，血肉不灭质变的复活"
- **文案** 黑暗里有什么东西自己长了出来——它用这个战场上所有死掉的血肉，拼成了自己的身体。
- **序列** 0 倒吊人 · **能量 7 / cd 9** · `consumption: 'summon'`
- **效果** `spawn(unit_abomination, hpRatio: 0.5 + 0.08 × 本场已阵亡单位数（上限 1.0）, atkRatio: 0.7, position: 'tail')`
- **机制** 异变怪物：高血量、高攻击、`element: physical`、`tags: ['shadow','spirit','flesh']`；自带亡语 `on_death` → 对全体敌方 `damage(element: physical, 3)`。
- **翻译/语义** "黑暗中凭空制造怪物"= 凭空 `spawn`；"血肉不灭**质变的复活**"= 用战场上的死亡总量喂养它——死得越多，造出来的越不像东西。这是本途径唯一一张把"战场上死了多少人"当资源的卡。
- ⚠️ 依赖 `spawn.hpRatio` 支持**运行时表达式** + 引擎暴露 `deathsThisBattle` 统计（新增项 19，🔴；与愚者稿 `maxAttackThisBattle` 同属"战场统计暴露"需求，建议统一做一个只读 `battleStats` 对象）。**退化方案**：固定 `hpRatio: 0.7`，代价是失去与战场进程的联动。`hpRatio` / `position` 复用 C5 ✅。

#### 【主动】替罪 🜂 ★
- **原著** 序列0 倒吊人 —— "权柄：……**替罪**……"；"'替罪'：**代替目标承受伤害和死亡**"
- **文案** 你把自己挂了上去。它该受的伤，你来受；它该尝的死，你来尝。
- **序列** 0 倒吊人 · **能量 6 / cd 8** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: hp_asc }`
- **效果** `mount_status(scapegoat, duration: 4)`（挂在**指定友军**身上）：
  - `transfer_ratio: 1.0`：该友军受到的伤害**转嫁给施法者**（不占 `damage_taken_mul` 乘区）
  - `lethal_redirect: true`：该友军若受到致死伤害，改由**施法者**承担这次死亡判定（可触发施法者自身的【血肉不灭】）
- **翻译/语义** **序列0 的核心权柄，本途径最后一块拼图**。原著写明是"代替**目标**承受"——所以状态挂在**友军**身上，方向是"目标 → 你"，与刺客 F5 `pain_link`（你 → 目标）**正好相反**。第二段的"代替**死亡**"是它区别于普通伤害转移的关键。
- ⚠️ 依赖：① `damage_redirect`（新增项 5，🔴）；② `lethal_redirect` 与 `lethal_protect`（新增项 3）的时序——**替死判定必须先于施法者自身死亡结算**，需先定致死 / 复活链的优先级；③ **F56**（状态寻址施法者，🔴）。**退化方案**：去掉 `lethal_redirect`，只做伤害转嫁，仍是一张强保护卡。
