# 囚犯途径（被缚者）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入暗影世界系核心机制 **「恶欲值」单位级量表（0–10）+ 诅咒链接网 + 异类谱系**；
> ③ 新增 **跨系 combo 卡**（囚犯⇄源堡占卜家 提线木偶 / 囚犯⇄失序之国律师 替身 / 囚犯⇄罪犯 恶欲值）；
> ④ 补 1 张主题界域牌（灵界潜域，v0.2 已落，纳入本重构）。
> 框架依据 `../meta/GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》与《暗影世界系技能设定》；跨系机制依据《九大源质总览》《暗影世界系技能设定》§6。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **诅咒** ★核心 | `诅咒链接`(curse_link，可堆叠网络) | 诅咒之源 / 变形诅咒 → 挂链接 | **链接数决定分摊放大系数**（分摊 ×(1+0.2×(N−1))）；伤害转嫁、反噬免疫 | 诅咒之源 / 万咒加身 |
| ② **束缚** | `枷锁` / `灵性囚笼` / `被缚者` | 束缚 / 封印 / 吸收恶欲值 → 挂枷锁 | **吸收恶欲值**转化为诅咒链接层；封印疯狂欲望（不可解） | 侵蚀诅咒 / 被缚者 |
| ③ **异类** ★形态谱系 | `狼人化` / `活尸` / `怨魂` / `木偶`（谱系栈 lineage_stack） | 形态转换 → push 谱系 | **演出：回放前序形态**；谱系深度 D → 异类之王压制力 +20%×D | 演出 / 异类之王 |
| ④ **物品** | `附身物体` / 无生命物品 | 随手物品 / 操纵物品 / 附身物体 | 操纵全部无生命物品；物品权柄增幅 | 物品权柄 |

> **暗影世界系签名机制（咬合器维度）**：本系签名 = **恶欲值（单位级 0–10）+ 诅咒链接网 + 异类谱系**。
> - **恶欲值（单位级）**：战场每单位各自持有一条（写入全局 `StatusDef`）。罪犯产、囚犯消、律师拧。阈值（照搬《暗影世界系技能设定》§2.2）：
>   - 0–3 正常；**4–6 躁动**：造成伤害 +20%，20% 概率攻击最近单位（含友军）；
>   - **7–9 失控**：伤害 +50%，35% 概率攻击友军，无法被治疗；
>   - **=10 欲望爆炸**：受自身最大生命 25% 精神伤害，归零，向相邻单位各传 3 点恶欲值。
> - **诅咒链接网**（囚犯专属引擎改革）：`诅咒链接 N` = 同时链接 N 个目标（含自身源头）；任一被链接单位受伤 → 全网分摊（分摊系数 = `1 + 0.2×(N−1)`）；囚犯自身为源头时损伤按比例转嫁网络。
> - **异类谱系**（囚犯专属引擎改革）：形态转换 → push 入栈，谱系深度 D；`演出` 回放栈中前序形态（弱序列4 强度）；D → 异类之王压制力 +20%×D。
>
> **跨源质写入方**：恶欲值 → 罪犯（产）、律师（腐蚀·拧高）；诅咒链接网 → 囚犯主消费方；提线木偶 → 囚犯（毒性傀儡/怨魂附身）↔ 占卜家（源堡）；替身 → 囚犯（诅咒转嫁）↔ 律师（定义权）↔ 占卜家/刺客。

### 普通（序列 9–8）

#### 【被动】体魄强化 🜏 异类
- **原著** 序列9 囚犯 —— "体魄强化，强壮"
- **文案** 长年囚禁没能压垮你的肉身，反倒把它磨得更硬。战斗开始时，攻击力 +2，护甲 +1。
- **序列** 9 囚犯 · **hook** `on_battle_start`
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(armor, +1, duration: null)`
- **翻译/语义** 序列9 第一条"体魄强化"直译。异类轴变身地基（@v0.2 体魄强化）。⚠️D。

#### 【被动】知觉敏锐 🜐 物品
- **原著** 序列9 囚犯 —— "知觉敏锐"
- **文案** 你比别人先看见、先听见、先摸到那件能要人命的东西。战斗开始时，行动条速率 +6。
- **序列** 9 囚犯 · **hook** `on_battle_start`
- **效果** `modify_stat(gauge_rate, +6, duration: null)`
- **翻译/语义** "知觉敏锐"落地为节奏（先察觉=先出手），非隐藏信息维度。INV-S5 合规（被动改源属性）。⚠️D。

#### 【主动】随手物品 🜐 物品 · **E**
- **原著** 序列9 囚犯 —— "擅长用随手物品杀人"
- **文案** 你的手边永远有东西能要人命。抄起手边之物砸过去，造成 4 点物理伤害；若是锁链，还能把它缠住。
- **序列** 9 囚犯 · **能量 2 / cd 2 / 吟唱 0** · `reach: ranged` · Manual(fallbackSort: `hp_desc`)
- **效果** `damage(element: physical, 4)` + `{ ref: 'mount_shackle_1t', condition: { kind: 'chance', p: 0.3 } }`
- **翻译/语义** 本途径"火球术"：低费纯直伤。概率只作用于是否附加 `枷锁` 状态（非伤害维度，R5 合规），写 EffectRef.condition（G1）。物品轴 enabler（挂 `附身物体` 前置）。⚠️D。

#### 【主动】犯罪技巧 🜎 束缚
- **原著** 序列9 囚犯 —— "掌握诸多犯罪技巧"
- **文案** 下绊、迷眼、背后那一下——你太熟这些了。造成 2 点物理伤害，并把目标的行动条向后拨 25。
- **序列** 9 囚犯 · **能量 2 / cd 3 / 吟唱 0** · `reach: melee` · Manual(fallbackSort: `gauge_desc`)
- **效果** `damage(element: physical, 2)` + `modify_resource(gauge.current, -25, delta)`
- **翻译/语义** 节奏破坏=推条。束缚轴起手（控场）。⚠️D。

#### 【主动】爆发欲望 🜎 束缚 · **E**
- **原著** 序列8 疯子 —— "牺牲理智换力量：爆发欲望换取全方面提高"
- **文案** 你把理智松开一口子。3 回合内攻击力 +3、行动条速率 +8、护甲 +2；代价是防御 −2、精神抗性 −20%。而那股涌起的恶欲，被你一把攥住——全部转为束缚自己的力量。
- **序列** 8 疯子 · **能量 2 / cd 4 / 吟唱 0** · `targetSpec: SELF`
- **效果** `mount_status(frenzy, duration: 3)`：`attack +3` / `gauge_rate +8` / `armor +2`（全方面提高）；`defense -2` / `resist:mental -20%`；`dispelable: false`；**同时 `modify_resource(lust, +3)` 自身 → 立即 `absorb(lust, → curse_link, stacks:+3)`**（束缚轴消纳恶欲值演示）
- **翻译/语义** 原 v0.2 只做自身增益；本重构补"恶欲值"主题——囚犯版（暗影世界系 §5.1）把自身恶欲值全部转为吸收，落为 3 层 `诅咒链接`。⚠️ 依赖 `absorb` 算子（本稿新增项 1）。⚠️D。

## 四、轴引擎 / 咬合器 / 跨系 自检

- **enabler→payoff 闭环**：诅咒轴=诅咒链接网络（诅咒之源挂网→无反噬/万咒加身读网放大）；束缚轴=吸收恶欲值转链网（爆发欲望/厄缚汲取/侵蚀诅咒/被缚者）；异类轴=谱系栈（狼人化/灵体化 push→演出回放/异类之王读深度）；物品轴=无生命物品操纵（随手物品/操纵物品→物品权柄）。四轴均显式成链。
- **暗影世界系咬合器**：恶欲值（单位级 0–10）由罪犯产、囚犯消、律师拧；诅咒链接网（分摊系数 1+0.2×(N−1)）为囚犯专属引擎；异类谱系栈（深度 D→压制 +20%×D）为囚犯专属引擎。三者均已 weave 入卡面。
- **跨系 combo（非复刻）**：双线同提（读占卜家提线木偶）、厄缚汲取（读罪犯恶欲值）、诅咒木偶·改（读律师替身），均为"读取友方别家招牌状态再升级"。
- **界域牌**：灵界潜域（序列5 上层 overlay）1 张，占总量内。

## 五、本稿遗留

- **数值全档待标**：所有能量/伤害/时长/层数 ⚠️D（沿用 D4）。`gauge` 推拉类（犯罪技巧/怨魂尖啸）、AOE 类（怨魂尖啸/万咒加身）、网络分摊系数（1+0.2×(N−1) 的 N 计数）为盲区。
- **诅咒链接网络母版**：`诅咒链接` 需实现"同时链接 N 个目标 + 全网分摊 + 分摊系数 1+0.2×(N−1) + 源头转嫁比例"——依赖本稿新增项 2（网络母版，非 v0.2 的单向 `curse_link`）。
- **异类谱系栈**：`lineage_push` / `演出回放` / `lineage_depth` 依赖本稿新增项 3。
- **`absorb(lust, → curse_link)` 算子**：束缚轴消纳恶欲值转链接层，依赖本稿新增项 1。
- **未单独成技能的原著能力**（有意省略）：序列6 控制幽魂（并入【唤醒死尸】升级）、序列5 镜面闪现/自由出入灵界（仅文案 flavor）、序列3 沉默具体形式（推导为【长久沉默】）。
