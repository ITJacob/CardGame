# 罪犯途径（深渊）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入暗影世界系核心机制 **「恶欲值」单位级量表（0–10）+ 诅咒链接网 + 异类谱系**，罪犯侧为**产能方**；
> ③ 新增 **跨系 combo 卡**（罪犯⇄失序之国律师 恶欲值 / 罪犯⇄灾祸之城刺客 黑焰 / 罪犯⇄母巢耕种者 污秽）；
> ④ 保留并纳入主题界域牌【深渊化】（brief §10.4 列于罪犯，双向：全场每回合 2 点无视护甲腐蚀 + 替身类能力失效）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》与《暗影世界系技能设定》；跨系机制依据《九大源质总览》《暗影世界系技能设定》§6。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **恶欲** ★核心 | `恶欲值`(lust，单位级 0–10) | 掌控欲望 / 欲望爆炸 / 污秽之语·堕落 → 推高恶欲值 | **恶欲值越高伤害越高**（4–6 +20% / 7–9 +50%），但失控风险上升；呓语/深渊即我读阈值结算 | 欲望使徒 / 欲望爆炸 |
| ② **污秽** | **`filth`**（2026-09-13 显式登记的跨系记账状态，`crossPathway:true`，`participants:[罪犯/耕种者/怪物]`）；**挂载来源** = `侵蚀` / `中毒` / `深渊之咒` | 污秽之语 / 侵蚀者 → 挂侵蚀 dot | **无视护甲持续穿透**；对已中毒/burn 目标追加同类 | 污秽之王 / 侵蚀者 |
| ③ **领域** | 界域 + 火/毒 AOE | 深渊化界域 / 强酸沼泽 / 腐蚀毒雾 | 领域内敌人减速+持续伤害；岩浆之剑 / 地狱之火 / 深渊之火 | 深渊化 / 深渊之火 |
| ④ **恶魔** ★现存最佳链 | `仪式刻印`(rite_mark) | **恶魔仪式**（生命 −6 → 能量 +8 → 刻印 +1 层） | **深渊召唤**（消耗全部刻印层 → 恶魔强度/数量） | 恶魔仪式 / 深渊召唤 |

> **暗影世界系签名机制（咬合器维度）**：本系签名 = **恶欲值（单位级 0–10）+ 诅咒链接网 + 异类谱系**。
> - **恶欲值（单位级）**：战场每单位各自持有一条。**罪犯是产能方**——不断推高（越强但越失控）；**囚犯是消纳方**——吸收转诅咒链接；**律师（失序之国）拧**——腐蚀直接推高敌人恶欲值。阈值（照搬《暗影世界系技能设定》§2.2）：
>   - 0–3 正常；**4–6 躁动**：伤害 +20%，20% 概率改攻最近单位（含友军）；
>   - **7–9 失控**：伤害 +50%，35% 概率攻友军，无法被治疗；
>   - **=10 欲望爆炸**：受自身最大生命 25% 精神伤害，归零，向相邻各传 3 点。
> - **刻印链（罪犯专属引擎改革）**：`恶魔仪式`（生命−6→能量+8→`仪式刻印`+1 层）→ `深渊召唤`（消耗全部刻印层 → 恶魔强度/数量 = f(N)）。把现存唯一完整 enabler→payoff 链扶正为轴心。
> - 诅咒链接网 / 异类谱系 见囚犯稿 §〇（罪犯侧经"转化"把被欲望击垮的敌人 push 入囚犯谱系）。
