# 收尸人途径 · 技能池 v0.1

灵感源：ima 知识库《诡秘之主-途径数据》→ 收尸人途径（aka 死神途径，源质「永暗之河」，相邻途径=战士、不眠者）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5，已核对 `_GENERATION_BRIEF.md` 与 `愚者途径_技能池_v0.1.md`。

> 本稿是**设计约定**，不是终稿数值。所有数值标注推导依据，最终需过验证脚本。
> 「文案」为玩家视角的效果描述，用于肉鸽派发展示；「效果」为引擎落地表达。
> 主题天然贴合 brief 的「复活/历史 → heal + spawn + 亡语」规则：通灵/死灵 → `spawn` 亡灵单位，不死者/复苏 → `heal`/`regen`/`亡语` 复活，摆渡人/死亡支配 → 大招用 `spawn` + `mount_status`。

## 〇、肉鸽化前提

| 约定 | 内容 |
|---|---|
| 槽位 | 每英雄 **4 主动 + 4 被动** |
| 派发 | 爬塔随机派发，逐步构筑 |
| 共享 | 部分技能带 `sharedAcross`，可被相邻途径（战士/不眠者）的职业重复抽到 |
| 稀有度 | 由序列位阶直接映射（见下表） |

### 稀有度 = 序列位阶（自然映射）

| 序列 | 稀有度 | 派发权重 | 定位 |
|---|---|---|---|
| 9–8 | 普通 Common | 高 | 骨架，开局即可得 |
| 7–6 | 精良 Uncommon | 中 | 成型件 |
| 5–4 | 稀有 Rare | 低 | 构筑核心 |
| 3–2 | 史诗 Epic | 很低 | 大招 / 转折点 |
| 1–0 | 传说 Legendary | 极低 | 一局最多 1 张 |

### 四条构筑轴

| 轴 | 关键词 | 玩法 |
|---|---|---|
| 🜃 **死亡感知** | 信息 / 能量 | 从尸体与死亡气息中榨取节奏（能量、护甲、易伤预知） |
| 🜄 **通灵召唤** | 亡灵 / 铺场 | `spawn` 骷髅/怨灵/行尸，靠尸体海碾过去 |
| 🜂 **不死复苏** | 续航 / 复活 | `heal`/`regen`/`亡语`，极厚生命力与一次复活 |
| 🜁 **死亡支配** | 控制 / 权柄 | `mount_status` 易伤/守护 + 大招 `spawn`+debuff，操弄生死 |

## 一、技能池

图例：⚠️ = 需要框架扩展（已登记改动记录）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】尸嗅 🜃
- **文案** 你天生嗅得到尸骸与将死之气，每回合开始都能从死亡里捞到一丝节奏，获得 1 点能量。
- **序列** 9 收尸人 · **hook** `on_turn_start`
- **效果** `modify_resource(energy, +1)`
- **推导/语义** 死亡感知的基石：把"对尸体与死亡气息的本能感知"译成稳定能量流（对比愚者「占卜」走概率，这里确定性更强，因尸体是既成事实）。约 1 能量/回合 ≈ 1.2 伤害当量。

#### 【被动】尸体解读 🜃
- **文案** 俯身读取尸体残留的最后一缕信息，每当一个敌人倒下，你便回收到 2 点能量。
- **序列** 9 收尸人 · **hook** `on_death`（敌方单位）
- **效果** `modify_resource(energy, +2)`（触发者=敌方死亡时）
- **推导/语义** "从尸体获取微弱非凡特性" → 击杀回能，是召唤/通灵轴的能量引擎。价值随敌人数线性放大。

#### 【被动】地下感知 🜃
- **文案** 你感知到墓穴的脉络与土层，战斗开始时如置身墓土壁垒，获得 3 点护甲。
- **序列** 8 掘墓人 · **hook** `on_battle_start`（⚠️ A1 新增触发点）
- **效果** `modify_resource(armor, +3, delta)`
- **推导/语义** "感知地下与墓穴结构" → 落地为护甲。3 护甲 ≈ 既有的 `opening_aura`(+2 护甲) 同量级略强，符合普通档。

#### 【主动】尸语 🜄
- **文案** 对刚倒下的尸体低语几句残语，从残魂里唤出一具骷髅兵，替你站上最前排。
- **序列** 8 掘墓人 · **能量 2 / cd 3** · `consumption: summon`
- **效果** `spawn(unit_skeleton)`
- **推导/语义** "尸语：与刚死尸体对话" → 直接把尸体变召唤物。2 能量门槛低，是通灵轴润滑剂。
- ⚠️ 需新增单位定义 `unit_skeleton`（见本途径框架改动）。

#### 【主动】裹尸布 🜂
- **文案** 扯过一角裹尸布缠住自己，挡下 3 点伤害，并缓缓回拢 2 点生命。
- **序列** 8 掘墓人 · **能量 1 / cd 2** · `targetSpec: SELF`
- **效果** `mount_status(shield, +3, 3t)` + `heal 2`
- **推导/语义** 不死复苏轴的早期小续航。1 能量极低门槛（基准 3 能量=6 伤害，这里给 3 护盾+2 治疗≈等价的防御/回复），是粘合剂。

### 精良（序列 7–6）

#### 【主动】通灵 🜄
- **文案** 沟通并约束一缕游荡灵体，召出一只怨灵，中血量、以精神撕咬敌人。
- **序列** 7 通灵者 · **能量 3 / cd 4** · `consumption: summon`
- **效果** `spawn(unit_wraith)`
- **推导/语义** "沟通与约束灵体" → 中阶召唤物，承上启下。
- ⚠️ 需新增单位定义 `unit_wraith`。

#### 【被动】灵体约束 🜄
- **文案** 你精于约束灵体，所有被你唤出的亡灵都更结实：攻击 +2、生命 +5。
- **序列** 7 通灵者 · **hook** `on_spawn`（友方召唤物登场时）
- **效果** `modify_stat(atk, +2)` + `modify_stat(max_hp, +5)`（作用于刚生成的友方召唤物）
- **推导/语义** "掌握通灵与灵体交流能力" → 通灵轴被动增益。用 `on_spawn` 给新召唤单位附属性（非开局光环，非 A2 bug 情形）。
- ⚠️ 需 `spawn` 支持 `companionBuff`（spawn 时给该单位附带 modify_stat，扩展改动记录 C5 的 spawn 能力）——见本途径框架改动。

#### 【主动】死灵术 🜄
- **文案** 操纵死灵之力，从地里拽起一具迟缓却厚实的行尸，替你顶在最前。
- **序列** 6 死灵导师 · **能量 4 / cd 5** · `consumption: summon`
- **效果** `spawn(unit_zombie)`
- **推导/语义** "操纵亡灵与死灵术" → 坦克型召唤物。
- ⚠️ 需新增单位定义 `unit_zombie`。

#### 【被动】亡语铭刻 🜂
- **文案** 你在自己身上刻下亡语：当死亡降临，一具骷髅会从你残躯里爬起，替你继续战斗（每场一次）。
- **序列** 6 死灵导师 · **hook** `on_death`（自身）
- **效果** `spawn(unit_skeleton)`（自身死亡时，于原坐标生成）
- **推导/语义** 不死复苏轴早期版"亡语复活"。复用既有的 `on_death` 触发 + `spawn`（C5 已登记重生位置/坐标规则），无需新状态。

#### 【主动】残息汲取 🜃
- **文案** 抽取敌人将散未散的残息，造成 3 点伤害，并借此回拢 2 点生命。
- **序列** 7 通灵者 · **能量 3 / cd 3** · `reach: ranged`
- **效果** `damage 3 (necrotic)` + `drain 2`（`heal 2` 自身）
- **推导/语义** "沟通灵体"引申为吸取残息 → `drain` 原语。3 伤害+2 吸血 = 5 能量基准（3×1.2=3.6 直伤 + 生命回复，略低于火球但因带续航合理）。

### 稀有（序列 5–4）

#### 【主动】守门 🜁
- **文案** 看门人守着亡者与墓园，你为一名友军立起门扉，替它挡下指向它的攻击。
- **序列** 5 看门人 · **能量 3 / cd 4** · `targetSpec: SELF_OR_ALLY`
- **效果** `mount_status(守护, 4t)`
- **推导/语义** "看守亡者与墓园" → 守护（替友军挡）。复用既有 `守护` 状态，零新机制。

#### 【被动】墓园结界 🜁
- **文案** 墓园的阴寒在开场笼罩战场，敌方全体前 2 回合受到的伤害提升 30%。
- **序列** 5 看门人 · **hook** `on_battle_start`（⚠️ A1）
- **效果** 全体敌方 `mount_status(易伤, 2t)`（`damage_taken_mul: 1.3`）
- **推导/语义** 死亡支配轴的开局压制。复用 `易伤`（A14 裁定 ×1.3），2t 短窗口避免过强。

#### 【被动】不死者之躯 🜂 ★
- **文案** 你已是半步不死者，战斗开始时体魄极强：获得再生（持续回血），且生命上限永久 +10。
- **序列** 4 不死者 · **hook** `on_battle_start`（⚠️ A1）
- **效果** `mount_status(regen)`（总回 12 / 6t，既有的可驱散再生）+ `modify_stat(max_hp, +10, duration: null)`
- **推导/语义** 不死复苏轴旗舰。"极强生命力" → 再生 + 生命上限。+10 上限在力量3(60 血)时 ≈ 16.7% 提升，配合再生构成厚血内核。

#### 【主动】复苏 🜂
- **文案** 以不死之力唤起残息，为自身或一名友军立即恢复 8 点生命。
- **序列** 4 不死者 · **能量 3 / cd 4** · `targetSpec: SELF_OR_ALLY`
- **效果** `heal 8`（必须用 `heal` 而非 `modify_resource` —— A22 / INV-D5）
- **推导/语义** 与 `regen`（总 12、6t、可驱散）差异化：瞬发 8、不可驱散、量更少但即时。锚点：≈力量3 时 13% 最大生命。

#### 【主动】亡者大军 🜄
- **文案** 看门人一声令下，墓园之门洞开，两具骷髅同时爬出列阵。
- **序列** 5 看门人 · **能量 4 / cd 6** · `consumption: summon`
- **效果** `spawn(unit_skeleton)` ×2
- **推导/语义** 通灵轴铺场峰值。4 能量换 2 单位，性价比高于单召，是尸体海的支点。
- ⚠️ 复用 `unit_skeleton`。

#### 【被动】死亡预感 🜃
- **文案** 你能预感到死亡的临近，战斗开始时便已蓄好一口气息，立即获得 5 点能量。
- **序列** 5 看门人 · **hook** `on_battle_start`（⚠️ A1）
- **效果** `modify_resource(energy, +5)`
- **推导/语义** 死亡感知轴的高阶节奏件，等价于愚者「灵视」的能量部分（无上限加成版）。5 能量 ×1.2 = 6 伤害当量。

### 史诗（序列 3–2）

#### 【主动】引渡 🜁 ★
- **文案** 摆渡人出手，将敌人的魂魄引向冥河：造成 3 点伤害，并标记其灵魂（受伤 +30%），同时唤出一只怨灵助战。
- **序列** 3 摆渡人 · **能量 4 / cd 5** · `reach: ranged`
- **效果** `damage 3 (necrotic)` + `mount_status(易伤, 3t)`（目标）+ `spawn(unit_wraith)`（己方）
- **推导/语义** 死亡支配轴旗舰。"引渡与冥河权柄" → `spawn` + `mount_status` 组合（依 brief 提示）。3 直伤 + 易伤增幅 + 召唤，三位一体。
- ⚠️ 复用 `unit_wraith`、`易伤`。

#### 【主动】亡灵号令 🜁
- **文案** 死亡执政官的号令响彻墓园，全体敌人被死亡气息侵染，受到 2 点伤害且 3 回合内受伤 +30%。
- **序列** 2 死亡执政官 · **能量 5 / cd 6** · `targetSpec: ALL_ENEMIES`
- **效果** `damage 2 (necrotic)` ×全体 + `mount_status(易伤, 3t)` ×全体
- **推导/语义** 死亡支配轴 AoE 压制。5 能量换全体易伤 3t，是后续集火的放大器；直伤压到 2 因 AoE 本身价值高。

#### 【被动】死亡法则 🜁
- **文案** 你执掌部分死亡法则，你造成的所有伤害提升 15%。
- **序列** 2 死亡执政官 · **hook** 常驻
- **效果** `modify_stat(damage_mul, +0.15, duration: null)`
- **推导/语义** "掌握死亡法则" → 全局增伤。`damage_mul` 需为既有 `StatKey`；若引擎未暴露此 key，则属新状态项（⚠️ 待标 D 组）。

#### 【被动】亡灵支配 🜄 ★
- **文案** 你统御亡灵，所有被你唤出的亡灵都浸着死气，持续回血（再生）。
- **序列** 2 死亡执政官 · **hook** `on_spawn`（友方召唤物登场时）
- **效果** `mount_status(regen)`（作用于刚生成的友方召唤物）
- **推导/语义** 通灵召唤轴旗舰。"亡灵支配权柄" → 召唤物自带再生，尸体海越打越厚。
- ⚠️ 同样依赖 `spawn.companionBuff`（本途径框架改动，扩展 C5）。

#### 【被动】亡语重生 🜂
- **文案** 即便被彻底击倒，不死的本质仍让你从尸堆里爬起：以 30% 生命复活一次（每场限一次）。
- **序列** 3 摆渡人 · **hook** `on_death`（自身）
- **效果** `spawn(自身, hpRatio: 0.3)`（每场一次）
- **推导/语义** 不死复苏轴终版"亡语复活"。直接复用改动记录 C5 的 `spawn` hpRatio + 重生位置（原坐标/队尾）。
- ⚠️ 依赖 C5（`spawn` 支持 hpRatio + 重生位置）。

### 传说（序列 1–0）

#### 【被动】苍白视界 🜃 ★
- **文案** 苍白皇帝洞见一切将死之物的终局：开场便以死亡视界侵蚀敌阵（全体易伤 3 回合），且每回合从死亡里榨取 2 点能量。
- **序列** 1 苍白皇帝 · **hook** `on_battle_start`（⚠️ A1）+ `on_turn_start`
- **效果** 全体敌方 `mount_status(易伤, 3t)` + 自身 `modify_resource(energy, +2)`（每回合）
- **推导/语义** 死亡感知轴旗舰，也是整条途径的节奏/压制顶点。易伤 3t 长窗 + 稳定 2 能量/回合，把"感知死亡"推到极致。序列 1–0 仅做高费大招/flavor。

#### 【主动】死神之镰 🜁
- **文案** 死神挥下镰刀，斩出 8 点伤害，令敌人灵魂破绽大开（全体易伤 4 回合），并召出一缕怨灵随行。
- **序列** 0 死神 · **能量 6 / cd 8** · `targetSpec: ALL_ENEMIES`（直伤为主目标，易伤为全体）
- **效果** `damage 8 (necrotic)`（主目标）+ `mount_status(易伤, 4t)` ×全体 + `spawn(unit_wraith)`
- **推导/语义** 序列 0 终极大招（flavor 为主）。8 伤害 ≈ 6 能量×1.2 基准打平，代价在全体易伤 4t 的恐怖增幅；一局至多 1 张。

#### 【主动】永暗之河 🜄
- **文案** 永暗之河在脚下奔涌，三具骷髅自河面爬出列阵，你亦从这死亡之河里回拢 6 点生命。
- **序列** 0 死神 · **能量 6 / cd 8** · `consumption: summon`
- **效果** `spawn(unit_skeleton)` ×3 + `heal 6`（自身）
- **推导/语义** 序列 0 另一面：铺场 + 续航。3 骷髅 = 尸潮顶点；6 治疗收尾。与死神之镰二选一构筑。

## 三、跨途径共享（永暗之河相邻途径）

收尸人途径与「战士」「不眠者」同源质「永暗之河」分组，下列技能用 `sharedAcross` 声明可共享：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 尸嗅 / 尸体解读 / 死亡预感 | 战士、不眠者 | 对尸体与死亡气息的本能感知，战士的战场经验、不眠者的守夜直觉皆通 |
| 地下感知 | 战士 | 墓土壁垒式护甲契合战士前排定位 |
| 守门（守护） | 战士 | 看门人守护亡者 = 战士守护队友，语义同构 |
| 不死者之躯 / 复苏 / 亡语重生 | 不眠者 | "不眠"即不死特性，复苏与一次复活天然契合 |
| 尸语 / 通灵（spawn 灵体） | 不眠者 | 不眠者分支亦沟通游荡灵体，召唤亡灵互通 |
