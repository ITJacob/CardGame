### 核心机制：规则与律令（Decree）—— 本途径的灵魂

原著给仲裁人途径写了一句最要紧的话：**序列6「对一定区域立下新规则，违背则受束缚」**。这句话决定了本途径不是"又一个控制途径"，而是**"立法者"**：仲裁人不直接按住敌人，而是**宣判一条规则，把"要不要违背"的选择权还给对手，然后在它违背的瞬间落槌**。

**这与律师途径的分野就在这一步**：律师是**钻规则的空子、扭曲规则、独占规则**（序列4「篡改 / 增加 / 利用规则」，序列1「重新定义让秩序有利于自身」）；仲裁人是**立规则、守秩序、行审判**。所以本途径的规则一律是**公开、明确、双向可验证**的——敌人知道规则，也知道违背的代价；而律师的规则操作永远是对己有利的暗箱。机制上这也更好落地：规则是**挂在敌人身上的、可被玩家看见的状态**，不是隐藏判定。

载体是状态 `decree`（🔴 本稿新增项 2），挂在**敌方单位**身上，携带四个要素：

| 要素 | 含义 |
|---|---|
| `rule` | 禁令类型（不得发动主动技能 / 不得攻击 / 不得给自己或他人上增益 / 不得位移 / 不得治疗） |
| `charges` | 可惩罚几次（违背 N 次后规则自动失效——"三振出局"，也防止无限惩罚） |
| `duration` | 规则存续（tick） |
| `punishment` | 违背时的惩罚载荷（伤害 / 束缚 / 沉默 / 推条） |

**判据**是「该单位**发动主动技能**」这一即时节点（🔴 本稿新增项 1，`on_active_skill`）；惩罚结算**归施法者**（依赖 F56 状态寻址施法者）。

规则随序列递进的**层次表**（本稿最需要做出层次的地方）：

| 序列 | 技能 | 规则范围 | 违背的代价 | 时长 / 次数 |
|---|---|---|---|---|
| 6 法官 | 【立规】 | **单体** | 受**束缚**（`shackle`：禁位移 + `gauge_rate` 降）+ 少量精神伤害 | 6t / 2 次 |
| 5 惩戒骑士 | 【禁制追击】 | **单体**（叠加在惩戒目标上） | 被**必定命中**的一击追惩（伤害，不是控制） | 6t / 3 次 |
| 4 律令法师 | 【律令·神秘减弱，现实增强】 | **敌方全体**（宽泛限制，不再是"某条禁令"） | 无需违背——律令是**持续生效的压制**（耗能加重 + 减攻），己方同步"现实增强" | 8t（原著 30 秒 ~ 一刻钟） |
| 1 秩序之手 | 【秩序领域】 | **敌方全体 + 规则可选** | 违背者受**重罚**（伤害 + 束缚 + 推条三连） | 10t / 3 次 |
| 1 秩序之手 | 【废止】 | **不是立规，是去除既有规则**（非底层） | 清空上层界域压制栈 + 锁本回合界域切换 | 4t |
| 0 审判者 | 【底层规则】 | **世界底层规则 + 赋予豁免权** | 降临改写底层规则的界域；并为己方全体签发豁免 | 8t |

> **设计纪律**：本稿的"规则"**不是**硬性禁止（那只是 `沉默` / `眩晕` 换皮）。规则的价值在于**博弈**——对手仍可以违背，代价由它自己付。因此【立规】的退化方案（改成直接 `沉默`）只在 `on_active_skill` 触发点无法落地时启用，且必须注明"失去博弈感"。

### 核心机制：辖区（Jurisdiction）—— 区域层次

原著序列8 治安官白纸黑字写了「**辖区**：指定区域获得超凡实力和环境帮助」，序列3 混乱猎手把辖区「**扩大至大都市**」。落地为一条 ZoneDef `zone_jurisdiction`（🟡 本稿新增项 10，与 F47 `zone_astral_field` 同源——A23 已把区域载荷清单化，机制已存在，只缺数据），并在 B6 升级阶梯上做三级：

| 档 | 对应序列 | 覆盖 | 载荷（⚠️D） |
|---|---|---|---|
| Ⅰ 辖区 | 8 治安官 | 己方半场一块（约 2 格） | 己方单位 `attack +2`、受伤害 ×0.9；区域内敌方单位 `gauge_rate ×0.9`（环境不帮它） |
| Ⅱ 大都市 | 3 混乱猎手 | 己方**全场** | 同上，数值加强（`attack +3`、×0.85 / ×0.85） |
| Ⅲ 秩序领域 | 1 秩序之手 | **全场**（含敌方半场，🟡 落位待与 G8 一起拍板） | 叠加全场 `decree`（见上表） |

> ⚠️ **G8 落位待拍板**：G8 原文只约束**单位位移**。本稿的 Ⅰ / Ⅱ 档一律落在己方半场（绝对安全）；Ⅲ 档需要跨中线铺区域，与愚者稿【诡秘之境】、耕种者稿【创造世界】是同一个待决问题，建议三稿一起拍。若不批准跨场，【秩序领域】退化为"己方全场 + 敌方全体挂 decree 状态"（不走 Zone），机制不受影响。

> **技能总量 35 个（主动 28 / 被动 7；普通 6 / 精良 9 / 稀有 7 / 史诗 7 / 传说 6）**。仲裁人途径在原著里的规则类能力密度极高——单是序列6 法官就有七个判词（禁止 / 囚禁 / 禁闭 / 鞭打 / 流放 / 死亡 / 守秘）、序列4 有五个（律令 / 剥夺 / 禁锢 / 震慑 / 放逐 / 处决），要"遵照原著"就必须给足覆盖；单局构筑密度由派发权重控制，池子大小不影响 4+4 槽位。

### 普通（序列 9–8）

#### 【被动】信服与权威 🜁
- **原著** 序列9 仲裁人 —— "让人信服的魅力和权威"
- **文案** 你往那儿一站，就是规矩本身——敌人面对你时难免自惭形秽，出手也软了三分。
- **序列** 9 仲裁人 · **hook** `on_battle_start`（A1 ✅ 已落地）
- **效果** `modify_stat(attack, -1, duration: null)` 敌方全体（整场）
- **翻译/语义** 原著序列9 的两条能力之一是"让人信服的魅力和权威"。卡牌里没有社交维度，权威的唯一可结算出口就是**削弱对手的攻击意志**——注意它**不是**减伤（不是"你更能扛"），而是"对方打不动"，与愚者稿【能力精进】的自身增伤方向相反。⚠️D：整场 -1 攻是否过高需验证脚本复核，可改为开局 4t 后转 -0.5。
- ⚠️ 依赖 `modify_stat` 的 **AOE 目标 + 整场 duration**（🟡 本稿新增项 16）。

#### 【主动】屈服 🜃
- **原著** 序列9 仲裁人 —— "让冲突方不自觉想要屈服"
- **文案** 你抬眼看了它一眼，它的刀便偏了——那一击挥向了你身侧的空处。
- **序列** 9 仲裁人 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(overawed, charges: 1, duration: 3)`；`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`
- **翻译/语义** **本稿最重要的补漏之一**。原著白纸黑字的"不自觉想要屈服"——不是恐惧（那是刺客 / 收尸人），不是混乱（那是律师），而是"**它自己不想打了**"。引擎里最贴的表达就是**下一次攻击打向空处**（C7 已端到端验证 ✅），比"眩晕 / 减攻"都更贴合"不自觉"三个字。用 C6 `charges: 1` 表达"一次"。
- **与律师的分野** 律师的同类能力是"扭曲目标意图"（改它打谁），仲裁人是"让它自己放弃这一击"（打空）。
- ⚠️ 新状态 `overawed` 数据登记（🟢 本稿新增项 19，复用 C7 无新机制）。

#### 【主动】格斗术 🜂
- **原著** 序列9 仲裁人 —— "出色格斗能力"
- **文案** 你近身上前，一记利落的直拳砸在它脸上——仲裁人的拳头，从来先于判决到达。
- **序列** 9 仲裁人 · **能量 3 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 5)`
- **翻译/语义** **本途径的「火球术」锚点**：3 能量 → 5 物理伤害（基准 1.2 汇率），低费、无附加、纯直伤。原著仲裁人途径低序列**唯一的攻击性描述**就是这句"出色格斗能力"，v0.1 完全没有输出地基（全靠"治安压制 3 伤 / 警告 1 伤"），导致前 4 个序列打不出任何东西。**G8 合规**：`reach: melee` 是近战攻击进程，不调 `move`、不改站位。
- **升级阶梯**（B6）伤害 5 → 7 → 9；或解锁"械斗"分支：对目标追加 `modify_resource(gauge.current, -20, delta)`（打退）。

#### 【被动】过目不忘 🜃 ★
- **原著** 序列8 治安官 —— "见过就能牢牢记住目标样子，获得额外感应"
- **文案** 你只要看过一眼，那张脸就再也抹不掉了——记住的东西，藏不起来，也逃不掉。
- **序列** 8 治安官 · **hook** `on_battle_start`（A1）+ `on_spawn`（第三方监听，⚠️）
- **效果** `mount_status(marked, duration: null)` 敌方全体（整场）：
  - 你对被标记单位造成的伤害 **+1**
  - 被标记单位的**隐匿 / 潜行 / 不可锁定**类状态**对你无效**（依赖 C8 的「识破」分支）
  - 你的单体技能候选池**优先**命中被标记单位（依赖 C8 加权）
- **翻译/语义** **本途径体系的入口，v0.1 完全漏掉**。原著是"记住样子 + 获得额外感应"两条语义，正对应卡牌里的两件值钱事：**伤害加成**与**识破隐匿**。它是【察觉异常】【混乱感应】【失衡感应】【惩戒】四张卡的价值放大器——没有"记住"，后面所有"针对"都无从谈起。
- ⚠️ 依赖：C8「识破」分支（🟢 已登记未实现）+ 新状态 `marked`（🟡 本稿新增项 9，与 F1 `inscription` 计数型同源但只需布尔标记）+ **敌方新登场单位（召唤物）补标记**需要全局 `on_spawn` 第三方监听（🔴 与耕种者 v0.2 新增项 1 同源）。**退化方案**：去掉召唤物补标记，只标记开局在场的敌人。

#### 【主动】辖区 🜁 ★
- **原著** 序列8 治安官 —— "『辖区』：指定区域获得超凡实力和环境帮助"
- **文案** 这里是你的辖区。脚下的路、墙里的砖、风里的味道都站在你这边——而踏进来的外人，寸步难行。
- **序列** 8 治安官 · **能量 3 / cd 5 / 吟唱 0** · `consumption: 'zone'` · 落点：己方半场

- ⚠️ 依赖 ZoneDef `zone_full_moon`（🔴，与 F47 `zone_astral_field`、愚者 v0.2 新增项 16、不眠者 v0.2 新增项 10、收尸人 v0.2 新增项 10、观众 v0.2 新增项 5 同源，并入同一 Zone 母版）+ 状态 `reveal` / `concealed` 双向分支（观众 v0.2 新增项 4 同族）。⚠️D

#### 【主动】律令·神秘减弱，现实增强 🜄 ★
- **原著** 序列4 律令法师 —— "『律令』（核心）：制定**宽泛限制**维持 30 秒到一刻钟 / 如'**神秘减弱，现实增强**'——**削弱所有非凡能力**"
- **文案** 「于此地，神秘减弱，现实增强。」话音落下，敌人的非凡能力开始迟滞、走形、变得昂贵——而你脚下的大地，比刚才更实了。
- **序列** 4 律令法师 · **能量 5 / cd 7 / 吟唱 ⚠️D** · `targetSpec: { faction: ALL }`（双向：敌我各一套载荷）
- **效果** `Sequence[`
  - 敌方**全体**：`mount_status(耗能加重, 8t)` + `modify_stat(attack, -3, duration: 8)`,
  - 己方**全体**：`modify_resource(armor, +3, delta)`（"现实增强"）`]`

- ⚠️ 依赖：既有状态 `耗能加重`（✅）+ AOE `modify_stat` 带 duration 回滚（🟡 新增项 16）+ 需要**双向 targetSpec**（己方一套 / 敌方一套，两个 EffectRef 各用 `target` 覆盖，model.ts:64 已支持）。

#### 【主动】分割战场 🜁

- **文案** 你抬手划下一道看不见的界线。线的这一边和那一边，从此谁也够不着谁。

#### 【主动】五五开 🜄 ★
- **原著** 序列2 平衡者 —— "单对单**强制降低 / 提升敌人至自己水准**（『五五开』）"
- **文案** 你把它拉到了和你同一条线上。它比你强，就跌下来；它比你弱，就抬上来——总之，五五开。
- **序列** 2 平衡者 · **能量 4 / cd 6 / 吟唱 ⚠️D** · Manual（fallbackSort: `atk_desc`）
- **效果** `equalize_stat(target ← self, keys: ['attack', 'defense', 'armor', 'gauge_rate'], duration: 6)`
  - **双向**：目标当前值高于施法者 → 降至施法者水准；低于施法者 → 提升至施法者水准
- **翻译/语义** **本途径最有味道的机制，v0.1 完全没有**。原著白纸黑字"强制降低 / **提升**敌人至自己水准"——注意它是**双向**的，不是单纯的削弱。本稿明确**拉平的四项属性**：
  | 属性 | 拉平 | 理由 |
  |---|---|---|
  | `attack` | ✅ | 最直观的"实力"，也是"五五开"的核心体感 |
  | `defense` | ✅ | 同上，与 attack 成对 |
  | `armor` | ✅ | 属资源型防御，可安全 set（不参与 hp 结算） |
  | `gauge_rate` | ✅ | 出手频率是"实力"的一半；且 `gauge_rate` 是**源属性**，不违反 INV-S5 |
  | `hp` / `hp_max` | ❌ | **不拉平**。改 hp_max 会触发死亡/溢出结算地狱，改 hp 等于直接斩杀，都不属于"拉平实力" |
  | `energy` / `energy_max` / `energy_regen` | ❌ | 同上，且能量是派发资源，改它等于改构筑 |
  - **INV-S5 合规**：本条改的是 `gauge_rate`（源属性），**不是**派生的行动周期。
- **战术双面性** 对强敌是**削弱**（攻防被砍）；对弱敌是**增强**（抬到你水准）——所以它不是无脑强卡，误用会把杂兵抬成精英。这正是原著"平衡"的味道。
- ⚠️ **🔴 阻塞**：依赖 `equalize_stat`（新增项 4）——当前 `modify_stat` 只有 delta 模式，无法表达"设定为某值"。
- **退化方案** 改为双向固定值：`If(target.attack > self.attack)` → `modify_stat(attack, -4, duration: 6)`，`else` → `modify_stat(attack, +2, duration: 6)`，其余三项同理（各需 2 条 EffectRef，共 8 条）。**代价**：拉平变为近似值，且"精确五五开"的体感丢失。

#### 【主动】均衡分割 🜄
- **原著** 序列2 平衡者 —— "部分'平衡'权柄：**分割战场保证实力平衡**"
- **文案** 你把战场一分为二，然后拨了拨天平——你们两边最强的那个，从此一样强。
- **序列** 2 平衡者 · **能量 5 / cd 6 / 吟唱 ⚠️D** · 双目标（各自动选取）
- **效果** `Sequence[`
  - `mount_status(isolated, duration: 5)` 施加于**敌方攻击力最高**的单位（"分割战场"）,
  - `equalize_stat(敌方 attack 最高单位 ← 己方 attack 最高单位, keys: ['attack', 'defense'], duration: 6)`（"保证实力平衡"）`]`
- **翻译/语义** 原著序列2 的"分割战场"与序列3 是**同一能力的两个用途**：序列3 分割是为了**猎杀混乱**（切开、孤立、逐个审判）；序列2 分割是为了**保证平衡**（切开、然后拉平）。本稿刻意让这两张卡**共用** `isolated` 状态，只差后半段载荷——这是原著"同一权柄两种用法"的正确表达方式，比造两个独立机制干净得多。
- **与【五五开】的差异** 五五开是**拉平到你**（单方面定义水准）；均衡分割是**拉平到彼此**（双方最强者对齐）。前者是判决，后者是调停。
- ⚠️ 🔴 依赖 `equalize_stat`（新增项 4）+ 新 targetSpec `ENEMY_STAT_HIGHEST` / `ALLY_STAT_HIGHEST`（🟡 新增项 14，与 F57 `ENEMY_ENERGY_DESC` 同源）。

#### 【被动】失衡感应 🜃
- **原著** 序列2 平衡者 —— "能**感应不平衡发现隐秘目标**"
- **文案** 谁在这片战场上站得太高，你一眼就能看出来——而站得最高的那个，往往藏得最深。
- **序列** 2 平衡者 · **hook** `on_battle_start`（A1）
- **效果** 自动锁定敌方中 **`attack` 最高**的单位（平局取 `index_asc`），挂载 `unbalanced`（整场）：
  - 你对其造成的伤害 ×1.2
  - 其隐匿 / 潜行 / 不可锁定类状态对你无效（C8「识破」分支）
- **翻译/语义** 原著"感应不平衡发现隐秘目标"——"不平衡"在卡牌里唯一可判定的形式是"**某个单位明显强过其他人**"，故判据取 `attack` 最高；"发现隐秘目标"则明确要求带**识破隐匿**。与【混乱感应】的判据（负面最多）形成对照：一个看"谁最强"，一个看"谁最失控"，都是原著明写的能力，不容合并。
- ⚠️ 依赖：新状态 `unbalanced`（🟡 新增项 9）+ `ENEMY_STAT_HIGHEST`（🟡 新增项 14）+ C8。

### 传说（序列 1–0）

#### 【主动】秩序领域 🜁 ★

- **文案** 你为这片战场立了法。从这一刻起，这里的每一条规矩都由你书写——而违规者，会知道代价。
- **序列** 1 秩序之手 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `targetSpec: { faction: ENEMY, scope: all }`

- **规则可选**是本条的序列1 味道：低序列的法官只能判"不许动"，秩序之手可以**为整片战场挑选禁令的类型**（不许施法 / 不许攻击 / 不许加持），"制定规则"四个字才立得住。

#### 【主动】废止 🜄 ★
- **原著** 序列1 秩序之手 —— "能**修改或暂时去除原有规则（非底层）**"
- **文案** 你伸手从这片战场上抽走了一条既有的规矩。它消失了四秒——四秒，足够改掉很多事。
- **序列** 1 秩序之手 · **能量 5 / cd 8 / 吟唱 ⚠️D** · 全场（不指向单位）
- **界域** 上层 →「废止」(4 tick)
- **环境规则** 全场 `disable` 一切 `consumption: domain` 行为——**本域存续期间，无人能再切换界域**（天然双向：敌我同禁）
- **效果** `Sequence[`
  - `dispel(target: domain, filter: { tier: 'overlay' }, count: all)`（**抽走战场上全部正在生效的上层界域**——被压制的下层随之恢复生效）,
  - `domain(op: overlay, def: 'edict_seal', duration: 4)`（降临「废止」域：锁死界域切换，见环境规则）,
  - `modify_resource(lost, +1)`（界域操作租金）`]`
- **翻译/语义** **原著招牌，也是本稿最有味道的一张卡**。注意原著的两个限定：① "**原有**规则"——不是新立的（那是【立规】/【秩序领域】），而是**把已经存在的战斗规则暂时抽掉**；② "**非底层**"——base 层不可驱散（INV-B11），底层规则是序列0 的活（见【底层规则】），序列1 只能动上层。
- **为什么不是"驱散"或"免疫"** 因为"去除规则"作用于**全场、不分敌我**，也**不针对单位**——它改的是战场本身的运行方式，不是某个单位身上的状态。界域系统落地后，"战场级规则"的载体就是上层界域：抽走规则 = 解除界域（`dispel` domain 目标，效果上下文 §二已落），锁规则 = 「废止」域的环境规则（`disable` 按 `consumption` 过滤，执行参数 §一已落）。这是本途径唯一一张"不指向任何单位"的卡，也是它与其余 21 条途径拉开身位的卡。
- ✅ **2026-09-07 落地**：v0.2 曾拍板"规则开关子系统不立项、本卡暂不实现"；brief §9.1 已解禁——规则改写由**界域**承载（统一的载体、持续的回合数、可被打断/覆盖的生命周期），本卡按界域牌重写，零新机制。

#### 【主动】中止奇异 🜃
- **原著** 序列1 秩序之手 —— "能**中止混乱奇异**，感应秩序变化"
- **文案** 秩序落下的地方，混乱无处存身——那些诡异的加持、畸变的庇护，一并散了形。
- **序列** 1 秩序之手 · **能量 5 / cd 7 / 吟唱 ⚠️D** · `targetSpec: { faction: ENEMY, scope: all }`
- **效果** 敌方**全体**：`dispel(target, category: ['buff'], count: all)` + `damage(element: mental, 3)`；并挂载自身 `order_sense`（6t）：期间**敌方新获得的增益** `duration ×0.5`（⚠️D）
- **翻译/语义** 原著"中止混乱奇异"——"混乱奇异"在卡牌里最贴的载体是**敌方身上的异常加持与畸变状态**（`buff` 类）。做成**群体剥夺 + 后续压制**：先一次性扫平全场增益（中止），再让它们在一段时间内新上的增益都打个对折（"秩序已临，混乱难再成形"）。后半段是它与【剥夺】（单体全驱散）拉开档次的地方。
- ⚠️ 依赖：C2 `dispel.category` 数组（✅）+ `incoming_status_duration_mul` 宿主侧 duration 缩放（🟡，与耕种者 v0.2 新增项 18 同源，建议并入同一实现）+ 敌方全体 targetSpec（🟡，与 F59 `ALL_ALLIES` 同源，一并实现）。

#### 【主动】审判 🜂 ★
- **原著** 序列0 审判者 —— "'审判'权柄：**违背秩序者皆可审判，有整个世界意志和力量加持**"
- **文案** 你宣判的那一刻，整个世界的意志都站在你身后——它身上的每一道罪，都在这一击里被清算。

- **翻译/语义** 原著序列0 的审判权柄有两点必须都落地：① "**违背秩序者皆可审判**"——审判的**对象资格**来自"它身上有多少问题"，故伤害按目标身上的负面状态数**逐条累加**（这是本途径"规则 → 违背 → 受罚"链条的终局兑现：前面铺垫的每一道 debuff 都在这里变现）；② "**整个世界意志和力量加持**"——力量不只来自你，故伤害**波及全场其余敌人**（不是分摊，是每人一份余波）。

## 三、跨途径共享（失序之国相邻：律师）

源质同源（失序之国），仲裁人与律师是**唯一一对互为相邻**的途径。共享用 `sharedAcross: ['lawyer']` 声明。

**先立分野，再谈共享**：

| | 仲裁人（本途径） | 律师 |
|---|---|---|
| 对规则的态度 | **立规则、守秩序、行审判**——规则是公开的、双向的、我也要守 | **钻空子、扭曲规则、独占规则**——规则是可利用的、单向的、只对我有利 |
| 心智影响的手段 | 让对方**屈服 / 坦白 / 承认**（权威、审讯） | 让对方**被引导 / 被腐蚀 / 被扭曲**（口才、贿赂、腐蚀） |
| 典型动词 | 宣判、禁止、囚禁、剥夺、放逐、处决、审判、拉平 | 扭曲、贿赂、腐蚀、混乱、利用、放大、狂乱、定义 |

因此共享的判定标准是：**落在两条途径共有的"秩序执行 / 心智影响"语义上，但不涉及「规则的制定权」**。

| 技能 | 共享给 | 理由 |
|---|---|---|
| 屈服 | 律师（序列9） | 律师序列9「扭曲 / 引导目标思维」与仲裁人「让冲突方不自觉想要屈服」同属**心智影响**，且打空（C7）是通用的目标改写表达 |
| 察觉异常 | 律师（序列9） | 律师序列9「擅长发现利用规则漏洞和**对手薄弱处**」= 察觉薄弱；序列6 腐化男爵要腐蚀人心，前提是"看得见哪里阴暗" |
| 过目不忘 | 律师（序列9） | 律师的思辨与质证建立在"记住对手"之上；标记型机制（记住 → 针对）两条途径通用 |
| 禁止 | 律师（序列4） | 律师序列4 堕落伯爵「篡改 / 增加 / **利用**规则，营造有利战斗环境」——规则类**执行**手段互通；沉默本身是通用控制 |
| 震慑 | 律师（序列3） | 律师序列3 狂乱法师「上位者：**威严**实质化为武器，下位者身不由己听从」——威严震慑是两条途径共有的语义 |

> **明确不共享**（共享会稀释本途径辨识度）：
> - **规则制定权三件套**：立规 / 禁制追击 / 律令·神秘减弱现实增强 / 秩序领域 / 废止 / 底层规则 —— 这是仲裁人与律师**唯一的分界线**所在。律师对规则做的是"利用 / 扭曲 / 定义"，绝不能拿到"立规与违背受罚"这套机制，否则两条途径在机制上就合并了。
