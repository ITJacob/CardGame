# 不眠者途径 · 技能池 v0.2

灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **不眠者途径**（序列0：黑暗，源质「永暗之河」，相邻途径：收尸人，核心象征：黑暗、恐惧、隐秘、厄运）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5 / 技能池生成规范 brief，并已逐条核对 `src/` 实际 schema 与 `框架改动记录.md`。

> **本版定位**：v0.2 是**原著校准版**。相比 v0.1 主要做三件事——
> ① 逐序列比对原著能力表（序列 9→0），**补回全部被漏掉的招牌能力**：夜色成长、午夜诗篇三分支、入梦 / 塑梦、安魂、驱使自然灵、黑夜领域、发丝缠绕、厄运、黑暗之剑、恐惧灵光、梦魇世界、隐秘三件套（隐秘化 / 隐秘之地 / 展现被隐秘的内容）、厄难、黑暗仆人、灵之统帅，以及序列0 的五大权柄；
> ② **剔除偏离原著的翻译**：v0.1 把「隐秘」降格成序列8 的潜行卡、把「安魂」做成纯治疗、把「越黑暗越强」整个漏掉、把「入梦」做成通用眩晕——这些都不在原著里；
> ③ 把原著里**具体的手段**（诗篇影响敌人 / 队友 / 目标三种风格、封印于牙齿释放自然灵、骨制长剑消融、发丝缠绕、隐秘之地封印、从黑暗中回归）还原成可落地的机制。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。
>
> **本稿三条自律**（为规避已知框架坑，写在最前面）：
> - **零 `on_turn_start`**：本稿全部周期性效果挂 `on_tick`，完全不碰 G15 的死触发点。
> - **零自推条**：不存在任何给自身 `gauge.current +N` 的效果（G5 / G6）。改节奏只动 `gauge_rate` 或推/拖**他人**。
> - **零概率**：原著「厄运」主题一律落成**确定性**形式（节奏拖慢 / 行动条倒退 / 负面状态附加），不掷骰子（R5 + brief §3.0 的"命运/概率主题落成节奏"口径）。

| 轴 | 原著依据 | 关键词 | 玩法 |
|---|---|---|---|

| 🕯 **安魂** | 序列6（安魂：安抚灵魂，抹平欲望和情绪 / 能直接看见灵体生物）+ 序列4（安魂质变：死灵怨魂也变缓慢安宁）+ 序列5（驱使自然灵，封印于牙齿释放 / 可驱使 4–5 个灵，一心多用）+ 序列1（灵之统帅：统御自然灵和亡灵）+ 序列0（灵体灵性权柄） | 安抚 / 削弱 / 召唤 | 抹平敌人的增益与欲望，召唤并统御灵体 |

> **本稿主轴：隐秘的三个层次**。原著里「隐秘」是不眠者最核心也最独特的权柄，v0.1 只做了一张序列8 的潜行卡。本版按原著的三种用法分三层落地：
> **① 自身隐秘**（【隐秘权柄】常驻 + 【无迹之影】受击即隐）→ **② 给友军隐秘**（【隐秘化】单体 / 可给自己）→ **③ 把敌人封进隐秘之地**（【隐秘之地】连其友军都够不到它）。反向的【掀幕】对应原著"也能展现被隐秘的内容"，让这条轴有攻有守。
>
> 技能总量 **34 个**（主动 21 / 被动 13，v0.1 为 24 个）。不眠者途径在原著里是能力谱系非常宽的一条（十个序列各自独立成体系，序列0 独占五大权柄），要"遵照原著"就必须给足覆盖；单局构筑密度由派发权重控制，池子大小不影响 4+4 槽位。

### 普通（序列 9–8）

#### 【被动】不眠之躯 🌑
- **原著** 序列9 不眠者 —— "每天只需 3-4 小时休息"
- **文案** 你的身体早已习惯不眠，别人睡一整夜才攒下的精力，你在片刻的假寐里就能补回。
- **序列** 9 不眠者 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(energy_max, +5, duration: null)` + `modify_stat(energy_regen, +0.2, duration: null)`（每 tick，G14 口径）
- **翻译/语义** 原著只是"休息需求少"，v0.1 却据此造出了一整条"能量续航轴"（不眠涌动、不眠意志、永暗庇护、厄难之拥四张卡都是它的变体），这是本途径 v0.1 最大的偏离。本版把它压回**一条序列9 的骨架被动**，能量只是"睡得少"的副产品，不再是构筑轴。⚠️D

#### 【被动】夜视 🌑
- **原著** 序列9 不眠者 —— "无需光照具备卓越视力"；"敏锐察觉黑暗里的危险"
- **文案** 黑暗于你并非阻碍——藏在暗处的身形瞒不过你的眼睛，而它们自以为得手的偷袭，也总是慢了半步。
- **序列** 9 不眠者 · **hook** `on_battle_start`
- **效果** 挂载 `dark_sight`（整场）：① 敌方 `concealed` / `shadow_veil` / `stealth` 类状态**对你无效**；② `on_take_damage` → `If(攻击者处于隐匿类状态)` → 该次伤害 ×0.75
- **翻译/语义** 原著两条语义都落地：① "无需光照的视力" = 识破隐匿（依赖 C8 的「识破」分支，与愚者【灵视】【灵体之线】同源）；② "察觉黑暗里的危险" = 反伏击减伤，不是 v0.1 那句"对有控制状态的敌人 +2 伤害"（原著没写这个）。
- ⚠️ 依赖 C8（🟢 已登记未实现）+ 新 targetSpec `attacker`（**F61** 🟡，可能只是把反伤内部已有的攻击者指针暴露成配置）。退化：去掉反伏击分支，只留识破。⚠️D

#### 【被动】夜色渐浓 🌑
- **原著** 序列9 不眠者 —— "夜越深精力越充沛，力量/敏捷/思维超越常人"
- **文案** 夜色每浓一分，你的力量、身手与思绪便更清明一分——黎明之前，不会有人的锋芒比你更盛。
- **序列** 9 不眠者 · **hook** `on_tick`
- **效果** `mount_status(nightfall, stacks: +1, maxStacks: 5)`（整场）；每层提供 `attack +1` / `gauge_rate +2` / `energy_regen +0.04`（随层数动态浮动，满层 +5 / +10 / +0.2）
- **翻译/语义** **原著招牌能力，v0.1 完全漏掉**。这是本途径唯一一条随战斗时长成长的机制，也是"越黑暗越强"的可判定条件来源。三层语义一比一落地：力量 = `attack`、敏捷 = `gauge_rate`（**INV-S5 合规**，改的是速率源属性不是派生的行动周期）、思维 = `energy_regen`。
- ⚠️ 依赖 `mount_status.stacks`（**F51** 🟡）+ `per_stack_stat`（本稿新增项 3，🔴）。**退化方案**：改阈值触发（层数 ≥3 时挂 `modify_stat(attack, +3, duration: 2)`），丢掉"渐进"手感但保住机制。⚠️D

#### 【被动】午夜武艺 🌑
- **原著** 序列8 午夜诗人 —— "擅长格斗、射击、攀爬和感应"
- **文案** 你在午夜里练就的身手从不需要灯火照明——拳脚、准头与攀爬的本能，早已刻进骨子里。
- **序列** 8 午夜诗人 · **hook** `on_battle_start`
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(defense, +1, duration: null)`
- **翻译/语义** 原著白纸黑字的身体素养，直接落成常量攻防（单卡纪律：攻防 ±1~±2）。这是本途径的属性地板，让低序列也有基本的站场能力；"感应"那一条并入【夜视】，不重复立项。
- **升级阶梯**（B6）+1 / +1。
- ⚠️D

#### 【主动】午夜诗篇·恍惚 🌙
- **原著** 序列8 午夜诗人 —— "用不同风格的诗篇影响生灵：使**敌人精神恍惚**"
- **文案** 你念起一支节拍错乱的诗——它的思绪散了，挥出的拳也失了准头。
- **序列** 8 午夜诗人 · **能量 2 / cd 2** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `damage(element: mental, 2)` + `mount_status(daze, duration: 3)`：`damage_mul: 0.8` + `modify_stat(gauge_rate, ×0.9, duration: 3)`
- **翻译/语义** 原著"诗篇影响生灵"是**三分支**能力（敌人恍惚 / 队友安静 / 目标恐惧），v0.1 只做了一张通用沉默卡，三个分支全丢了。本版把三个分支拆成三张卡（本条 / 安眠谣 / 惊惧诗），各自独立进池。⚠️D
- ⚠️ 依赖新状态 `daze`（本稿新增项 18，🟡；建议并入"参数化增益/减益母版"）。**退化方案**：直接挂既有 `易伤`？不可——易伤是受伤乘区，与"输出衰减"方向相反，会改变卡的性质；退化为 `modify_stat(attack, -2, duration: 3)` 更稳。

#### 【主动】安眠谣 🕯
- **原著** 序列8 午夜诗人 —— "用不同风格的诗篇影响生灵：使**队友安静**"
- **文案** 你低声哼起一支安眠的调子——同伴急促的呼吸平复下来，身上的诅咒也松动了几分。
- **序列** 8 午夜诗人 · **能量 2 / cd 3** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: hp_asc }`
- **效果** `heal(5)`（**A22**：治疗必须用 `heal` 原语）+ `dispel(target, category: ['control','debuff'], count: 1)`（C2 数组 ✅）
- **翻译/语义** 诗篇的第二个分支。"安静"= 平复情绪 = 清控制 + 清负面；配 `heal` 是因为纯驱散在卡牌里收益过薄。注意**这条是安魂轴的低阶预演**，与序列6【安魂】的区别：安魂谣是**增益向**（治+净），安魂是**削弱向**（削+封）。
- ⚠️D

#### 【主动】惊惧诗 🌙
- **原著** 序列8 午夜诗人 —— "用不同风格的诗篇影响生灵：使**目标恐惧**"
- **文案** 你吟出一行不该被听见的句子——它的瞳孔骤然收缩，握武器的手开始发抖。
- **序列** 8 午夜诗人 · **能量 2 / cd 3** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `damage(element: mental, 3)` + `mount_status(dread, duration: 2)`（`modify_stat(attack, -3, duration: 2)` + `damage_mul: 0.8`）
- **翻译/语义** 诗篇的第三个分支，也是本途径**恐惧链的最下一环**——序列8 惊惧诗 → 序列3 恐惧灵光 → 序列0 恐惧权柄，同一状态 `dread` 三级复用。
- ⚠️ 依赖状态 `dread`（**与水手途径 v0.2 新增项 3 同名同源，建议直接复用，不另立一条**，本稿新增项 14）。⚠️D

### 精良（序列 7–6）

#### 【主动】入梦 🌙 ★
- **原著** 序列7 梦魇 —— "『入梦』：自由出入极大范围熟睡者的梦，**强行拉人入梦**"
- **文案** 你伸手探进它的睡意，把它整个人拽了进去——在它自己的梦里，它连抬手都做不到。
- **序列** 7 梦魇 · **能量 3 / cd 4** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: mental, 2)` + `mount_status(slumber, duration: 4)`：`disable` 全部四行为（口径同既有「眩晕」）+ `damage_taken_mul: 1.2`（睡梦中毫无防备）
- **翻译/语义** **本途径的招牌控制，也是梦魇轴旗舰**。v0.1 把入梦做成了通用「眩晕」，但原著里"梦"是**可以被操纵的容器**——序列7 的塑梦、序列3 的梦魇世界、序列0 的永眠都在它上面做文章。所以必须单独立 `slumber` 状态族，不能复用「眩晕」。
- ⚠️ 依赖新状态 `slumber`（本稿新增项 1，🔴）。**退化方案**：挂「眩晕 4t」+ `易伤 4t` 近似，代价是【塑梦】【梦魇世界】【永眠】三张卡失去锚点、必须整体重做。⚠️D

#### 【主动】塑梦 🌙
- **原著** 序列7 梦魇 —— "『塑梦』：让梦境按设想发展，**引导秘密或击溃精神**"
- **文案** 你替它把这场梦改了走向——梦里的东西开始啃食它的精神，而它藏得最深的那个秘密，已经落在了你手里。
- **序列** 7 梦魇 · **能量 3 / cd 4** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `If(target_has_status: ['slumber'])` → `then: Sequence[`
  - `mount_status(nightmare_torment, duration: 4)`：`on_tick → damage(element: mental, 2)`，并把宿主 `slumber` 的 duration 刷新至 4（**击溃精神**）,
  - `mount_status(vulnerable, duration: 4)`（**引导秘密** = 套出弱点）,
  - `modify_resource(energy, +2, delta)` 给自身（**得知秘密**）`]`
  `else: damage(element: mental, 2) + mount_status(slumber, duration: 3)`（无梦可塑，就先把它拉进梦里）
- **翻译/语义** 原著"塑梦"是**对已入梦者的二次操作**，所以本卡必须有 `If` 分支——这正是它与【入梦】的分工。原著的两个用途（引导秘密 / 击溃精神）分别落成"暴露易伤 + 自身得能"与"精神 dot"。
- ⚠️ 依赖 `If` + `target_has_status`（**F52** 🟡）+ `slumber`（新增项 1，🔴）+ 新状态 `nightmare_torment`（建议并入 F 组合并候选 4「参数化复合 debuff 模板」，与新增项 5 同源）。⚠️D

#### 【被动】梦境行者 🌙
- **原著** 序列7 梦魇 —— "自由出入**极大范围**熟睡者的梦"
- **文案** 只要有谁还沉在梦里，就没有你够不到的地方——距离与前排，都拦不住一个走在梦里的人。
- **序列** 7 梦魇 · **hook** `on_battle_start`
- **效果** 挂载 `dream_walker`（整场）：① 你对处于 `slumber` 的敌方单位施放技能时**忽略 reach / 前排限制**（`ignore_range_restriction: true`）；② 你施加的 `slumber` duration +1

## 四、本稿遗留

- **数值全档待标**：34 个技能的能量 / 伤害 / 时长 / 层数均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中 `gauge_rate` 乘算类与 `gauge.current` 倒退类技能的定价无既有锚点，是最大盲区（沿用 **D2**）。
- **未单独成技能的原著能力**（有意省略或合并，留待后续）：
  - 序列9「无需光照具备卓越视力」—— 战场没有"光照"维度，故折为识破隐匿并入【夜视】
  - 序列8「擅长格斗、射击、攀爬和感应」—— 折为【午夜武艺】的攻防常量；"射击"在本途径无 ranged/melee 战术差异，不单独立卡；"感应"并入【夜视】
  - 序列7「自由出入……梦」的**"出入"（位移）** —— 受 **G8** 限制且引擎无"梦境坐标"概念，未落地；仅取"极大范围"落成【梦境行者】的无视距离限制
  - 序列6「强制入梦范围提升至 150 米」/ 序列5「梦魇范围提升至 200 米」—— 引擎无施法距离维度，两次提升合并为【强制入梦】的"从单体升级为群体"，150/200 两个数字不建模
  - 序列5「封印于**牙齿**释放」—— "牙齿"是载体 flavor，不建模；释放 = `spawn`
  - 序列4「正午阳光下被削弱」—— 折为"夜色 ≤1 层时的攻防减值"；若后续引入光明类区域（歌颂者【无暗之域】），再升级为区域条件判定
  - 序列3「梦魇世界影响**一座小城市**」—— 规模折为全场 Zone，未做规模分级
  - 序列1「大天使层面的骑士水准」—— 位格碾压（brief §3 不搬），折为【灵之统帅】里自身 +3 攻的常量
  - 序列0「让目标入梦 / 永眠 / 消融」—— 三个动词合并为【永眠·消融】一张卡
  - 序列0「误导窥探」—— 卡牌无"窥探/反占卜"维度，不建模
- **未决机制优先级**：`lethal_protect`（【黑暗仆人·不灭】）与 `eternal_sleep`（【永眠·消融】【黑暗之剑】）正面对冲。需先定**致死 / 复活 / 反复活**的结算优先级链，否则【黑暗仆人·不灭】强度不可控（愚者稿【命运锚点】、秘祈人稿【替罪】已提同一问题，建议汇总阶段统一拍板）。
- **"黑暗"条件的可判定性**：本稿建立了两个判据（`nightfall` 层数 / `zone_night_realm`），但前者依赖 `per_stack_stat` 或阈值谓词、后者依赖 Zone 载荷能承载 `mount_status`/`modify_stat`，**两者都是 🔴**。若只能落地一个，优先 `nightfall`（它不依赖 Zone，覆盖面更广，且【守夜人体质】【黑暗仆人·不灭】都以它为主判据）。
- **本稿无 `move` 类技能**：原著不眠者途径**没有任何位移类能力**（v0.1 的【暗影潜行】及其"不可锁定 + 现身爆发"是偏离原著的设计，已删除）。"出入梦"的位移因 G8 与缺少梦境坐标未落地（见上）。这一取舍使本途径完全不受 G8 约束，也意味着本稿没有任何跨半场风险。
- **概率使用**：本稿**零概率**。原著"厄运"主题全部落成确定性形式（节奏拖慢 / 行动条倒退 / 负面状态附加），符合 R5 与 brief §3.0 的"命运/概率主题落成节奏"口径。
- **`on_turn_start` 使用**：本稿**零使用**。全部周期性效果挂 `on_tick`，完全规避 **G15**；也不存在 G15-b 的时间尺度冲突。
