# 愚者途径 · 技能池 v0.1

灵感源：ima 知识库《诡秘之主-途径数据》→ 占卜家途径（aka 愚者途径，源堡，三支柱「诡秘之主」）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5，并已核对 `src/catalog/model.ts` 的实际 schema。

> 本稿是**设计约定**，不是终稿数值。所有数值标注了推导依据，最终需过验证脚本（见改动记录 D 组）。

## 〇、肉鸽化前提（本版新增的设计约束）

| 约定 | 内容 |
|---|---|
| 槽位 | 每英雄 **4 主动 + 4 被动** |
| 派发 | 爬塔随机派发，逐步构筑 |
| 共享 | 部分技能带 `sharedAcross`，可被相邻途径（学徒/偷盗者）的职业重复抽到 |
| 稀有度 | 由序列位阶直接映射（见下表） |

### 稀有度 = 序列位阶（自然映射，无需另设维度）

| 序列 | 稀有度 | 派发权重 | 定位 |
|---|---|---|---|
| 9–8 | 普通 Common | 高 | 骨架，开局即可得 |
| 7–6 | 精良 Uncommon | 中 | 成型件 |
| 5–4 | 稀有 Rare | 低 | 构筑核心 |
| 3–2 | 史诗 Epic | 很低 | 大招 / 转折点 |
| 1–0 | 传说 Legendary | 极低 | 一局最多 1 张 |

### 四条构筑轴（肉鸽要保证技能能成体系，不能是散装）

| 轴 | 关键词 | 玩法 |
|---|---|---|
| 🜁 **预知** | 能量 / 节奏 | 攒能量快，技能连发 |
| 🜂 **戏法** | 位移 / 站位 | 操控战场位置，把敌人拽出来打 |
| 🜃 **秘偶** | 控制 / 干扰 | 嘲讽、诅咒、驱散增益 |
| 🜄 **奇迹** | 续航 / 复活 | 治疗、护盾、复活，磨死对手 |

## 一、技能池

图例：⚠️ = 需要框架扩展（已登记改动记录）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】灵视 🜁
- **序列** 9 占卜家 · **hook** `on_battle_start`（⚠️ A1 新增触发点）
- **效果** `modify_resource(energy, +5)` + `modify_stat(energy_max, +5, duration: null)`
- **推导** 5 能量 × 1.2 汇率 = 6 伤害 ≈ 力量3 时 10% 最大生命。与既有 `opening_aura`（+2 护甲 ≈ +8% TTK）同量级略强。
- **为什么带 +5 上限** 纯 +5 能量的收益与智力成反比（智力0=25tick 质变，智力6=3.6tick 无感）。加上限让高智力也吃香，顺带解决后期能量溢出浪费。
- **重复获得** 升级：+5/+5 → +8/+8 → +12/+12

#### 【被动】占卜 🜁
- **序列** 9 占卜家 · **hook** `on_turn_start`
- **效果** `Chance(0.3)` → `modify_resource(energy, +2)`
- **合规** R5：概率只用于"是否给能量"这个非伤害维度，走 RandomSource，需按 R3 登记。期望 0.6 能量/回合。

#### 【被动】平衡感 🜂
- **序列** 8 小丑 · **hook** `on_battle_start`
- **效果** `modify_stat(gauge_rate, +8, duration: null)`
- **推导** 行动周期 = 75/(15+8×敏捷)。敏捷3 时 rate 39 → 周期 1.92 tick；+8 后 rate 47 → 1.60 tick，**提速 17%**。
- **合规** INV-S5 只禁止改"行动周期"这个派生值；`gauge_rate` 是源属性，`StatKey` 里已有，无需改框架。⚠️ 数值待标（D2）

#### 【主动】小丑戏法 🜂
- **序列** 8 小丑 · **能量 1 / cd 2** · `reach: none`
- **效果** `move(swap_neighbor, direction: 1)` + `mount_status(shield, +3, 3t)`
- 把自己换到后排（index 增大 = 远离前线），让前排顶上，顺手拿 3 点护盾。
- **肉鸽价值** 1 能量极低门槛，是戏法轴的润滑剂。

#### 【主动】预知 🜁
- **序列** 9 占卜家 · **能量 2 / cd 3** · `targetSpec: SELF`
- **效果** `modify_resource(gauge.current, +25, delta)`
- **推导** 阈值 75，+25 = 抢先 1/3 个行动周期出手。
- **翻译依据** 引擎确定性、无隐藏信息，"预知"只能译成"提前拿到本来要等的东西"。

### 精良（序列 7–6）

#### 【主动】火焰跳跃 🜂
- **序列** 7 魔术师 · **能量 2 / cd 3** · `reach: ranged`
- **效果** `move(param → 指定空位)` + `damage 3 (fire)`
- **定价** 位移在双路各 4 格 + 坍缩 + 插队的战场里本身就是硬资源，所以伤害压到 3（基准是 3 能量 = 6 伤害）。

#### 【主动】空气弹跳 🜂
- **序列** 7 魔术师 · **能量 2 / cd 3** · `reach: ranged`
- **效果** `damage 2 (physical)` + `modify_resource(gauge.current, -50, delta)`（复用现成 `knockback`）
- ⚠️ **定价存疑** 代码里击退是固定 -50，而阈值是 75 —— 一次击退推后 2/3 个行动周期，比文档「50/n」强得多。这个技能的能量很可能要给到 3。见改动记录 D1。

#### 【主动】无形之手 🜂 ★
- **序列** 7 魔术师 · **能量 2 / cd 4** · `reach: ranged` · Manual（fallbackSort: `index_desc`）
- **效果** `move(pull_forward)` —— 把敌方单位在其**自己队列内**前拉 1 格
- **设计价值** 敌方后排躲在 index 3 吃不到伤害，这一手把他拽到前线。是戏法轴最有战术味道的技能。
- ⚠️ 需新增 `move.op: 'pull_forward'`（当前只有 swap_neighbor / insert_tail_cross_lane / param）—— 改动记录 C1

#### 【主动】易容 🜄
- **序列** 6 无面人 · **能量 3 / cd 4** · `targetSpec: SELF`
- **效果** `dispel(unit, dispelable:true, category:'debuff')` + `dispel(..., 'dot')` + `dispel(..., 'control')` + `mount_status(shield, +3, 3t)`
- **语义** "换一张脸，旧麻烦追不上你" —— 恰好就是 `dispel` 的语义。这是全套里最漂亮的映射。
- ⚠️ `dispel.category` 当前只支持单个字符串 → 需要 3 条 dispel 串联，或扩展为数组（改动记录 C2）

#### 【被动】面部欺骗 🜄
- **序列** 6 无面人 · **hook** `on_battle_start`
- **效果** `mount_status(glibness, 2t)` —— 新状态 `damage_taken_mul: 0.75`
- **语义** "第一眼看不出真假"，开局 2 回合减伤 25%
- ⚠️ 需新增状态 `glibness`（改动记录 C3）。可与既有 `fortify`（×0.7, 4t）合并考虑，但 0.75/2t 定位更轻、更适合做普通-精良档。

### 稀有（序列 5–4）

#### 【主动】秘偶 🜃 ★
- **序列** 5 秘偶大师 · **能量 3 / cd 4** · `reach: ranged` · Manual（**fallbackSort: `hp_desc`**，INV-E6 硬性要求）
- **效果** `mount_status(taunt, 4t)` + `damage 2 (mental)`
- 与既有 `taunt`（duration 6）差异化：这里 4t 但附带伤害。

#### 【主动】诅咒 🜃
- **序列** 4 诡法师 · **能量 3 / cd 3** · `reach: ranged`
- **效果** `mount_status(vulnerable, 4t)` + `damage 2 (mental)`
- `vulnerable` = ×1.3 乘区（A14 已裁定）。

#### 【主动】诡秘之咒 🜃
- **序列** 4 诡法师 · **能量 4 / cd 5** · `reach: ranged`
- **效果** `dispel(unit, dispelable:true, category:'buff', count:1)` + `damage 3 (mental)`
- **语义** "剥离他的好运" —— 驱散敌方增益。与「易容」同用 dispel，一攻一守。

#### 【主动】连续施法 🜁 ★（术语首次实战）
- **序列** 4 诡法师 · **能量 5 / cd 5** · `reach: ranged`
- **效果** `TermRef(repeat, body: [damage 2 (mental)], count: 3, shareTarget: true)`
- **为什么重要** A17 裁定的 Repeat 算子到现在还没有技能用它。这是它第一次落地。
- **定价** 3×2 = 6 伤害 / 5 能量 = 1.2，正好打平基准。看似亏，但价值在"一个 Action 内三段、只触发一次受击/反击、只撞一次"（B8 裁定）。
- ⚠️ 建议先按 `damage 2 × 3` 上，验证后再考虑 3×3。

#### 【被动】灵体之线 🜁
- **序列** 5 秘偶大师 · **hook** `on_deal_damage`（击败单位时）
- **效果** `modify_resource(energy, +3, delta)`
- **肉鸽价值** 击杀回能，是高费连发构筑的引擎。

#### 【主动】灵偶替身 🜃
- **序列** 5 秘偶大师 · **能量 4 / cd 6** · `consumption: summon`
- **效果** `spawn(unit_marionette)` —— 秘偶单位（低血量、继承施法者部分属性）
- ⚠️ 需新增单位定义 `unit_marionette`

### 史诗（序列 3–2）

#### 【主动】过去的自己 🜄 ★
- **序列** 3 古代学者 · **能量 3 / cd 4** · `targetSpec: SELF_OR_ALLY`
- **效果** `heal 8`（**必须用 `heal` 而非 `modify_resource`** —— A22 / INV-D5）
- **语义** "从历史孔隙里借出那个还没受伤的自己"
- **差异化** 与 `regen`（总回 12、6t、可驱散）定位不冲突：瞬发 8、不可驱散、量更少但即时。

#### 【主动】历史重现 🜄
- **序列** 3 古代学者 · **能量 4 / cd 5**
- **效果** `Sequence[ damage 3 (mental), heal 3 (self) ]`
- **语义** "重现那一击，也重现那个自己"。Sequence 算子落地。

#### 【被动】复活式再生 🜄
- **序列** 3 古代学者 / 2 奇迹师 · **hook** `on_death`
- **效果** `spawn(自身, hpRatio: 0.3)` —— 每场一次
- ⚠️ 需 spawn 支持 `hpRatio` + 重生位置规则（原坐标 / 队尾）—— 改动记录 C5

#### 【主动】命运操纵 🜁 ★
- **序列** 2 奇迹师 · **能量 4 / cd 5** · Manual（fallbackSort: `hp_desc`）
- **效果** `modify_resource(gauge.current, +20)` 自身 + `modify_resource(gauge.current, -20)` 目标
- **语义** "命运不是随机的，只是谁先谁后"
- **合规** INV-S5 只禁止改"行动周期"这个派生值；改 `gauge.current` 是允许的（A24）。这是"操纵命运"在确定性引擎里的唯一正确形态。

#### 【主动】奇迹 🜄 ★
- **序列** 2 奇迹师 · **能量 5 / cd 8** · `targetSpec: ALLY`
- **效果** `mount_status(miracle)` —— 目标友军死亡时以 50% 生命复活
- ⚠️ 需新增状态 `miracle`（`on_death` → `spawn`）—— 改动记录 C4

#### 【被动】奇迹之光 🜄
- **序列** 2 奇迹师 · **hook** `on_battle_start`
- **效果** 全体友军 `modify_resource(armor, +3, delta)`

## 三、跨途径共享（源堡三途径）

源堡三条途径互为相邻途径（高序列可混合），共享技能用 `sharedAcross` 声明：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 灵视 / 占卜 | 学徒、偷盗者 | 三者同属源堡，信息类能力互通 |
| 命运操纵 | 偷盗者（命运木马） | 偷盗者序列2 就是钻命运缝隙，天然契合 |
| 愚弄命运 | 偷盗者（错误） | 篡改因果 = 愚弄命运 |

## 四、本稿遗留

- 全部 24 个技能的能量定价只做了粗推，需过验证脚本（改动记录 D4）
- `gauge_rate` / `gauge.current` 类技能的定价无既有锚点，是本次最大的数值盲区
- 「闪避 / 免疫 / 隐匿」类能力（诡秘里很多）当前无原语承载，本稿全部绕开了。若后续要做，需要的是"候选池过滤"机制，不是新状态 —— 见改动记录 C8
