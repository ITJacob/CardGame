# 阅读者途径（白塔） · 技能池 v0.1

灵感源：ima 知识库《诡秘之主-途径数据》→ 阅读者途径（aka 白塔途径，源质「混沌海」；相邻途径：秘祈人、观众、歌颂者、水手）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5，并已核对 `_GENERATION_BRIEF.md` 与 `愚者途径_技能池_v0.1.md` 的硬约束。

> 本稿是**设计约定**，不是终稿数值。所有数值标注了推导依据，最终需过验证脚本。
> 「文案」为玩家视角的效果描述（含 flavor），用于肉鸽派发时展示；「效果」为引擎落地表达，必须可映射到九原语。
> 翻译纪律：速学/博学者（信息类）→ `modify_resource(energy)` 资源前置或 `modify_stat` 自身增益；推理/守知（识别真伪）→ `dispel` 敌方 buff 或 `mount_status(易伤)`；预言/全知 → 同愚者"预知"用自身 `gauge.current +N`（抢先出手，绝不写"预判敌人下一步"这类不可落地机制）。

## 一、技能池

图例：⚠️ = 需要框架扩展（本途径新增，见末尾「本途径框架改动」）；★ = 该轴旗舰技能。

### 普通（序列 9–8）

#### 【被动】过目不忘 🜁
- **文案** 战斗开始时，你博闻强记，立即获得 5 点能量，且本场战斗中能量上限永久 +5。
- **序列** 9 阅读者 · **hook** `on_battle_start`（⚠️ 复用通用触发点 A1）
- **效果** `modify_resource(energy, +5)` + `modify_stat(energy_max, +5, duration: null)`
- **推导** 5 能量 × 1.2 汇率 ≈ 6 伤害 ≈ 力量3 时 10% 最大生命，与愚者「灵视」同量级，确保高智力也吃香、解决后期能量溢出。

#### 【被动】速读 🜁
- **文案** 每回合开始时，你飞速掠过书页，有 30% 概率领悟到一丝知识，随机获得 2 点能量（期望 0.6 能量/回合）。
- **序列** 9 阅读者 · **hook** `on_turn_start`
- **效果** `{ ref: 'gain_energy_2', condition: { kind: 'chance', p: 0.3 } }`
- **合规** 引擎支持概率（播种式 `RandomSource` + 登记制，R2/R3/R6），正确写法是 EffectRef 上的 **`condition`**，不是不存在的 `Chance()` 算子（已修正，见 G1 更正）。概率只用于"是否给能量"这个非伤害维度，不涉及战斗隐藏信息。

#### 【被动】博闻强记 🜃
- **文案** 战斗开始时，你的学识化作敏捷，行动速率永久 +8，出手更频繁。
- **序列** 8 推理学员 · **hook** `on_battle_start`（复用通用 A1）
- **效果** `modify_stat(gauge_rate, +8, duration: null)`
- **推导** 行动周期 = 75/(15+8×敏捷)；敏捷3 时 rate 39→周期 1.92 tick，+8 后 rate 47→1.60 tick，**提速约 17%**（同愚者「平衡感」量级）。⚠️ 数值待标（见本稿遗留）。

#### 【被动】直觉预感 🜄
- **文案** 你偶尔闪过一丝预感，战斗开始时行动条被悄然推前，抢在对手之前出手。
- **序列** 9 阅读者 · **hook** `on_battle_start`（复用通用 A1）
- **效果** `modify_resource(gauge.current, +15, delta)`
- **推导** 阈值 75，+15 = 抢先 1/5 个行动周期；"预感/直觉"在确定性引擎里只能译成"提前拿到本要等的东西"。

#### 【主动】逻辑推演 🜂
- **文案** 循着对手的破绽推演其弱点，标记其易伤，并造成 2 点精神伤害。
- **序列** 8 推理学员 · **能量 2 / cd 3** · `reach: ranged`
- **效果** `mount_status(vulnerable, 4t)` + `damage 2 (mental)`
- **推导** 推理出弱点 = `vulnerable`（×1.3 受伤乘区，A14 已裁定）；直伤压到 2 是因为"标记破绽"本身就是硬资源（基准 3 能量=6 伤害，此处 2 能量=2 直伤 + 易伤乘区）。

#### 【主动】快速检索 🜁
- **文案** 从脑海中翻出恰好有用的知识，立即推进自身行动条，抢在对手之前出手。
- **序列** 9 阅读者 · **能量 2 / cd 3** · `targetSpec: SELF`
- **效果** `modify_resource(gauge.current, +25, delta)`
- **推导** 阈值 75，+25 = 抢先 1/3 行动周期；信息类→资源前置的直译。

### 精良（序列 7–6）

#### 【主动】辨伪 🜂
- **文案** 一眼识破对手的虚张声势，驱散其 1 个增益效果，并造成 3 点精神伤害。
- **序列** 7 守知者 · **能量 3 / cd 4** · `reach: ranged`
- **效果** `dispel(unit, dispelable: true, category: 'buff', count: 1)` + `damage 3 (mental)`
- **语义** 守知者"识别真伪" = 剥离敌方增益；与愚者「诡秘之咒」同用 `dispel`，一攻一守。

#### 【主动】守知 🜃
- **文案** 守护珍贵的知识，为一名友军织起 3 点护盾，并驱散其 1 个减益。
- **序列** 7 守知者 · **能量 3 / cd 4** · `targetSpec: SELF_OR_ALLY`
- **效果** `mount_status(shield, +3, 3t)` + `dispel(unit, dispelable: true, category: 'debuff', count: 1)`
- **语义** 守知 = 守护；护盾 + 清减益，复用现有 `shield` 与单类 `dispel`（不需 C2 数组扩展）。

#### 【被动】求知若渴 🜃
- **文案** 战斗开始时，你的求知欲化为学识，智力永久 +3，能量恢复随之提升。
- **序列** 6 博学者 · **hook** `on_battle_start`（复用通用 A1）
- **效果** `modify_stat(int, +3, duration: null)`
- **推导** 能量恢复 = 0.2 + 0.2×智力 / tick；+3 智力 → 恢复 +0.6/tick，长线收益显著，契合博学者"跨领域渊博"。

#### 【主动】知识整合 🜁
- **文案** 将杂学凝练为灵感，立即获得 6 点能量，为下一手大招蓄势。
- **序列** 6 博学者 · **能量 2 / cd 4** · `targetSpec: SELF`
- **效果** `modify_resource(energy, +6)`
- **推导** 信息类→资源前置；6 能量 ≈ 7.2 伤害预算，但此处为纯资源（2 能量换 6 能量，净 +4），是速学轴润滑剂。

#### 【主动】真知灼见 🜂
- **文案** 以博学者的洞察撕开伪装，对目标造成 2 点精神伤害并标记易伤 3 回合。
- **序列** 6 博学者 · **能量 3 / cd 4** · `reach: ranged`
- **效果** `damage 2 (mental)` + `mount_status(vulnerable, 3t)`
- **语义** 辨识真伪的进阶版：在「逻辑推演」的 4t 易伤基础上补足直伤，定位更偏精良成型件。

#### 【主动】致命破绽 🜂 ★（推理辨识旗舰）
- **文案** 你已看穿对手的每一处死穴——这一次打击必定撕开它的防御。
- **序列** 7 守知者 · **能量 4 / cd 5** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `Sequence[ mount_status(vulnerable, 4t), damage 5 (mental) ]`
- **语义** 推理辨识轴的收口：先钉死易伤（×1.3），再补 5 点精神直伤。5 能量预算内（基准 3 能量=6 伤害，剩 1 能量额度用于"必中破绽"的战术价值）。
- **设计价值** 与「逻辑推演」「真知灼见」构成"破绽三连"，是全轴构筑核心。

### 稀有（序列 5–4）

#### 【主动】灵感泉涌 🜁 ★（速学旗舰）
- **文案** 灵感如泉涌般迸发，你瞬间厘清一切，立即获得 8 点能量。
- **序列** 5 秘术导师 · **能量 2 / cd 3** · `targetSpec: SELF`
- **效果** `modify_resource(energy, +8)`
- **推导** 速学轴终极资源前置：2 能量净赚 6 能量（≈7.2 伤害预算），支撑高费连发构筑；配合「过目不忘」上限增益形成能量池滚雪球。

#### 【主动】秘术传授 🜃 ★（知识增益旗舰）
- **文案** 将秘术传授给一名友军，使其本场攻击伤害提升 20%，并立即获得 4 点护盾。
- **序列** 5 秘术导师 · **能量 3 / cd 4** · `targetSpec: ALLY`
- **效果** `mount_status(tutelage, 4t)` + `mount_status(shield, +4, 3t)`
- **语义** "指导他人" = 给友军挂强化状态。`tutelage` 为新状态：`damage_mul: 1.2`、`duration: 4`、`触发 on_deal_damage`、`作用于友军`。⚠️ 需新增状态 `tutelage`（本途径框架改动 RD1）。

#### 【主动】未来残页 🜄
- **文案** 你拾起一片来自未来的残页，抢先出手，并将对手推回时间的湍流。
- **序列** 4 预言家 · **能量 3 / cd 4** · `targetSpec: SELF`（副效果作用于敌方单体）
- **效果** `modify_resource(gauge.current, +20, delta)` 自身 + `modify_resource(gauge.current, -20, delta)` 目标
- **推导** 阈值 75，±20 = 自身抢先约 1/4 周期、目标推后约 1/4 周期，"预言未来"在确定性引擎里的正确形态（同愚者「命运操纵」）。

#### 【被动】学识共鸣 🜁
- **文案** 每当一名敌人倒下，你从遗留的知识中汲取回响，获得 2 点能量。
- **序列** 5 秘术导师 · **hook** `on_death`（敌方单位死亡时）
- **效果** `modify_resource(energy, +2, delta)`
- **肉鸽价值** 击杀回能，是速学轴高费连发构筑的引擎（同愚者「灵体之线」定位）。

#### 【主动】预判格挡 🜄
- **文案** 你预感到来袭的攻击，提前架起学识之盾，并将对手的时机向后推延。
- **序列** 4 预言家 · **能量 3 / cd 4** · `targetSpec: SELF_OR_ENEMY`
- **效果** `mount_status(shield, +5, 3t)` 自身 + `modify_resource(gauge.current, -30, delta)` 目标
- **语义** "预判"落为抢先防御 + 推后敌方出手（-30 行动条），绝无"读心"类不可落地机制。

### 史诗（序列 3–2）

#### 【主动】未来视 🜄 ★（预言全知旗舰）
- **文案** 你窥见整条时间线的走向，抢先出手，并将敌人彻底推离它的节奏。
- **序列** 3 洞悉者 · **能量 4 / cd 5** · Manual（fallbackSort: `hp_desc`）
- **效果** `modify_resource(gauge.current, +25, delta)` 自身 + `modify_resource(gauge.current, -25, delta)` 目标
- **语义** 全知轴的收口：自身抢先 1/3 周期、目标推后 1/3 周期，双向拉开行动差，是预言全知构筑的核心节奏点。

#### 【主动】洞悉本质 🜂
- **文案** 你洞悉了事物的本质与规律——若它已露出破绽，这一击将贯穿其防御。
- **序列** 3 洞悉者 · **能量 4 / cd 5** · `reach: ranged`
- **效果** `If(target has status vulnerable) → damage 4 (mental) else damage 2 (mental)`
- **语义** 术语算子 `If` 首次实战落地（1.4 已列，非新框架）；与「致命破绽 / 逻辑推演」的易伤标记形成组合技：已破绽则重击，未破绽则轻击。

#### 【主动】智慧权柄 🜃
- **文案** 智天使降临，知识与智慧的深层权柄加身，你的学识与能量上限被彻底拔高。
- **序列** 2 智天使 · **能量 4 / cd 6** · `targetSpec: SELF`（高费大招）
- **效果** `modify_stat(int, +5, duration: null)` + `modify_stat(energy_max, +10, duration: null)`
- **推导** 智力 +5 → 能量恢复 +1.0/tick、能量池 +10；位格碾压只借名字做 flavor，机制仍是"更大数值的同一件事"。

#### 【被动】洞悉预知 🜄
- **文案** 战斗开始时，全知之低语在队员耳畔响起，全队行动条被一同推前。
- **序列** 2 智天使 · **hook** `on_battle_start`（复用通用 A1）
- **效果** 全体友军 `modify_resource(gauge.current, +10, delta)`
- **语义** 全知 = 全队抢先；需作用于全体友军的 `targetSpec: ALL_ALLIES`。⚠️ 需新增 targetSpec `ALL_ALLIES`（本途径框架改动 RD2）。

#### 【被动】全知低语 🜁
- **文案** 每回合开始时，全知的低语为你注入灵感，稳定获得 3 点能量（确定，无随机）。
- **序列** 3 洞悉者 · **hook** `on_turn_start`
- **效果** `modify_resource(energy, +3, delta)`
- **合规** 与「速读」的区别在于这是**确定**增益（非 R3 概率），契合全知"无所不知"的体感。

## 三、跨途径共享（源质「混沌海」相邻途径）

阅读者（白塔）与秘祈人、观众、歌颂者、水手同属混沌海源质分组，以下技能可 `sharedAcross` 给相邻途径：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 过目不忘 / 速读 / 知识整合 / 灵感泉涌 | 观众、秘祈人 | 三者皆重"信息/知识获取"，速学（资源前置）互通；观众的心智洞察、秘祈人的知识祈祷天然契合 |
| 逻辑推演 / 辨伪 / 真知灼见 | 观众、秘祈人 | 推理辨识（标记易伤 / 剥增益）对应观众的心智操控、秘祈人的真伪辨明 |
| 守知 / 秘术传授 | 歌颂者、秘祈人 | 守护与"传授增益"对应歌颂者的圣歌祝福、秘祈人的祝祷强化 |
| 直觉预感 / 未来残页 / 预判格挡 | 水手、观众 | 预言全知（抢先出手）对应水手的风暴预知、观众的先机洞察 |
| 全知之眼 | 观众（仅高序列混合时） | 全知洞察是观众"心智权柄"的远端同构，但仅作 flavor 大招共享 |

## 四、本稿遗留

- 全部 24 个技能的能量定价只做了粗推，需过验证脚本（通用改动记录 D4）。
- `gauge_rate` / `gauge.current` 类技能的定价无既有锚点，是本次最大的数值盲区（同愚者 D2）。
