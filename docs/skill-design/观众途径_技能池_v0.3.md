# 观众途径（空想家）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按混沌海系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入混沌海系核心机制 **「放牧(Grazing)」动态能力槽**（存储任意途径灵魂 → 用其能力，全局唯一跨系借技能）；
> ③ 新增 **跨系 combo 卡**（观众↔源堡·占卜家 读预兆、观众↔秘祈人 放牧借能）；
> ④ 补 1–2 张主题界域牌（集体梦境）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；混沌海机制依据《混沌海系技能设定》《九大源质总览》。
>
> **本版定位**：v0.2/v0.3 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"、放牧维度与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **观察** | `洞察`(omen, 敌方标记, 可叠层) | 观察/读心/气场 → 给目标挂 `洞察` | 若\[洞察\] 心理暗示/读心生效、推友军先手 | 读心者 |
| ② **情绪** | `情绪`(mood, 敌方 debuff / 友方 buff) | 震慑/狂乱/安抚/心理暗示 → 挂 `情绪` | 若\[情绪\] 精神伤害放大、友方安抚 | 心理医生 |
| ③ **梦境** | `梦境`(dream, 敌方, duration) | 引导/修改/梦境穿梭 → 挂 `梦境` | 若\[梦境\] 拉入梦境封印、日积月累改写 | 织梦人 |
| ④ **空想** ★核心 | `空想`(fantasy, 自身累积 charges) | 操纵/书写/空想 → 累积 `空想` | 若\[空想≥N\] 想象具现 / 篡改潜意识驱使目标 | **空想家** |

> **放牧维度（混沌海系 §2.2 / 总览 §1 万能接口②）**：本系签名机制「放牧(Grazing)」= 战场级**动态能力槽** `grazing_slot`，存储被纳管的灵魂及其途径，可释放该途径能力（全局唯一跨系借技能）。观众/歌颂者经「纳管」参与此机制。
> - **enabler**：友方击杀 / 控制一个单位 → `grazing_slot +1`（记录该单位途径与其一项招牌能力）。
> - **payoff**：释放被放牧单位的一项能力（一次）。
> - **阈级（⚠️D，自行设计）**：槽 ≥1 释放 1 项；≥3 释放时该能力 ×1.3；≥5 释放 `cd -1` 且可指定 2 目标；=MAX(⚠️D 暂定 7) 本回合被放牧能力视为本途径技能（吃 `空想`/`净化` 增益）。
>
> **跨源质写入方**：秘祈人（牧羊人）主承载放牧；观众/歌颂者可经「纳管残响」「放牧·借能」卡接入同一 `grazing_slot`，形成混沌海内部五途径互为相邻的联动网。

## 三、跨途径共享（混沌海相邻途径 + 跨系 combo）

混沌海五途径互为相邻（观众/歌颂者/阅读者/水手/秘祈人），共享用 `sharedAcross`；跨系 combo 卡通过 `StatusDef.crossPathway:true` 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 读心/气场感知/洞察权柄/凡有言必被知 | 阅读者 | 观察—读心—识破链是两条途径共同地基 |
| 安抚/出众精神 | 歌颂者 | 消除恐惧/精神抗性一脉相承 |
| 心理暗示·权柄 | 歌颂者 | "认为自己强就会强"=外部鼓舞的正反面 |
| 间接影响 | 阅读者、歌颂者、水手 | 推友军行动条通用辅助件 |
| **读占卜家预兆** | **占卜家（源堡）** | 跨系 combo：读取友方 `omen`(预兆) 升级（枢纽状态） |
| **放牧·借能** | **秘祈人（混沌海）** | 跨系 combo：读取 `grazing_slot` 释放别家能力（放牧枢纽） |

> **枢纽状态（落地优先级最高）**：`提线木偶(puppet_string)`/`替身`/`寄生(flesh_parasite)`/`混乱`/`恶欲值`/`命运` 标 `crossPathway:true` + 参与途径白名单（总览 §3）。本稿另将 **`omen`(预兆)** 与 **`grazing_slot`(放牧)** 标为跨系可读（供观众两条 combo 卡），属混沌海内部相邻联动的扩展登记。
