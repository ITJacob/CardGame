# 猎人途径（红祭司）· 技能池 v0.3


> **版本**：v0.3（2026-09-06）—— 在 v0.2 原著校准版基础上增量升级，补入**界域 / 位格 / 性别 / 吟唱**四个维度（依据 `_GENERATION_BRIEF.md` v0.3 §10–§13）。v0.2 的原著校准成果全部保留。
> 文件名沿用 `v0.2`，内容已升级至 v0.3。
灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **猎人途径**（源质「灾祸之城」，旧日「毁灭天灾」，序列0 红祭司，相邻途径 = 刺客）。
框架：`docs/ddd/`（战斗内核 DDD 终版）+ `_GENERATION_BRIEF.md`；旧框架编号（A/C/D/E/F/G 组）的现落点见 brief §7（v1.5 旧档、原《框架改动记录》与 `src/` 实现均已删除，原文可在 git 历史查阅）

> **本版定位**：v0.2 是**原著校准版**。相比前一版，主要做三件事——
> ① 逐序列比对原著能力表（序列 9→0 共 10 档），补回全部遗漏的原著招牌能力，尤其是**「集众」这条本途径最独特的主轴**（序列4 奠基 → 序列3 借队友能力 → 序列2 无限制分享 → 序列1 质变）；
> ② 把火焰七技、阴谋家三技、收割者三技、战争主教五技这些原著**逐条列举**的具体手段，逐条落成可落地的机制，而不是抽象成「火焰伤害 +N」；
> ③ 剔除一切偏离原著、凭空发明的招式（本途径原著**没有任何治疗、护盾、诅咒、复活能力**，全稿零 `heal`、零复活、零诅咒）。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数 / 百分比）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。
>
> **本稿合规自检（先声明，后文不再重复）**：
> - **G8**：全稿真实 `move` 只有 1 处（【火焰马刀】的 `pull_forward`，锁定 `from.faction`，敌方在自己队列内前移，不越中线）。"突进/冲锋/扑杀"一律做成近战攻击进程（flavor），不调 `move`。
> - **G5/G6**：全稿**零**「自身 `gauge.current +N`」写法。节奏类效果一律作用于**友军**或走 `on_battle_start` 被动，或改 `gauge_rate`（速率，非当前值）。
> - **G15 / G15-b**：全稿**零** `on_turn_start` 依赖——本途径没有任何"每回合开始"型效果，时间尺度冲突从根上不存在。
> - **INV-S5**：只改 `gauge_rate`，从不直接修正派生行动周期。
> - **A2**：全稿**零** `on_spawn`。本途径有陷阱与士兵两类召唤物，所有"开局/整场"语义一律走 `on_battle_start`（A1，已落地）。
> - **A22**：全稿零 `heal` 原语（原著猎人途径无治疗能力），故本条自动合规。
> - **R5**：全稿零概率。原著"挑衅/阴谋/征服"是**确定性**的心理与权柄压制，不做掷骰子。
> - **原著纪律**：无一条技能借用其他途径的招式名；凡与别稿/F 组机制同源的，均在 ⚠️ 行注明并建议并入母版。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】猎人的感官 🏹
- **原著** 序列9 猎人 —— "感官直线提升：分辨气味、看到浅脚印、听见心跳微风"
- **文案** 你能听见它的心跳，闻得到它三天前留下的气味——再会藏的猎物，在你眼里也像踩在雪地上一样清楚。
- **序列** 9 猎人 · **hook** `on_battle_start`（A1，已落地）
- **效果** 挂载 `hunter_sense`（整场，`dispelable: false`）：
  - 敌方 `stealth` / `shadow_veil` 等隐匿、不可选中类状态**对你无效**（依赖 C8 候选池过滤）
  - 你的单体技能自动优选**当前生命值最低**的敌方单位（`fallbackSort: hp_asc`）
- **翻译/语义** 原著是**感知**能力。卡牌没有隐藏信息，故按 brief §3 拆成两条可落地的东西：① "看见隐藏的东西" = 识破隐匿；② "听见心跳" = 最能判断谁快死了 = 目标优选。两者都是"信息"，但只有第二条在卡牌里有战术价值，所以第二条权重更高。
- ⚠️ 依赖 C8 候选池过滤的「识破」分支（🔴 未实现）。**与愚者 v0.2【灵视】【灵体之线】是同一需求的三处登记，建议合并实现**；本稿不重复立项。数值 ⚠️D。

#### 【被动】结构要点 🏹
- **原著** 序列9 猎人 —— "能直观找到结构要点"
- **文案** 你一眼就看出它护甲衔接处的那条缝——你的每一次攻击，都落在最不该被砸的地方。
- **序列** 9 猎人 · **hook** `on_battle_start`
- **效果** 挂载 `structural_eye`（整场）：你的攻击**无视目标 50% 的护甲**（`armor_pierce: 0.5`）
- **翻译/语义** "直观找到结构要点" = 打在结构上最薄弱的接缝处 = **破甲**。这是本途径唯一的破甲来源，也是 🏹 收割轴在低序列的地基——序列5 的"弱点侦察 / 精准"都是它的高序列延伸。
- ⚠️ 依赖新字段 `armor_pierce`（本稿新增项 1，🔴）。**退化方案**：改为 `on_deal_damage` → 目标 `modify_stat(armor, -3, duration: 3)`，代价是破甲会被 `dispel(category:'buff')` 洗掉，且对高护甲目标的边际收益不同。

#### 【被动】野外生存 🏹
- **原著** 序列9 猎人 —— "身体素质全面超越常人（熊的强壮 + 猫的轻灵）/ 野外生存知识"
- **文案** 你在林子里活下来的每一年都还在这副身体上：熊一样的力气，猫一样的敏捷，以及永远知道该往哪儿退的本能。
- **序列** 9 猎人 · **hook** `on_battle_start`
- **效果** 自身 `modify_stat(hp_max, +10, duration: null)` + `modify_stat(attack, +1, duration: null)` + `modify_stat(gauge_rate, +6, duration: null)`
- **翻译/语义** 原著三条素质各落一条属性：熊的强壮 = `hp_max` + `attack`，猫的轻灵 = **敏捷**。"敏捷"在引擎里是派生行动周期的源属性，**INV-S5 禁止直接修正**，故落成 `gauge_rate`（合规，且是同一语义）。野外生存知识在卡牌里无对应维度，只作为 flavor 计入前两条。
- ⚠️ `gauge_rate` 的定价是全项目已知盲区（**D2**，🔴 未标），+6 是占位建议值 ⚠️D。

#### 【主动】扑杀 🏹
- **原著** 序列9 猎人 —— "身体素质全面超越常人（熊的强壮 + 猫的轻灵）"
- **文案** 你像熊一样压上去，又像猫一样快——它还没看清你的动作，已经被撞翻在地。
- **序列** 9 猎人 · **能量 2 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_asc`）
- **效果** `damage(element: physical, 4)`
- **翻译/语义** **本稿最重要的地基件**。原著序列9 猎人**没有记名的攻击招式**——序列7 才有火焰，序列5 才有收割，低序列唯一的战斗力就是那副"熊的强壮 + 猫的轻灵"的身体。故按原著语义落成低费近战直伤：本途径的「火球术」替代品，无附加、纯伤害，用来撑起前 4 个序列的输出骨架。4 伤 / 2 能 = 2.0 汇率，高于基准 1.2，与愚者稿【飞牌】（同为"低序列唯一输出手段"）同一定价逻辑。⚠️D 待标。
- **为什么是近战不是远程** 原著序列9 未写任何弓箭 / 枪械（那是通识者、仲裁人的领域）。"熊的强壮 + 猫的轻灵"是**扑上去打**的身体素质，故 `reach: melee`。**G8 合规**：近战是攻击进程，不调 `move`、不越中线。
- **升级阶梯**（B6）伤害 4 → 6 → 8；或解锁「连击」：对同一目标追加 `damage(element: physical, 2)`。

#### 【主动】挑衅 🕸 ★
- **原著** 序列8 挑衅者 —— "『挑衅』（核心）：洞察目标敏感点，激怒对方失去理智 / 被动效果 + 主动激发（辱骂语言 + 羞辱行为）"
- **文案** 你一句话精准戳在它最不敢被人提起的地方——它红了眼，脑子里只剩下"弄死你"，破绽和队形都忘了。
- **序列** 8 挑衅者 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(taunt, 3t)` + `mount_status(vulnerable, 3t)` + `modify_stat(attack, -2, 3t)` + `modify_stat(defense, -2, 3t)`
- **翻译/语义** 原著"挑衅"是**四件事叠在一起**，本稿四条全落：① "激怒对方" → 既有 `嘲讽`（强制攻击你）；② "洞察目标敏感点" → 既有 `易伤`（×1.3，弱点被戳中）；③ "失去理智" → `attack -2`（只会蛮打，没了章法）；④ 失去理智的另一面 → `defense -2`。**不做成"纯粹拉仇恨"**——那会把序列8 的核心能力退化成一个通用的嘲讽技能。
- **与相邻能力的区分** 【羞辱】是它的被动面（你被打了才触发）；【误导】【煽动】是序列6 的高级版（不是打你，是打空 / 打队友）。
- ⚠️ 全部复用既有状态与既有 `modify_stat`（✅ 零新依赖），是 🕸 轴唯一"现在就能落地"的技能。数值 ⚠️D。

#### 【被动】羞辱 🕸
- **原著** 序列8 挑衅者 —— "被动效果 + 主动激发（辱骂语言 + **羞辱行为**）"
- **文案** 它每打中你一次，你就笑着再补一句——它越怒，露出的破绽越大。
- **序列** 8 挑衅者 · **hook** `on_take_damage`（作用于攻击者）
- **效果** 对攻击者 `mount_status(vulnerable, 2t)`
- **翻译/语义** 原著挑衅者是**被动 + 主动**双轨：主动是【挑衅】（你去激怒它），被动是"你天然招人恨、谁打你谁上头"。落地为"谁打你，谁露出破绽"——与【挑衅】形成闭环：挑衅把它拉过来打你，羞辱让它每打你一次就更脆一点。
- **与【激怒反击】式设计的差异** 本稿**不做反伤**。原著序列8 没有任何"反弹伤害"的设定；"激怒"的后果是**失控（露出破绽）**，不是受伤。反弹伤害那是战士途径的语义。
- ⚠️ 依赖 F61 `attacker` targetSpec（🟡 已登记，可能只是把「反伤」内部已有的攻击者指针暴露成可配置 targetSpec，若已可用则降为文档补登）。本稿不重复立项。

### 精良（序列 7–6）

#### 【主动】火鸦术 🔥
- **原著** 序列7 纵火家 —— "『火鸦术』"
- **文案** 你手心的火团扑腾着长出翅膀，化作一只火鸦撞进它的胸口，羽毛落处，火就烧了起来。
- **序列** 7 纵火家 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_asc`）
- **效果** `damage(element: fire, 3)` + `mount_status(burn, 3t)`
- **翻译/语义** 原著纵火家的**招牌起手式**。火鸦 = 凝聚成形的火焰弹（承载七技中的"凝聚压缩"），命中后引燃（承载"注火"）。定位 = 本途径的火球术：**严格踩 3 能量锚点**，直伤 3 低于基准 5，缺的 2 点由 burn 补。
- ⚠️ burn 的折算依赖 **D4**（🔴 未标：文档口径"每 tick 2 伤 / duration 3 = 总 6 点"，但 tick 粒度远小于回合计，实际到账速度未实测）。若确认按 tick 快速结算，本技能能量需上调至 4 或直伤砍到 2。
- **升级阶梯**（B6）直伤 3 → 4 → 5；或解锁原著「巨大火球」：改为对目标及其相邻单位 `damage(element: fire, 4)`（`spread: splash_adjacent`）。

#### 【主动】炽白之枪 🔥 ★
- **原著** 序列7 纵火家 —— "『炽白之枪』"
- **文案** 火焰被压缩到极致，褪去橙红，只剩一缕炽得发白的光——它贯穿护甲，也贯穿了它。
- **序列** 7 纵火家 · **能量 5 / cd 4 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `armor_desc`）
- **效果** `damage(element: fire, 6)`，`armor_pierce: 1.0`（**完全无视护甲**）
- **翻译/语义** 原著炽白之枪是纵火家**单发最高温**的攻击手段，"炽白"就是压缩到极限的火焰（七技中的"凝聚压缩"顶点）。落到引擎里，"温度高到能熔穿一切"最干净的表达就是**全额破甲**——这是 🔥 轴的旗舰，也是本途径稀有度最高的纯直伤卡。5 能量 = 6 伤锚点，破甲作为 5→6 之外的溢价（对方护甲越高，本卡越值）。
- **与【远程轰炸】的差异** 炽白之枪单体、破甲、打重甲目标；远程轰炸全体、不破甲、打铺场。两者在序列上差 3 档，不要混用。
- ⚠️ 依赖 `armor_pierce`（本稿新增项 1，🔴，与【结构要点】同源共用一个字段）。**退化方案**：改为 `damage(fire, 6)` + `modify_stat(armor, -8, duration: 3)`（先熔甲再打，语义接近但会被驱散）。
- ⚠️ 依赖新 targetSpec 排序 `armor_desc`（🟢，并入本稿新增项 10 的排序集合；若不可实现则退回 `hp_asc`）。

#### 【主动】燃烧之墙 🔥
- **原著** 序列7 纵火家 —— "『燃烧之墙』"
- **文案** 一道火墙自地面窜起横亘战场，把战线切成两半——谁要过去，就得先穿过它。
- **序列** 7 纵火家 · **能量 4 / cd 5 / 吟唱 0** · `reach: allEnemies`
- **效果** 全体敌人 `damage(element: fire, 2)` + `mount_status(burn, 3t)` + `modify_resource(gauge.current, -15, delta)`
- **翻译/语义** 原著火墙是**地形 + 伤害**的复合技能（承载七技中的"范围影响"）。引擎没有 zone 阻挡语义可依赖，但"被火墙挡住"的体感可以落成**推后行动条**（想过墙得先绕，慢一步）。三条载荷各自对应原著的一个侧面：烧到（伤害）、持续烧（burn）、被挡住（节奏）。
- **G8 说明** 火墙是**伤害 + 节奏**技能，不做任何位移、不改任何单位站位，无越中线风险。
- **与【远程轰炸】的关系** 燃烧之墙是序列7 版本，远程轰炸是序列4 的"全面升级版"（原著序列2 明写「远程轰炸全面升级」）。两者构成 **B6 升级阶梯**，重复抽到时按 B5 `duplicatePolicy: 'upgrade'` 处理。
- ⚠️ 依赖 burn 折算（D4）+ `gauge.current` 定价（D2，🔴）。范围技能按敌方人数线性放大，需按 4 人满编复核。⚠️D。

#### 【主动】延时爆炸 🔥
- **原著** 序列7 纵火家 —— 火焰操控七技之「**延时爆炸**」
- **文案** 你在它脚下留了一颗火种，然后走开。两息之后，它脚下的地面炸开了花。
- **序列** 7 纵火家 · **能量 3 / cd 4 / 吟唱 0** · Manual（fallbackSort: `index_asc`）
- **效果** `mount_status(delayed_blast, duration: 2)`；状态触发器 `on_remove`（**duration 到期**）→ 对目标及其相邻单位 `damage(element: fire, 5)`
- **翻译/语义** 七技里最有设计感的一条，**零新机制**即可落地：`on_remove` 触发效果引擎已 fire（`combat.ts:320`，收尸人稿已验证可用），`duration: 2` 就是"延时"。用状态到期而不是 `on_tick` 计数，是因为到期触发**天然不可被驱散打断节奏之外的方式规避**（被 `dispel` 掉则哑弹，这本身就是合理的反制面）。
- **与【火鸦术】的差异** 火鸦术是即时 3 伤 + 燃烧；延时爆炸是 2 tick 后 5 伤 + 溅射。前者稳，后者高风险高回报（可在 2 tick 内被打断，也可能正好炸在敌人聚拢时）。
- ⚠️ 依赖 `on_remove` 触发效果（✅ 已 fire）。数值 ⚠️D。

#### 【主动】火焰附魔 🔥
- **原著** 序列7 纵火家 —— 火焰操控七技之「**武器附火**」「**临时武器**」「**体表防御**」
- **文案** 火焰顺着你的手臂爬上刀刃，也在你皮肤下铺开一层流动的赤色——砍中的会烧起来，砍你的也会。
- **序列** 7 纵火家 · **能量 2 / cd 4 / 吟唱 0** · `targetSpec: SELF`
- **效果** `mount_status(flame_armament, duration: 4)`：
  - 触发器 `on_deal_damage` → 对同一目标追加 `damage(element: fire, 2)`（武器附火）
  - `modify_stat(resist:fire, +30, 4t)` + `mount_status(反伤, 4t, value: 2)`（体表防御）
- **翻译/语义** 原著七技里有三条都属"把火放在自己/武器上"（临时武器、武器附火、体表防御），本稿**合并为一张卡**——它们在设计上就是同一个意思的三个说法，拆成三张会稀释精良档。攻防各一载荷，正好对应"火刃"与"火甲"。
- **与【火焰化】的差异** 火焰附魔是**序列7 的表层覆火**（抗火 + 反伤 + 攻击附带火伤），火焰化是**序列4 的身体火焰化**（半元素化，抗火极高、近身者被点燃）。两者是同一设计意图的**低序列版与高序列版**，构成 B6 升级阶梯。
- ⚠️ 依赖既有 `反伤` 状态的数值参数化（🟡，既有状态登记有 `反伤` 但未定 value 字段口径）。数值 ⚠️D。

#### 【被动】注火 🔥
- **原著** 序列7 纵火家 —— 火焰操控七技之「**注火**」
- **文案** 火一旦烧起来，你就往里再添一把——你打的每一处伤口，都在给那团火加柴。
- **序列** 7 纵火家 · **hook** `on_deal_damage`
- **效果** `If(target_has_status: ['burn'])` → `then: 刷新目标 `burn` 的 duration 并 +1t`（单次上限 +2t，⚠️D）
- **翻译/语义** "注火"= 往已有的火里注入更多燃料 → 火烧得更久。**刻意不做成"燃烧目标额外受伤"**——那是凭空发明的加伤，原著"注火"的语义只是"让火烧得更旺"，即延长 duration。这让 🔥 轴从"叠 dot"变成"维持 dot"，玩法上更贴合纵火家的形象（控火者，不是放火者）。
- **为什么值得占一个被动槽** 它把 burn 从"3 tick 就掉的临时伤"变成"只要你在打就一直烧着"的持续压力，是 🔥 轴的粘合剂。单独抽到很弱，配【火鸦术】【燃烧之墙】【远程轰炸】后价值翻倍——正是肉鸽想要的组合曲线。
- ⚠️ 依赖 F52 `If` 谓词 `target_has_status`（🟡 已登记，本稿直接用、不重复立项）+ "刷新并延长 duration"的状态操作（🟡，与【注火】同族的通用需求，若引擎刷新语义为重置 duration 则需改为重新挂载）。

#### 【主动】误导 🕸 ★
- **原著** 序列6 阴谋家 —— "误导、迷惑和欺骗的超凡能力（『阴谋』核心）"

- **序列** 6 阴谋家 · **能量 3 / cd 4 / 吟唱 0** · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(deceived, charges: 1, duration: 3)`；`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`
- **翻译/语义** 原著序列6 的核心是"**阴谋**"——误导、迷惑、欺骗。卡牌里没有心理可骗，只有**目标系统**可操作，故落成"让对手打空"，直接复用 **C7 已端到端验证**的 `target_override → first_empty`（含单测，✅ 已落地）。🕸 轴的旗舰：这是本途径最"阴谋家"的一张卡，也是唯一**在序列6 就能改写敌人行动**的技能。

- ⚠️ 依赖 C7（✅ 已实现）+ C6 `charges`（✅ 已实现）。**零新依赖**，是本稿落地成本最低的控制卡。数值 ⚠️D。

#### 【主动】煽动 🕸
- **原著** 序列6 阴谋家 —— "『煽动 / 鼓动』能力"
- **文案** 你在它耳边说了句什么——它回过头，看向了刚才还站在自己身边的那个人。
- **序列** 6 阴谋家 · **能量 4 / cd 5 / 吟唱 0** · Manual（fallbackSort: `index_asc`）
- **效果** `mount_status(incited, duration: 3)`；`target_override` → 持有者**同阵营**内存活单位（`hp_desc`）
- **翻译/语义** 原著"煽动 / 鼓动"是让他人的情绪与敌意转向。引擎里最贴的表达是 `target_override` 指向**其己方队友**——不是打空（那是误导），是让它真的去打自己人。这是 🕸 轴的最高伤害转化（敌人的一次攻击变成了对我方有利的输出）。
- **与 F 组的关系** 本条与 F9 `puppet_string`（囚犯）、F15 `charm`（罪犯/药师）、F3 `puppeteered`（偷盗者）、F19 `countersuit`（律师）**同属 F 组「`target_override` 状态族」合并候选 3**。本稿**不重新发明机制**，只填该族的一个参数组合（锚点 = 同阵营 `hp_desc`，存续 = `duration: 3`）。落地时随该母版一并收敛。

#### 【主动】火焰马刀 🔥
- **原著** 序列6 阴谋家 —— "火焰精细化操纵：塑形成鞭子、马刀等"
- **文案** 火焰在你手中凝成一柄马刀的形状——你劈下去，又顺势把它的步伐勾乱了半分。
- **序列** 6 阴谋家 · **能量 3 / cd 3 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `index_desc`）
- **效果** `damage(element: fire, 4)` + `move(pull_forward, distance: 1)`（把目标在**其自己队列内**前拉 1 格）
- **翻译/语义** 原著序列6 是"**精细化**"塑形（鞭子、马刀）——与序列7 的粗放火团形成对比。落到引擎里，"精细化"的体现就是它**附带战术位移**（马刀劈砍带勾拽），而序列7 的火鸦/火墙只有伤害。这是本途径唯一一把"武器"，也是序列7 七技中"临时武器"的高序列版本。
- **G8 合规说明** `pull_forward` 是 **C1 已落地**的 move.op，实现上锁定 `from.faction`（`handlers.ts:handleMove`），即**敌方单位只在敌方队列内前移**，永远不跨中线。这是本稿唯一使用 `move` 原语的技能。
- **与【火焰附魔】的组合** 先附魔（攻击附带 2 点火伤），再用火焰马刀近身砍，一次攻击打出 4 + 2 火焰，并被火系乘区放大。
- ⚠️ 数值 ⚠️D。位移本身是硬资源（brief §2），故 3 能量的直伤只给 4（低于基准 4.8）。

#### 【主动】弱点侦察 🏹 ★
- **原著** 序列5 收割者 —— "『弱点侦察』：从神秘学角度发现目标弱点"
- **文案** 你的目光从神秘学的角度扫过它——护甲的接缝、灵性的淤滞、那道还没长好的旧伤。你一清二楚。
- **序列** 5 收割者 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(vulnerable, 4t)` + `dispel(target, category: ['buff'], count: 1)`
- **翻译/语义** 原著关键词是"**从神秘学角度**"——不是肉眼找破绽（那是序列9 的"结构要点"），是看穿对方的**超凡防护**。故落成两条：① 挂既有 `易伤`（×1.3，弱点被点明）；② **剥掉对方一个增益**（撕开神秘学防护）。第二条是本技能的灵魂，也是它区别于"通用易伤技能"的地方。
- **为什么能量只要 2** 它是**开窗口**技能，本身不产生价值，价值全在后续的【收割】【毁灭之矛】上。低价 + 短 cd 保证 🏹 轴的"侦察 → 收割"链条能连起来。🏹 轴旗舰。
- ⚠️ 依赖 C2 `dispel.category` 数组（✅ 已落地）。**零新依赖**。数值 ⚠️D。

#### 【主动】收割 🏹
- **原著** 序列5 收割者 —— "『收割』：附加攻击收割生命，命中弱点一击致命"
- **文案** 镰刃划过它的伤口，你把它正在流走的生命收进了自己体内；若这一刀正落在弱点上，那就不只是伤了。
- **序列** 5 收割者 · **能量 4 / cd 4 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_asc`）
- **效果** `drain(hp, 4)` + `If(target_has_status: ['vulnerable'])` → `then: damage(element: none, 3)`
- **翻译/语义** 原著"收割"是**两件事**：① "收割生命"（吸血，九原语里 `drain` 天然对应，零新机制）；② "**命中弱点一击致命**"（这是"收割"的定义性条款——不是"伤害更高"，是"命中弱点就是致命的"）。第②条在本序列只能落成"命中已标记弱点时追加一次打击"（一击致命的完整形态要等序列1 的【毁灭之矛】）。
- **与【毁灭之矛】的关系** 【收割】= 弱点 +3 伤（量变）；【毁灭之矛】= 弱点 + 直接致死（质变）。两者构成 🏹 轴的完整阶梯。
- ⚠️ 依赖 F52 `If` 谓词 `target_has_status`（🟡）+ `drain` 的定价锚点（**本稿第二大数值盲区**：`drain` 无既有锚点，"伤 X 回 X"折算成多少能量未定，见「本稿遗留」）。数值 ⚠️D。

#### 【被动】精准 🏹
- **原著** 序列5 收割者 —— "『精准』：让攻击精准命中预定位置"
- **文案** 你决定打哪儿，就打哪儿——没有谁能替它挡下来，也没有哪种把戏能让它从你眼前消失。
- **序列** 5 收割者 · **hook** `on_battle_start`
- **效果** 挂载 `precision`（整场）：
  - 你的攻击**不会被 `守护` 状态转移**（绕过替友军挡刀）
  - 你的单体技能**不受目标隐匿 / 不可选中状态影响**（依赖 C8 候选池过滤）
  - 你的 `target_override` 类效果**优先级高于**目标的 `嘲讽` / `守护`
- **翻译/语义** 原著"精准命中**预定位置**"——关键词是"**预定**"，即"我要打谁就打到谁，谁也别想替他挡、别想藏、别想把我的注意力挪走"。这比"加伤害"**原著得多**，也比"加伤害"有价值得多：它是 🏹 轴对抗一切"目标干扰 / 目标保护"体系的解法。
- ⚠️ 依赖 C8 候选池过滤（🔴）+ "绕过 `守护`" 与 "目标改写优先级裁定"（🟡，需先定 `守护` / `嘲讽` / `target_override` 三者的优先级链，与 F9 的"与嘲讽/守护冲突时建议 `puppet_string` 优先"是同一张裁定表，本稿主张**后施加者 + 施法者侧 `precision` 双优先**）。

#### 【主动】火焰化 ⚔
- **原著** 序列4 铁血骑士 —— "『火焰化』"
- **文案** 你的身体散开又重聚，化作一团人形的火焰——拳头穿过去了，而穿过去的那个东西正烧起来。
- **序列** 4 铁血骑士 · **能量 3 / cd 5 / 吟唱 ⚠️D** · `targetSpec: SELF`

  - `modify_stat(resist:fire, +60, 4t)` + `modify_stat(armor, +5, 4t)`
  - 触发器 `on_take_damage` → 对攻击者 `mount_status(burn, 2t)`（碰到火焰身躯者被点燃）
- **翻译/语义** 原著"火焰化"= 身体元素化。引擎里没有"物理免疫"（那属于位格碾压，brief §3 明确不搬），故落成：极高火抗 + 一定护甲（打不穿）+ **近身者被点燃**（火焰的攻击性反制）。第三条是它与【钢铁化】的分水岭——钢铁化是"你打不动我"，火焰化是"你打不动我，而且你会烧起来"。

- ⚠️ 依赖 `on_take_damage` → F61 `attacker` targetSpec（🟡，与【羞辱】同源共用）。

#### 【主动】远程轰炸 ⚔
- **原著** 序列4 铁血骑士 —— "『远程轰炸』（5–10 公里）"
- **文案** 火球自天而降，一颗接一颗砸在敌阵里——你甚至没有看向那边。
- **序列** 4 铁血骑士 · **能量 5 / cd 6 / 吟唱 ⚠️D** · `reach: allEnemies`
- **效果** 全体敌人 `damage(element: fire, 4)` + `mount_status(burn, 2t)`
- **翻译/语义** 原著白纸黑字写了"**5–10 公里**"——这是一个**射程**概念，而卡牌战场是「双路各 4 格」，没有距离维度。按 brief §3"位格/尺度类概念不搬"的处理口径，把"射程远到不需要靠近"落成 **AOE 全体** + **不可反击**（远程）。序列2 明写"远程轰炸全面升级"，故本卡是【燃烧之墙】的高序列版（更高直伤、更短 burn、全体覆盖）。
- **与【燃烧之墙】的差异** 火墙 4 能 / 3 伤 + burn 3t + 推条（控场向）；轰炸 5 能 / 4 伤 + burn 2t（纯输出向）。前者是"墙"，后者是"炸"。

#### 【被动】集众·铁血 ⚔ ★
- **原著** 序列4 铁血骑士 —— "团队集众：集中全队力量灵性于自身，**共享视野**，**分摊伤害**"
- **文案** 你把全队的力量与灵性都聚到自己身上——他们看得见的你都看得见，而他们该受的伤，你来扛。
- **序列** 4 铁血骑士 · **hook** `on_battle_start`
- **效果** 挂载 `massing`（整场，`dispelable: false`），并对全体存活友军挂载 `massing_link`（整场）：
  - **① 集中力量**：自身 `modify_stat(attack, +1 × 存活友军数, duration: null)`（随队伍规模动态刷新）
  - **② 分摊伤害**：任一持有 `massing_link` 的友军受到伤害时，该次伤害的 **30%** 转由**你（集众者）** 承受（`on_take_damage` → 持有者减伤 30%，集众者受等量 `damage(element: none, …)`）
  - **③ 共享视野**：全体友军获得「敌方隐匿 / 不可选中状态对其无效」（依赖 C8）
- **翻译/语义** **本途径最核心、最不能做砸的一条技能**。原著原文三件事，本稿一件不落：
  - "集中全队力量灵性于自身" → 攻击力随**存活**友军数增长。**注意是"存活"**——队友倒下，你的力量就少一分，这让"保住队伍"成为本途径的**核心资源决策**，而不是无脑铺场。
  - "分摊伤害" → **你替队友扛**（不是队友替你扛）。方向很重要：原著是"集中全队力量于**自身**"，那么代价自然也由自己承担。这让集众者成为**团队锚点**：活着就全队减伤 30%，死了全队增益全失 —— 攻防两面都在赌同一个单位的存活。
  - "共享视野" → 全队识破隐匿。
- **本稿唯一的"反向设计"说明** 从纯强度看，"替队友扛 30% 伤害"是**亏**的。这是刻意的：原著集众就是"把全队的力量与代价都揽到自己身上"，是铁血骑士的**气质**（"铁血"= 自己扛）。平衡上由 ① 的动态攻击力与 ③ 的全队识破补回，且队伍越大收益越高。
- ⚠️ 三处引擎缺口：① **跨单位伤害转嫁（群体版）**（本稿新增项 3，🔴 —— 既有「伤害转移」状态与 F5 `pain_link` 都是"施法者受伤转嫁给目标"，本条需要的是**反向**（友军受伤转嫁给施法者）且**群体化**）；② **状态携带 `casterId` 并可寻址施法者**（**与 F56 同源**，🔴，本稿不重复立项，直接依赖）；③ **动态属性（按存活友军数计算）**（本稿新增项 6，🔴）。
- **退化方案** ① 改为固定 `modify_stat(attack, +3, null)`，并在每次友军死亡时（`on_death` 全局监听）`modify_stat(attack, -1)`；② 分摊改为固定 30% 且只对**相邻**友军生效（缩小依赖面）；③ 共享视野并入【猎人的感官】。

#### 【被动】钢铁勇气 ⚔
- **原著** 序列4 铁血骑士 —— "钢铁般勇气，不再被恐惧击倒"
- **文案** 你不是不知道怕，你只是不再因为怕而后退半步——任何试图让你恐惧、让你动摇、让你爱上别的东西的把戏，都碰不到你。
- **序列** 4 铁血骑士 · **hook** `on_battle_start`

  - `immune: ['fear']`（挂载期间，恐惧类状态无法被施加到你身上，依赖 G12 `immune` 字段）
  - 触发器 `on_apply` → `dispel(self, category: ['control'], count: 1)`（一次性挣脱既有的控制）
- **翻译/语义** 原著只说"**不再被恐惧击倒**"，**不是"免疫所有控制"**。故本稿严格限定在恐惧 / 精神压迫一类，不碰眩晕——否则这条被动会变成传说级的通用免疫。第二条"挣脱一次"是原著"不再被……击倒"的另一面：已经倒下的，也能站起来一次。
- ⚠️ 依赖 G12 `immune` 字段（🔴 未实现）+ **新 StatusCategory `fear`**（本稿新增项 15，🟡 —— G12 原案按 `debuff / dot / control / buff` 四个 category 匹配，若直接用 `immune: ['control']` 会把眩晕一并免疫掉，**过强且偏离原著**）。

#### 【主动】借用能力 ⚔
- **原著** 序列3 战争主教 —— "3 公里内**使用团队成员非凡能力**"
- **文案** 你伸出手，从身边的同伴身上借走了他最擅长的那一样东西——现在是你的了。
- **序列** 3 战争主教 · **能量 3 / cd 5 / 吟唱 ⚠️D** · `targetSpec: { faction: ALLY }` · Manual（fallbackSort: `stat_max_desc`）
- **效果** 读取目标友军**最高的一项属性**（`attack` / `defense` / `armor` / `gauge_rate` 四取一），`modify_stat(<该属性>, +该属性值 × 0.5, duration: 4)` 给自身
- **翻译/语义** 原著这条是战争主教最招牌的能力：**用队友的能力**。引擎里"使用他人的技能"无法表达（技能是 `UnitDef` 上的静态列表，运行时复制技能需要整套新机制），故按 brief §3 的降级口径，落成"**借用队友的长板**"——你把队友最强的那一项属性拿走一半。这保留了原著的两个关键体感：① 你是**团队的力量枢纽**（队友越强你越强）；② 借来的东西是**临时的**（duration 4，到期归还）。
- **与【集众·铁血】的关系** 集众是"按人数加攻击"（量），借用能力是"按质量加属性"（质）。两者叠加后，一个带了强力队友的战争主教，面板会高得离谱——这是 ⚔ 轴的**设计意图**，代价是全队都依赖同一个人。
- ⚠️ 依赖"读取目标运行时属性并按比例加成"（本稿新增项 7，🔴 —— 与愚者 v0.2 新增项 8 `maxAttackThisBattle` 是同一族的"读运行时统计值"需求，建议**统一为一个 `valueFrom` 取值来源枚举**）。**退化方案**：`modify_stat(attack, +4, 4t)` + `modify_stat(armor, +5, 4t)` 固定双加成，代价是失去"借长板"的选择感。
- ⚠️ 依赖新排序 `stat_max_desc`（🟢，并入本稿新增项 10）。数值 ⚠️D。

#### 【主动】战争迷雾 ⚔
- **原著** 序列3 战争主教 —— "『战争迷雾』"
- **文案** 灰色的雾从你脚下漫开，吞掉阵型、吞掉口令——它们开始在雾里互相猜疑，而你的队伍看得一清二楚。
- **序列** 3 战争主教 · **能量 5 / cd 7 / 吟唱 ⚠️D** · `consumption: 'zone'`
- **效果** `spawn_zone(zone_war_mist)`：
  - 区域内**敌方**单位 `modify_stat(attack, -2)` + `on_tick` → `modify_resource(gauge.current, -4, delta)`
  - 区域内**己方**单位 `damage_taken_mul: 0.9`
- **翻译/语义** 原著的战争迷雾是**信息遮蔽**：敌人看不见、听不清、指挥失灵，而我方不受影响。引擎里最贴的表达就是**非对称的区域 debuff**——敌方掉攻、掉节奏，己方减伤。这比"让敌人打空"更贴"迷雾"（迷雾影响的是**状态**，不是**目标选择**）。

  `]`

  - 你施加的 `burn` 状态 `duration +1`
- **翻译/语义** 原著"火焰提升为紫色"是**质变级的火焰升级**，且序列2 明写"各能力**全面升级**"。引擎里"火焰等级"没有维度，故落成**火系专属增伤光环 + burn 时长 +1**。这是 🔥 轴的旗舰与**终局开关**：一旦挂上，本途径全部 11 个火系技能同时升档（火鸦术 / 炽白之枪 / 燃烧之墙 / 延时爆炸 / 火焰附魔 / 火焰马刀 / 火焰化 / 远程轰炸 + 注火续燃）。
- **为什么是持续整场而不是几回合** 原著这是**序列晋升带来的永久性质变**，不是临时 buff。做成 duration: null 才能体现"成了天气术士，火就不一样了"。
- ⚠️ 依赖"按伤害元素过滤的伤害乘区"（本稿新增项 12，🟡 —— 与愚者 v0.2 新增项 14「按 pathway 标签过滤的伤害乘区」是同一需求的两面，建议**统一为一个带 `filter: { element? / pathway? }` 的参数化乘区**）。**退化方案**：改为"自身 `attack +3`" 的通用增伤，代价是火抗高的敌人照样挡得住，失去"火焰质变"的语义。数值 ⚠️D。

#### 【被动】无限制分享 ⚔
- **原著** 序列2 天气术士 —— "10 公里内使用团队成员能力，**分享无限制**"
- **文案** 借来的东西，你没有独吞——你拿到的每一点力量，都同时出现在了每一个同伴身上。
- **序列** 2 天气术士 · **hook** `on_battle_start`
- **效果** 挂载 `sharing_unlimited`（整场）：
  - 你身上每获得一个 `category: 'buff'` 的状态（`on_apply`），**复制**一份给全体存活友军（`duration` 与层数减半，⚠️D，且**不扣除**你身上的那份）
  - 全体友军**互相**分摊受到的伤害（任一友军受击，20% 平摊给其余存活友军）
- **翻译/语义** 原著序列2 比序列3 多出的那个词是"**分享无限制**"——序列3 是"我把你们的能力**拿来用**"，序列2 是"我拿来的，还能**分给你们**"。故本条落点是**增益分发**：你身上的增益自动复制给全队（一半强度）。第二条"全员互相分摊"是【集众·铁血】分摊机制的**全队化**（序列4 是你替大家扛，序列2 是大家互相扛 —— 这正是"无限制"的体感）。
- **与【集众·铁血】的层次** 序列4：单向（你 ← 大家的力量，你 → 大家的伤害）；序列2：全向（力量在队内自由流动）。这是 ⚔ 轴最核心的**四档递进**：铁血（集中）→ 战争主教（借用）→ 天气术士（无限制分享）→ 征服者（质变）。
- ⚠️ 依赖：① 新算子 `copy_status`（本稿新增项 5，🔴 —— 与 F50 `drain category:'buff'` 同源，但 F50 是**转移**（目标失去、施法者获得），本条是**复制**（双方都有），需新增）；② 群体互相分摊（本稿新增项 3，🔴，与【集众·铁血】共用同一母版）；③ F59 `ALL_ALLIES`（🟡）。

### 传说（序列 1–0）

#### 【主动】征服 ⚔ ★
- **原著** 序列1 征服者 —— "『征服』权柄：让目标**身心臣服**，**彻底征服后永远效忠**"
- **文案** 你看着它的眼睛，说了一个字。它的膝盖先软下去，然后是它的意志——从这一刻起，它不再是它自己的人了。
- **序列** 1 征服者 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(conquered, duration: 6)`：
  - `target_override` → 持有者**同阵营** `hp_desc` 单位（身心臣服，掉头攻向旧主）
  - `modify_stat(attack, -2, 6t)` + `damage_taken_mul: 1.2`（不肯全力、且任你宰割）
  - 触发器：持有者在此期间**死亡** → `spawn(unit_war_soldier, template: <该单位>, hpRatio: 0.5, position: 'tail')`（彻底征服，死后以士兵的身份永远效忠）
- **翻译/语义** 原著"征服"权柄有**两个阶段**，本稿两阶段都落：① "身心臣服" = 转头打自己人（比【煽动】更强：持续时间翻倍、附带减攻与受伤加深，因为它是**权柄**不是话术）；② "彻底征服后**永远效忠**" = 它死了也要为你作战——**这是本途径最有原著味的一条机制**，把"征服"从"控制一段时间"推进到"永久改变归属"。
- **与【煽动】的差异** 煽动是话术（3t、只改目标），征服是权柄（6t、改目标 + 削弱 + 死后转化）。后者是前者的传说级形态。
- ⚠️ 依赖：① `target_override` 指向同阵营单位（🔴，同【煽动】）；② 跨阵营 `spawn`（本稿新增项 18，🟢 —— **与收尸人 v0.2 新增项 11「跨阵营 spawn」同源**，建议并入同一母版；**G8 合规**：是新建单位落在己方队尾，不是 relocate 敌方单位）；③ `spawn.template`（本稿新增项 19，🟢 —— **与愚者 v0.2 新增项 4 同源**）。数值 ⚠️D。
- **未决** 若死者身上带 C4 `miracle` / G4 `reviveOf`，是"先复活"还是"先被征服转化"？需定复活与征服的结算优先级（见「本稿遗留」）。

#### 【主动】以偶为兵 ⚔ ★
- **原著** 序列1 征服者 —— "『以偶为兵』（**撒豆成兵**）：**征服无生命物体**转化为士兵"
- **文案** 你埋下的那些铁夹子、这片战场上的碎石与断木——你征服了它们。于是它们站了起来，握紧了不存在的刀。
- **序列** 1 征服者 · **能量 4 / cd 7 / 吟唱 ⚠️D** · `consumption: 'summon'`
- **效果** `Repeat(count: <己方 `unit_snare_trap` 数量>, body: Sequence[`
  - 对其中一个 `unit_snare_trap` 造成致死伤害（**引爆其亡语**：对相邻敌人 `damage 4 (physical)` + `眩晕 1t`）
  - `spawn(unit_war_soldier, position: 'tail')`
  `])`；若场上无陷阱，则改为 `spawn(unit_war_soldier, position: 'tail')` ×1（撒豆成兵：把碎石瓦砾化为士兵）
- **翻译/语义** **本稿最喜欢的一条翻译**。原著"征服**无生命物体**转化为士兵"——引擎里没有"无生命物体"，但本途径**恰好有一个无生命物体**：F36 `unit_snare_trap`（捕兽夹，atk 0、不行动、纯占位）。于是"以偶为兵"落成：**把你自己埋下的陷阱，征服成士兵**。
  - 这条设计同时解决了三件事：① 让 F36 `unit_snare_trap` 从"一张冷门卡"变成 combo 核心（先布陷阱 → 再转成兵）；② 让"征服无生命物体"这条抽象权柄有了**具体的、可验证的**落地对象；③ 引爆陷阱的亡语让这次转化自带一次范围伤害 —— "铁夹子炸开，火光里站起一名士兵"，画面与机制完全对齐。
  - 兜底分支（无陷阱时直接召 1 兵）承载原著的另一个名字"**撒豆成兵**"——没有偶，就地取材。
- **与【献祭祈求】的反向关系** 献祭祈求把士兵**献出去**换一次神助，以偶为兵把陷阱**变成**士兵。两者一进一出，构成 ⚔ 轴的"祭品经济学"：布陷阱 → 转士兵 → 献士兵 → 换爆发。这是本途径**最深的一条 combo 链**，跨三个稀有度档。
- ⚠️ 依赖：① `Repeat` / `Sequence` 运行时展开（**G3**，🟡）；② `Repeat` 的**动态 count**（本稿新增项 8，🔴 扩展 —— 需支持 `count` 取运行时数量；退化方案：count 固定 2，超出部分忽略）；③ 新 targetSpec `OWN_SUMMON`（本稿新增项 10，🟡）；④ 对**己方**单位造成伤害（`damage` 原语的 faction 限制需确认，🟡）。数值 ⚠️D。

#### 【主动】毁灭之矛 🏹 ★
- **原著** 序列1 征服者 —— "『毁灭之矛』：『收割』**质变版**，**命中弱点相当于必然死亡**"
- **文案** 你投出的不是矛，是一个已经写好的结局——**如果它身上有你点明的那处弱点，那支矛落下的地方，就是终点。**
- **序列** 1 征服者 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `hp_asc`）
- **效果** `damage(element: none, 5)` + `If(target_has_status: ['vulnerable'])` → `then: execute`（**直接致死**）
- **翻译/语义** 原著这条写得极其明确："**质变版**"+"**命中弱点相当于必然死亡**"。所以本稿**不做成"暴击加伤"**——那是量变，是【收割】的活。序列1 的毁灭之矛必须是：**弱点已标记 → 直接带走**，不管它还有多少血、多少护甲。
  - 这让 🏹 轴的完整链条终于闭合：结构要点（破甲）→ 弱点侦察（标记）→ 收割（弱点追加伤害）→ **毁灭之矛（弱点即死）**。这也是本途径唯一的"斩杀"手段。
  - 平衡上由"必须**先**挂上易伤"约束（【弱点侦察】2 能量 / cd 3），且对 Boss 类单位建议走 `execute` 的免疫白名单（见遗留）。
- ⚠️ 依赖新算子 `execute`（本稿新增项 2，🔴 —— **与收尸人 v0.2 新增项 1 同源，建议并入同一母版，本稿不重复立项**；其退化方案 `damage(element: none, 9999)` 会被护甲/减伤拦截，对本条反而是**更好的平衡口径**，因为护甲流仍有活路）+ F52 `target_has_status`（🟡）。数值 ⚠️D。

#### 【被动】集众质变 ⚔ ★
- **原著** 序列1 征服者 —— "『集众』**质变**：**力量达一定数量产生质变**"
- **文案** 当足够多的人站在你身后时，发生的不只是"更多"——是"不一样"。你们的呼吸开始同步，刀锋开始指向同一个方向。
- **序列** 1 征服者 · **hook** `on_battle_start`
- **效果** 挂载 `massing_ascend`（整场）：
  - 每存活 1 名友军，自身 `modify_stat(attack, +1)`（动态，与【集众·铁血】的 ① 叠加）
  - **质变阈值**：当存活友军数 **≥ 3**（⚠️D 待标）时触发质变 —— 全体友军 `damage_mul: 1.2` + 你受到的伤害 **×0.8**
- **翻译/语义** 原著关键词是"**质变**"，不是"更多"——即**越过一个数量阈值后，性质发生变化**。故本条落成一个**阈值触发器**：数量只是门槛，跨过去之后给的是**全队乘区 + 自身减伤**（性质变了：从"我一个人扛"变成"我们是一个整体"）。
- **⚠️ 与原著的偏差（本稿唯一一处刻意保守）** 原著是"力量达**一定数量**产生质变"，未给具体数字。本稿取"存活友军 ≥ 3"（即含自己在内 4 人，在 4 槽位 + 召唤物的语境下是个需要经营才能维持的门槛）。⚠️D 待标。
- ⚠️ 依赖：① 动态属性（本稿新增项 6，🔴，与【集众·铁血】同源共用）；② 阈值触发的运行时检查（🔴，同上）；③ F59 `ALL_ALLIES`（🟡）。数值 ⚠️D。

#### 【主动】战争权柄 ⚔ ★
- **原著** 序列0 红祭司 —— "『战争』权柄：**存在即可让目标区域发生战争**"
- **文案** 你站在那里，战争就开始了——它们不再分敌我，不再听号令，只剩下"杀"这一件事。
- **序列** 0 红祭司 · **能量 7 / cd 10 / 吟唱 ⚠️D** · `reach: allEnemies`
- **效果** 全体敌人 `mount_status(warmonger, duration: 6)`：
  - `target_override` → **`nearest_any`**（最近的单位，**不分阵营**）
  - `modify_stat(attack, +3, 6t)` + `modify_stat(armor, -5, 6t)`
  - `If(gender_is(target, male))` → `damage_taken_mul: 1.15`（6t）（**「男性」权柄**：男性单位在战争之主的权柄下无可退避）
- **翻译/语义** **本途径最有"权柄感"的一张卡，也是本稿唯一一张"敌我不分"的卡**。原著"存在即可让目标区域发生**战争**"——战争的本质不是"我方打你方"，是"**所有人打所有人**"。故落点不是范围伤害，而是**把敌人的敌我识别彻底打碎**：它们开始攻击离自己最近的任何单位，包括自己的同伴。
  - 附带 `attack +3 / armor -5` 是"战争"的另一面：**更凶，也更脆**。这是一把双刃剑（敌方输出暴涨），也是这张卡必须 7 能量 / cd 10 的原因 —— 它不是"安全的大招"，是"把战场点燃"。
- **与【煽动】【征服】的差异** 煽动 = 单体、打指定队友（话术）；征服 = 单体、永久（权柄）；战争权柄 = **全体、敌我不分、双刃剑**（战争本身）。三者的"控制强度 / 精确性 / 代价"正好构成一个阶梯。
- **「男性」权柄的落地** 序列0 权柄谱系中「男性」一支：v0.3 性别已是战斗内可读属性（2026-09-07 拍板：战外养成决定、战斗内不可变），条件面走 `gender_is` 谓词——男性目标在战争权柄下受伤加深（×1.15）。§4.2 表中「男性权柄未落地」的登记随之销项。
- ⚠️ 依赖 `target_override` 新锚点 `nearest_any`（本稿新增项 13，🟡 —— 属 F 组「`target_override` 状态族」合并候选 3，建议在统一状态族里**多注册一个锚点参数**即可，不新增机制）。⚠️ **需拍板**：若"最近的单位"可能是施法者本人，会与 `嘲讽` / `守护` / `precision` 的优先级冲突，需纳入优先级裁定表。数值 ⚠️D。

#### 【主动】毁灭权柄 🏹 ★
- **原著** 序列0 红祭司 —— "『毁灭』权柄：上可毁灭星球，下可杀死真神"
- **文案** 那不是火焰，是"消失"本身。凡是还没死透的，都会被一并抹掉。
- **序列** 0 红祭司 · **能量 7 / cd 10 / 吟唱 ⚠️D** · `reach: allEnemies`
- **效果** 全体敌人 `damage(element: fire, 8)` + `If(target_hp_percent ≤ 0.3)` → `then: execute`
- **翻译/语义** 原著"毁灭"权柄的尺度是"星球 / 真神"，属于 brief §3 明确不搬的位格碾压。故按"只做数值更大的同一件事 + 保留原著**语义边界**"的口径落地：① 全场巨额火伤（毁灭的"广度"）；② 对残血者**直接抹除**（毁灭的"彻底性"——不是打伤，是**不存在了**）。第②条是本条与"普通大范围 AOE"的分界线，也是"毁灭"与"火焰"这两条下位权柄的区别：火焰烧不死的，毁灭能。
- **与【毁灭之矛】的差异** 毁灭之矛 = 单体、需挂易伤、无视血量（精确斩杀）；毁灭权柄 = 全体、按血量阈值（30%）、范围抹除。一个是矛，一个是天灾。
- ⚠️ 依赖：`execute`（本稿新增项 2，🔴，与收尸人同源）+ 条件谓词 `target_hp_percent`（本稿新增项 14，🟡 —— **与收尸人 v0.2 新增项 2 同源**，建议并入同一谓词集）+ 范围技能随人数放大（需 4 人满编复核）。数值 ⚠️D。

## 三、跨途径共享（相邻途径：刺客，同属灾祸之城）

猎人（红祭司）与刺客（魔女）同为**灾祸之城**源质、同属旧日「毁灭天灾」，高序列可互换。共享技能用 `sharedAcross` 声明：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 挑衅 / 羞辱 | 刺客 | 刺客序列8 **教唆者**的"诱发心底恶欲、激化矛盾、挑起冲突"与挑衅者的"洞察敏感点、激怒失控"是同一套情绪操纵的两种说法；机制上都是既有 `嘲讽` + `易伤`，零额外成本 |
| 误导 / 煽动 | 刺客 | 刺客序列8 教唆者明写"**误导**、说服"，与阴谋家的"误导、迷惑、欺骗"字面重合。同属 F 组 `target_override` 状态族，共用母版即可 |
| 猎人的感官 / 结构要点 | 刺客 | 刺客序列9 明写"固化**鹰的视力**和黑暗视觉"，与猎人序列9"感官直线提升"同源；两者都是低序列的感知型被动，混合后不冲突 |
| 弱点侦察 | 刺客 | 刺客序列9"力量爆发于**一击**"、序列5 痛苦——都依赖"先找到要害"；共享后刺客可获得它缺的"开窗口"手段 |
| 收割 | 刺客 | `drain` 与刺客的痛苦 / 生命转移语义同源（刺客稿已把 `pain_link` 反向共享给猎人），可作刺客的续航替补 |
| 操纵天气 | 刺客 | 刺客序列2 **灾难**明写"天灾（暴雪 / 海啸 / 地震 / 陨石）"，与天气术士的"创造极端天气"是同一权柄的两个名字。**建议两者共用同一套 ZoneDef 母版**，只换元素与载荷 |
| 钢铁勇气 | 刺客 | 刺客序列2「灾难」/ 序列1「末日」语境下同样需要"不被恐惧击倒"；共享一条通用的 `fear` 免疫比各造一条干净 |

> **不共享（会稀释途径辨识度）**：
> - **全部 🔥 火系技能**（火鸦术 / 炽白之枪 / 燃烧之墙 / 延时爆炸 / 火焰附魔 / 火焰马刀 / 注火 / 火焰化）—— 刺客是**黑焰与冰霜**，橙红火焰是猎人途径的独家招牌。
> - **全部 ⚔ 集众技能**（集众·铁血 / 借用能力 / 战吼 / 献祭祈求 / 心灵沟通 / 无限制分享 / 集众质变）—— **集众是本途径最独特也最有味道的机制**，共享等于把猎人途径的灵魂送出去。
> - **战争迷雾 / 战争权柄** —— "战争"是红祭司的专属权柄；刺客对应的是"灾难 / 末日"（矛盾集中爆发），语义不同，不应混用。
> - **毁灭之矛 / 毁灭权柄** —— 刺客序列0 是"**混沌**"（万物归于未发生的可能性），不是"毁灭"（让事物不存在）。两者结局看起来像，机制与哲学完全相反。
> - **征服 / 以偶为兵** —— 刺客的"魅惑"是让目标**爱上**你（欢愉 / 魅力），猎人的"征服"是让目标**臣服**于你；前者是软控制，后者是所有权转移。混用会让两条途径的低序列体验趋同。
>
> **反向**：刺客稿已把「匕首投掷 / 致命要害 / 致命伏击」「教唆 / 言语傀儡 / 巧言」「女巫咒术 / 诅咒低语 / 绝望印记」共享给猎人，本稿接受并建议**仅接受其中的「教唆」类**（与【挑衅】【误导】同族），**谢绝诅咒 / 疾病类**——原著猎人途径没有任何诅咒与疾病能力，接受会破坏途径纯度。

## 四、本稿遗留

### 4.1 数值盲区（全部 ⚠️D）

- **全稿 37 个技能的数值均为占位建议值**，需过验证脚本（D4）重定。
- **团队类技能的定价是本途径最大的盲区**：本稿有 **7 个技能**（集众·铁血 / 借用能力 / 战吼 / 心灵沟通 / 无限制分享 / 集众质变 / 战争权柄）的收益**随队伍规模线性或超线性放大**，而既有数值锚点（brief §2）全部是**单体**口径。在 4 人满编 + 召唤物的场景下，这些技能的强度可能与 1v1 差 3 倍以上。**建议为团队类技能单独建一套定价口径**，优先级高于本稿其他数值项。
- **burn 折算**（D4，🔴）：依赖它的技能共 5 个（火鸦术 / 燃烧之墙 / 远程轰炸 / 注火 / 火焰化）。tick 粒度远小于回合，实际到账速度未实测。
- **`drain` 无既有锚点**：【收割】"伤 4 回 4"折算成多少能量未定。
- **`gauge.current` / `gauge_rate` 类**（D2，🔴）：燃烧之墙 -15、战吼 +10、战争迷雾 -4/tick、操纵天气 -6 rate、野外生存 +6 rate，共 5 处。
- **范围技能（allEnemies）随敌方人数线性放大**：燃烧之墙 / 远程轰炸 / 战争权柄 / 毁灭权柄 需按 4 人满编复核。
- **集众的百分比**：分摊 30%（集众·铁血）、互相分摊 20%（无限制分享）、质变阈值"存活友军 ≥ 3"——三个数字全部待标，且互相耦合（分摊比例越高，质变阈值应越低）。

### 4.3 未决机制

1. **优先级裁定表缺失（本稿最急）**：`守护` / `嘲讽` / `target_override`（煽动 / 误导 / 征服 / 战争权柄）/ `precision`（绕过守护）四者共存时谁优先？本稿 6 个技能依赖这张表。F9 已提"puppet_string 优先于嘲讽/守护"，本稿主张的排序是：**`precision`（施法者侧绕过）> `target_override`（后施加者）> `嘲讽` > `守护`**。需拍板。
2. **【征服】与复活的冲突**：被 `conquered` 的单位死亡时，若它身上有 C4 `miracle` / G4 `reviveOf`，是"先复活"还是"先转为己方士兵"？建议**征服优先**（征服是权柄级，且原著写"彻底征服后**永远**效忠"），但需定进复活结算链。
3. **`execute` 的适用范围**：【毁灭之矛】【毁灭权柄】都能"无视血量直接致死"。是否对 Boss / 精英类单位设免疫白名单？本稿建议设（否则两卡会直接终结所有 Boss 战）。
4. **【无限制分享】的指数化风险**：若队内多人持有该被动，或增益数量较多（如【战吼】+【借用能力】+【钢铁化】同时生效），"复制给全队"可能产生叠加爆炸。建议设"每个友军同时最多持有 N 个被复制的增益"（⚠️D）。
5. **【战争权柄】的 Zone / 全员目标边界**：全员 `target_override → nearest_any` 时，若最近单位是施法者本人，等于变相嘲讽。需明确是否排除施法者。
6. **本途径零 `heal`**：原著猎人途径确实没有任何治疗 / 恢复 / 净化能力，故全稿未用 `heal` 原语（A22 自动合规）。反过来说，**本途径的续航完全依赖 `drain`（收割）与减伤（钢铁化 / 火焰化 / 集众分摊）**——若验证后发现续航不足，不应给猎人加治疗，而应调高 `drain` 与减伤的数值。
