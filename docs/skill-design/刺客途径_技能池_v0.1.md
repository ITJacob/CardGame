# 刺客途径 · 技能池 v0.1

灵感源：ima 知识库《诡秘之主-途径数据》→ 刺客途径（aka 魔女途径，源质「灾祸之城」，相邻途径=猎人）。
框架：02_详细设计 v1.5 / 03_参数层 v1.5，并已核对 `src/catalog/model.ts` 的实际 schema。

> 本稿是**设计约定**，不是终稿数值。所有数值标注了推导依据，最终需过验证脚本（见改动记录 D 组）。
> 「文案」为玩家视角的效果描述，用于肉鸽派发时展示；「效果」为引擎落地表达。
> 本途径定位为「诅咒 / 负面 / 控制」型，优先复用已有状态（易伤 / 中毒 / 沉默 / 嘲讽 / 伤害转移 / 再生），仅新增 2 个本途径特有 debuff（痛苦链接、绝望）。

## 〇、肉鸽化前提（本版新增的设计约束）

| 约定 | 内容 |
|---|---|
| 槽位 | 每英雄 **4 主动 + 4 被动** |
| 派发 | 爬塔随机派发，逐步构筑 |
| 共享 | 部分技能带 `sharedAcross`，可被相邻途径（猎人）的职业重复抽到 |
| 稀有度 | 由序列位阶直接映射（见下表） |

### 稀有度 = 序列位阶（自然映射，无需另设维度）

| 序列 | 稀有度 | 派发权重 | 定位 |
|---|---|---|---|
| 9–8 | 普通 Common | 高 | 骨架，开局即可得 |
| 7–6 | 精良 Uncommon | 中 | 成型件 |
| 5–4 | 稀有 Rare | 低 | 构筑核心 |
| 3–2 | 史诗 Epic | 很低 | 大招 / 转折点 |
| 1–0 | 传说 Legendary | 极低 | 一局最多 1 张 |

### 四条构筑轴（肉鸽要保证技能能成体系，不能是散装）

| 轴 | 关键词 | 玩法 |
|---|---|---|
| 🗡 **潜行爆发** | 直伤 / 起手易伤 | 匕首暗器贴脸，先挂易伤再一击，打爆发 |
| 🗣 **教唆操纵** | 嘲讽 / 目标覆盖 | 用语言挑拨，强迫敌人攻击错误的目标（借 `嘲讽` / `target_override`） |
| 💀 **诅咒负面** | 诅咒 / dot / 新 debuff | 女巫的黑暗法术，叠易伤、中毒、痛苦链接、绝望 |
| 💋 **情感欲望** | 魅惑 / 控制 | 欢愉之力操控情感，魅惑敌人只盯你，配合沉默锁死 |

## 一、技能池

图例：⚠️ = 需要框架扩展（已登记改动记录）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】潜行 🗡
- **文案** 你隐入阴影，战斗开始时便抢先一步出手，让猎物来不及反应。
- **序列** 9 刺客 · **hook** `on_battle_start`（⚠️ A1 新增触发点）
- **效果** `modify_resource(gauge.current, +15, delta)`
- **推导** 行动阈值 75，+15 ≈ 抢先 1/5 个行动周期。与愚者「预知」(+25) 同语义不同量级，刺客版更轻、更贴"先手起势"。

#### 【主动】匕首投掷 🗡
- **文案** 甩手一记匕首暗器，精准命中远处敌人，造成 3 点物理伤害。
- **序列** 9 刺客 · **能量 2 / cd 2** · `reach: ranged`
- **效果** `damage 3 (physical)`
- **推导** 2 能量 × 1.2 = 2.4 → 取整 3，略优于基准，作为骨架直伤位。

#### 【被动】致命要害 🗡
- **文案** 你熟悉每一处致命要害，出手时有 25% 概率让伤口更难愈合——为目标挂上易伤。
- **序列** 9 刺客 · **hook** `on_deal_damage`
- **效果** `{ ref: 'mount_vulnerable_2t', condition: { kind: 'chance', p: 0.25 } }`
- **合规** 引擎支持概率（播种式 `RandomSource` + 登记制，R2/R3/R6），正确写法是 EffectRef 上的 **`condition`**，不是不存在的 `Chance()` 算子（已修正，见 G1 更正）。概率只用于"是否挂易伤"这个非直伤维度。期望每 4 次出手 1 次易伤。

#### 【主动】教唆 🗣
- **文案** 几句挑拨的耳语，便让目标只盯着你——它愤怒地扑向你，忘了身后的同伴。
- **序列** 8 教唆者 · **能量 2 / cd 3** · `reach: ranged`
- **效果** `mount_status(taunt, 3t)`
- **语义** "教唆"= 用语言操纵他人行动，引擎里最贴合的就是 `嘲讽`（强制攻击施法者）。复用既有 taunt，无新机制。

#### 【被动】巧言 🗣
- **文案** 你三言两语便能攫取局势的主动，每回合开始自然积攒 1 点能量。
- **序列** 8 教唆者 · **hook** `on_turn_start`
- **效果** `modify_resource(energy, +1)`
- **肉鸽价值** 语言操纵的"节奏"收益，轻量但稳定，喂饱 🗣/🗡 高费连招。

### 精良（序列 7–6）

#### 【主动】女巫咒术 💀
- **文案** 念诵一段黑暗咒文，灼烧目标心神，造成 2 点精神伤害并使其受伤加深（易伤 3 回合）。
- **序列** 7 女巫 · **能量 3 / cd 3** · `reach: ranged`
- **效果** `damage 2 (mental)` + `mount_status(vulnerable, 3t)`
- **语义** 女巫的黑暗法术 = 诅咒，优先复用 `vulnerable`（×1.3 乘区，A14 已裁定）。

#### 【主动】暗影步 🗡 ★
- **文案** 你踏着阴影贴近目标完成背刺，造成 3 点物理伤害，并让这一击的伤口更难愈合（易伤 2 回合）。
- **序列** 7 女巫 · **能量 3 / cd 4** · `reach: ranged`
- **效果** `damage 3 (physical)` + `mount_status(vulnerable, 2t)`
- **设计价值** 潜行轴旗舰：背刺为近战攻击进程（「突进」仅为 flavor，不调站位、不越中线，遵循 G8 铁律），所以直伤压到 3；挂易伤让后续爆发吃满 ×1.3。原 `move.op: param` 落点会越中线，已移除，不再依赖 C1。

#### 【主动】魅惑 💋 ★
- **文案** 你巧笑倩兮，敌人被欢愉冲昏了头，眼中只剩你一人，痴痴地扑向你。
- **序列** 6 欢愉 · **能量 3 / cd 4** · `reach: ranged`
- **效果** `mount_status(taunt, 3t)` + `damage 1 (mental)`
- **语义** 欢愉 / 情感操纵 → 复用 `嘲讽`（强制攻击施法者）即"被你魅惑只盯着你"，附 1 点精神伤害点题。

#### 【被动】欢愉涌动 💋
- **文案** 你施加的每个负面效果都让敌人愈发沉醉，每挂上一个 debuff 便回 1 点能量。
- **序列** 6 欢愉 · **hook** `on_apply`（`targetSpec: enemy_debuff`）
- **效果** `modify_resource(energy, +1)`
- **肉鸽价值** 诅咒轴是 debuff 制造机，此被动把"挂状态"变成能量引擎，串起整条负面链。

#### 【主动】诅咒低语 💀
- **文案** 一阵阴冷的低语钻进耳中，造成 1 点精神伤害，并在体内种下缓慢发作的剧毒。
- **序列** 7 女巫 · **能量 2 / cd 3** · `reach: ranged`
- **效果** `damage 1 (mental)` + `mount_status(poison, 3t)`
- **语义** 复用既有 `poison`（持续伤害 dot），压低直伤换 dot，符合"诅咒"定位。

### 稀有（序列 5–4）

#### 【主动】痛苦咒 💀
- **文案** 你将目标的痛苦与你相连，造成 3 点精神伤害，并种下「痛苦链接」——此后你受伤时，它替你分担一半。
- **序列** 5 痛苦 · **能量 4 / cd 4** · `reach: ranged`
- **效果** `damage 3 (mental)` + `mount_status(pain_link, 3t)`（⚠️ 本途径新增状态，见末尾）
- **语义** "施加与转移痛苦" → 施法者受伤时，50% 等量转嫁给链接目标。是 💀 轴的核心新机制。

#### 【主动】苦难转移 💀
- **文案** 你一把揽过同伴的厄运，让友军受到的伤害尽数转嫁到自己身上（再循痛苦链接甩给敌人）。
- **序列** 5 痛苦 · **能量 3 / cd 4** · `targetSpec: ALLY`
- **效果** `mount_status(伤害转移, link → self, 3t)`
- **语义** 复用既有状态 `伤害转移`（伤害转嫁），无新机制；与「痛苦咒」形成"你受伤→敌人替你扛"的闭环。

#### 【主动】言语傀儡 🗣 ★
- **文案** 你巧舌如簧，把敌人变成提线木偶：它下一击不再朝向你，而是狠狠砸向自己的同伴，并被你标记得伤势更重（易伤 2 回合）。
- **序列** 5 痛苦 · **能量 4 / cd 4** · `reach: ranged`
- **效果** `target_override(目标下一次攻击 → 其相邻友军)` + `mount_status(vulnerable, 2t)`
- **语义** 教唆的升级形态——直接改写敌人攻击目标。是 🗣 轴旗舰。
- ⚠️ 需 `target_override` 指向"指定友军"（非自身、非空坐标）。愚者 `愚弄命运`(C7) 已验证 `target_override` 可用，本稿扩展到"指向友军"，引用 C7 同链，不重复立项。

#### 【主动】致命伏击 🗡
- **文案** 从阴影中暴起的一击，6 点物理伤害直取要害；若目标已被易伤标记，则吃满 ×1.3 的撕裂之痛。
- **序列** 4 绝望 · **能量 4 / cd 4** · `reach: ranged`
- **效果** `damage 6 (physical)`（易伤由 `vulnerable` 乘区自动结算）
- **推导** 4 能量基准 = 4.8 伤害，给到 6 是因为"需先挂易伤才达满收益"的前置成本。若目标无易伤则仅 6 直伤，属中规中矩。

#### 【主动】绝望印记 💀 ★
- **文案** 你在敌人灵魂上烙下「绝望」印记：受伤加深 20%，且每 tick 被冰冷的无属性侵蚀啃咬 1 点，持续 3 tick。
- **序列** 4 绝望 · **能量 4 / cd 5** · `reach: ranged`
- **效果** `damage 3 (mental)` + `mount_status(despair, 3t)`（⚠️ 本途径新增状态，见末尾）
- **语义** "让目标陷入绝望" → 用新 debuff `despair` 承载：受伤乘区 + 每 tick dot。是 💀 轴最具标识度的技能。

#### 【主动】心缚 💋
- **文案** 你以欢愉编织心缚，敌人被魅惑只盯着你（嘲讽），同时被你的低语封口，无法吟唱技能（沉默）2 回合。
- **序列** 4 绝望 · **能量 3 / cd 4** · `reach: ranged`
- **效果** `mount_status(taunt, 2t)` + `mount_status(沉默, 2t)`
- **语义** 💋 轴控制升级：魅惑 + 禁技能，彻底锁死一个目标，为团队创造输出窗口。

### 史诗（序列 3–2）

#### 【被动】不老 💀
- **文案** 你不老之躯延缓衰老，战斗开始时便浸润在缓慢再生的气息中，持续 5 回合回血。
- **序列** 3 不老 · **hook** `on_battle_start`
- **效果** `mount_status(regen, 5t)`
- **语义** "延缓衰老、延长寿命" → 复用既有 `regen`（持续回血），无新机制。

#### 【主动】灾难降临 💀 ★
- **文案** 你召来灾难性的诅咒，所有敌人被「绝望」笼罩（受伤 +20%、每 tick 被侵蚀 1 点，3 tick），并承受 3 点精神伤害。
- **序列** 2 灾难 · **能量 5 / cd 6** · `reach: allEnemies`
- **效果** `damage 3 (mental)`（全体） + `mount_status(despair, 3t)`（全体，⚠️ 本途径新增状态）
- **语义** "召唤灾难性诅咒、灾难领域权柄" → 全体挂 `despair`，是 💀 轴范围化的大招。

#### 【主动】痛苦共鸣 💀
- **文案** 你与全场敌人共鸣痛苦，所有人都被「痛苦链接」缠上——你今后所受的伤害，将由他们一同分担。
- **序列** 2 灾难 · **能量 5 / cd 6** · `reach: allEnemies`
- **效果** `mount_status(pain_link, 3t)`（全体，⚠️ 本途径新增状态）
- **语义** 「痛苦咒」的范围版，把"你受伤→敌人替扛"扩到全屏，硬吃集火反而反伤。

#### 【被动】不凋 💋
- **文案** 欢愉不凋，战斗开始时你的生命上限永久 +15，更难被一波带走。
- **序列** 3 不老 · **hook** `on_battle_start`
- **效果** `modify_stat(max_hp, +15, duration: null)`
- **推导** 30 + 10×力量，+15 约等于力量1.5 的生命量，属中档增益，契合"延长寿命"。

#### 【主动】影舞 🗡
- **文案** 你化作三道残影连刺，对目标打出 3 段物理伤害，每段 3 点（共 9 点），只占用一次行动。
- **序列** 3 不老 · **能量 5 / cd 5** · `reach: ranged`
- **效果** `TermRef(repeat, body: [damage 3 (physical)], count: 3, shareTarget: true)`
- **为什么重要** Repeat 算子（A17 裁定）的实战落地：三段同目标、只触发一次受击/反击、只撞一次乘区。
- **推导** 3×3 = 9 伤害 / 5 能量 = 1.8，高于基准 1.2，溢价来自"一个 Action 内三段、只吃一次反伤"（B8 裁定）。

### 传说（序列 1–0）

#### 【被动】末日预言 💀
- **文案** 你已窥见终结的模样：每回合开始，对当前生命最低的那个敌人烙下「绝望」，并补上 1 点精神伤害。
- **序列** 1 末日 · **hook** `on_turn_start`（`fallbackSort: hp_asc`）
- **效果** 对生命最低敌人 `mount_status(despair, 2t)`（⚠️ 新增状态） + `damage 1 (mental)`
- **语义** "预示与引导终结" → 持续盯死残血目标，为处决做铺垫。

#### 【主动】灾祸之城 💀 ★
- **文案** 你展开灾祸之城的权柄：所有敌人陷入「绝望」（受伤 +20%、每 tick 被侵蚀 1 点，4 tick），被标记得伤势更重（易伤 4 回合），并承受 5 点精神伤害。毁灭、诅咒与末日尽归你手。
- **序列** 0 混沌魔女 · **能量 6 / cd 8** · `reach: allEnemies`
- **效果** `damage 5 (mental)`（全体） + `mount_status(despair, 4t)`（全体） + `mount_status(vulnerable, 4t)`（全体）
- **语义** 源质「灾祸之城」终极权柄 = 毁灭 + 诅咒 + 末日三合一的范围大招，是整条 💀 轴的顶点。

#### 【主动】终焉 🗡
- **文案** 一击终焉：对目标造成 8 点物理伤害；若它已濒死（生命低于 30%），这一击的伤害翻倍，彻底了结。
- **序列** 1 末日 · **能量 6 / cd 8** · `reach: ranged`
- **效果** `If(target.hp_ratio < 0.3, damage 8 (physical) × 2, else damage 8 (physical))`
- **语义** "引导终结" → 用 If 算子实现处决线，是 🗡 潜行爆发的传说级收尾。

## 四、本稿遗留

- 全部 24 个技能的能量定价只做了粗推，需过验证脚本（改动记录 D4）。
- `gauge.current` / `max_hp` 类技能的定价无既有锚点，是本次最大的数值盲区（与愚者稿 D2 同性质）。
- `target_override` 指向"指定友军"（非自身 / 非空坐标）尚未实测，需确认 C7 扩展后的落点合法性。
- 「概率挂易伤」「概率回能」等非伤害概率维度，需统一在 RandomSource 登记（R3），最终概率数值待平衡。

## 本途径框架改动（新增）

### 🔴 新状态 `pain_link`（痛苦链接）
- **语义**：施法者受到伤害时，等量伤害的 50% 转嫁给链接目标。
- **字段**：
  - `damage_taken_mul`：无（不影响承伤倍率，仅做伤害转移）
  - `transfer_ratio`：0.5（转嫁比例）
  - `duration`：3t
  - 触发事件：`on_take_damage`（施法者受伤时，对链接目标 `damage` 等量 ×0.5）
  - 作用对象：敌方单体（由 `mount_status(pain_link, 3t)` 挂在目标上，链接回施法者）
- **服务于**：痛苦咒(5)、痛苦共鸣(2，范围版)

### 🔴 新状态 `despair`（绝望）
- **语义**：目标陷入绝望，受伤加深且被持续侵蚀啃咬。
- **字段**：
  - `damage_taken_mul`：1.2（受伤 ×1.2 乘区）
  - 附加 dot：`on_tick` 受到 1 点无属性伤害（与 `burn`/`poison`/`whisper` 同为每 tick 结算）
  - `duration`：3t（传说「灾祸之城」为 4t、「末日预言」为 2t）
  - 触发事件：`on_take_damage` 结算乘区 + `on_tick` 侵蚀
  - 作用对象：敌方单体 / 全体（灾难降临、灾祸之城、末日预言为全体 / 最低血）
- ⚠️ **修正（G15-b）** 原写 dot 挂 `on_turn_start`，但 `duration: 3t` 只有 3 tick，而 `on_turn_start` 约每 5 tick 才轮到一次 → **dot 一次都结算不到就过期了**。已改为 `on_tick`（与引擎内其他 dot 一致），总量仍为 3 伤（3t × 1/tick），与原文案"持续 3 回合、每回合 1 点"的**总额 3 点**一致。
- **服务于**：绝望印记(4)、灾难降临(2)、末日预言(1)、灾祸之城(0)

> 说明：本途径未引入新单位、新算子（`Repeat` / `If` / `Sequence` 均为 brief 既有术语算子）、新 `move.op`（复用 C1 的 `param`）或新 `targetSpec`（复用 `ranged` / `allEnemies` / `ALLY`）。共 **2 条** 框架改动，均为新增 debuff 状态。
