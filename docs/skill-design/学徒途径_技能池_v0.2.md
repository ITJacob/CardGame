## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【主动】开门 🜁
- **原著** 序列9 学徒 —— "「开门」：穿墙而过，手掌按住墙壁出现幽蓝大门"
- **文案** 你按住虚空，一道幽蓝的门扉在墙上浮现——你穿门而过，出现在战场的另一处，门扉闭合时的气流掀动了近旁的敌人。
- **序列** 9 学徒 · **能量 2 / cd 3 / 吟唱 0** · `targetSpec: { faction: ALLY, anchor: EMPTY_ALLY_SLOT }`（自身）
- **效果** `move(param → 己方半场内指定空位)`（自身，**G8 合规**）+ `damage(element: physical, 2)` 对 `{ faction: ENEMY, anchor: front_line }`
- **翻译/语义** 本途径的**原点技能**，v0.1 完全没有。G8 铁律下"穿墙"只能在己方半场内落位（不得进对方半场），落点用新的空位锚点表达；穿出时的气流挤压 = 对敌方前排 2 点物理伤。位移在「双路各 4 格 + 坍缩 + 插队」的战场里是硬资源，故直伤压到 2（2 能量锚点 ≈ 3.3 伤的一半）。
- ⚠️ 依赖新锚点 `EMPTY_ALLY_SLOT`（本稿新增项 1，已落 ddd：共享内核参数 §一 anchor `empty_ally_slot`）。数值 ⚠️D。

#### 【被动】仪式·门 🜁
- **原著** 序列9 学徒 —— "能使用仪式魔法"
- **文案** 开战前你便布下了一道仪式——三息之后，那道门会在敌阵前方自行洞开。
- **序列** 9 学徒 · **hook** `on_battle_start`（A1 ✅ 已落地）
- **效果** `mount_status(ritual_gate, duration: 4)`；状态触发器 `on_remove` → `damage(element: none, 4)` 对 `{ faction: ENEMY, anchor: front_line }`
- **翻译/语义** 原著序列9 的另一半，v0.1 也漏了。仪式魔法的核心是**延时生效**：先布置、后爆发。引擎里最干净的表达是 `mount_status` + `on_remove`（✅ 已 fire，已落 ddd：编队上下文 §六 mount/unmount）——duration 到期即触发，零新机制。元素取 `none`：空间挤伤不属于七元素。**注意 v0.1 写的 `space` 元素在引擎 `Element` 枚举里根本不存在**（fire/ice/poison/shock/mental/physical/water/none），本稿全部改掉。
- ⚠️ 需确认 `on_remove` 在被 `dispel` 时同样会 fire —— 若会，则"仪式被打断却照样开门"，是强度漏洞；`on_remove` 的 reason 过滤已落 ddd（本稿新增项 2：编队上下文 §六 H29，可按 Expired / Dispelled 区分）。数值 ⚠️D。

#### 【主动】戏法·闪光 🜂 ★
- **原著** 序列8 戏法大师 —— "掌握各种奇怪法术：闪光、黑幕、转移气体、巨响、冰冻、电击、造雾、刮风、点火、摔倒术、驱物、逃脱戏法"
- **文案** 一道刺目的强光在它眼前炸开，紧接着是一声贯耳的巨响——它挥出的下一击，砍在了空处。
- **序列** 8 戏法大师 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `mount_status(flash, charges: 1, duration: 3)`（`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`，**C7** ✅ 已验证）+ `modify_resource(gauge.current, -20, delta)`
- **翻译/语义** 原著序列8 一整把小法术中的**闪光 + 巨响**：闪光 = 致盲（打空），巨响 = 震慑（行动条推后）。复用 C7 已端到端验证的 `target_override → first_empty`，用 C6 `charges: 1` 表达"只瞎一次"。**戏法轴的旗舰**，因为原著里"戏法"这件事本身就只属于序列8。
- ⚠️ 击退量参照 D1 拍板的 `KNOCKBACK_DISTANCE`（阈值 75 → 推后约 2/3 行动周期），本条取 -20 而非 -50，属"轻推"。数值 ⚠️D。

#### 【主动】戏法·三元素 🜂
- **原著** 序列8 戏法大师 —— "…冰冻、电击、…点火…"
- **文案** 你打出一串细碎的手势——一点火苗、一层白霜、一缕电光，接连落在它身上。
- **序列** 8 戏法大师 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `Sequence[ damage(element: fire, 2), damage(element: ice, 2), damage(element: shock, 2) ]`
- **翻译/语义** 原著序列8 是一**整套**小法术，逐个做成技能会撑爆普通档；把点火 / 冰冻 / 电击合成一个"三元素连击"，既覆盖三个原著条目，又天然表达"花招多、单发威力小"。三段独立结算 = 吃三次护甲 / 抗性，实际期望低于单段 6 伤，故 3 能量给 6 总伤仍在预算内（火球术锚点 3 能量 → 5 伤）。
- ⚠️ 依赖 `Sequence` 算子运行时已展开（**G3**，已落 ddd：编目参数 §一，动态段数已确认）。数值 ⚠️D。

#### 【主动】戏法·摔倒术 🜂
- **原著** 序列8 戏法大师 —— "…刮风、…摔倒术、驱物…"
- **文案** 它脚下一绊莫名踉跄，你顺手卷起一阵风，把它推得更远。
- **序列** 8 戏法大师 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `index_desc`）
- **效果** `damage(element: physical, 2)` + `move(push_back)`（目标在**自己队列内**后移 1 格，**C1** ✅ 已落地）
- **翻译/语义** 摔倒术（失衡）+ 刮风（推）+ 驱物（隔空施力）三条原著条目合成一个"推挤"技能。**G8 合规**：`push_back` 已锁定 `from.faction`（C1 落地说明），不会越中线。
- **与【无形之手】的关系** 摔倒术推后（把它推离你），无形之手拉前（把它拽出来）。一推一拉构成开门轴的调度对；前者是序列8 的小戏法，后者是序列5 的招牌。

#### 【被动】逃脱戏法 🜁
- **原著** 序列8 戏法大师 —— "…逃脱戏法"
- **文案** 你的袖子里永远留着一手——每一次被逼到绝路，你都能从原地消失，出现在后排。
- **序列** 8 戏法大师 · **hook** `on_battle_start`
- **效果** 挂载 `escape_act`（`charges: 3`，`duration: null` 整场，C6 ✅）；触发器 `on_take_damage` → `move(push_back, distance: 99)`（自身退回己方半场最后位，**G8 合规**）+ 该次伤害 ×0.8，随后 `charges - 1`
- **翻译/语义** 逃脱戏法 = 受击即脱身。用 C6 `charges: 3` 表达"每场三次"（原著戏法大师的应变力，不写成无限以免无脑站前排）。减伤 ×0.8 与退位合并，避免"退到后排后再也打不到"的极端。
- ⚠️ 依赖状态触发器内执行 `move` 的时序（本稿新增项 3，已落 ddd：编队上下文 §十 H43，状态触发器为非状态原语、时序已定义）。数值 ⚠️D。

### 精良（序列 7–6）

#### 【被动】危险预感 🜄
- **原著** 序列7 占星人 —— "灵性直觉增强，出现危险预感"
- **文案** 危险降临前的半息，你的后颈会先一步发凉——三次之内，你都能提前避开要害。
- **序列** 7 占星人 · **hook** `on_battle_start`
- **效果** 挂载 `danger_sense`（`charges: 3`，`duration: null` 整场）；触发器 `on_take_damage` → 该次伤害 ×0.7，`charges - 1`
- **翻译/语义** "预感" = 提前规避 = 减伤。用 C6 `charges` 表达有限次的预感。**刻意避开 `on_turn_start`**：G15（引擎从不 fire）+ G15-b（即便修好，短 duration 配低频触发也接不上），改为整场 charges 型，两条纪律都绕开。
- ⚠️ 与愚者 v0.2 的 `premonition` / `wound_transfer` / `poise`（愚者稿新增项 19）是同一「次数型减伤」模板，**已并入参数化减伤状态母版**（H3，编队参数 §2.4）。数值 ⚠️D。

#### 【主动】干扰占卜 🜄
- **原著** 序列7 占星人 —— "干扰占卜及灵性直觉"
- **文案** 你搅乱了它头顶的星象——它读不出你的方位，能量也开始从指缝里漏走。
- **序列** 7 占星人 · **能量 3 / cd 4 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `energy_desc`）
- **效果** `mount_status(divination_jam, duration: 3)`：
  - `on_tick` → `modify_resource(energy, -1, delta)`（**F55** ✅ 已落 ddd：效果参数 §一 modify_resource 行，对敌方削能下限截断为 0）
  - `charges: 1` 的 `behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`（**C7** ✅）
- **翻译/语义** 原著"干扰占卜"干扰的是**信息与灵性直觉**。卡牌里信息本身不值钱，值钱的是"能不能攒出能量"和"能不能打中"，故落成两条：削能量（灵性被遮蔽，攒不出力）+ 一次打空（方位错乱）。这是本途径**唯一的削能量**手段，与偷盗者·窃取严格区分——偷盗者是**搬运**（归自己），学徒是**干扰**（凭空散掉）。
- ⚠️ 依赖新 targetSpec 排序 `energy_desc`（本稿新增项 4，已落 ddd：共享内核参数 §一 sort `energy_desc`，与 F57 同出口）。数值 ⚠️D。

#### 【主动】星相学 🜄
- **原著** 序列7 占星人 —— "占星术：水晶球占卜 + 星相学"
- **文案** 你在星图上钉住了它的位置——从此它藏不住、躲不掉，而它的每一步都慢了半拍。
- **序列** 7 占星人 · **能量 3 / cd 4 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(star_mark, duration: 4)`：
  - 该单位身上的隐匿 / 不可选中类状态**对己方无效**（C8「识破」分支）
  - `modify_stat(gauge_rate, -5, duration: 4)`（**INV-S5 合规**：改的是速率源属性，不是派生的行动周期）
- **翻译/语义** 占星的核心收益是**定位**。原著里"干扰 / 识破"是同一枚硬币的两面——序列7 既然会干扰占卜，就必然也会**反制隐匿**。这是源堡系里除占卜家·灵体之线（克魔女 / 隐身 / 阴影躲藏）之外的第二个反隐匿出口。
- ⚠️ 依赖 C8 候选池过滤的「识破」分支（已落 ddd：共享内核参数 §四；与愚者 v0.2【灵视】【灵体之线】同源，不重复立项）。数值 ⚠️D。

#### 【被动】记录 🜃 ★
- **原著** 序列6 记录官 —— "「记录」：重现目标使用的非凡能力并存储 / 序列7-9 能力可记录 20 个（效果接近原版），序列5-6 可记录 8 个（效果减半）"
- **文案** 它打在你身上的每一招，都被你原样拓进灵性拓片里——连同那一招的属性与力道。
- **序列** 6 记录官 · **hook** `on_take_damage`（自身）
- **效果** `inscription` 层数 +1（沿用 **F1** 已登记，🟢；上限建议 **8**，对齐原著"序列5-6 可记录 8 个"）+ 刷新状态 `recorded` 的两个数据槽：`element` = 本次伤害的元素、`tier` = 本次伤害的档位
- **翻译/语义** **本途径的灵魂技能，也是 v0.1 翻译得最失败的一条**。原著的"记录"是**重现并存储他人用过的非凡能力**——关键字是"**他人用过的**"和"**存储**"。所以记录的不是一层抽象计数，而是**那一招本身**。引擎落地分两层：
  - 层数 `inscription`（F1，🟢）回答"记了多少"；
  - 状态 `recorded`（本稿新增项 5，已落 ddd：编队参数 §1.1b slots 行 H33）回答"记的是哪一招"——携带 `element` / `tier` 两个**数据槽**。
  两层合起来，【重现】才可能打出"和对方刚才那招同属性"的伤害，而不是 v0.1【复刻】那种固定的两段精神伤害。
- ⚠️ 依赖：F1 `inscription`（🟢 已落 H11）+ 状态数据槽（本稿新增项 5，已落 ddd：编队参数 §1.1b H33）。**退化方案**：只留 `inscription` 层数、`recorded` 缺省按 `mental` 结算（即 v0.1 口径），机制已全落地，退化仅作数据侧简化可选。

- **翻译/语义** 原著"再现"有三个对象——**场景 / 人物 / 非凡能力**。本稿取**人物**这一支（"让被记录者降临"）：把 `inscription` 换成一具"被记下的人"的影像，为己方作战。召唤物沿用 **F23 `unit_thoughtform`**（学徒 v0.1 已登记的灵体分身，已归并 H1 召唤物基线，编队参数 §2.4），**不新立单位**。**记录轴的旗舰**。
- **与【重现】的差异** **重现 = 复现那一招**（伤害）；**再现 = 复现那个人**（召唤）。原著两条能力分属序列6 与序列2，本稿刻意拆开，避免像 v0.1 那样把记录整轴压成"攒层换伤害"。
- ⚠️ 依赖：**C5** `spawn` 的 `hpRatio` + `position`（✅ 已落地）+ F48 `status.consume`（✅ 已落 ddd：效果上下文 §2.1）+ `If` / `Sequence` 展开（**G3**，已落 ddd：编目参数 §一）。数值 ⚠️D。

#### 【主动】自我符号 🜄
- **原著** 序列2 旅法师 —— "「自我符号」：转化为象征符号，借助星界前往不同世界"
- **文案** 你的形体坍缩成一枚符号——穿过星界之后，你在战场的另一端重新落笔成形。
- **序列** 2 旅法师 · **能量 4 / cd 6 / 吟唱 ⚠️D** · `targetSpec: { faction: ALLY, anchor: EMPTY_ALLY_SLOT }`（自身）
- **效果** `mount_status(sigil_self, duration: 2)`：`untargetable_by_targeted: true`（C8）+ `damage_taken_mul: 0.7`；触发器 `on_remove` → `move(param → 己方半场内指定空位)`（自身）
- **翻译/语义** 原著自我符号本质是**移动 / 隐匿手段**（符号化后借星界去别处），落地成"先消失两息，再在别处现形"——既躲过一轮集火，又完成一次真实位移。**G8 合规**：落点限定己方半场。
- ⚠️ 依赖 C8（已落 ddd：共享内核参数 §四）+ `EMPTY_ALLY_SLOT` 锚点（同【开门】，新增项 1，已落 ddd：共享内核参数 §一 `empty_ally_slot`）+ 状态触发器内执行 `move`（新增项 3，已落 ddd：编队上下文 §十 H43）。

### 传说（序列 1–0）

#### 【主动】定位 🜄
- **原著** 序列1 星之匙 —— "「定位」权柄：自身永不迷失，让敌人无法定位"
- **文案** 你握住了这颗星球上所有的坐标——你永远不会走错，而它们，从此找不到北。
- **序列** 1 星之匙 · **能量 5 / cd 6 / 吟唱 ⚠️D** · `targetSpec: { faction: ENEMY, scope: ALL }`
- **效果** 对**全体敌方单位** `mount_status(located, duration: 4)`：`damage_taken_mul: 1.15` + `charges: 1` 的 `behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`（**C7** ✅）；同时自身 `modify_stat(gauge_rate, +6, duration: 4)`（"永不迷失"）
- **翻译/语义** 原著"定位"权柄是**双向**的：对自己 = 永不迷失；对敌人 = 让它无法定位（它的攻击找不到目标）。前者落成自身速率提升（INV-S5 合规），后者落成"更容易被打中 + 一次打空"。
- ⚠️ 依赖：全体敌方 targetSpec（本稿新增项 10，已落 ddd：共享内核参数 §一 `scope: all` + faction 过滤，H18）+ C7（✅）。数值 ⚠️D。

#### 【主动】时空迷宫 🜄 ★
- **原著** 序列1 星之匙 —— "「时空迷宫」：时间即空间，制造时间混乱或空间循环迷宫"
- **文案** 你把所有向前走的路都折成了同一个拐角——它们在迷宫里越走越远，而时间也开始乱了顺序。
- **序列** 1 星之匙 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `targetSpec: { faction: ENEMY, scope: ALL }`
- **效果** 对全体敌方 `mount_status(time_maze, duration: 3)`：
  - `on_tick` → `modify_resource(gauge.current, -6, delta)`（空间循环：越走越回不去）
  - `modify_stat(gauge_rate, -5, duration: 3)`（时间混乱）
- **翻译/语义** 原著"**时间即空间**"——这条能力本来就同时操纵两个维度，最贴的落地就是**同时推条与减速**：`gauge.current` 表达"空间上被困住"，`gauge_rate` 表达"时间上被拖慢"。**星界轴的旗舰**。
- ⚠️ 依赖：全体敌方 targetSpec（新增项 10，已落 ddd：共享内核参数 §一 `scope: all` H18）+ gauge 类效果定价（**D2 盲区**，⚠️D）。G8 无关（不涉及任何位移）。

#### 【主动】空间破碎 🜁
- **原著** 序列1 星之匙 —— "「空间破碎」（重力操纵）"
- **文案** 你翻转了这一片空间的重力——敌阵在塌陷中失衡、后仰，甲胄被挤压得吱呀作响。
- **序列** 1 星之匙 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `targetSpec: { faction: ENEMY, scope: ALL }`
- **效果** `Sequence[ damage(element: physical, 4)（全体）, move(push_back)（全体）, modify_stat(armor, -3, duration: 3)（全体） ]`
- **翻译/语义** 原著在"空间破碎"后面括注的是**重力操纵**——所以它不是切割（切割是序列3 撕裂空间），而是**塌陷 + 失衡**：全体受伤、全体被推后、全体护甲被压坏。
- ⚠️ 依赖：全体敌方 targetSpec（新增项 10，已落 ddd：`scope: all` H18）+ 多目标 `move`（本稿新增项 11，已落 ddd：`scope: all` 目标集 + move 逐目标结算）+ C1 `push_back`（✅）。数值 ⚠️D——**全体击退的强度极难标定，是本文数值风险最高的一项**。

#### 【主动】封印 🜄
- **原著** 序列1 星之匙 —— "初步掌控「封印」权柄"（序列0「封印」权柄：含时光、迷宫要素，可短时间封印旧日）
- **文案** 门在它身后合上、落下、上锁——连时间都不再为它流动。等门重新打开时，它已被时空磨去了一层。
- **序列** 1 星之匙 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(sealed, duration: 4)`：
  - `gauge_freeze: true`（新增项 7，已落 ddd：编队参数 §1.1b H24 冻结档）+ `untargetable_by_targeted: true`（C8）
  - `heal_received_mul: 0`（封在门后，连治疗都递不进去；**F20 `petrify`** 同源）
  - 触发器 `on_remove` → `damage(element: none, 5)`（破封时的时空反噬）
- **翻译/语义** 原著"封印"含**时光 + 迷宫**两个要素，且能短时间封印旧日——是本途径最硬的单体控制。落地为"门后"：不行动、不被打、不被奶，出来时吃时空反噬。
- **与【放逐】的差异** 放逐 = 丢进乱流（3t / 4 伤 / 可被驱散打断）；封印 = 锁进门后（4t / 5 伤 / 连治疗都进不去 / 更贵 / 单体）。
- ⚠️ 依赖：`gauge_freeze`（新增项 7，已落 ddd：编队参数 §1.1b H24 冻结档）+ C8（已落 ddd：共享内核参数 §四）+ `heal_received_mul`（F20 已落 H21，编队参数 §1.1b）。

#### 【主动】门之概念 🜁
- **原著** 序列0 门 —— "「门」之概念：打开或关上所有与「门」相关的事物"
- **文案** 你说了一声"关"——所有朝向它的门都合上了：补给进不来，伤口合不上，退路也不存在。
- **序列** 0 门 · **能量 5 / cd 7 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `mount_status(door_shut, duration: 4)`：
  - `move_immune: true`（退路那扇门关了，**F7 `shackle`** 同源）
  - `heal_received_mul: 0`（救济进不来，**F20 `petrify`** 同源）
  - `buff_blocked: true`（加持同样进不来，本稿新增项 12，已落 ddd：编队参数 §1.1b buffBlocked H38）
- **翻译/语义** 原著"打开或关上**所有**与门相关的事物"——关上门的关键不是伤害，而是**断绝**：断位移、断治疗、断增益。三条"断"全部由已有 / 已登记机制拼出（`shackle` 的禁位移、`petrify` 的断治疗、新增的断增益），**不发明任何"权柄"级新机制**，这是本稿处理序列0 概念类能力的基本方法。
- ⚠️ 依赖：`moveImmune`（F7 同源，与愚者 v0.2 新增项 6 同一字段，已落 ddd：编队参数 §1.1b H27）+ `heal_received_mul`（F20 已落 H21）+ `buff_blocked`（新增项 12，已落 ddd：编队参数 §1.1b H38；与 F17 `lust` 的"禁获护盾"同源）。

#### 【主动】空间牢笼 🜄
- **原著** 序列0 门 —— "「空间」权柄：制造空间牢笼、令空间毁灭坍塌、瞬间前往任何空间、开辟异度空间"
- **文案** 六面看不见的墙在它四周合拢——空间开始向内收缩，而它连一步都挪不动。
- **序列** 0 门 · **能量 5 / cd 7 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(space_cage, duration: 4)`：
  - `move_immune: true`（困住，**F7** 同源）
  - `damage_taken_mul: 1.25`
  - `on_tick` → `damage(element: physical, 1)`（牢笼持续收缩，共 4 伤）
- **翻译/语义** 原著空间权柄的第一条就是"制造空间牢笼"。与【封印】的区分很清楚：封印是**移出战斗**（谁也碰不到谁），牢笼是**困在原地**（动不了，但照样挨打，且越收越紧）。这是本途径最强的点杀前置。
- ⚠️ 依赖：F7 `moveImmune`（已落 ddd：编队参数 §1.1b H27，与【门之概念】①、【无处不在】③、**愚者 v0.2 新增项 6** 共用同一字段，已统一实现）+ `on_tick` dot 载荷（✅）。数值 ⚠️D。

#### 【被动】无处不在 🜁 ★
- **原著** 序列0 门 —— "「无处不在」（闪现极致）、「概念化」"
- **文案** 闪现到了极致，便是无处不在——你同时站在战场的每一处，敌人推不动一个并不只在原地的你。
- **序列** 0 门 · **hook** `on_battle_start`
- **效果** 挂载 `ubiquity`（整场）：
  - `modify_stat(gauge_rate, +6, duration: null)`（无处不在 = 出手频率大幅提升，INV-S5 合规）
  - `spawn(unit_thoughtform, hpRatio: 0.3, position: 'tail')`（留在星界那头的"另一个你"，沿用 **F23**，已归并 H1，**C5** ✅）
  - `move_immune: true`（你无处不在，没有一个"位置"能被推走；**F7** 同源）
- **翻译/语义** 原著写得很清楚，"无处不在"是**闪现的极致**，不是真身分裂。三条落地分别对应：频率（到处都有你的出手）、一个留在别处的残影、**无法被位移推走**（你不在任何一个固定的地方）。**开门轴的旗舰**。
- ⚠️ 依赖：F23 单位（已归并 H1 召唤物基线，不新立单位）+ C5（✅）+ F7 `moveImmune`（已落 ddd：编队参数 §1.1b H27）。数值 ⚠️D。

## 三、跨途径共享（源堡三途径）

源堡三条途径互为相邻（占卜家 / 学徒 / 偷盗者，高序列可混合），共享用 `sharedAcross` 声明：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 星相学 / 干扰占卜 | 占卜家、偷盗者 | 占卜家序列9 就掌握占星术与灵视；偷盗者序列7 解密学者"解析梦境幻象、找出敌人方位"同源 |
| 记录 / 重现 / 半神记录 / 再现 | **偷盗者** | 序列6 盗火人"窃取他人非凡能力"与记录官"重现他人非凡能力"是同一语义的正反两面（一个拿走、一个复刻）。**不共享给占卜家**——占卜家途径原著没有任何"复刻他人能力"的能力 |
| 旅行家之门 / 开门 | 偷盗者 | 序列0「错误」权柄明载含"**部分空间**" |
| 无形之手 | 占卜家 | 占卜家序列5 秘偶大师靠灵体之线远距离操纵目标，语义相邻（愚者稿 v0.2 已把误入的【无形之手】删除，本稿以共享方式正规归还） |
| 空间隐藏 / 幻化 | 占卜家、偷盗者 | 源堡三途径共享"隐秘 / 变化"核心象征 |
| 闪现 | 偷盗者 | 欺诈 / 脱身类高速位移，与偷盗者的战斗风格契合 |

> **不共享**：放逐 / 封印 / 时空迷宫 / 空间牢笼 / 门之概念 / 无处不在 / 破障之门 / 撕裂空间 / 融入空间 / 自我符号 / 维度之视 —— 门与空间权柄是学徒途径的独有招牌，共享会稀释途径辨识度。

**反向引入（重要）**：本途径应能抽到**占卜家**的 灵视 / 占卜 / 占星术 / 制造幻觉 / 变形（愚者 v0.2 第三节已把前三者与变形 `sharedAcross` 给学徒、偷盗者）。

> 这一条不是凑数：**原著学徒序列9 只有「开门」和仪式魔法，没有任何信息 / 感知 / 记忆类能力**。v0.1 为了凑够被动数量，凭空发明了【灵性记忆】（开局 +4 能量、能量上限 +3），本稿已删除；低序列被动的缺口**应当**由共享来的占卜家技能填补，而不是自己造。这也是本途径被动只有 9 个却仍够用的原因。

## 四、本稿遗留

- **数值全档待标**：33 个技能的能量 / 伤害 / 时长 / 层数均为占位建议值，统一 ⚠️D。其中 `gauge.current` / `gauge_rate` / `gauge.threshold` 类技能的定价**无既有锚点**，是最大盲区（沿用 D2）——受影响技能：戏法·闪光、干扰占卜、星相学、漫游星空、维度之视、定位、时空迷宫，共 7 个。次高风险是【空间破碎】的**全体击退**（强度随敌方单位数放大，几乎无法用单卡预算标定）。
- **v0.1 的隐性硬错误（非风格问题）**：v0.1 大量技能使用 `space` 元素（次元切割 / 空间主宰 / 门之权柄 / 灵界漫游 / 维度放逐…），而引擎 `Element` 枚举只有 `fire / ice / poison / shock / mental / physical / water / none`，**没有 `space`**。本稿统一约定：
  - **空间挤压 / 撕裂 / 重力** → `physical`
  - **纯空间概念伤（放逐撕扯、仪式门、封印反噬）** → `none`
  - **星界 / 占卜 / 记录相关** → `mental`
  这是本稿的翻译约定，原著并未指定。
- **本途径零概率**：v0.1 的【界域穿梭者】用 25% 概率减伤，但原著漫游者只有"融入空间 / 撕裂空间 / 漫游星空"，**没有任何概率性闪避设定**；本稿删除该技能。全 33 个技能无一处使用 `condition: { kind: 'chance' }`——占星 / 命运类主题一律落在节奏（`gauge.*`）而非掷骰上（brief §3.0 的"命运 / 预知主题例外"条款）。
- **未单独成技能的原著条目**（有意省略，留待后续）：
  - 序列8「黑幕」「造雾」「转移气体」—— 与闪光 / 摔倒术同族，建议并入【戏法·闪光】【戏法·摔倒术】的升级阶梯（B6），不单独立项
  - 序列8「驱物」—— 高阶版已并入【无形之手】（序列5），低阶版并入【戏法·摔倒术】的刮风
  - 序列0「开辟异度空间」—— 需 zone 机制（A23），留待 zone 议题统一处理
  - 序列0「瞬间前往任何空间」—— 与【自我符号】同义，未重复立项
  - 序列0「概念化」—— 并入【无处不在】（"无处不在"本身就是概念化的表现），未单独立项
  - 序列1「定位」中"自身永不迷失"的地图外场景 —— 卡牌无地图层，只取战斗内语义（速率提升）
- **记录轴的退化上线路径**（已验证可跑通，不必等新机制）：「状态数据槽」（新增项 5）已落 ddd（编队参数 §1.1b H33），【记录】【重现】可按"同元素还击"完整语义上线；退化路径仍保留为数据侧简化可选。
- **【仪式·门】的 `on_remove` reason**：若被 `dispel` 也会 fire，则"仪式被打断却照样开门"是强度漏洞，需 reason 过滤或明确接受该设定。
- **序列6 仍是全途径最薄的一环**：原著序列6 记录官只有"记录"一条能力。本稿已用【记录】（被动）/【重现】（主动）/【半神记录】（序列5 被动）三条去覆盖；新增项 5、6 均已落 ddd（H33 slots / 执行参数 §2.1 全局监听），记录轴可按完整语义落地，不再退化成 v0.1 的"攒层换固定伤害"。
- **【空间破碎】的多目标 `move`** 若引擎不支持一次 `move` 作用于多个目标，需退化为 `Repeat(N)[move]` 或只推前排，强度与风味都会掉一档。
