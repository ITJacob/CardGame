# 刺客途径（魔女）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入灾祸之城系核心机制 **「替身」跨源质枢纽状态**（刺客↔源堡占卜家↔失序之国律师）；
> ③ 新增 **跨系 combo 卡**（刺客↔源堡 替身、刺客↔永暗之河 死灵黑焰）；
> ④ 补 2 张主题界域牌（镜像迷宫 / 镜中世界）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《灾祸之城系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> **性别纪律**：刺客序列7 女巫「男性变女性」为明确原著依据——**序列4+ 高位技能与序列7 女巫之形**标 **性别 女**（战外晋升序列7 完成转换，战斗内不可变，brief §12）。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **形** | `形`(body_form, 自身, stealth/定身) | 羽毛般轻盈 / 鹰的视力 / 阴影躲藏 / 隐形 → 挂 `形`（隐匿/轻盈） | 若\[`形`\] → 石化定身 / 原初·静止（节奏归零） | 原初·静止 |
| ② **魅** | `魅惑`(charm, 敌方, duration) | 魅惑 / 说服 → 挂 `魅惑`（改打友军） | 若\[`魅惑`\] → 反复魅惑真爱 / 激化矛盾门户大开 | 魅力权柄 |
| ③ **镜** ★核心 | `镜`(mirror, 镜位, 分身) | 镜子替身 / 魔镜占卜 → 建 `镜` 位（替身/镜像分身） | 若\[`镜`\] → 镜像迷宫分身 / 镜中人复活 / 镜中世界 | 镜中世界 |
| ④ **疫** | `疫灾`(plague, 敌方, dot/黑焰) | 疾病 / 黑焰 → 挂 `疫灾`（dot/黑焰） | 若\[`疫灾`\] → 瘟疫爆发 / 命运诅咒补刀 / 末日 | 末日 |

> **替身枢纽维度（灾祸之城系 §2.2 / 总览 §3）**：`替身` 是跨**三源质**的枢纽状态（刺客镜替身 / 占卜家纸人替身 / 律师替身定义），在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单。刺客经【镜子替身】【镜面替身·改】写入 `替身`，源堡/失序之国可读写。另 黑焰/地狱之火 ↔ 永暗之河 收尸人「亡灵」（见 §三 死灵黑焰）；命运诅咒 ↔ 光之钥「命运」（见 §三 命运枢纽）。

## 三、跨途径共享（灾祸之城 + 跨系 combo）

刺客（魔女）与猎人（红祭司）同属灾祸之城，相邻可互换。共享用 `sharedAcross`；跨系 combo 卡通过 **`StatusDef.crossPathway:true`** 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 魅惑 / 激化矛盾 / 说服 | 猎人 | 同属情绪操纵，零额外成本 |
| 力量爆发于一击 / 阴影躲藏 / 鹰的视力 | 猎人 | 低序列身法感知同源 |
| 灾难 / 命运诅咒 | 猎人 | 同天气术士权柄，共用 ZoneDef 母版 |
| 冰霜 / 冰霜护甲 | 猎人 | 通用减速/护甲，不侵火系招牌 |
| **镜面替身·改** | **源堡 占卜家** | 跨系 combo：读 `puppet_string`（纸人替身）升级镜替身（替身枢纽） |
| **死灵黑焰** | **永暗之河 收尸人** | 跨系 combo：读 `亡灵/奴役` 升级黑焰为燃灵（见 §三 登记） |

> **枢纽状态（落地优先级最高）**：`替身` / `命运` / `混乱` / `恶欲值` / `集众` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单（见《九大源质总览》§3）。`替身` 由刺客【镜子替身】【镜面替身·改】、占卜家【纸人替身】、律师【替身定义】共写；`命运` 由刺客【命运诅咒】【末日】与怪物（命运之轮）共写。
