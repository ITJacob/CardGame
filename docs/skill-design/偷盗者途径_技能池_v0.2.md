### 本途径的三条翻译纪律（全稿共用）

1. **「偷东西」一律用 `drain`，不用 `damage`。** `drain` 的搬运语义（敌方失去、我方获得）就是"偷"在引擎里的唯一保真形态。能量 / 增益两个方向的 `drain` 扩展已登记为 **F49 / F50**（已落 ddd：效果参数 §一 drain 行），全稿直接引用、不重复立项。
2. **「命运 / 时间」一律落 `gauge.*`，不落概率。** 原著偷盗者途径**没有任何概率性设定**（"钻命运漏洞"是技巧不是掷骰），故全稿 0 处 `condition: { kind: 'chance' }`；且依 **G5 / G6 铁律**，不出现任何"主动技能给自己 `gauge.current +N`"的写法——本途径与"先手"相关的收益一律推**友军**或做成 `on_battle_start` 被动。
3. **「寄生 / 分身」一律走状态 + `spawn`，不发明第十个原语。** 宿主流血归施法者依赖 **F56**（状态携带 `casterId`，已落 ddd：编队参数 §1.1b casterId 行），分身替换复用 **G4** `spawn.reviveOf` + **C5** 的 `hpRatio` / `position`（已落 ddd：效果参数 §1.1 spawn 参数）。

### 普通（序列 9–8）

#### 【主动】窃取 🜁
- **原著** 序列9 偷盗者 —— "「窃取」：轻松窃取目标口袋内物品"
- **文案** 你的手从它的口袋里掠过——钱袋没了，而你连它什么时候被划开的都没让它察觉。
- **序列** 9 偷盗者 · **能量 2 / cd 3 / 吟唱 0** · `reach: melee`（贴身才有"摸口袋"的语义）· Manual（fallbackSort: `energy_desc`）
- **效果** `drain(resource: energy, 3)` + `damage(element: physical, 1)`
- **翻译/语义** **v0.1 把这条做成了贴身吸血（「扒窃」`drain(hp,2)`），是偏离原著**——序列9 原著白纸黑字是"窃取口袋内**物品**"，吸血在原著里属于寄生者（序列4）而非偷盗者。卡牌里"口袋里的东西"唯一的实体就是**能量**（它是敌方可支出的资源），故落 `drain(energy)`；"物品"被拿走的那点刺痛保留 1 点物理伤作为 flavor。**🜁 轴的起点技能**，全轴最便宜的润滑剂。
- ⚠️ 依赖 **F49** `drain.resource: 'energy'`（已落 ddd：效果参数 §一 drain 行）。目标能量不足时按实际值结算、不产生负数。数值 ⚠️D。
- **升级阶梯**（B6）`drain(energy, 3)` → 4 → 5，能量同步 2 → 3 → 4。

#### 【被动】敏捷之手 🜁
- **原著** 序列9 偷盗者 —— "「敏捷之手」：提升手腕指头灵活度"
- **文案** 你的手腕与十指灵活得不像人手——同样的时间里，你总能比别人多摸一次、多出一手。
- **序列** 9 偷盗者 · **hook** `on_battle_start`（A1 ✅ 已落地）
- **效果** `modify_stat(gauge_rate, +8, duration: null)`（整场，作用于自身）
- **翻译/语义** 原著是**手指灵活** → 战斗里唯一能承载的维度是**出手频率**。⚠️ **INV-S5 自检**：改的是 `gauge_rate`（`StatKey` 合法键），不是派生的行动周期，合规；**G5/G6 自检**：这是 `on_battle_start` 被动而非主动自推条，合规。
- ⚠️ `gauge_rate` 定价沿用 **D2** 盲区（🟡），整场型无 duration 更需单列。数值 ⚠️D。
- **与 v0.1 的差异** v0.1 完全没有这条，序列9 只落地了"偷"这一条，本版补齐原著三能力。

#### 【被动】卓越观察 🜁
- **原著** 序列9 偷盗者 —— "「卓越观察」：感应 10 米内贵重物品"
- **文案** 你一眼就看出谁身上带着值钱的东西——躲起来的没用，揣得深的也没用。
- **序列** 9 偷盗者 · **hook** `on_battle_start`
- **效果** 挂载 `keen_eye`（整场）：
  - 敌方 `stealth` / `shadow_veil` / `untargetable` 类状态**对你无效**（依赖 C8 的「识破」分支）
  - 你对**携带 ≥1 个 buff 或 shield** 的目标造成的伤害 ×1.25（"值钱的目标"）
- **翻译/语义** 原著是"感应贵重物品"——卡牌里没有物品，但有"身上挂着好东西的人"（护盾 / 增益）。故拆成两条：① 感应到藏起来的（识破隐匿）；② 感应到值钱的（对带增益目标增伤）。
- ⚠️ 依赖 C8 候选池过滤的「识破」分支（已落 ddd：共享内核参数 §四，与愚者 v0.2【灵视】【灵体之线】同源）；"携带 buff/shield"判定需条件谓词（与 F52 同族，已落 ddd：共享内核参数 §三 `has_status`）。数值 ⚠️D。

#### 【主动】思维误导 🜂 ★
- **原著** 序列8 诈骗师 —— "「思维误导」+「精神干扰」"
- **文案** 你在它脑子里轻轻拨了一下——它挥出的那一击，砍在了它自己以为你站着的地方。
- **序列** 8 诈骗师 · **能量 2 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(misdirect, charges: 1, duration: 3)`（`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`）
- **翻译/语义** 「思维误导」= 让它想错 = **让它打空**。复用 **C7 已端到端验证**的 `target_override → first_empty` + **C6** `charges: 1`（只被骗一次）。**🜂 轴的旗舰**，因为"误导"这件事在原著里从序列8 一路贯穿到序列0（欺诈自然规则、以假代真），低序列的这一张是整条轴的原型。
- **与【精神干扰】的分工** 误导改的是**它打谁**（空间维度），干扰改的是**它什么时候能打**（节奏维度）。原著把两者并列，本稿也并列。
- ⚠️ 依赖 C7（✅ 已验证）+ C6（✅ 已落地），**无新依赖**。数值 ⚠️D。

#### 【主动】精神干扰 🜂
- **原著** 序列8 诈骗师 —— "「思维误导」+「精神干扰」"
- **文案** 一串细碎的噪声钻进它的脑袋，它的动作慢了半拍，而那半拍足够你做很多事。
- **序列** 8 诈骗师 · **能量 3 / cd 3 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: mental, 2)` + `modify_resource(gauge.current, -20, delta)`
- **翻译/语义** 「精神干扰」= 打断专注 = **节奏推后**。2 伤 / -20 gauge 的配比遵循 brief「位移/控制类技能要压低直伤」。
- ⚠️ 推条量参照 D1 拍板的 `KNOCKBACK_DISTANCE = 50`（阈值 75），本条取 -20 属"轻推"。定价无既有锚点（D2）。数值 ⚠️D。

#### 【被动】微表情 🜂
- **原著** 序列8 诈骗师 —— "「卓越观察」质变：观察微表情、小动作"
- **文案** 它肩膀一动你就知道拳要往哪儿落——你侧了半寸，那一击擦着你的衣角过去了。
- **序列** 8 诈骗师 · **hook** `on_battle_start`
- **效果** 挂载 `micro_read`（`charges: 3`，`duration: null` 整场，C6 ✅）；触发器 `on_take_damage` → 该次伤害 ×0.75，随后 `charges - 1`
- **翻译/语义** 序列8 的"观察质变"是**读身体语言** → 提前规避 → 减伤。用 C6 `charges: 3` 表达"每场能读出三次"，不做无限以免与后续减伤手段叠成无敌。
- ⚠️ **与愚者 v0.2【直觉预感】同源**（同为"预感 → 次数型减伤"），已并入「参数化减伤状态」母版（H3，编队参数 §2.4）。数值 ⚠️D。

#### 【被动】魅力口才 🜂
- **原著** 序列8 诈骗师 —— "「魅力」+「口才」：话术提升 + 超凡说服力"
- **文案** 你说出口的谎，连命运都愿意多信一会儿——它们在你身上留得比别人久。
- **序列** 8 诈骗师 · **hook** `on_battle_start`
- **效果** 挂载 `silver_tongue`（整场）：你施加的**减益 / 控制类**状态，`duration +1`
- **翻译/语义** 卡牌里没有社交检定，"超凡说服力"唯一可落地的意思是**你的谎更持久**——即你挂上去的负面状态多存续 1 tick。这是本途径的**状态协同引擎**，让【思维误导】（3t→4t）、【窃取记忆】（silence 3t→4t）、【欺诈规则】（4t→5t）全部跟着变强。
- ⚠️ 需"施法者侧的 duration 修正"字段（本稿新增项 8，已落 ddd：编队参数 §1.1b durationModifier 行 H14）。**退化方案**：改为给自身 `mount_status` 时由技能数据直接写死 +1 tick 的时长（数据侧解决，零引擎改动）。
- **与【欺瞒导师】的关系** 魅力口才延长**时长**，欺瞒导师保证**不被驱散**；一量一质，构成 🜂 轴后段的双支柱。

### 精良（序列 7–6）

#### 【主动】解析幻象 🜂
- **原著** 序列7 解密学者 —— "能解析梦境、幻象等谜团，找出敌人方位"
- **文案** 你一眼看穿了那层幻象的织法——它散了，而藏在后面的东西也一并露了出来。
- **序列** 7 解密学者 · **能量 3 / cd 4 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `buff_count_desc`）
- **效果** `dispel(target, dispelable: true, category: ['buff', 'shield'], count: 2)`（**C2** ✅）+ `damage(element: mental, 1)` + 挂载 `disillusioned`（2t）：该单位身上的隐匿 / 潜行类状态对你无效
- **翻译/语义** 原著"解析梦境、幻象"在卡牌里的实体只有两个：**增益 / 护盾**（别人的幻术产物）与**隐匿**（藏起来的敌人）。故一条技能同时做"拆幻象"与"看见藏起来的"。
- ⚠️ 依赖 C2（✅）+ C8 识破分支（已落 ddd：共享内核参数 §四）；新排序 `buff_count_desc`（与愚者 v0.2 新增项 13 同源，已落 ddd：共享内核参数 §一 sorts）。数值 ⚠️D。

#### 【被动】找出方位 🜂
- **原著** 序列7 解密学者 —— "…找出敌人方位"
- **文案** 你总能算出它在哪儿——前排挡不住你，阴影也藏不住它。
- **序列** 7 解密学者 · **hook** `on_battle_start`

- **原著** 序列0 错误 —— "「错误」：**以假代真窃取权柄，制造漏洞回避攻击**"
- **文案** 这里出错了——它那一击明明砍在了你身上，可你身上什么都没有；倒下的，是它自己。"错误"就是这么回事：真的会变成假的，假的会变成真的。
- **序列** 0 错误 · **能量 6 / cd 8 / 吟唱 ⚠️D** · `targetSpec: SELF`
- **效果** `mount_status(error, charges: 2, duration: 6)`：
  - 触发器 `on_take_damage` → **该次伤害完全无效**（制造漏洞回避攻击），随后 `charges - 1`
  - 同一次触发 → `damage(element: mental, 等于该次伤害的 40%)` 给**攻击者**（以假代真：你以为砍中了，其实砍到了你自己）
- **翻译/语义** **序列0 的权柄，本途径的终极防御。** 原著两句全部落地："制造漏洞回避攻击"= 伤害归零（不是减伤，是**没有这回事发生**）；"以假代真"= 反噬到攻击者自己身上。用 C6 `charges: 2` 表达"两次错误"。
- ⚠️ 依赖：① **完全免疫 N 次伤害**（本稿新增项 3，已落 ddd：编队参数 §2.4 H3 乘区 = 0 档 + C6 charges）+ "把被免疫的伤害值传给反噬效果"（跨效果传值，已落 ddd：效果参数 §1.1 valueFrom `lastEffectReturn`）；② 反噬需要 `attacker` 目标寻址（**F61**，已落 ddd：执行参数 §一 RedirectRule.to `attacker`）。数值 ⚠️D。

#### 【主动】窃取权柄 🜁
- **原著** 序列0 错误 —— 权柄：**窃取**（"以假代真**窃取权柄**"）
- **文案** 你伸手把它名下的东西全部划到了自己名下——它曾凭这些站着，现在它什么都不是了。
- **序列** 0 错误 · **能量 6 / cd 9 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `buff_count_desc`）
- **效果** `Sequence[`
  - `drain(category: 'buff', count: all)`（**F50**）——把它身上一切"权柄"搬到你名下,
  - `mount_status(authority_lost, duration: 4)` 目标：`buff_blocked: true`（期间无法获得新的增益）+ `damage(element: mental, 3)` `]`
- **翻译/语义** 🜁 轴的终点。与【盗火】（偷一个能力）的差距就是位格差距：权柄级窃取是**全部搬走 + 让它再也得不到**。这是全稿唯一一次 `drain(count: all)`，也是本途径对"窃取"这个主题的总结陈词。
- ⚠️ 依赖 **F50**（已落 ddd：效果参数 §一 drain 行）+ `buff_blocked`（与学徒 v0.2 新增项 12 同源，已落 ddd：编队参数 §1.1b H38）。数值 ⚠️D。
- **为什么不设 ★** 🜁 的旗舰给了【盗火】：旗舰应该是**定义打法**的卡，而【窃取权柄】只是把"偷"放大到极限的终结技，不产生新构筑思路（同愚者稿对【奇迹】的处理）。

源堡三条途径互为相邻（占卜家 / 学徒 / 偷盗者，高序列可混合），共享用 `sharedAcross` 声明：

|---|---|---|
| 占卜家（愚者 v0.2 §三） | 灵视 / 占卜 / 占星术 / 制造幻觉 / 变形 | 愚者 v0.2 已声明 `sharedAcross` 给学徒、偷盗者 |

> - **记录 / 重现** = **复刻**：敌人失去什么都没有，学徒只是"抄了一份"（抄走的是信息）。

## 四、本稿遗留

- **数值全档待标**：36 个技能的能量 / 伤害 / 时长 / 层数均为占位建议值，统一 ⚠️D。其中 `gauge.current` / `gauge_rate` / `gauge.threshold` 类技能的定价**无既有锚点**，是最大盲区（沿用 D2）——受影响技能：精神干扰、敏捷之手、偷走想法、窃取距离、窃取时间、衰老、石制壁钟、窃取锚、命运缝隙，共 9 个。次高风险是【窃取权柄】的 `drain(count: all)`（强度随敌方堆叠量放大，几乎无法用单卡预算标定）。
- **本途径零概率**：原著偷盗者途径**没有任何概率性设定**（"钻命运漏洞"是技巧不是掷骰），故全 36 个技能**无一处**使用 `condition: { kind: 'chance' }`；命运 / 时间主题一律落在 `gauge.*` 上（brief §3.0 的"命运 / 预知主题例外"条款）。
- **本途径零 `on_turn_start`**：全部被动改挂 `on_battle_start`（A1 ✅）/ `on_tick` / `on_deal_damage` / `on_take_damage` / `on_kill`（A4 ✅）/ `on_death`，**不受 G15 影响**。（v0.1 的 预读密文 / 潜意识窃取 / 因果虫洞 三条因挂 `on_turn_start` 而完全不生效，本版已全部改掉。）同理，全稿无"短 duration + `on_turn_start`"的组合，**不涉及 G15-b 时间尺度冲突**。
- **本途径零 G8 违例**：全稿唯一调用 `move` 的技能是【窃取距离】（`push_back`，C1 ✅ 已锁 `from.faction`，位移发生在敌方自己的队列内）。原著偷盗者途径**没有突进 / 闪现类能力**，故本稿不存在"突进做成近战攻击进程"的改写需求。
- **未单独成技能的原著条目**（有意省略，留待后续）：
  - 序列7「神秘学知识掌握」「观察、联想和推导能力提升」—— 纯被动素养，无独立机制落点；flavor 并入【解析幻象】与【灵性直觉】
  - 序列4 的「**窃取位置**」—— **G8 铁律禁止跨阵营 relocate**，无法落地，只做了同条的「窃取距离」
  - 序列6「50 米」/ 序列5「80 米」/ 序列4「维持 2 小时」/ 序列2「用一周」—— 射程与长时概念在单局战斗中无意义，一律压缩为 `reach` 与 `duration`
  - 序列2「可窃取六种能力」—— 数量本身在卡牌里不产生玩法差异，由【三连窃取】代表"多取"这一档，未为"六种"单独立项
  - 序列8「魅力」与「口才」—— 原著写作"「魅力」+「口才」：话术提升 + 超凡说服力"，二者描述重合，本稿合并为一条【魅力口才】，未拆分
  - 序列1「展现历史事件」—— 原著称召唤壁钟"展现历史事件"，但**未说明用途**；本稿取"记录并回放时间"的自洽解释，若后续有更权威的设定需回改
  - 序列0「部分空间」权柄 —— 由共享引入的学徒【旅行家之门】【开门】承载，本途径未单独立项
- **【盗火】的退化风险**："状态数据槽"（与学徒 v0.2 新增项 5 同源）已落 ddd（编队参数 §1.1b slots 行 H33），`stolen_ability` 可按"用它的火打它"的完整语义落地，无需退化。
- **【窃取锚】的 INV-S5 裁定**：`gauge_threshold` 虽是合法 `StatKey`，但改它等价于改行动周期（周期 = threshold / rate）。需拍板是否触碰 INV-S5；若判定违规则改用退化方案（`gauge.current` 双向推拉）。
- **【寄生】的阶段切换**：本稿新增项 12 已落 ddd（编队参数 §1.1b formGroup/phases 行 H50）；若数据侧不走阶段定义，仍可退化为 `parasitized(3t)` → `on_remove` → `puppeteered(2t)` 的两状态串联（`on_remove` ✅ 已 fire），零新机制，代价是两个状态各自可被驱散。
- **本途径无治疗**：全稿未使用 `heal` 原语（回血全部走 `drain` 的搬运语义），故不涉及 **A22**；若后续要补"借助宿主恢复"的治疗版本，必须用 `heal`，不得用 `modify_resource(hp, +N)`。
