灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **战士途径**（源质：混沌海；相邻：不眠者；序列0 黄昏巨人；核心象征：战斗、守护、黄昏、衰败）。
框架：`docs/ddd/`（战斗内核 DDD 终版）+ `_GENERATION_BRIEF.md`；旧框架编号（A/C/D/E/F/G 组）的现落点见 brief §7；并对齐愚者稿 v0.2 的落地口径（v1.5 旧档、原《框架改动记录》与 `src/` 实现均已删除，原文可在 git 历史查阅）

> **本版定位**：v0.2 是**原著校准版**。相比 v0.1 主要做三件事——
> ① 逐序列比对原著能力表，把序列 9→0 全部招牌能力补回（武器防具精通 / 格斗术 / 抗性 / 武器大师 / 晨曦领域·黎明铠甲·晨曦之剑·光之风暴 / 守护状态 / 隐蔽·猎魔之眼·药剂印记 / 银甲·水银化·银白细剑·借光隐藏 / 牢笼·黄昏巨剑·老化·黄昏重生 / **代行**）；
> ② 剔除 v0.1 中凭空发明的原著外能力（吸血、反伤、"荣耀冲锋"等），并把误标的元素口径（`holy` 不在 Element 枚举内）纠正为 `none`；
> ③ 把本途径的灵魂——序列1「**代行**」及其代价「**因代行存在，无法获得其他权柄，只有之前序列能力提升**」——做成可落地的机制。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数 / 抗性）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能；⚠️D = 数值占位待标

### 普通（序列 9–8）

#### 【主动】格斗术·连击 🜁
- **原著** 序列9 战士 —— "各种武器防具精通、**各种格斗术掌握**"
- **文案** 你熟稔每一种徒手与持械的打法，两记连贯的拳脚砸在同一个破绽上。
- **序列** 9 战士 · **能量 2 / cd 2** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `Repeat[ damage(element: physical, 2), count: 2 ]`
- **翻译/语义** 本途径的输出地基，定位 = 战士途径的「火球术」：低费、无附加、纯直伤。2 能 / 4 伤 = 2.0 汇率，高于基准 1.2，因为它要撑起整条途径前期的输出骨架。用 `Repeat` 表达"连击"（多段只触发一次受击/反击，B8 口径）。⚠️D 待标。
- **升级阶梯**（B6）段数 2 → 3 → 4（序列8 格斗家档）；或解锁「关节技」：末段附加 `modify_resource(gauge.current, -15, delta)`。

#### 【被动】强健体魄 🜁
- **原著** 序列9 战士 —— "**超越常人的力量与敏捷**"
- **文案** 你的力量与敏捷早已越过常人的极限，出手更重，步子也更快。
- **序列** 9 战士 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(gauge_rate, +3, duration: null)`
- **翻译/语义** 原著两句并列，故拆两维：力量 → `attack`；敏捷 → `gauge_rate`。⚠️ **INV-S5**：行动周期是派生值，禁止直接修正，只改 `gauge_rate`（数值 ⚠️D，且 `gauge_rate` 定价无既有锚点，沿用 D2 盲区）。v0.1 只做了 `hp_max`，把"敏捷"整句丢了。

#### 【被动】兵械通晓 🜁
- **原著** 序列9 战士 —— "**各种武器防具精通**"
- **文案** 你懂每一种兵器的重心，也懂每一副护甲的接缝——手上更有力，身上更耐打。
- **序列** 9 战士 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(attack, +1, duration: null)` + `modify_resource(armor, +3)`（自身，整场）
- **翻译/语义** 一句原著拆两半：武器精通 → `attack`；防具精通 → `armor`。护甲按"5 一档"纪律取 3（≈0.6 档）。⚠️D。

#### 【被动】铁躯 🜂 ★
- **原著** 序列8 格斗家 —— "格斗专家，**能凭借身体减弱超自然力量影响**"
- **文案** 非凡力量落在你身上，就像雨水落在铁板上——滑开，只留下一点湿痕。
- **序列** 8 格斗家 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `iron_body`（整场，`category: buff`，不可驱散）：**全元素抗性 +12**（`resist: *`）
- **翻译/语义** **本途径的辨识度所在，v0.1 完全漏掉**。原著这句是战士途径在设定上的招牌：别的途径靠仪式和法术对抗超自然，战士靠**身体**。卡牌里唯一对应的维度就是 `resist`。"超自然力量"在原著里是泛指，故取**全元素**而非单元素抗性。⚠️ 依赖 `resist_all` 通配（本稿新增项 5，🟡；退化方案为逐元素写 5 条 `modify_stat`，零新增但状态臃肿）。⚠️D。

#### 【主动】近身缠斗 🜁
- **原著** 序列8 格斗家 —— "**擅长近距离战斗**"
- **文案** 你贴上去，用身体和兵刃缠住它——它想挥下一击，却发现节奏已经被你踩住了。
- **序列** 8 格斗家 · **能量 2 / cd 2** · `reach: melee` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: physical, 4)` + `modify_resource(gauge.current, -20, delta)`（目标）
- **翻译/语义** "擅长近距离战斗"不是"近战伤害更高"这种空话，落地成**近身压制节奏**：贴身缠斗拖慢对方出手。减 `gauge.current` 与击退（`KNOCKBACK_DISTANCE = 50`，D1 参数）是同一字段，-20 是"缠住"而非"击退"的轻度档。⚠️D。

#### 【主动】卸力 🜂
- **原著** 序列8 格斗家 —— "能**凭借身体减弱**超自然力量影响"
- **文案** 你卸掉那一道缠上来的异力，顺势在身前凝出一面薄薄的银光。
- **序列** 8 格斗家 · **能量 1 / cd 3** · `targetSpec: SELF`
- **效果** `dispel(self, category: ['debuff', 'dot'], count: 1)`（C2 数组已落地）+ `mount_status(shield, +4, 2t)`（自身）
- **翻译/语义** 【铁躯】是**事前**减伤（抗性），【卸力】是**事后**摆脱（驱散），同一句原著的两种落地。1 能量是守护轴的润滑剂，压低直伤（0）换功能性。⚠️D。

### 精良（序列 7–6）

#### 【被动】武器大师 🜁 ★
- **原著** 序列7 武器大师 —— "**任何武器到手即大师级水准（含非凡武器）**"
- **文案** 凡是能被握在手里的东西，到你手上就是杀器——连甲缝在哪里，你一摸就知道。
- **序列** 7 武器大师 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `weapon_grandmaster`（整场）：`modify_stat(attack, +3, duration: null)` + 自身造成的 `physical` 伤害 **`armor_pierce: 0.5`（无视目标一半护甲）**
- **翻译/语义** v0.1 把"武器大师"做成了`Repeat`三连斩（多段），**原著并不是多段，而是"拿到什么都能用"**。故改为两条：常驻攻击力提升 + 破甲（找到甲缝）。⚠️ 依赖 damage 载荷 `armor_pierce`（本稿新增项 4，🟡）。⚠️D。

#### 【被动】驭器 🜁
- **原著** 序列7 武器大师 —— "**有效降低武器负面影响**"
- **文案** 非凡武器反噬的那一半代价，到你手里总要打个对折。
- **序列** 7 武器大师 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `weapon_tamer`（整场）：施加于**自身的** `debuff` / `dot` 类状态，`duration ×0.5`
- **翻译/语义** **原著极有辨识度的一条，v0.1 完全漏掉**。原著非凡武器普遍带负面代价，战士途径的价值就在于"敢用"。卡牌里"武器的负面影响"最贴的对应物是**挂在自己身上的负面状态**。⚠️ 依赖 `duration_mul`（本稿新增项 7，🟡）；**退化方案**：`on_tick` 每 2 tick `dispel(self, category: ['debuff'], count: 1)`（复用 C2，零新增）。⚠️D。

#### 【主动】破甲重击 🜁
- **原著** 序列7 武器大师 —— "**超强力量**、体质和敏捷"
- **文案** 你抡圆了砸下去，力量不止落在它身上，也砸碎了它身上的甲。
- **序列** 7 武器大师 · **能量 3 / cd 3** · `reach: melee` · Manual（fallbackSort: `armor_desc`）
- **效果** `damage(element: physical, 4)` + `modify_resource(armor, -3, delta)`（目标）
- **翻译/语义** 原著"超强力量"的直接落地：直伤 + 削甲（护甲 5 一档，取 3 ≈ 0.6 档）。为后续输出铺路的武艺轴成型件。⚠️D。

#### 【主动】晨曦之剑 🜁 ★
- **原著** 序列6 黎明骑士 —— "『**晨曦之剑**』：凝聚武器（最强为**双手巨剑**）"
- **文案** 晨曦在你掌心凝成一柄剑；你若愿把它铸成双手巨剑，它便沉重到能劈开城墙——只是挥起来，慢了些。
- **序列** 6 黎明骑士 · **能量 3 / cd 4** · `targetSpec: SELF`
- **效果** `mount_status(dawn_blade, 4t)`：`modify_stat(attack, +4, duration: 4)` + 触发器 `on_deal_damage` → 附加 `damage(element: none, 2)`（晨曦灼烧）
- **升级阶梯**（B6）**双手巨剑**档：`attack +6` 但 `modify_stat(gauge_rate, -3, duration: 4)`（巨剑笨重）。
- **翻译/语义** 原著这条是**凝聚武器**（把晨曦凝成实体兵器），最贴的引擎表达是"可驱散的形态增益状态"（同 F10 `beast_form` 口径），而不是一次性伤害。⚠️ **INV-S5**：巨剑的"变慢"必须写成 `gauge_rate`，不得写行动周期。元素取 `none` —— 黎明/神圣伤害在 Element 枚举内无对应项，本版不立项新元素（本稿新增项 16，🟢，记录在案）。⚠️D。

#### 【主动】黎明铠甲 🜂
- **原著** 序列6 黎明骑士 —— "『**黎明铠甲**』：精炼全身盔甲"
- **文案** 晨曦在你的躯体上锻成一副贴身的甲，罩住你的同时，也烧掉了附着其上的污秽。
- **序列** 6 黎明骑士 · **能量 2 / cd 3** · `targetSpec: SELF`
- **效果** `modify_resource(armor, +6, duration: 4)`（自身）+ `dispel(self, category: ['debuff'], count: 1)`
- **翻译/语义** 原著写的是"精炼全身盔甲"——**护甲**，与序列3「银色全身盔甲」的差别在于：序列6 是护甲值，序列3 是"守护力量实质化"（减伤乘区 + 抗性）。本稿用 `armor`（序列6）vs `damage_taken_mul` + `resist_all`（序列3）区分两者，避免做成同一张卡。⚠️D。

#### 【主动】晨曦领域 🜃
- **原著** 序列6 黎明骑士 —— "『**晨曦领域**』：**破除幻觉、驱散怨魂、削弱邪恶**"
- **文案** 晨曦铺开一片领域：同伴眼前的幻象碎了，而那些邪物在光里矮了一截。
- **序列** 6 黎明骑士 · **能量 4 / cd 5** · `targetSpec: { faction: ALLY, scope: ALL }` + `{ faction: ENEMY, scope: ALL }`
- **效果** `Sequence[`
  - 全体**友军**：`dispel(unit, category: ['debuff', 'control', 'dot'], count: 1)`（破除幻觉 / 驱散怨魂）,
  - 全体**敌方**：`modify_stat(attack, -2, duration: 3)`（削弱邪恶）`]`
- **翻译/语义** 原著三个动词正好对应两条干净的引擎表达：破幻/驱魂 = 驱散（C2 数组已落地）；削弱邪恶 = 降攻击。"领域"**不新造 ZoneDef**，直接用全体目标表达（避免与 A23 的区域载荷重复立项）。⚠️ 依赖 `ALL_ALLIES`（F59，🟡，框架记录已注明战士需要）+ 新增 `ALL_ENEMIES`（本稿新增项 6，🟡，**与 F59 同源，建议并入同一"全体目标"母版**）。⚠️D。

#### 【主动】光之风暴 🜁
- **原著** 序列6 黎明骑士 —— "『**光之风暴**』：**最强攻击**，锐利飓风摧毁人体"
- **文案** 你掀起的不是风，是无数片薄到看不见的光——它们在敌人之间掠过，留下一道道细而深的口子。
- **序列** 6 黎明骑士 · **能量 4 / cd 5** · `targetSpec: { faction: ENEMY, scope: ALL }`
- **效果** 全体敌方 `damage(element: none, 4)` + `modify_resource(armor, -2, delta)`
- **翻译/语义** 原著白纸黑字写了"**最强攻击**"，所以序列6 就给 AOE，不必等到高序列。⚠️ 依赖 `ALL_ENEMIES`（本稿新增项 6）。⚠️D。
- **升级阶梯**（B6）序列2 荣耀者的战斗权柄版本：`damage(element: none, 6)` + `armor -3`（原著序列2 战斗权柄清单里同样列着"光之风暴"，故做成同一技能的强化档，不再单独立卡）。

### 稀有（序列 5–4）

#### 【主动】守护状态 🜂 ★
- **原著** 序列5 守护者 —— "『**守护状态**』：**巨剑插地，竖立无形墙壁，帮同伴承担伤害**"；"**放弃攻击后**高序列以下极少能打破防御"
- **文案** 你把巨剑插进地面，一道看不见的墙随之立起——打向同伴的那一击，落在了你的身上。
- **序列** 5 守护者 · **能量 3 / cd 4** · 双目标：指定 1 名友军 + `SELF`
- **效果** `Sequence[`
  - 自身 `mount_status(守护)`（**复用既有状态**，`binding.guardTarget` = 指定友军，替其承担伤害，priority 10）,
  - 自身 `mount_status(坚守, 4t)`（`damage_taken_mul: 0.7`）,

### 传说（序列 1–0）

#### 【被动】代行 🜄 ★
- **原著** 序列1 神明之手 —— "『**代行**』权柄（简化）：**代表效忠神明 / 旧日展现威能**、降下神罚"；"**因"代行"存在，无法获得其他权柄，只有之前序列能力提升**"
- **文案** 你不是在自己战斗——你代那位存在行事。于是你先前走过的每一级序列，都被推到了更远的地方；而你再也接不住任何一份来自别处的力量。
- **序列** 1 神明之手 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `mandate`（整场，`category: buff`，不可驱散）：
  - **收益**：`damage_mul: 1.25`，`filter: { pathway: 'warrior' }` —— **只有之前序列能力提升**（本途径技能增强，无新能力）
  - **代价**：`immune: { sourcePathways: ['*', '!warrior'] }` —— **无法获得其他权柄**（一切非本途径来源的增益状态无法挂到你身上）
- **翻译/语义** **本稿的灵魂**。原著这条最特别的地方是它**自带枷锁**：代行者借更高存在的威能，代价是永远只能"把自己已有的能力推得更远"。这是全 22 条途径里少见的"负向设计"，在卡牌里几乎可以一比一落地——**增益只作用于本途径技能 + 屏蔽一切外来增益**（含友军给的 buff、其他途径的共享技能）。这条也是【神罚】的前置：因为你代行，所以你降下的打击叫神罚。
- ⚠️ 依赖：① 按途径标签过滤的伤害乘区（本稿新增项 14，🟡，**与愚者稿「能力精进」新增项 14 同源，建议并入同一母版**；退化方案为按元素过滤，代价是吃不到途径区分）；② `immune` 支持按**来源途径**过滤（本稿新增项 3，🔴，**与 G12 `immune` 同源，建议并入同一字段**）。⚠️D。
- **设计风险** 代价一侧若太重（连友军治疗以外的 buff 都吃不到），会让携带者无法参与任何跨途径组合技；若太轻，就丢掉了原著的味道。**建议落地时先按"屏蔽一切来自其他途径技能的状态"实现，治疗类（`heal` 原语，非状态）不受影响** —— 这样代价明确但不至于锁死组队。

#### 【主动】神罚 🜄
- **原著** 序列1 神明之手 —— "代行权柄：**代表效忠神明 / 旧日展现威能、降下神罚**"
- **文案** 你抬起手，替那位存在落下判决——光不是照下来的，是压下来的；凡已被黄昏侵蚀的，压得更狠。
- **序列** 1 神明之手 · **能量 6 / cd 7** · `targetSpec: { faction: ENEMY, scope: ALL }`
- **效果** 全体敌方 `damage(element: none, 5)`，`If(目标持有 aging)` → 该次伤害 ×1.5 + 每个目标 `mount_status(aging, stacks: 1, duration: 4)`
- **翻译/语义** "降下神罚"在语义上是**无差别的天罚**，故做成 AOE 而非单体；"代表更高存在"的体感则由【代行】的乘区与屏蔽提供（两卡联动）。对已 `aging` 目标 ×1.5 是给黄昏轴的正向协同：先用【迟暮】铺老化，再降神罚。⚠️ 依赖 `aging`（本稿新增项 1，🔴）+ `ALL_ENEMIES`（本稿新增项 6）+ **F52 `target_has_status`**（🟡）。⚠️D。

#### 【主动】黄昏·万物崩解 🜄 ★
- **原著** 序列0 黄昏巨人 —— "『黄昏』权柄：**物质、意志乃至虚空衰败崩溃消亡**；让目标**飞快衰老 / 衰败 / 失控**"
- **文案** 黄昏落在它身上——先是甲，然后是骨，然后是它还想站着的那点念头。最后连它脚下的那片空处，也开始往下掉。
- **序列** 0 黄昏巨人 · **能量 6 / cd 8** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: none, 4)` + `mount_status(collapse, duration: 5)`（目标）
- **机制** 状态 `collapse`（**崩解**）：
  - `on_tick` → `damage(element: none, 3)` ＋ `aging` 层数 +1（`maxStacks: 6`）
  - `damage_taken_mul: 1.2`
  - `dispelable: false`（权柄级，**运行时覆写**，与愚者稿「灵界掌控者」新增项 9 同源）
  - 到期后残留 `aging` 层数不清空（衰败是不可逆的）
- **翻译/语义** 序列0 的黄昏权柄是【迟暮】的**完全体**：迟暮让目标"变老"，崩解让目标"**从存在上开始掉**"——更高的每 tick 伤害、更快的叠层、不可驱散，并且到期后衰败层数**不回滚**（这是它与所有其他 debuff 的语义差别，也是它值 6 能量 + 传说位阶的原因）。原著"**失控**"在引擎里无对应维度（无 AI 行为系统），本稿不做，记入遗留。
- ⚠️ 依赖 `aging`（本稿新增项 1，🔴）+ 运行时覆写 `dispelable`（与愚者稿新增项 9 同源，🔴，**建议并入同一母版**）。⚠️D。

#### 【被动】战斗权柄 🜁 ★
- **原著** 序列0 黄昏巨人 —— "『战斗』权柄：**最恐怖力量 + 最巨大身形 + 最强力摧毁 + 最坚固守护 + 技巧**"
- **文案** 战斗的权柄在你身上展开：更重的拳、更高的身量、更硬的壳，以及一个老兵才有的、恰到好处的分寸。
- **序列** 0 黄昏巨人 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `battle_authority`（整场，不可驱散）：`modify_stat(attack, +5, duration: null)` + `modify_resource(armor, +8)` + `modify_stat(gauge_rate, +4, duration: null)` + `resist_all +10`
- **翻译/语义** 原著五个词正好对应五个既有维度：力量 → `attack`；身形 → `armor`（身高体量的引擎替代）+ `hp` 无关（不写 hp 以免与【强健体魄】重复）；摧毁 → 由 `attack` 与其余攻击技能承载；守护 → `armor` + `resist_all`；技巧 → `gauge_rate`。**刻意不写"全知全能"式的描述性能力**（brief 第 5 节红线）。⚠️ **INV-S5**：技巧只改 `gauge_rate`。⚠️D。

#### 【被动】神圣·荣耀即晨曦即黄昏 🜄
- **原著** 序列0 黄昏巨人 / 序列2 荣耀者 —— "『神圣』权柄 + 部分『代行』权柄"；"**荣耀即晨曦即黄昏，摧毁即净化**"
- **文案** 你摧毁的每一具躯壳，都变成洒在同伴身上的光——在你这里，杀戮与净化从来是同一件事。
- **序列** 0 黄昏巨人 · **hook** `on_kill`（A4，已落地）
- **效果** `on_kill` → 全体友军 `heal(3)`（**A22**：治疗必须用 `heal` 原语）+ 自身 `dispel(self, category: ['debuff'], count: 1)`
- **翻译/语义** "摧毁即净化"是序列2 就已点明的口径，序列0 是它的权柄级版本，故做成**击杀驱动的持续净化**：每杀一个，同伴回一口、自己净一层。与【黄昏巨剑】的 `on_kill` 治疗是同一语义的两档（前者一次性、本条常驻）。**刻意不用 `spawn`/zone/新状态**，只靠 `on_kill` + `heal` + `dispel` 三个既有原语，是本稿落地成本最低的传说卡。⚠️ 依赖 `ALL_ALLIES`（F59，🟡）。⚠️D。

## 四、本稿遗留

- **数值全档待标**：33 个技能的能量 / 伤害 / 时长 / 层数 / 抗性均为占位建议值，统一 ⚠️D。其中 `gauge_rate` 与 `gauge.current` 类技能的定价无既有锚点（沿用 D2 盲区），是本稿最大数值盲区；`resist_all` 的抗性百分比同样无锚点。
- **未单独成技能的原著能力**（有意省略，留待后续）：
  - 序列0「让目标……**失控**」、序列4「飓风级高速奔跑」的真实位移 —— 引擎无 AI 行为维度 / 受 G8 约束，前者不做，后者降级为节奏（见【疾风奔袭】）
  - 序列2「光之风暴」—— 已并入【光之风暴】的 B6 升级阶梯，不重复立卡
  - 序列6「黎明铠甲」与序列3「银色全身盔甲」的文本区分度低 —— 本稿以「护甲值」vs「减伤乘区 + 全抗性」强行区分，若汇总阶段认为过近可考虑合并
  - 序列1「代行」的"效忠神明/旧日"对象 —— 纯 flavor，不影响机制
- **未引入概率**：本稿 33 个技能**零处使用 `condition: { kind: 'chance' }`**。战士途径在原著里是"确定性"的 martial 路线，用掷骰子表达它的命中与力量会破坏体感；R3/R4/R5 对本稿无约束面。
- **未使用 `on_turn_start`**：本稿所有持续型效果一律挂 `on_tick` / `on_deal_damage` / `on_take_damage` / `on_kill` / `on_remove`，**刻意避开 G15 死触发点**，因此不存在 G15 / G15-b 的时间尺度问题。
- **未决机制优先级**：【代行】的"屏蔽外来增益"与跨途径组合技（如歌颂者的群体增益、观众的心理增益）正面对冲。若未来有多途径组队玩法，需先定"`immune` 按来源途径过滤"与"组合技是否豁免"的优先级，否则【代行】的强度不可标定。
- **【无幻之心】强度存疑**：整场免疫 `control` 在控制密集的环境里偏强，建议落地时改为"每场前 2 次"（`charges: 2`，C6 已落地）作为平衡档。⚠️D。
- **元素口径**：黎明 / 神圣 / 黄昏类伤害本版统一用 `none` 承载，**代价是没有"抗神圣"这一 counter 维度**。若后续要引入，需扩展 Element 枚举（与水手稿 F63 `water` 同类，本版不立项，见第五节第 16 条）。
- **对照表存疑**（写作时发现，供汇总阶段参考）：
  1. 对照表把战士途径的源质标为**混沌海**，但相邻只列了**不眠者**（永暗之河）——跨源质相邻且只列一条，与其他途径的相邻写法（多为 1–2 条同源质）不一致，**疑为录入错误**（通行设定里黄昏巨人属永暗之河，与黑暗、死神同源）。本稿按对照表执行（相邻 = 不眠者），但跨途径共享的判定依据因此偏弱。
  2. 序列1「神明之手」在对照表里**只有"代行"一项能力与一句限制**，没有具体招式名（对比其他途径序列1 通常有 3–4 项），导致本档只能做 2 个技能，是**全途径里序列1 覆盖最薄的一条**。
  3. 序列0 只列权柄清单、无招式名，且"部分代行权柄"与序列1 的"代行"重复，本稿按"序列1 主代行、序列0 主黄昏/战斗/神圣"分工处理。
