## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能；⚠️D = 数值占位待标

### 普通（序列 9–8）

#### 【主动】格斗术·连击 🜁
- **原著** 序列9 战士 —— "各种武器防具精通、**各种格斗术掌握**"
- **文案** 你熟稔每一种徒手与持械的打法，两记连贯的拳脚砸在同一个破绽上。
- **序列** 9 战士 · **能量 2 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `Repeat[ damage(element: physical, 2), count: 2 ]`
- **翻译/语义** 本途径的输出地基，定位 = 战士途径的「火球术」：低费、无附加、纯直伤。2 能 / 4 伤 = 2.0 汇率，高于基准 1.2，因为它要撑起整条途径前期的输出骨架。用 `Repeat` 表达"连击"（多段只触发一次受击/反击，B8 口径）。⚠️D 待标。
- **升级阶梯**（B6）段数 2 → 3 → 4（序列8 格斗家档）；或解锁「关节技」：末段附加 `modify_resource(gauge.current, -15, delta)`。

#### 【被动】强健体魄 🜁
- **原著** 序列9 战士 —— "**超越常人的力量与敏捷**"
- **文案** 你的力量与敏捷早已越过常人的极限，出手更重，步子也更快。
- **序列** 9 战士 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(attack, +2, duration: null)` + `modify_stat(gauge_rate, +3, duration: null)`
- **翻译/语义** 原著两句并列，故拆两维：力量 → `attack`；敏捷 → `gauge_rate`。⚠️ **INV-S5**：行动周期是派生值，禁止直接修正，只改 `gauge_rate`（数值 ⚠️D，且 `gauge_rate` 定价无既有锚点，沿用 D2 盲区）。v0.1 只做了 `hp_max`，把"敏捷"整句丢了。

#### 【被动】兵械通晓 🜁
- **原著** 序列9 战士 —— "**各种武器防具精通**"
- **文案** 你懂每一种兵器的重心，也懂每一副护甲的接缝——手上更有力，身上更耐打。
- **序列** 9 战士 · **hook** `on_battle_start`（A1）
- **效果** `modify_stat(attack, +1, duration: null)` + `modify_resource(armor, +3)`（自身，整场）
- **翻译/语义** 一句原著拆两半：武器精通 → `attack`；防具精通 → `armor`。护甲按"5 一档"纪律取 3（≈0.6 档）。⚠️D。

#### 【被动】铁躯 🜂 ★
- **原著** 序列8 格斗家 —— "格斗专家，**能凭借身体减弱超自然力量影响**"
- **文案** 非凡力量落在你身上，就像雨水落在铁板上——滑开，只留下一点湿痕。
- **序列** 8 格斗家 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `iron_body`（整场，`category: buff`，不可驱散）：**全元素抗性 +12**（`resist: *`）
- **翻译/语义** **本途径的辨识度所在，v0.1 完全漏掉**。原著这句是战士途径在设定上的招牌：别的途径靠仪式和法术对抗超自然，战士靠**身体**。卡牌里唯一对应的维度就是 `resist`。"超自然力量"在原著里是泛指，故取**全元素**而非单元素抗性。⚠️ `resist_all` 通配（✅ 新增项 5，已落 ddd：效果参数 §一 `resist:*`；退化方案逐元素 5 条仍备）。⚠️D。

#### 【主动】近身缠斗 🜁
- **原著** 序列8 格斗家 —— "**擅长近距离战斗**"
- **文案** 你贴上去，用身体和兵刃缠住它——它想挥下一击，却发现节奏已经被你踩住了。
- **序列** 8 格斗家 · **能量 2 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: physical, 4)` + `modify_resource(gauge.current, -20, delta)`（目标）
- **翻译/语义** "擅长近距离战斗"不是"近战伤害更高"这种空话，落地成**近身压制节奏**：贴身缠斗拖慢对方出手。减 `gauge.current` 与击退（`KNOCKBACK_DISTANCE = 50`，D1 参数）是同一字段，-20 是"缠住"而非"击退"的轻度档。⚠️D。

#### 【主动】卸力 🜂
- **原著** 序列8 格斗家 —— "能**凭借身体减弱**超自然力量影响"
- **文案** 你卸掉那一道缠上来的异力，顺势在身前凝出一面薄薄的银光。
- **序列** 8 格斗家 · **能量 1 / cd 3 / 吟唱 0** · `targetSpec: SELF`
- **效果** `dispel(self, category: ['debuff', 'dot'], count: 1)`（C2 数组已落地）+ `mount_status(shield, +4, 2t)`（自身）
- **翻译/语义** 【铁躯】是**事前**减伤（抗性），【卸力】是**事后**摆脱（驱散），同一句原著的两种落地。1 能量是守护轴的润滑剂，压低直伤（0）换功能性。⚠️D。

#### 【被动】武器大师 🜁 ★

#### 【被动】驭器 🜁

- **序列** 7 武器大师 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `weapon_tamer`（整场）：施加于**自身的** `debuff` / `dot` 类状态，`duration ×0.5`
- **翻译/语义** **原著极有辨识度的一条，v0.1 完全漏掉**。原著非凡武器普遍带负面代价，战士途径的价值就在于"敢用"。卡牌里"武器的负面影响"最贴的对应物是**挂在自己身上的负面状态**。⚠️ `duration_mul`（✅ 新增项 7，H14 `durationModifier` scope `incoming`）；**退化方案**（`on_tick` 驱散，C2）仍备。⚠️D。

- **翻译/语义** **黄昏轴旗舰，v0.1 完全漏掉**。原著"逐渐老化至死"的体感是**递进**，不是瞬间伤害，故必须做成"随时间叠层、每层降属性"的递减曲线——这是本途径与所有 `dot + 乘区` 类 debuff 的分界线：**别人是持续掉血，战士是让你越打越弱**。"让目标飞快衰老/衰败/**失控**"里的失控在引擎里无对应维度，本稿不做（记入遗留）。
- **退化方案**（若层数机制不落地）：`aging` = `damage_taken_mul: 1.15` + `on_tick: damage 2 (none)` + `modify_stat(attack, -2, duration: 同状态时长)`（固定衰减，不随层数递进），仍是合格的老化 debuff，代价是丢掉"逐渐"的时间感。
- ⚠️ 依赖均已落：F51 `mount_status.stacks`（✅ StatusGrant.stacks，编队上下文 §六）+ 按层数修正属性（✅ H34 `statPerStack`，与 F8 `mind_taint` 同族）+ dot/乘区（✅ H2，与 F6 / F12 / F13 / F18 同母版）。⚠️D。

#### 【被动】黄昏重生 🜄
- **原著** 序列2 荣耀者 —— "『黄昏』权柄（简化）：**让自身老去蒸发后灵界重生**"
- **文案** 你在暮色里老去、蒸发——然后从灵界的那一侧走回来。回来的人还是你，只是更老了。
- **序列** 2 荣耀者 · **hook** `on_death`（自身）
- **效果** `mount_status(twilight_return, charges: 1, duration: null)`（C6 ✅）；触发器 `on_death` → `spawn(reviveOf: 自身, hpRatio: 0.4, position: 'tail')`（C5 ✅ + G4 `reviveOf`，✅ 效果参数 §1.1）+ 自身 `mount_status(aging, stacks: 2, duration: 5)`（**重生的代价是继续衰老**）
- **翻译/语义** 原著这句极有味道，且**两段都要落地**：① "老去蒸发"= 死亡；② "灵界重生"= 复活。关键设计在**代价**：复活后自带 2 层 `aging`，所以这条复活不是白嫖，而是把序列2 的黄昏权柄用在自己身上——与【迟暮】形成闭环。原著未写次数，本稿取 1 次（`charges: 1`），⚠️D 待标。⚠️ G4 `spawn.reviveOf`（✅ 效果参数 §1.1）+ C5 / C6（✅）。

### 传说（序列 1–0）

#### 【被动】代行 🜄 ★
- **原著** 序列1 神明之手 —— "『**代行**』权柄（简化）：**代表效忠神明 / 旧日展现威能**、降下神罚"；"**因"代行"存在，无法获得其他权柄，只有之前序列能力提升**"
- **文案** 你不是在自己战斗——你代那位存在行事。于是你先前走过的每一级序列，都被推到了更远的地方；而你再也接不住任何一份来自别处的力量。
- **序列** 1 神明之手 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `mandate`（整场，`category: buff`，不可驱散）：
  - **收益**：`damage_mul: 1.25`，`filter: { pathway: 'warrior' }` —— **只有之前序列能力提升**（本途径技能增强，无新能力）
  - **代价**：`immune: { sourcePathways: ['*', '!warrior'] }` —— **无法获得其他权柄**（一切非本途径来源的增益状态无法挂到你身上）
- **翻译/语义** **本稿的灵魂**。原著这条最特别的地方是它**自带枷锁**：代行者借更高存在的威能，代价是永远只能"把自己已有的能力推得更远"。这是全 22 条途径里少见的"负向设计"，在卡牌里几乎可以一比一落地——**增益只作用于本途径技能 + 屏蔽一切外来增益**（含友军给的 buff、其他途径的共享技能）。这条也是【神罚】的前置：因为你代行，所以你降下的打击叫神罚。
- ⚠️ 依赖均已落：① 按途径过滤的伤害乘区（✅ 新增项 14，H4 `filter` 按途径；退化方案按元素仍备）；② `immune` 按来源途径过滤（✅ 新增项 3，§1.1b `immune.sourcePathways`，G12 同字段扩展）。⚠️D。
- **设计风险** 代价一侧若太重（连友军治疗以外的 buff 都吃不到），会让携带者无法参与任何跨途径组合技；若太轻，就丢掉了原著的味道。**建议落地时先按"屏蔽一切来自其他途径技能的状态"实现，治疗类（`heal` 原语，非状态）不受影响** —— 这样代价明确但不至于锁死组队。

#### 【主动】黄昏·万物崩解 🜄 ★

## 四、本稿遗留

- **数值全档待标**：33 个技能的能量 / 伤害 / 时长 / 层数 / 抗性均为占位建议值，统一 ⚠️D。其中 `gauge_rate` 与 `gauge.current` 类技能的定价无既有锚点（沿用 D2 盲区），是本稿最大数值盲区；`resist_all` 的抗性百分比同样无锚点。
- **未单独成技能的原著能力**（有意省略，留待后续）：
  - 序列0「让目标……**失控**」、序列4「飓风级高速奔跑」的真实位移 —— 引擎无 AI 行为维度 / 受 G8 约束，前者不做，后者降级为节奏（见【疾风奔袭】）
  - 序列2「光之风暴」—— 已并入【光之风暴】的 B6 升级阶梯，不重复立卡
  - 序列6「黎明铠甲」与序列3「银色全身盔甲」的文本区分度低 —— 本稿以「护甲值」vs「减伤乘区 + 全抗性」强行区分，若汇总阶段认为过近可考虑合并
  - 序列1「代行」的"效忠神明/旧日"对象 —— 纯 flavor，不影响机制
- **未引入概率**：本稿 33 个技能**零处使用 `condition: { kind: 'chance' }`**。战士途径在原著里是"确定性"的 martial 路线，用掷骰子表达它的命中与力量会破坏体感；R3/R4/R5 对本稿无约束面。
- **未使用 `on_turn_start`**：本稿所有持续型效果一律挂 `on_tick` / `on_deal_damage` / `on_take_damage` / `on_kill` / `on_remove`，**刻意避开 G15 死触发点**，因此不存在 G15 / G15-b 的时间尺度问题。
- **未决机制优先级**：【代行】的"屏蔽外来增益"与跨途径组合技（如歌颂者的群体增益、观众的心理增益）正面对冲。若未来有多途径组队玩法，需先定"`immune` 按来源途径过滤"与"组合技是否豁免"的优先级，否则【代行】的强度不可标定。
- **【无幻之心】强度存疑**：整场免疫 `control` 在控制密集的环境里偏强，建议落地时改为"每场前 2 次"（`charges: 2`，C6 已落地）作为平衡档。⚠️D。
- **元素口径**：黎明 / 神圣 / 黄昏类伤害本版统一用 `none` 承载，**代价是没有"抗神圣"这一 counter 维度**。若后续要引入，需扩展 Element 枚举（与水手稿 F63 `water` 同类，本版不立项，见第五节第 16 条）。
- **对照表存疑**（写作时发现，供汇总阶段参考）：
  1. 对照表把战士途径的源质标为**混沌海**，但相邻只列了**不眠者**（永暗之河）——跨源质相邻且只列一条，与其他途径的相邻写法（多为 1–2 条同源质）不一致，**疑为录入错误**（通行设定里黄昏巨人属永暗之河，与黑暗、死神同源）。本稿按对照表执行（相邻 = 不眠者），但跨途径共享的判定依据因此偏弱。
  2. 序列1「神明之手」在对照表里**只有"代行"一项能力与一句限制**，没有具体招式名（对比其他途径序列1 通常有 3–4 项），导致本档只能做 2 个技能，是**全途径里序列1 覆盖最薄的一条**。
  3. 序列0 只列权柄清单、无招式名，且"部分代行权柄"与序列1 的"代行"重复，本稿按"序列1 主代行、序列0 主黄昏/战斗/神圣"分工处理。
