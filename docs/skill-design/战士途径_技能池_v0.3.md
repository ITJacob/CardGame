# 战士途径（序列0：黄昏巨人）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入永暗之河系核心机制 **「隐秘值」战场维度**（secrecy 0–10，主消费方之一，经"隐蔽"写入）；
> ③ 新增 **跨系 combo 卡**（永暗之河↔源堡：隐蔽↔占卜家 隐秘值）；
> ④ 补 1 张主题界域牌（晨曦领域）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；序列映射依据《永暗之河系技能设定》《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

> **v2 修订要点**：战士已移入永暗之河系，不眠者/收尸人/战士聚齐为「死亡·黑暗·灵体」承接组；战士的 `隐蔽(conceal)` 与占卜家/不眠者共用同一 `secrecy` 维度，是隐秘联动组的天然成员。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **武艺** ⚔ | `武技`(martial_skill) | 武器通晓 / 武器大师 → 累积 `武技` | 若\[武技\] 任意武器大师级 / 巨力挥击 / 神罚 | 武器大师 |
| ② **守护** 🛡 ★核心 | `守护`(guard) | 守护姿态 / 守护状态 → 挂 `守护` | 若\[守护\] 为同伴承担伤害 / 壁垒实质化 / 银甲承伤 | 守护状态 |
| ③ **猎魔（黎明/晨曦）** 🌅 | `黎明`(dawn, 晨曦/隐蔽) | 猎魔之眼 / 隐蔽 / 晨曦领域 → 挂 `黎明` | 若\[黎明\] 破幻驱怨 / 削弱邪恶 / 不可被定位 / 晨曦领域 | 晨曦领域 |
| ④ **黄昏** 🌇 | `黄昏`(aging, 衰败) | 暮色侵蚀 / 黄昏之触 → 对敌挂 `黄昏` | 若\[黄昏\] 目标老化至死 / 衰败失控 / 万物崩溃 | 黄昏巨人 |

> **隐秘值维度（永暗之河系 §2.3，主消费方之一）**：战场级属性 0–10，独立于力/敏/智/灵/体/魅。战士经"隐蔽 / 借光隐藏"等 +1/次（见【隐蔽】、【隐秘之影·承接】）。层级（照搬总览，与源堡同源）：
> - **≥4**：场上所有 `提线木偶` 每回合 +1 层（收尸人·奴役目标最稳）
> - **≥7**：友方「隐秘 / conceal / 愚弄」类技能 **+50%**
> - **=10**：触发「**源堡共鸣**」——本回合所有带 `提线木偶` 的目标可被任意友方（含跨源质）操控一次
>
> **跨源质写入方**：源堡（占卜家·愚弄/隐秘）、永暗之河（不眠者·隐秘 / 收尸人·灵体之线 / 战士·隐蔽）三方共用同一 `secrecy` 维度，战士是主消费方之一（隐蔽↔占卜家 隐秘值联动）。

## 三、跨途径共享（永暗之河三途径 + 跨系 combo）

相邻（不眠者 / 收尸人）用 `sharedAcross`；跨系 combo 卡通过 **`StatusDef.crossPathway:true`** 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 守护状态 / 承伤壁垒 / 银色铠甲 | 不眠者 / 收尸人 | 同源"为同伴承担伤害""壁垒"骨架（本系常驻） |
| 隐蔽 / 猎魔之眼 / 隐秘之影·承接 | 不眠者 | 隐蔽(conceal) 组内核，白名单内；共享 secrecy 维度 |
| 晨曦领域 | 收尸人 | 晨曦↔冥界对冲，已定规则 |
| 借光隐藏 | **占卜家（源堡）** | 跨系 combo：读取友方 `conceal` / 共享 `secrecy` 升级为不可被定位（隐蔽↔占卜家 隐秘值联动） |

> **枢纽状态（落地优先级最高）**：`提线木偶(puppet_string)`、`寄生`、`替身`、`混乱`、`恶欲值`、`命运`、`隐秘(conceal)` / `secrecy` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单。本途径接入 **`conceal/secrecy`（占卜家/不眠者/战士）** 与 **`guard`（不眠者/收尸人/战士）** 两条枢纽，白名单见 §六。

## 五、本稿遗留
