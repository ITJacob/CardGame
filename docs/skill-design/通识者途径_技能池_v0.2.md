> **本版定位**：v0.2 是**原著校准版**。v0.1 的骨架（能量回复、护甲、自推行动条、群体治疗）大多是从"通识/全知"这个抽象词推导出来的，与原著序列 9→0 的具体能力对不上。本版推倒重来，只做三件事——
> ① 把对照表里**白纸黑字写出的原著能力**逐条落地（唤醒记忆、王水/硝酸甘油/齿轮装置、遗迹禁忌知识、仪式魔法、鉴定、机械奇物、虚假星象/星之祝福/星之诅咒、炼成、注入灵魂、汲取、解离、环境掌控者、知识妖精、规律/解析/制造/学习权柄、导师、文明图卷、文明/教化权柄、现实知识）；
> ② 把本途径真正的灵魂——**制造/造物**——做成有层次的体系（序列6 造机械 → 序列4 炼成并注入灵魂 → 序列2 制造权柄量产 → 序列0 现实知识改写）；
> ③ 剔除 v0.1 中没有原著依据的自造能力（自推条的"通识速记/星象推演"、结晶禁疗的"物质嬗变"、"估值变现"、"深层奥秘"等）。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数 / 抗性）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达（九原语 + 已登记扩展 + 本稿新增项）。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项 #）；★ = 该轴的旗舰技能；⚠️D = 数值占位待标

### 普通（序列 9–8）

#### 【被动】唤醒记忆 🜁 ★
- **原著** 序列9 通识者 —— "'唤醒记忆'：记起看过的所有知识"
- **文案** 你合上眼，把读过的每一页在脑中重新翻开一遍——那些知识一直都在，只是需要被叫醒。
- **序列** 9 通识者 · **hook** `on_battle_start`（A1）
- **效果** `modify_resource(energy, +8, delta)` + `modify_stat(energy_max, +5, duration: null)`（整场）
- **翻译/语义** "记起看过的所有知识"= 一次性把储备调取出来，故做成**开局一次性**的能量爆发 + 提高能量上限（记忆容量变大），而不是每回合回能——"持续学习"是另一条能力（见【学习权柄】）。8 能量 ≈ 1.6 张标准卡预算（一张卡 ≈ 3 能量）。⚠️D。

#### 【主动】硝酸甘油 🜂
- **原著** 序列9 通识者 —— "精通王水、硝酸甘油、齿轮装置等"
- **文案** 你扔出一小管摇晃过的硝酸甘油——它炸开的火光，比任何咒语都直白。
- **序列** 9 通识者 · **能量 3 / cd 3** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: fire, 5)` + `mount_status(burn, 3t)`（`burn` 已实现：2 伤/tick · 3t）
- **翻译/语义** 原著"精通硝酸甘油"直译就是爆炸物 → 火属性直伤 + 灼烧，无附加机制。**这是本途径低序列唯一的正牌输出手段，定位 = 本途径的「火球术」**：本稿前 4 个序列里只有它与【王水】【齿轮装置】能打出伤害，若不做，整条途径前期没有输出地基（同愚者稿【飞牌】的理由）。3 能 5 伤 = 1.67 汇率，高于基准 1.2，正是为此。⚠️D。
- **升级阶梯**（B6）伤害 5 → 7 → 9；或解锁「震荡」：追加 `modify_resource(gauge.current, -25, delta)`（爆炸击退，**G8 合规**——不调 `move`，只推行动条）。

#### 【主动】王水 🜂
- **原著** 序列9 通识者 —— "精通王水、硝酸甘油、齿轮装置等"
- **文案** 你泼出那瓶能溶解黄金的液体——护甲、机关、外壳，在它面前都只是待溶的金属。
- **序列** 9 通识者 · **能量 2 / cd 3** · `reach: ranged` · Manual（fallbackSort: `armor_desc`）
- **效果** `damage(element: poison, 3)` + `modify_resource(armor, -5, delta)`
- **翻译/语义** "王水"的语义就是**溶解金属**，而引擎里"金属"唯一的对应物是护甲 → 落为低伤 + 破甲。与【硝酸甘油】构成"纯直伤 vs 破甲"的选择：2 能 3 伤（汇率 1.5）换 5 点破甲，正好是单卡纪律里的"护甲 5 一档"。这是本途径**破甲体系的最低档**（【解离】【完美之境】是它的高阶延伸）。⚠️D。
- ⚠️ 依赖新排序 `armor_desc`（本稿新增项 #18，🟡）；退化方案 `fallbackSort: atk_desc`。

#### 【主动】齿轮装置 🜂
- **原著** 序列9 通识者 —— "精通王水、硝酸甘油、齿轮装置等"
- **文案** 你甩出一串咬合的齿轮，它们缠住敌人的手脚，让它慢了整整半拍。
- **序列** 9 通识者 · **能量 2 / cd 4** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: physical, 2)` + `modify_resource(gauge.current, -30, delta)`
- **翻译/语义** "齿轮装置"= 机械性阻滞。用**推后行动条**表达"被卡住"，**不调 `move`**（G8 合规，且真实位移在双路四格战场里比推条更贵）。2 能 2 伤 + 半次行动的拖延——直伤刻意压低，因为节奏本身就是硬资源（brief §2）。这是本途径唯一的**单体拖慢**手段。⚠️ `gauge.current` 类效果定价无既有锚点（D2）。⚠️D。

#### 【被动】遗迹禁忌知识 🜁
- **原著** 序列8 考古学家 —— "拥有历史知识、野外生存知识、遗迹禁忌知识"
- **文案** 你知道的那些东西，本不该被人知道——但也正因如此，没有什么精神上的把戏能真正吓到你。
- **序列** 8 考古学家 · **hook** `on_battle_start`
- **效果** 自身 `modify_stat(resist:mental, +20, duration: null)` + `modify_stat(resist:poison, +10, duration: null)`（整场）
- **翻译/语义** "禁忌知识"在原著里的代价与收益都在**精神**层面，引擎里唯一的对应物是元素抗性（`resist:<元素>`，`mental` 属元素枚举）。落为整场精神抗性 + 少量毒素抗性（承接同序列的"野外生存知识"）。抗性纪律 ±10~±20%，本条取上沿。⚠️D。

#### 【被动】荒野体魄 🜂
- **原著** 序列8 考古学家 —— "足够强壮的体魄" + "野外生存知识"
- **文案** 长年在废墟与荒野里刨土的人，身体早就不是书房里的那具了。
- **序列** 8 考古学家 · **hook** `on_battle_start`
- **效果** 自身 `modify_stat(hp_max, +10, duration: null)`（整场）；若引擎不自动补足，则追加 `modify_resource(hp, +10, delta)`
- **翻译/语义** 原著白纸黑字的"强壮体魄"，直译为血上限。生命上限锚点 30 + 10×力量，+10 ≈ 力量 +1 档（力量3 时约 17% 血量），作为普通档骨架合理。⚠️ 需确认 `modify_stat(hp_max)` 的当前生命补足行为（与【现实知识】同一疑问）。⚠️D。

#### 【主动】考古发掘 🜂
- **原著** 序列8 考古学家 —— "拥有历史知识……"（从遗迹中获取非凡物品）
- **文案** 你的铲子磕到了什么硬物——一具沉睡千年的古物傀儡，抖落尘土站了起来。
- **序列** 8 考古学家 · **能量 3 / cd 4** · `consumption: summon`
- **效果** `spawn(unit_relic, position: 'tail', hpRatio: 0.4)`（F42 已登记；复用 C5 已实现的 `hpRatio` + `position`）
- **翻译/语义** "考古发掘"= 从遗迹里取出非凡物品。引擎里"获得一件物品"唯一可落地的形态是召唤物。⚠️ **A2 铁律**：该单位登场会 fire `on_spawn`，因此**绝不能**给它挂任何"开局"语义的光环；本途径是召唤/造物大户，本稿所有"每场一次 / 开局"效果一律走 `on_battle_start`（A1）。
- 依赖 F42 `unit_relic`（🔴）+ C5（✅）。⚠️D。

#### 【主动】仪式魔法 🜁
- **原著** 序列8 考古学家 —— "能勉强应用仪式魔法"
- **文案** 你用炭笔在脚下画了半圈残缺的仪式——它不完美，但足够让同伴的手更稳一点、刀更快一点。
- **序列** 8 考古学家 · **能量 2 / cd 4** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: atk_desc }`
- **效果** `modify_stat(attack, +2, duration: 4)` 给目标友军
- **翻译/语义** 原著强调的是"**勉强**"——故做成最朴素的单属性增益，不加任何附加效果。它在本途径的传授阶梯里是最低一档：仪式魔法 +2 → 导师 +20% 伤害 & 回能 → 教化权柄 +25% 伤害 & 回能 & 精神抗性。⚠️D。

### 精良（序列 7–6）

#### 【主动】鉴定 🜁
- **原著** 序列7 鉴定师 —— "快速鉴定神奇物品，不用占卜推理" / "直觉把握超凡物品的能力和问题，规避危险使用"
- **文案** 你扫了一眼就报出它的来路、能力与致命缺陷——那件被它当作依凭的东西，顿时失去了光泽。
- **序列** 7 鉴定师 · **能量 3 / cd 4** · `reach: ranged` · Manual（fallbackSort: `buff_count_desc`）
- **效果** `Sequence[ dispel(target, category: ['buff'], count: 1), mount_status(vulnerable, 4t) ]`
- **翻译/语义** **本途径翻译得最干净的一条**。原著"鉴定"= 看出物品的**能力**与**问题**。引擎里：看出能力 = 把那件依凭（增益）**拆下来**（`dispel`）；看出问题 = 挂易伤（×1.3 乘区）。两条合起来才是"鉴定"的完整语义，缺一条都只是半个鉴定。这也是本途径**唯一的驱散手段**。
- 依赖 C2 `dispel.category` 数组（✅）+ 排序 `buff_count_desc`（🟡，愚者稿新增项 13 已提出，同源共用）。⚠️D。
- **与相邻途径的关系** "不用占卜推理"是原著特意用来与窥秘人（占卜、窥秘）划清界限的一句——故本条**不掺任何概率/占卜语义**，是纯粹的"看一眼就知道"。

#### 【被动】危险规避 🜁
- **原著** 序列7 鉴定师 —— "规避危险使用"（直觉把握超凡物品的**问题**，从而规避危险）
- **文案** 你早就看出哪里会出事——前两次落在你身上的重击，都被你提前挪开了半寸。
- **序列** 7 鉴定师 · **hook** `on_battle_start` → `mount_status(hazard_ward, charges: 2, duration: null)`
- **效果** 状态 `hazard_ward`（整场、2 层）：触发器 `on_take_damage` → 该次伤害 ×0.5，`charges - 1`；归零卸载（C6 已实现）
- **翻译/语义** 原著"规避危险"是**事前**的、不是事后的 → 用次数型减伤（C6 `charges`，已落地）表达，而不是"受击后自疗"。整场 2 层、**不设 duration**，这样就不存在与 `on_turn_start`（G15）相关的时间尺度冲突（G15-b）。
- ⚠️ 依赖新状态 `hazard_ward`（本稿新增项 #15，🟡）；与 F 组合并候选 2（参数化减伤状态）同源，建议并入母版。⚠️D。

#### 【主动】机械奇物 🜂
- **原著** 序列6 机械专家 —— "能制造机械奇物和非凡物品"
- **文案** 你从随身的零件箱里倒出一堆废铜烂铁，三两下拧成一台会走、会站的机械。
- **序列** 6 机械专家 · **能量 4 / cd 5** · `consumption: summon`
- **效果** `spawn(unit_automaton, position: 'tail', hpRatio: 0.55)`（F43 已登记）
- **翻译/语义** 造物轴的**持久铺场件**：中血量、站得住、可被后续【机械维修】【注入灵魂】定向服务。⚠️ **A2**：禁挂任何开场光环。依赖 F43 `unit_automaton`（🔴）+ C5（✅）。⚠️D。
- **升级阶梯**（B6）
  - 「非凡物品」（同序列原著另一半）：改为不召唤单位，而是给一名友军 `mount_status(relic_armament, 6t)`（attack +4 / armor +5）—— 覆盖原著"非凡物品"这半句，同时给造物轴一条不吃召唤位的分支。
  - 「弑神之器」（序列4 原著"有高序列材料可制造对抗天使的东西"）：在非凡物品基础上追加 `modify_stat(resist:mental, +30, 6t)`。
  - ⚠️ 依赖新状态 `relic_armament`（本稿新增项 #19，🟡；退化方案为两条 `modify_stat` + `modify_resource` 直接表达，不需要新状态）。

#### 【主动】机械维修 🜂
- **原著** 序列6 机械专家 —— "能制造机械奇物"（**本稿明确引申**：能造即能养）
- **文案** 你掀开它的外壳，用扳手和焊枪在火花里把它重新拼回能站的样子。
- **序列** 6 机械专家 · **能量 2 / cd 3** · `targetSpec: { faction: ALLY, filter: MACHINE, fallbackSort: hp_asc }`

- **效果** `spawn_zone(zone_dominion)`：区域内**敌方**单位每 tick 刷新 `mount_status(vulnerable, 2t)`；区域内敌方 `modify_stat(gauge_rate, ×0.85)`
- **翻译/语义** "环境掌控者"在引擎里唯一的容器是 ZoneDef（A23 已把区域载荷清单化，**机制已存在，只缺数据**）。载荷取两件：持续暴露破绽（易伤）+ 地形拖慢（速率），都不占新机制，且与 F47 `zone_astral_field` 完全同构。
- ⚠️ 依赖新 ZoneDef `zone_dominion`（本稿新增项 #13，🟢；与 F47 同源，建议并入同一母版）。**未决**：Zone 落位是否受 **G8**（不得越中线）约束？G8 原文只约束**单位**位移，愚者【诡秘之境】已提出同一问题，需统一拍板。⚠️D。

#### 【主动】规律权柄 🜃 ★
- **原著** 序列2 知识导师 —— "'规律'权柄：改变物理规律（燃烧未必有火焰等）"
- **文案** 你改写了这里的一条规律——火，从此不再必然灼烧。
- **序列** 2 知识导师 · **能量 5 / cd 7** · `targetSpec: { faction: ALLY_ALL }`（F59）
- **效果** `mount_status(law_edit, duration: 5)` 给全体友军：`damage_taken_mul: 0.5`，**仅对指定元素生效**（技能变体决定元素：规律·无焰 `fire` / 规律·不蚀 `poison` / 规律·不流 `ice` / 规律·不击 `shock`）
- **翻译/语义** **本途径最有味道的高阶机制，也是 v0.1 完全没做的一条**。原著举的例子就是"燃烧未必有火焰"——即**现象与结果脱钩**：火还在烧，但不再造成火焰伤害。引擎里最贴近的表达就是"指定一种元素，让它对己方的伤害减半"。刻意做成**元素绑定的变体组**而不是通用减伤，正是为了保住"改写某一条**具体**规律"的原著语义——笼统的"全体减伤"是防护系途径的活，不是通识者的。
- ⚠️ 依赖**按元素过滤的伤害乘区**（本稿新增项 #3，🔴；与 F8「按伤害类型的乘区」同源，**建议并入同一母版**）。**退化方案**：退化为无条件 `damage_taken_mul: 0.75`（2t），可立即落地，代价是丢失"指定元素"的原著味、且与 F22 `sanctuary` / C3 `glibness` 撞车（F 组合并候选 2）。⚠️D。

#### 【被动】解析权柄 🜁
- **原著** 序列2 知识导师 —— "'解析'权柄增强：看到天使本质"
- **文案** 没有什么能在你面前藏住它的本质——伪装的本质是信息，而你恰好最擅长读信息。
- **序列** 2 知识导师 · **hook** `on_battle_start`
- **效果** 挂载 `analysis_authority`（整场）：敌方 `stealth` / `shadow_veil` / `untargetable` 类状态**对你无效**；你对**持有增益**的目标造成的伤害 ×1.25
- **翻译/语义** "看到本质"= 两层：① 看穿隐匿（潜行的本质是信息遮蔽，解析权柄直接读穿）；② 看穿强化（堆了一身 buff 的目标，本质被你看得更透，所以更好打）。第二层**刻意不占** `vulnerable` 的 ×1.3 乘区（避免叠乘失控），用独立乘区。这是本途径的**反隐匿 / 反增益**核心，也是它与【鉴定】的呼应（低阶拆一件，高阶看穿全部）。
- ⚠️ 依赖 C8（🟢 未实现）+ F 组合并候选 1（潜行 / 识破统一）同源；与愚者【灵体之线】同族，建议共用实现。⚠️D（1.25 为占位值）。

#### 【被动】学习权柄 🜁
- **原著** 序列2 知识导师 —— "'学习'权柄（弱化）"
- **文案** 你学得比谁都快——战斗拖得越久，你越清楚该怎么打。
- **序列** 2 知识导师 · **hook** `on_battle_start`
- **效果** 自身 `modify_stat(energy_regen, +0.3, duration: null)`（整场，**per tick**）
- **翻译/语义** 原著明确标注"**弱化**"，故只给一条朴素的速率增益，不加任何附加效果。时间单位是 **per tick** 而不是 per 回合（**G14**：tick 是最小时间单位，敏捷 0 的单位 5 tick 才出手一次；G14 已点名 v0.1 的【启蒙】文案措辞错误）。它与【唤醒记忆】（一次性大额）、【星轨推演】（不稳定小额）构成通识轴的三档节奏引擎。⚠️D（能量恢复锚点 = 0.2 + 0.2×智力 per tick，+0.3 相当于智力 +1.5）。

#### 【主动】制造权柄 🜂
- **原著** 序列2 知识导师 —— "'制造'权柄（弱化）"
- **文案** 不需要图纸，不需要材料——你说要有，于是就有了两台。
- **序列** 2 知识导师 · **能量 5 / cd 6** · `consumption: summon`
- **效果** `Repeat(2)[ spawn(unit_automaton, position: 'tail', hpRatio: 0.45) ]`
- **翻译/语义** 原著标注"**弱化**"，故与【炼成】形成清晰分工：炼成 = 就地取材、造**一个**更好的、但**临时**的（hpRatio 0.5 / 有灵魂 / 会消失）；制造权柄 = 凭空、**量产**、但单体更弱（hpRatio 0.45 / 无灵魂 / 持久）。**量产**才是"权柄"的体现。
- ⚠️ 依赖 **G3**（需确认 `Repeat` 运行时已实现，🟡；未实现则退化为并列写两条 `spawn` EffectRef）+ F43 `unit_automaton`（🔴）+ C5（✅）。**联动**：一次召唤两台 → 【熟能生巧】触发 2 次（受每场 3 次上限约束）。⚠️D。

#### 【主动】导师 🜄
- **原著** 序列2 知识导师 —— "'导师'"
- **文案** 你没有替它出手，你只是指了指——它便明白了一直没想通的那一招。
- **序列** 2 知识导师 · **能量 3 / cd 5** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: atk_desc }`
- **效果** `mount_status(tutored, duration: 5)` 给目标友军：`damage_mul: 1.2` + `modify_resource(energy, +3, delta)`
- **翻译/语义** "导师"= 教会别人，而不是替别人打。故：① 增益给**友军**不是自己；② 内容是"打得更准更狠"（`damage_mul`）+ 一点"顿悟"的能量。与【仪式魔法】（+2 攻，最朴素）、【教化权柄】（+ 智慧，永久向）构成传授阶梯的中段。
- ⚠️ 与 F14 `tutelage`（阅读者，damage_mul 1.2 / 4t）**同源**：本稿时长 5t + 附带回能，作为更高序列的档位，建议并入同一母版（本稿新增项 #16）。⚠️D。

### 传说（序列 1–0）

#### 【主动】文明图卷 🜄 ★
- **原著** 序列1 启蒙者 —— "可展现完整的文明图卷"
- **文案** 你在战场中央展开一幅完整的文明图卷：城市、田野、熔炉与学堂。同伴站在图上，忽然知道自己为何而战；而敌人脚下那些野蛮的、混乱的东西，开始自行崩解。
- **序列** 1 启蒙者 · **能量 6 / cd 8**
- **效果** `Sequence[` 己方全体 `modify_stat(attack, +3, duration: 6)` + `modify_stat(defense, +3, duration: 6)`（F59 `ALL_ALLIES`）, `dispel(敌方全体, category: ['buff'], count: 1)`（`ALL_ENEMIES`）`]`
- **翻译/语义** "**完整的**文明图卷"= **群体双维增益**（攻击 + 防御：文明是全面的，不是单一的）；外加"文明对照之下，野蛮自行崩解"= 驱散敌方全体一层增益。文明权柄原著三分支（混沌沉淀秩序 / 毁灭焕发新生 / 黑暗迸发光芒）中，"**混沌沉淀出秩序**"这一支就落在这里（抹去敌人身上混乱的增益）；另两支分别见【毁灭新生】与「本稿遗留」。
- ⚠️ 依赖 F59 `ALL_ALLIES`（🟡）+ `ALL_ENEMIES`（本稿新增项 #17，🟡，与 F59 同源建议成对实现）。⚠️D。

#### 【主动】毁灭新生 🜄
- **原著** 序列1 启蒙者 —— "'文明'权柄：让混沌沉淀秩序、毁灭焕发新生、黑暗迸发光芒"
- **文案** 文明从不畏惧终结——废墟之上，你的同伴重新站了起来。
- **序列** 1 启蒙者 · **能量 6 / cd 8** · `targetSpec: { faction: ALLY_ALL }` + 死亡友军
- **效果** `heal(8)` 给全体友军（**A22：治疗必须用 `heal` 原语**）+ `If(存在已死亡的友军)` → `spawn(reviveOf: 该友军, hpRatio: 0.4, position: '原坐标')`
- **翻译/语义** 文明权柄三分支里的"**毁灭焕发新生**"：群体治疗 + 一名友军复活。复活走 **G4** 已拍板的 `spawn.reviveOf` 方案（严守九原语纪律，不新增第 10 个原语）——本稿只是**引用**，不重复立项。这也是本途径唯一涉及复活的地方。
- ⚠️ 依赖 G4 `reviveOf`（🔴 未实现）+ C5（✅）。**退化方案**：去掉复活分支，改为 `heal(12)` 全体 + 驱散友军全体 1 个 debuff，语义仍落在"焕发新生"上，**建议先上退化版**验证强度。⚠️D。

#### 【主动】教化权柄 🜄
- **原著** 序列1 启蒙者 —— "'教化'权柄：提升目标智慧，给予启迪灵感"
- **文案** 你点亮了它的脑子——它还是它，但它忽然看懂了眼前这场战斗，甚至想到了你没教过的打法。
- **序列** 1 启蒙者 · **能量 5 / cd 7** · `targetSpec: { faction: ALLY, selectionMode: Manual, fallbackSort: atk_desc }`
- **效果** `mount_status(enlightened, duration: 6)` 给目标友军：`damage_mul: 1.25` + `modify_stat(energy_regen, +0.3, duration: 6)` + `modify_stat(resist:mental, +20, duration: 6)`
- **翻译/语义** "提升**智慧**"在原著里很抽象、在引擎里却很好落：打得更好（`damage_mul`）+ 想得更快（能量恢复）+ 不容易被迷惑（精神抗性）。三条合起来才是"智慧提升"，只给增伤就丢了原著味。它是**永久向的教化**（6t + 抗性），与【导师】（短期教学）的时长/强度阶梯清晰。
- ⚠️ 依赖新状态 `enlightened`（本稿新增项 #16，🟡；与 F14 `tutelage` 同源，建议并入母版）。⚠️D。

#### 【主动】完美之境 🜃
- **原著** 序列0 完美者 —— （"完美"：己方趋近完美，敌方显出残缺）
- **文案** 你在战场上写下"完美"二字——你的同伴忽然没有短板，而敌人身上每一处将就，都被照了出来。
- **序列** 0 完美者 · **能量 6 / cd 8**
- **效果** 己方全体 `mount_status(shield, +6, 5t)` + `modify_stat(gauge_rate, +6, 5t)`；敌方全体 `modify_resource(armor, -8, delta)` + `modify_stat(gauge_rate, -6, 5t)`
- **翻译/语义** 序列0 在 brief §3.0 里属"位格碾压，**不搬**"（1v1 场景下只能做成"数值更大的同一件事"，不如只借名字）。故本条**不试图还原"完美者"的位格**，只借"完美"这个**概念**做一张双向战场改写卡：己方补齐短板（护盾 + 提速），敌方暴露残缺（破甲 + 减速）。这是本途径唯一的全场双向技能，也是序列0 的招牌大招。
- ⚠️ `gauge_rate` 用速率不用 current（**G6 / INV-S5 合规**）；依赖 `ALL_ENEMIES`（本稿新增项 #17，🟡）+ F59。⚠️D。

#### 【被动】现实知识 🜁
- **原著** 序列0 完美者 —— "'现实知识'权柄：掌握现实世界全部知识并可**修改**"
- **文案** 你知道这个世界全部的图纸——包括你自己那一张。于是你提笔，把上面几个数字改了一下。
- **序列** 0 完美者 · **hook** `on_battle_start`
- **效果** 自身 `modify_stat(hp_max, +20, duration: null)` + `modify_stat(energy_max, +20, duration: null)` + `modify_stat(attack, +3, duration: null)`（整场）
- **翻译/语义** 原著两个动词都要落地：① "**掌握**全部知识" = 你什么都懂（自身全面强化）；② "可**修改**" = 改的不是临时状态而是**基础值**（`duration: null`，整场生效、不是可驱散的 buff）。这条是本途径传说档的**构筑地基**——拿到它，任何 Build 都会被整体抬高，符合"一局最多 1 张"的定位。
- ⚠️ 数值 ⚠️D（20 血 / 20 能 / 3 攻为占位量级，**明显偏高**，必须过验证脚本重定）；需确认 `modify_stat(hp_max, duration: null)` 是否自动补足当前生命（同【荒野体魄】的疑问，两处一并核实）。

#### 【被动】现实规律 🜃
- **原著** 序列0 完美者 —— "'规律'权柄（偏现实）"
- **文案** 开战之前，你就已经改写了现实世界里那条与你为敌的规律——从此，这种东西伤不到你的同伴。
- **序列** 0 完美者 · **hook** `on_battle_start`
- **效果** 己方全体 `modify_stat(resist:<构筑时选定的元素>, +40, duration: null)`（整场）
- **翻译/语义** 序列2【规律权柄】的同源高阶版，差异正是原著标注的"**偏现实**"：序列2 是战斗中临时改写一条规律（5t、指定元素、减半）；序列0 是战斗**开始前**就已改好、整场有效、幅度更大（抗性 +40）。元素在**构筑时选定**（不是战斗中选），这让它成为一张强力的针对卡——而这正是"现实世界的规律"该有的形态：它先于这场战斗存在。
- ⚠️ 依赖：① `StatKey: resist:<元素>` 的既有能力（✅）；② 施加给全体友军依赖 F59 `ALL_ALLIES`（🟡）；③ "构筑时选定元素"属肉鸽派发层配置（B1–B6，已拍板独立成 `progression` 上下文），需与派发层约定变体 ID。⚠️D（抗性纪律 ±10~±20%，+40 明显越线，是为传说档刻意留的，需复核；**若最终裁定不越线，建议下调至 +25 并改为仅自身**）。

## 三、跨途径共享（相邻途径：窥秘人，同属知识荒野）

通识者与窥秘人同属源质「知识荒野」，核心象征各占一半（通识者 = 知识 / 制造 / 文明 / 规律；窥秘人 = 神秘知识 / 窥秘 / 信息 / 预言）。共享用 `sharedAcross: ['seer']` 声明：

| 技能 | 共享给 | 理由 |
|---|---|---|
| 鉴定 | 窥秘人 | 窥秘人序列7「巫师」本身就是"法术**解析**与创造"，与"看出能力与问题"的鉴定语义高度重合；且这是两条途径共有的**驱散**刚需 |
| 遗迹禁忌知识 | 窥秘人 | 窥秘人序列9 即"魔法、巫术、占星术等**神秘知识**全面掌握"，禁忌知识属同一知识域 |

## 四、本稿遗留

- **数值全档待标**：36 个技能的能量 / 伤害 / 时长 / 层数 / 抗性均为占位建议值，统一 ⚠️D，需过验证脚本重定。其中 `gauge_rate` 类技能（星之祝福 / 环境掌控 / 完美之境）的定价**无既有锚点**（沿用 D2），是本稿最大盲区；【现实知识】的 +20 血 / +20 能 / +3 攻 与【现实规律】的 +40 抗性均为明显越线的占位量级，必须优先重定。
- **⚠️ 命名冲突：`petrify` vs `petrification`（必读）**
  - 本途径 v0.1 登记了 F20 `petrify`（结晶，`heal_received_mul: 0.5`），服务于 v0.1 的【物质嬗变】。
  - **本版已删除【物质嬗变】**——对照表里序列4 炼金术士只有"炼成 / 注入灵魂 / 高序列材料造物"三条，**没有任何"物质转化 / 结晶 / 禁疗"的依据**，属 v0.1 的偏离原著设计。
  - 因此：**本途径 v0.2 不再使用 `petrify`**。若没有其他途径主张，建议注销 F20；若刺客途径的 `petrification`（石化）需要这个 ID 词根，可直接释放给它。**落地前必须裁定一次**，否则会出现两个同词根、语义完全不同（禁疗 vs 石化）的状态并存。
- **A2 / `on_spawn` 纪律（本途径是重灾区）**：本稿有 5 个 skill 会 `spawn`（考古发掘 / 机械奇物 / 炼成 / 制造权柄 ×2 / 毁灭新生的复活分支）。所有"开局 / 每场一次"语义**一律**走 `on_battle_start`（A1），**禁止**用 `on_spawn` 表达。全稿唯一使用 `on_spawn` 语义的是【熟能生巧】，且它的语义正是"造物登场"——这是 `on_spawn` 的正确用法，已在正文中标为正面用例。
- **序列覆盖不均**：序列 7（鉴定师）只有 **2 个**技能（鉴定 / 危险规避），是全稿最薄的一档。原因是原著序列7 只有三个语义点（快速鉴定 / 直觉把握能力与问题 / 规避危险），本稿用 2 个技能覆盖完毕；若后续要补，建议拆出「器物鉴定」（群体版：敌方全体挂易伤 + 驱散 1 个 buff）。序列 2 反而最厚（5 个），因为原著在这一档列了 5 项能力。
- **未单独成技能的原著能力**（有意省略，留待后续）：
  - 序列1 文明权柄三分支中，"**黑暗迸发光芒**"未单独立项（"混沌沉淀秩序"已并入【文明图卷】、"毁灭焕发新生"已并入【毁灭新生】）。建议作为【毁灭新生】的**变体**：对敌方全体 `damage(element: mental, 5)` + 驱散其隐匿 / 潜行类状态。
  - 序列0 的"下位：学习 / 制造 / 解析"——已由【学习权柄】【制造权柄】【解析权柄】承载，**不重复立项**。
  - 序列9 "对神秘学有粗略了解"——已并入【遗迹禁忌知识】的抗性表现，未单独立项。
  - 序列8 "历史知识"——仅作为【考古发掘】的 flavor，无独立机制维度。
  - 序列4 "有高序列材料可制造对抗天使的东西"——作为【非凡物品】的升级阶梯「弑神之器」存在，未单独立卡。
  - **位格碾压**（序列1–0 的权柄级描述）依 brief §3.0 **一律不搬**，只借概念不借位格。
- **「材料 / 品质」系统只做了一层**：用户提示希望造物有"材料 / 品质"概念，但引擎当前没有材料资源维度。本稿只做了一层（【制造大师】的品质加成 +【注入灵魂】的点活 +【灵魂熔炉】的回收），**完整的"消耗材料换取更高品质"需要新的资源维度**，本稿未立项（那属于战斗外的构筑层，建议归入 `progression` 上下文讨论）。
- **未决机制**：
  - 【环境掌控】的 Zone 落位是否受 **G8** 约束（G8 原文只约束单位位移）——与愚者【诡秘之境】是同一个问题，需统一拍板。
  - 【汲取】需确认 `drain` 默认把 hp 转移给施法者（F49 只登记了 `resource` 字段扩展）。
  - `modify_stat(hp_max)` 是否自动补足当前生命（影响【荒野体魄】【现实知识】两条）。
  - 【毁灭新生】的复活分支依赖 G4 `reviveOf`（🔴），**建议先上退化版**（全体治疗 + 驱散 debuff）验证强度。
- **概率项需 R3 登记**：全稿仅 2 处引入概率——【星轨推演】`p: 0.4`（回能）、【星之诅咒】`p: 0.35`（附加易伤），二者均属**非伤害维度**，符合 R5；需在落地时登记进 `RandomUsageRegistry`。
