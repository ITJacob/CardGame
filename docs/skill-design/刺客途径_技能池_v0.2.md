# 刺客途径（魔女）· 技能池 v0.2

灵感源：ima 知识库《诡秘之主职业路径与能力对照表》→ **刺客途径**（源质「灾祸之城」，旧日「毁灭天灾」，序列0 魔女，相邻途径 = 猎人）。
框架：`docs/ddd/`（战斗内核 DDD 终版）+ `_GENERATION_BRIEF.md`；旧框架编号（A/C/D/E/F/G 组）的现落点见 brief §7（v1.5 旧档、原《框架改动记录》与 `src/` 实现均已删除，原文可在 git 历史查阅）

> **本版定位**：v0.2 是**原著校准版**。v0.1 的四条轴（潜行爆发 / 教唆操纵 / 诅咒负面 / 情感欲望）是**按卡牌功能倒推**的，结果与原著能力表对不上——原著刺客途径的核心象征是「**魅惑、混沌、镜中世界、灾难**」，v0.1 却把「镜中世界」整条主轴丢了个干净，也没落地黑焰 / 冰霜 / 疾病 / 瘟疫 / 石化 / 灾难 / 混沌，只剩一堆抽象的「诅咒 debuff」和凭空发明的「痛苦链接」。本版做三件事：
> ① 逐序列 9→0 比对原著能力表，把**镜中世界**作为主轴重做，补齐黑焰 / 冰霜 / 疾病 / 瘟疫 / 石化 / 灾难 / 末日 / 混沌 / 原初；
> ② 剔除 v0.1 中偏离原著的设计（痛苦链接体系、言语傀儡、巧言、影舞等）；
> ③ 把原著的具体手段（镜子替身法、镜像迷宫、投影传送、镜中人复活、无形蛛丝三用、头发为武器、诅咒不可替身转移）还原成可落地的机制。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / 时长 / 层数）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「效果」= 引擎落地表达。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【被动】羽毛般轻盈 🜄
- **原著** 序列9 刺客 —— "短时间内改变身体获得**羽毛般轻盈**" / "**灵巧步伐**"
- **文案** 你的身体轻得没有分量，出手总比对手快上半拍；而刀锋及体的瞬间，你已踩着灵巧的步子退了开去。
- **序列** 9 刺客 · **hook** `on_battle_start`（A1）
- **效果** `mount_status(featherlight, charges: 3, duration: null)`（整场）：
  - `modify_stat(gauge_rate, +6, duration: null)`（轻盈 = 出手更频繁）
  - 触发器 `on_take_damage` → `move(push_back, distance: 1)` 对**自身**（己方半场内后撤一格，G8 合规），随后 `charges - 1`（C6）
- **翻译/语义** 原著"羽毛般轻盈"与"灵巧步伐"是同一套身法的两个说法，本版合为一条。卡牌里没有跳跃高度、没有闪避判定，轻盈最贴的翻译是**节奏**（`gauge_rate`，INV-S5 合规——改的是速率源属性，不是派生的行动周期）；"灵巧步伐"则落成受击后自动后撤，用 C6 `charges: 3` 表达"整场只能闪三次"，防无限风筝。
- ⚠️ 数值锚点 **D2**（`gauge_rate` 修正定价 🔴 未标）。需确认**状态触发器载荷内调用 `move`** 是否走 G8 的 faction 校验（本稿新增项 16）。

#### 【被动】鹰的视力 🜄
- **原著** 序列9 刺客 —— "固化**鹰的视力和黑暗视觉**"
- **文案** 鹰的瞳孔在你的眼底凝固，黑暗与隐匿都瞒不过你——连躲进镜子里的人，你也能一眼看见。
- **序列** 9 刺客 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `eagle_sight`（整场）：敌方 `stealth` / `shadow_veil` / `untargetable` 类状态，以及**处于 `mirrored`（镜中囚禁）状态的单位**，对你一律无效——你可以选中并攻击它们
- **翻译/语义** 与愚者【灵视】【灵体之线】同需求，共用 C8 候选池过滤的「识破」分支。本途径额外多一层：**黑暗视觉 = 能看见镜中的人**——这让本稿的 `mirrored` 状态（敌人被拉进镜中世界）不至于变成"全场无敌"，是本途径内部的一个自洽制衡。
- ⚠️ 依赖 **C8**（🔴 未实现）。与愚者稿同源，**建议合并实现**。

#### 【主动】阴影躲藏 🜄
- **原著** 序列9 刺客 —— "擅长**躲藏阴影**"
- **文案** 你缩进阴影里，呼吸与夜色融为一体——下一次出手，从暗处刺出，格外致命。
- **序列** 9 刺客 · **能量 2 / cd 3** · `targetSpec: SELF`
- **效果** `mount_status(shadow_hide, charges: 1, duration: 2)`：
  - `target_exclusion: true`（敌方单体技能不可选中你，依赖 C8）
  - 持有期间你的下一次攻击 `damage_mul: 1.5`（`charges: 1`）
  - 触发器 `on_deal_damage` → 立即卸载（出手即暴露）
- **翻译/语义** 原著序列9 的"躲藏阴影"是低配隐匿：短、脆、一次性的偷袭窗口。与序列7 的【隐形】是同一能力的两个序列档，故本条做成"短隐匿 + 一次性爆发"，不做减伤。
- ⚠️ 与 **F4** `shadow_veil`（不眠者）、**F11** `stealth`（秘祈人）同源，**建议并入统一潜行母版**（F 组合并候选 1）。

#### 【主动】力量爆发于一击 🜄 ★
- **原著** 序列9 刺客 —— "**力量爆发于一击**"
- **文案** 你把全身的力量压进这一击里——若此刻你正藏在阴影或隐形之中，这一刀会从背后刺入，重得让人直不起腰。
- **序列** 9 刺客 · **能量 4 / cd 4** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: physical, 5)` + `If(self_has_status: [shadow_hide, invisible])` → `damage(element: physical, 4)` 追加
- **翻译/语义** **原著"力量爆发于一击"就是背刺的原型，v0.1 完全没有它**，是本稿最重要的补漏。定位 = 本途径的低序列输出地基：4 能量 5 伤（1.25 汇率，贴合基准 1.2），藏在阴影里追加 4 伤（合计 9）作为"前置条件"的回报——前置成本是必须先花一回合和 2 能量进入隐匿。
- **G8 合规** "贴近目标完成背刺"是**近战攻击进程**（flavor，不调 `move`、不改站位，依 G7/G9 先例）。
- ⚠️ `self_has_status` 谓词（本稿新增项 12，🟡；与 F52 `target_has_status` 同源）。**退化方案**：改为无条件 `damage(physical, 7)`，失去"必须先在阴影里"的玩法门槛。

#### 【主动】魅惑 🜂
- **原著** 序列8 教唆者 —— "**魅惑**"
- **文案** 你冲它笑了一下。它愣住了，转过身，把刀挥向了离自己最近的同伴。
- **序列** 8 教唆者 · **能量 3 / cd 4** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(charm, duration: 2)`（**F15** 已登记）+ `damage(element: mental, 1)`
- **翻译/语义** 直接复用 F15（反向嘲讽：被魅惑单位攻击其**己方队友**），零新机制。1 点精神伤害只是点题，主体是目标改写。与【误导】的差异：魅惑是**改打谁**，误导是**让它打空**。
- ⚠️ 依赖 **F15**（🔴，`target_override` 状态族；与 C7 / F3 / F9 / F19 同族，F 组合并候选 3）。

#### 【主动】误导 🜂
- **原著** 序列8 教唆者 —— "**误导、说服**"
- **文案** 你轻声说了句话，它便深信不疑——于是刀锋挥向了你身后那片根本不存在的阴影。
- **序列** 8 教唆者 · **能量 2 / cd 3** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(mislead, charges: 1, duration: 3)`；`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]`
- **翻译/语义** 复用 **C7 已验证**的 `target_override → first_empty`（打空）。原著教唆者的"误导 / 说服"在卡牌里没有心理可骗，出口只有目标系统——让它打空，就是最贴的"被误导"。
- **与愚者【制造幻觉】的关系** 同机制不同途径。愚者是"看见不存在的景象"，刺客是"被说服去砍不存在的敌人"；原著两者分属不同途径且各自明写，故不合并。

#### 【主动】激化矛盾 🜂 ★
- **原著** 序列8 教唆者 —— "擅长**诱发心底恶欲，激化矛盾，挑起冲突**"
- **文案** 你在它耳边说了句什么。它心底那点见不得光的欲望腾地烧起来——它红着眼扑向同伴，招式凶狠，却门户大开。
- **序列** 8 教唆者 · **能量 3 / cd 4** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `Sequence[`
  - `mount_status(charm, duration: 2)` —— **挑起冲突**（转头打自己人）,
  - `modify_stat(attack, +3, duration: 2)` —— **诱发心底恶欲**（失去理智地猛攻）,
  - `modify_stat(defense, -3, duration: 2)` —— **激化矛盾**（只顾攻、不顾守，门户大开）`]`
- **翻译/语义** 原著这一句是序列8 的核心，三个子句在引擎里恰好各有一个落点，本版**全部落地**。诱发的恶欲不是纯增益——`attack +3` 与 `defense -3` 成对出现，让被魅惑的敌人在"打队友打得更狠"的同时"更容易被你们打死"，收益与风险都归你。这是 🜂 轴的旗舰。
- ⚠️ 依赖 **F15** + **G3**（`Sequence` 需确认运行时已实现）+ `modify_stat` 带 duration 的回滚（v1.5 已修）。

#### 【被动】说服 🜂
- **原著** 序列8 教唆者 —— "魅惑、**说服**"
- **文案** 你说服它，而不是控制它——所以它信得更久，也更难被旁人点醒。
- **序列** 8 教唆者 · **hook** `on_battle_start`（A1）
- **效果** 挂载 `persuasion`（整场）：你施加的**所有 `target_override` 类状态**（`charm` / `mislead`）`duration +1 tick`
- **翻译/语义** 原著把"魅惑"与"说服"并列，但两者在机制上不好拆成两张牌。本版把"说服"做成 🜂 轴的**增幅器**：魅惑 2t→3t、误导 3t→4t，一次抬升整个控制体系的时长。与【反复魅惑】（序列5）形成"时长 + 深度"的双层递进。
- ⚠️ 需要"**按状态族过滤的 duration 加成**"（本稿新增项 19，🟡）。**退化方案**：改为"你施加的 `charm` duration +1"，只对该一个状态 id 生效，实现成本低但失去族级扩展。

### 精良（序列 7–6）

#### 【主动】隐形 🜄
- **原著** 序列7 女巫 —— "**隐形**"
- **文案** 你的身影在空气中化开，连轮廓都不剩——而当你重新出现时，刀已经递到了它的后心。
- **序列** 7 女巫 · **能量 3 / cd 4** · `targetSpec: SELF`
- **效果** `mount_status(invisible, charges: 1, duration: 3)`：
  - `target_exclusion: true`（C8）
  - `damage_taken_mul: 0.7`（隐形期间受创减免）
  - 下一次攻击 `damage_mul: 1.5`（`charges: 1`）
  - **不会**因出手而自动卸载（与【阴影躲藏】的关键差异：消耗的是"爆发层"，不是隐形本身）
- **翻译/语义** 序列7 的"隐形"是序列9"躲藏阴影"的质变版：更长（3t vs 2t）、带减伤、且出手不破除——这正是"低序列潜行"与"女巫法术"的位阶差。与【阴影躲藏】共用一次性的 `damage_mul ×1.5` 爆发层，使两条隐匿牌都能直接喂给【力量爆发于一击】。
- ⚠️ 与 **F4** `shadow_veil` 同源（F 组合并候选 1）；🟡 状态 `invisible` 建议并入统一潜行母版。

#### 【主动】黑焰 🜃
- **原著** 序列7 女巫 —— "**操控黑焰**"；序列6 欢愉 —— "黑焰可**如子弹射出** / **驱除诅咒**"
- **文案** 一簇漆黑的火苗在你掌心燃起，它没有温度，却把碰到的东西连同诅咒一起烧成灰烬。
- **序列** 7 女巫 · **能量 3 / cd 3** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `damage(element: fire, 4)` + `{ ref: 'apply_burn', condition: { kind: 'chance', p: 0.4 } }`
- **翻译/语义** **原著招牌能力，v0.1 完全没有**。元素的取舍：引擎没有 `dark`，黑焰落 `fire`（与猎人的橙红火焰共用元素维度，但**不共享给猎人**——猎人稿已明确谢绝，见第三节）。"黑焰"的辨识度来自**外观与技能名**，不靠元素。
- **升级阶梯（B6）** 伤害 4 → 6；并解锁两个**同名原著分支**：
  - 「**黑焰弹**」（序列6）：追加对目标身后相邻单位 `damage(fire, 2)`（`spread: splash_adjacent`）
  - 「**驱除诅咒**」（序列6）：追加 `dispel(self, category: ['debuff','dot','control'], count: all)`（C2 已实现）
  - 两个分支把序列6 的"黑焰子弹化 / 驱除诅咒"并入同一张牌的升阶，避免为两条单行能力各占一个池位。
- ⚠️ 概率写法依 **G1 更正**（EffectRef 的 `condition`，不是不存在的 `Chance()` 算子）；R3 登记，R5 限非伤害维度 ✔。数值 ⚠️D。

#### 【主动】冰霜 🜃
- **原著** 序列7 女巫 —— "**操控冰霜**"
- **文案** 寒气顺着你的指尖爬上它的四肢，动作一点点凝滞下来。
- **序列** 7 女巫 · **能量 3 / cd 3** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: ice, 3)` + `modify_stat(gauge_rate, -6, duration: 3)`
- **翻译/语义** **同上，v0.1 完全没有的招牌减速**。"操控冰霜"在引擎里的正解不是"冻结"（无此状态），而是**减速**：`gauge_rate -6` 让目标出手更慢。**INV-S5 合规**——改的是速率源属性，不是派生的行动周期。与【黑焰】构成"火 dot / 冰减速"的元素对位。
- ⚠️ 数值锚点 **D2**（🔴）；`modify_stat` duration 回滚（v1.5 已修）。

- **原著** 序列5 痛苦 —— "**疾病**：制造多种病原体，**加速感染爆发**，2-3 分钟可致猝死"

  - 触发器 `on_remove` → `damage(element: poison, 4)`（**感染爆发**；"2-3 分钟可致猝死"）
  - `category: ['dot','debuff']`（可驱散——但见【不可转移的诅咒】）
- **翻译/语义** **原著招牌，v0.1 完全没有，是本稿最大的补漏之一**。原著"疾病"的三个子句在引擎里恰好各有一处落点：① "制造多种病原体" = poison 属性的持续伤害（本稿统一：疾病 / 瘟疫 / 病原体 → **poison**）；② "加速感染爆发" = dot 逐 tick **递增**，而非固定值（这是疾病区别于 `burn` / `中毒` 的唯一机制特征，也是"加速"的正解）；③ "2-3 分钟可致猝死" = 到期时一次性爆发高伤。总计 4 tick 内 1+2+3+4=10 伤 + 爆发 4 伤 = 14 伤 / 4 能量，**明显偏高，⚠️D 必须重定**（建议 dot 降为 1/1/2/2、爆发降为 3）。

- **翻译/语义** 镜中世界权柄的**主场形态**：不是放逐一个人（那是序列3 的【镜中囚禁】），而是把**整个战场折进镜子里**一瞬间——全体敌人被抹掉 1 tick 的存在，全体友军被推前 20 点行动条。它是本途径唯一的"全场节奏改写"，也是 🜁 轴的终局。
- **⚠️ G5/G6 合规** 推的是**全体友军**（含自己，但自己回合释放时条已清零，自推无效——这正是 G5 铁律的边界）；本条的有效收益全部落在"推友军 + 打断敌人"上，**不依赖自推**。
- ⚠️ 依赖 `mirrored`（本稿新增项 3，🔴）+ **F59** `ALL_ALLIES`（🟡）+ **G3**（`Sequence`）。数值 ⚠️D。

#### 【被动】原初·静止 🜄 ★
- **原著** 序列0 魔女 —— "**原初**权柄：**静止 / 停滞 / 全能**，下位为『石化』"
- **文案** 每一次有生命在你面前熄灭，就有一个正要行动的身影被钉在原地——不是被抓住，是被**停住**了。
- **序列** 0 魔女 · **hook** `on_kill`（**A4** 已实现）
- **效果** 每当你击杀一个单位 → 对**行动条最接近满的敌方单位**（`fallbackSort: gauge_desc`）`modify_resource(gauge.current, -999, delta)` + `modify_stat(gauge_rate, -15, duration: 3)`
- **翻译/语义** 原著"原初"的三个面相里，"全能"在 1v1 卡牌里无法落地（brief 明确：位格碾压不搬），故只取**静止 / 停滞**——而这两者在引擎里恰好有**零新机制**的完美表达：把行动条清零（立即停住）+ 把速率压低（持续停滞）。**INV-S5 合规**：改的是 `gauge.current` / `gauge_rate` 两个源属性，不碰派生的行动周期。
- **与【石化】的关系** 原著明写"下位为『石化』"，所以本条与【石化】是同一权柄的两档：石化是"让一个人的身体变成石头"（定身 + 减伤），原初·静止是"让一个即将行动的身影停在时间之外"（节奏归零）。一硬控、一软控，刻意不做成同一条。
- ⚠️ 需确认 `gauge.current` 负 delta 的**下限截断为 0**（F55 已就 `energy` 提出同一问题，建议一并覆盖 `gauge.current`）；数值锚点 **D2**（🔴）。
