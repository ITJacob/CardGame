> 技能总量 **34 个**（主动 21 / 被动 13；+1 = 2026-09-08 界域牌批次新增【血月当空】）。药师途径在原著里是**治疗与召唤双修**的途径，且序列7–4 各有一整套独立招牌（吸血鬼 / 魔药教授 / 深红学者 / 巫王），要「遵照原著」就必须给足覆盖；单局构筑密度由派发权重控制，池子大小不影响 4+4 槽位。

### 核心机制：五种月相（本途径最有味道的机制）

原著序列0「月亮」明写 **血月 / 红月 / 银月 / 满月 / 缺月** 五种月相状态。**月相是挂在自身、彼此互斥的形态组**（`moon_phase` 组，同组挂载新的顶掉旧的，全场同时只存在一相）。

| 月相 | 原著出处 | 加成（⚠️D 全档待标） | 设计依据 |
|---|---|---|---|
| 🌑 **血月** | 序列0 五种月相 | 你造成的伤害 ×1.2；`drain` 类回复量 +2 | 血 = 掠夺、进攻 |
| 🌘 **红月** | 序列0 五种月相 | 你**施加的减益状态** `duration +2` | 红 = 侵蚀、持久 |
| 🌗 **银月** | 序列0 五种月相 | `energy_regen +0.2` / tick；`resist:mental +20` | 银 = 灵性澄澈（对应「灵性权柄」） |
| 🌕 **满月** | 序列5「满月：让范围处于满月状态」/ 序列0 | 你的 `heal` 治疗量 ×1.4 | 满 = 圆满、治愈（对应「难以想象的恢复能力」） |
| 🌒 **缺月** | 序列0 五种月相 | 你受到的伤害 ×0.8；敌方单体技能难以选中你（依赖 C8） | 缺 = 消退、隐匿（对应「黑暗」权柄） |

**切换规则（三条，可并存）**

| 规则 | 说明 |
|---|---|
| ① 自发周期（默认） | 持有 `moon_cycle`（由传说被动【月相·轮转】挂载）时，每 **6 tick** 沿 **血月 → 红月 → 银月 → 满月 → 缺月 → 血月** 循环轮转一相 |
| ② 主动切换 | 【主动】满月（序列5）可**强制切至满月**并重置周期计数；轮转从满月继续往下走。这是唯一一档主动切换技（治疗向，对应原著序列5 明写的「满月」） |
| ③ 条件触发 | 自身生命**首次**低于 30% 时，立即切至**满月**（求生本能 → 治疗强化），并保持到下一次自发轮转 |

> **为何只有「满月」能主动切**：原著序列5 只写了「满月」这一条月相法术（「让范围处于满月状态」），血月 / 红月 / 银月 / 缺月四相只在序列0 被列出名称、未给出各自的法术形态。故本版把主动切换权只给满月，其余四相交由【月相·轮转】的自发周期驱动（见「四、本稿遗留」将其列为升级阶梯分叉）。
>
> **未持有 `moon_cycle` 时**：【满月】仍可正常切至满月并享受满月加成，只是不会自发轮转 —— 保证稀有档的【满月】可以单卡成立，不成为传说被动的专属配件。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；⚠️D = 数值为占位建议值；★ = 该轴的旗舰技能

### 普通（序列 9–8）

#### 【主动】药剂调配 🜄
- **原著** 序列9 药师 —— 「擅长调配药剂」
- **文案** 你随手把几味药材捣碎调匀灌了下去，苦涩的暖流立刻淌遍全身。
- **序列** 9 药师 · **能量 2 / cd 2 / 吟唱 0** · `targetSpec: { faction: ALLY }`（Manual，fallbackSort: `hp_asc`）
- **效果** `heal(4)`
- **翻译/语义** 本途径的治疗地基。治疗密度刻意压到 2 能量 → 4 治（≈1.0/能量），低于「3 能量 = 5 伤」的直伤锚点 —— 治疗不白嫖直伤是通用纪律（沿用 brief §2）。⚠️D。严格遵守 **A22**（治疗必须用 `heal` 原语）。

#### 【主动】草药敷贴 🜄
- **原著** 序列9 药师 —— 「驯化使用植物治病」
- **文案** 你嚼碎一把活着的苔草敷上伤口，叶片仍在微微抽动，把生机一点点渡进血肉里。
- **序列** 9 药师 · **能量 3 / cd 3 / 吟唱 0** · `targetSpec: { faction: ALLY }`（Manual，fallbackSort: `hp_asc`）
- **效果** `Sequence[ heal(3), mount_status(再生, duration: 3) ]`
- **翻译/语义** 原著「**使用植物**治病」而非「调配药剂」—— 故做成「即时小治 + 持续恢复」两段，与【药剂调配】的纯瞬发区分。复用既有 `再生`（2/tick × 3t = 6）。⚠️D。

#### 【被动】毒素抗性 🜄
- **原著** 序列9 药师 —— 「毒素抗性强」
- **文案** 你常年与毒草为伴，寻常的毒已经毒不倒你；而每次中毒，身体都会自己把它解掉。
- **序列** 9 药师 · **hook** `on_battle_start`（A1，已落地 ✅）
- **效果** `modify_stat(resist:poison, +20, duration: null)` + 挂载 `antivenom`（整场）：触发器 `on_take_damage` → 若该次伤害 element 为 `poison`，则 `heal(1)`（自行解毒）
- **翻译/语义** 原著白纸黑字的「毒素抗性强」，直接落 `resist:poison`（StatKey 已支持 `resist:<元素>`）。「自行化解」那半用 `on_take_damage` 的小额回血表达，避免抗性堆到免疫。⚠️D。

#### 【被动】健康灵视 🜄 ★
- **原著** 序列9 药师 —— 「健康领域『灵视』」
- **文案** 你能看见别人身上的病气与裂口在哪里 —— 伤得越重的人，你越知道该怎么救。
- **序列** 9 药师 · **hook** `on_battle_start`
- **效果** 挂载 `health_sight`（整场）：你施放的 `heal` 若目标当前生命 < 50%，治疗量 ×1.5
- **翻译/语义** 原著「**健康领域**的灵视」= 看穿伤势。卡牌里无隐藏信息，故把「看得准」翻译成「对重伤目标治疗加成」—— 这条是本途径**治疗大户**定位的核心乘区，让【药剂调配】【草药敷贴】在残血时才真正爆发，符合救援手感。⚠️D。

#### 【主动】驯兽哨 🐾
- **原著** 序列8 驯兽师 —— 「驯化使用活着的动物（含超凡生物）」
- **文案** 你吹响骨哨，林子里那头被你驯过的狼循声而来，龇着牙站到了你身前。
- **序列** 8 驯兽师 · **能量 3 / cd 4 / 吟唱 0** · `consumption: summon`
- **效果** `spawn(unit_beast, position: 'tail')`（F38，✅ 纯数据 H1 召唤物基线）
- **翻译/语义** 原著强调的是「**活着的**动物」而非构装体 —— 故本途径的召唤物统一走动物/灵界生物线，不走魔像线。3 能量换一个站场单位（基准 3 能量 ≈ 6 伤），符合「召唤本身是硬资源」的定价。⚠️ A2 提醒：**禁止**给召唤物挂任何「开局」语义的状态（会随每次登场重复触发）。

#### 【被动】动物感官 🐾 ★
- **原著** 序列8 驯兽师 —— 「『动物感官』：读懂野兽想法，沟通 / 驱使 / 分享感官」
- **文案** 你与它们共享着同一副感官 —— 谁咬住了你，你的兽群就先一步知道。
- **序列** 8 驯兽师 · **hook** `on_battle_start`
- **效果** 挂载 `beast_sense`（整场）：
  - 己方**动物类 / 召唤物**单位 `modify_stat(attack, +1, duration: null)` + `modify_stat(gauge_rate, +5, duration: null)`（驱使）
  - 触发器 `on_take_damage`（自身）→ 己方全体召唤物 `modify_resource(gauge.current, +10, delta)`（分享感官：感知到威胁，抢先扑上）
- **翻译/语义** 原著三件事（读懂想法 / 沟通驱使 / 分享感官）在卡牌里只有后两件可落地：**驱使** = 召唤物属性增益；**分享感官** = 你挨打时召唤物被推行动条（抢先出手）。注意这里是**推友军**不是推自己 —— 严格遵守 **G5/G6**（主动/被动都不做自推条，自推条在自己回合等于没加）。⚠️D。
- ⚠️ 「动物类 / 召唤物」过滤（✅ 新增项 10，已落 ddd：编队参数 §1.2b `unitType` + 共享内核参数 §一 `filter.isSummon` / `casterOwned`）。**退化方案**（全体己方）仍备。

### 精良（序列 7–6）

#### 【被动】血族体质 🜸
- **原著** 序列7 吸血鬼 —— 「生命提升（活 300 岁）／出色体质、速度、敏捷」
- **文案** 三百年的岁月在你血管里沉淀 —— 你的身躯比看上去结实得多，出手也比任何人预想的快。
- **序列** 7 吸血鬼 · **hook** `on_battle_start`
- **效果** `modify_stat(hp_max, +15, duration: null)` + `modify_stat(armor, +3, duration: null)` + `modify_stat(gauge_rate, +5, duration: null)`
- **翻译/语义** 原著「活 300 岁」是寿命设定，卡牌无寿命维度，折算为**生命上限 + 体质（护甲）**；「速度、敏捷」折算为 `gauge_rate`。**严格遵守 INV-S5**：改的是 `gauge_rate` 这一源属性，绝不直接修正派生的行动周期。⚠️D（`gauge_rate` 定价无既有锚点，见 D2）。

#### 【被动】血族魅力 🜸
- **原著** 序列7 吸血鬼 —— 「颜值魅力提升」
- **文案** 你抬起眼的那一瞬，最先冲上来的那个敌人愣住了 —— 它对着空气狠狠挥出一击。
- **序列** 7 吸血鬼 · **hook** `on_battle_start`
- **效果** 对**敌方攻击力最高**的单位（`sort: atk_desc`）挂载 `captivated`（`charges: 1`、`duration: 5`）：`behaviorModifiers: [{ op: 'target_override', anchor: 'first_empty' }]` —— 其**下一次**攻击落空
- **翻译/语义** 「颜值魅力提升」在卡牌里唯一的出口是「让对方失神」。复用 **C7（已验证 ✅）** 的 `target_override → first_empty`。用 `charges: 1`（C6 已实现）表达「一次」，`duration: 5` 满足 **G15-b**（≥ 目标一个行动周期约 5 tick，避免状态先过期）。与序列1「美之权柄」是同一主题的低阶表现（见【美之震撼】）。⚠️D。

#### 【主动】腐蚀之爪 🜸 ★
- **原著** 序列7 吸血鬼 —— 「『腐蚀之爪』」
- **文案** 你的指甲暴长成漆黑的利爪，撕开的不只是皮肉 —— 连同它身上的护甲一并锈成了渣。
- **序列** 7 吸血鬼 · **能量 3 / cd 2 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `armor_desc`）
- **效果** `damage(element: poison, 4)` + `modify_stat(armor, -2, duration: 3)`
- **翻译/语义** **本稿最重要的补漏之一**，v0.1 完全没有。原著「腐蚀」的对象是**实体**（护甲、器物），所以不是挂中毒 dot，而是直接削 `armor` —— 这是本途径唯一的破甲手段，也是血月轴的输出地基。近战定位：本途径整体偏后排，需要一件贴身件。⚠️D。

#### 【主动】深渊枷锁 🜸
- **原著** 序列7 吸血鬼 —— 「『深渊枷锁』」
- **文案** 深渊里伸出漆黑的锁链，缠住它的四肢拖向黑暗 —— 它每动一下都比刚才更沉。
- **序列** 7 吸血鬼 · **能量 3 / cd 4 / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `gauge_desc`）
- **效果** `damage(element: none, 2)` + `mount_status(shackle, duration: 2)`（F7，✅ 已落 ddd：H24 减速族，编队参数 §1.1b `gaugeRateMul × moveImmune`）
- **翻译/语义** 原著明写的招牌控制。直接引用 **F7 `shackle`**（✅ H24，禁位移 + `gaugeRateMul`），**不重复立项**。元素是 `none`（深渊/黑暗），引擎无 dark 元素且**不新增**（沿用 F63 的否决口径：不轻易扩元素枚举，见「四、本稿遗留」）。⚠️D。

#### 【主动】黑暗之翼 🜸
- **原著** 序列7 吸血鬼 —— 「『黑暗之翼』」

- **退化方案** 若引擎不支持削减 `hp_max`（或不会同步截断当前生命），「缩短」改为 `damage(element: none, 6)` + `mount_status(易伤, 3t)`，代价是丢掉「年岁被抽走」的原著味。

## 四、本稿遗留

**数值**

- 33 个技能的能量 / 伤害 / 治疗量 / 时长 / 层数**全档为占位建议值，统一 ⚠️D**，需过验证脚本重定。
- 最大盲区是 **`gauge_rate` 类修正的定价**（血族体质 +5 / 深红体质 +10 / 黑暗之翼 +6 / 预服药水 +8）：沿用 **D2**，该维度当前无任何可靠锚点。
- **治疗量的定价锚点缺失**：brief §2 只给了「伤害 = 1.2 × 能量」，治疗侧全稿各途径各自为政。本稿统一按「治疗 = 1.0 × 能量」粗定（低于直伤汇率），但【创生】的 5 能 / 8 治 + 削上限、【生命之权】的 6 能双目标超出了这个口径，需单独标定。
- **月相各相加成**（血月 ×1.2 / 满月 ×1.4 / 缺月 ×0.8 / 红月 +2t / 银月 +0.2 能量）与**轮转周期 6 tick** 均为纯设计推导，无原著数值依据，见下方「原著存疑」。

**原著存疑 / 需回查（4 条）**

1. **五种月相各自的差异，原著未给出。** 对照表序列0 只列了「血月 / 红月 / 银月 / 满月 / 缺月」五个**名称**，没有说明各相有什么效果。本稿的「血月 = 攻击、满月 = 治疗、缺月 = 减伤、红月 = 减益延长、银月 = 灵性」全部是**依据相名与序列5「满月」那条推出来的设计**，不是原著原文。**这是本稿最大的原创成分**，若后续查到原著对月相有明确描述，需按原著回改。
2. **「血月 / 红月 / 银月 / 缺月」四相目前没有独立的主动卡。** 原著序列5 只写了「满月」一条月相法术，其余四相只在序列0 被列出名称。按「稀有度 = 序列位阶」的硬规则，它们只能落在传说档；本稿选择把四相交给【月相·轮转】的自发周期驱动，并把「四相单独成卡」列为【满月】的 B6 升级阶梯分叉（见该条）。
3. **序列5「闪现（月光范围内）」的「月光范围」原著未定义。** 本稿将其绑定为「友军所在处」（用 `swap_ally` 落地）。若原著中「月光范围」指的是【满月】法术照亮的区域，则【闪现】应改为「仅在你处于满月相时可用」—— 另一套更贴原著的写法，但会让卡面条件过于苛刻，本稿未采用，记此备查。
4. **序列8「驯化使用活着的动物（含超凡生物）」与序列3「从灵界召唤强大生物」的边界**原著未划清。本稿按序列位阶分工：序列8 = 普通动物（`unit_beast`）、序列3 = 灵界生物（`unit_elder_thing`）、序列4 蝙蝠分解 = 二者的中间形态（`unit_bat`）。

**机制未决项**

- **`modify_stat(hp_max, 负值)` 的语义未确认**（【创生】【生命之权】的「缩短 / 收回生命」分支）：引擎是否会在 `hp_max` 下降时同步截断当前生命？不确认则这两条无法落地，退化方案见【创生】条。
- **【蝙蝠分解】的「重组」判定**：需要「场上存活的 `unit_bat` 数量 > 0」这一谓词。若引擎无法在 `on_death` 时序内做单位计数查询，需退化为「持有 `swarm_form` 期间免死一次」（丢掉「除非全杀」的对抗面）。
- **复活 / 免死优先级链未定**：本稿的 `lethal_protect` 系（月光化 / 月亮纸人 / 蝙蝠分解 / 生命之权）与 C4 `miracle`、G4 `reviveOf` 跨途径共存时谁先结算，需框架层统一裁定（沿用愚者稿【命运锚点】提出的同一问题）。
- **本稿未使用 `on_turn_start`**：全部 33 个技能的触发点落在 `on_battle_start` / `on_kill` / `on_tick` / `on_take_damage` / `on_deal_damage` / `on_death` 六个**已确认会 fire** 的节点上，从设计源头规避了 **G15**（`on_turn_start` 是死触发点，会导致 36 个跨途径被动完全不生效）。同理，本稿**未引入任何概率**（药师途径原著无概率主题），规避 R3/R4/R5 的登记与审计成本。
