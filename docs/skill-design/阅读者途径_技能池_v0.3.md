# 阅读者途径（白塔）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入混沌海系核心机制 **「放牧」(Grazing)** 维度（全局唯一跨系借技能，本途径经 combo 卡与其联动）；
> ③ 新增 **跨系 combo 卡**（混沌海↔源堡 模仿/寄生、混沌海内部 放牧/解析）；
> ④ 补 1–3 张主题界域牌（星界/知识类）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》与《混沌海系技能设定》§5；跨系机制依据《九大源质总览》《源堡系技能设定》。
>
> **本版定位**：v0.2/v0.3 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **知识** 🜁 | `知识`(knowledge, 自身计数) | 阅读/推理/仪式魔法/武器精通 → 累积 `知识` 或刷新 `observed`(解析快照) | 若\[知识≥N\] 解析还原事件、推理加成、精神直伤 ×1.2 | 守知者 |
| ② **模仿** 🜃 | `模仿`(mimic, 自身槽, potency) | 解析对手能力 → 存入 `模仿` 槽(`observed` 快照) | 若\[模仿槽含X\] 以递增百分比释放 X（20%→100%） | 全知之眼 |
| ③ **预言** 🜄 | `预言`(prophet, 自身/友军) | 预言 → 给友军挂 `预言`/先手 | 看到未来最可能几种可能，推友军抢先手 / 规避 | 预言家 |
| ④ **规律** ★核心 🜂 | `规律`(law, 敌方标记) | 洞悉 → 给敌方挂 `规律`(弱点暴露) | 若\[规律\] 撬动规则(降甲/降全抗/穿透护盾)、敌人弱点暴露 | 洞悉者 |

> **全知/规律/解析 主题贯穿**：知识轴承载"解析/全知"的信息面，规律轴承载"规律权柄"的改写面，预言轴承载"预知/最优解"的节奏面——三者共同构成阅读者的**全知**内核；模仿轴是其招牌的"以彼之道"。
> **混沌海系签名维度 = 放牧(Grazing)**（见下方维度说明）：阅读者本身无 `放牧` 轴，但经 combo 卡（【解析·跨系共鸣】）读取友方秘祈人的 `放牧` 槽，实现"解析被放牧灵魂 → 模仿其能力"的跨系联动。

### 本系咬合器维度说明（混沌海系 §2.2 + 九大源质总览 §1 万能接口 ⑥）

**签名机制 = 放牧 (Grazing)**：动态能力槽，存储**任意途径的灵魂** → 用其能力。全局唯一"跨系借技能"机制（归属秘祈人，混沌海五途径互为相邻，其余四途径经 combo 卡借用）。

| 层级 / 效果 | 说明（照搬总览，不另立标准） |
|---|---|
| **enabler** | 吞噬单位灵魂入 `放牧` 槽（秘祈人·放牧灵魂），写入方=秘祈人 |
| **容量阈值** | 随序列 5→1 上限 7→9→13→18→22，同时驱使数 1→3→全部外放 |
| **payoff（跨系借技能）** | 释放被放牧单位的能力（数量随序列升）；放牧源堡系→临时用提线/寄生，放牧永暗之河→临时用亡灵，放牧本系→临时用雷霆/模仿 |
| **本系其他联动切入点** | ① 净化/雷霆 克死灵（↔永暗之河/暗影世界）；② 寄生/血肉寄生（↔源堡偷盗者，跨源质）；③ 阅读者的 `解析/模仿` 可读取友方秘祈人 `放牧` 槽中的灵魂快照 |

> 阅读者作为混沌海途径，在 §三 通过 `crossPathway:true` 读取 `放牧`/`寄生`/`提线木偶` 等枢纽状态，形成跨系 combo（非复刻）。
