# 猎人途径（红祭司）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入灾祸之城系核心机制 **「集众（Gathering）」团队资源池**（全局唯一团队接口）；
> ③ 新增 **跨系 combo 卡**（猎人↔母巢 兽群、猎人↔永暗之河 死灵黑焰）；
> ④ 补 2 张主题界域牌（战争迷雾 / 操纵天气）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《灾祸之城系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **收割** | `弱点`(weak_point, 敌方标记, 可叠层) | 猎人的感官 / 结构要点 / 弱点侦察 → 给目标挂 `弱点`+破甲 | 若\[目标 `弱点`\] → 收割追加伤害 / 毁灭之矛直接致死 | 毁灭之矛 |
| ② **阴谋** | `挑衅`(taunt, 敌方, duration) | 挑衅 → 挂 `挑衅`+嘲讽+易伤 | 若\[`挑衅`\] → 误导打空 / 煽动打队友 | 挑衅 / 误导 |
| ③ **燃焚** | `火焰`(flame, 武器/敌, 可叠层) | 火鸦术 / 注火 / 燃烧之墙 → 挂 `火焰`+burn | 若\[`火焰`\] → 炽白之枪破甲 / 紫色火焰全系升档 | 紫色火焰 |
| ④ **集众** ★核心 | `集众`(massing, 团队资源池, 随存活友军累积) | 集众·铁血 → 挂载 `集众`：集中全队力量/共享视野/分摊伤害 | 若\[`集众`≥N\] → 借用能力 / 无限制分享 / 战争权柄 | 集众·铁血 |

> **集众维度（灾祸之城系 §2.2 / 总览 §1）**：团队资源池机制（全局唯一），由本途径技能写入 `集众` 状态（enabler），随**存活友军数**累积；到阈值触发团队效果（payoff）。层级（照搬总览，以「存活友军数=集中到的队伍力量」建模）：
> - **集众槽 ≥2**（队伍含 ≥2 存活友军集中）：解锁【借用能力】——读取队友一项长板
> - **集众槽 ≥3**：解锁【无限制分享】——自身增益自动分发全队、全队互摊伤害
> - **集众槽 ≥4（集众质变）**：全体友军伤害 ×1.2 + 自身受伤 ×0.8（整体乘区）
>
> **跨源质写入方**：母巢药师「兽群」可纳入集众池（见 §三 集众·兽群 crossPathway），使猎人成为全 22 途径最通用的组队核心。另 地狱之火 ↔ 永暗之河 收尸人「亡灵」（见 §三 地狱之火·亡者）。

## 一、技能池

图例：⚠️ = 需框架扩展（注编号或本稿新增项）；★ = 该轴旗舰；**E** = enabler（挂载/累积身份状态）；**P** = payoff（读取身份状态放大）。

### 普通（序列 9–8）

#### 【被动】猎人的感官 🏹 收割 · **E**
- **原著** 序列9 猎人 —— "感官直线提升：分辨气味、看到浅脚印、听见心跳微风"
- **文案** 你能听见它的心跳，闻得到它三天前留下的气味——再会藏的猎物，在你眼里也像踩在雪地上一样清楚。
- **序列** 9 猎人 · **hook** `on_battle_start`
- **效果** 挂载 `hunter_sense`（整场，`dispelable: false`）：敌方 `stealth` / `shadow_veil` 等隐匿、不可选中类状态**对你无效**；你的单体技能自动优选**当前生命值最低**的敌方单位（`fallbackSort: hp_asc`）
- **翻译/语义** 感知能力拆两条：① "看到隐藏"=识破隐匿（C8 候选池过滤）；② "听见心跳"=目标优选。同时给收割轴起手挂 `弱点` 基础标记，让 payoff 有起手层。⚠️D。

#### 【被动】结构要点 🏹 收割 · **E**
- **原著** 序列9 猎人 —— "能直观找到结构要点"
- **文案** 你一眼就看出它护甲衔接处的那条缝——你的每一次攻击，都落在最不该被砸的地方。
- **序列** 9 猎人 · **hook** `on_battle_start`
- **效果** 挂载 `structural_eye`（整场）：你的攻击**无视目标 50% 的护甲**（`armor_pierce: 0.5`）
- **翻译/语义** "直观找到结构要点"=打在结构最薄弱处=破甲。收割轴低序列地基。⚠️ 依赖 `armor_pierce`（H16）。⚠️D。

#### 【被动】野外生存 🏹 收割 · **E**
- **原著** 序列9 猎人 —— "身体素质全面超越常人（熊的强壮 + 猫的轻灵）/ 野外生存知识"
- **文案** 你在林子里活下来的每一年都还在这副身体上：熊一样的力气，猫一样的敏捷。
- **序列** 9 猎人 · **hook** `on_battle_start`
- **效果** 自身 `modify_stat(hp_max, +10, duration: null)` + `modify_stat(attack, +1, duration: null)` + `modify_stat(gauge_rate, +6, duration: null)`
- **翻译/语义** 熊的强壮=hp+atk，猫的轻灵=（INV-S5 合规）落 `gauge_rate`。⚠️D（gauge_rate 定价 D2）。

#### 【主动】扑杀 🏹 收割 · 输出地基
- **原著** 序列9 猎人 —— "身体素质全面超越常人（熊的强壮 + 猫的轻灵）"
- **文案** 你像熊一样压上去，又像猫一样快——它还没看清你的动作，已经被撞翻在地。
- **序列** 9 猎人 · **能量 ⚠️D / cd ⚠️D / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_asc`）
- **效果** `damage(element: physical, ⚠️D)`
- **翻译/语义** 低序列唯一输出手段，纯伤害撑骨架（同愚者【飞牌】口径）。⚠️D。

#### 【主动】挑衅 🕸 阴谋 ★ · **E**
- **原著** 序列8 挑衅者 —— "『挑衅』（核心）：洞察目标敏感点，激怒对方失去理智"
- **文案** 你一句话精准戳在它最不敢被人提起的地方——它红了眼，脑子里只剩下弄死你，破绽和队形都忘了。
- **序列** 8 挑衅者 · **能量 ⚠️D / cd ⚠️D / 吟唱 0** · `reach: ranged` · Manual（fallbackSort: `atk_desc`）
- **效果** `mount_status(taunt, ⚠️D t)` + `mount_status(vulnerable, ⚠️D t)` + `modify_stat(attack, -2, ⚠️D t)` + `modify_stat(defense, -2, ⚠️D t)`（挂载阴谋轴身份状态 `挑衅`）
- **翻译/语义** 原著"挑衅"四合一：嘲讽（强攻你）+ 易伤（戳中弱点）+ 失去理智（降攻降防）。同时挂 `挑衅` 供【误导】【煽动】改写目标。⚠️D。

#### 【被动】羞辱 🕸 阴谋 · **P**
- **原著** 序列8 挑衅者 —— "被动效果 + 主动激发（辱骂语言 + 羞辱行为）"
- **文案** 它每打中你一次，你就笑着再补一句——它越怒，露出的破绽越大。
- **序列** 8 挑衅者 · **hook** `on_take_damage`（作用于攻击者）
- **效果** 对攻击者 `mount_status(vulnerable, ⚠️D t)`（读 `挑衅` 状态放大：被挑衅者每击你更脆）
- **翻译/语义** 挑衅闭环：挑衅把它拉来打你，羞辱让每次被它打你都更脆。⚠️ 依赖 F61 `attacker`。⚠️D。

## 三、跨途径共享（灾祸之城 + 跨系 combo）

猎人（红祭司）与刺客（魔女）同属灾祸之城，相邻可互换。共享用 `sharedAcross`；跨系 combo 卡通过 **`StatusDef.crossPathway:true`** 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 挑衅 / 羞辱 / 误导 / 煽动 | 刺客 | 同属情绪/目标改写，零额外成本 |
| 猎人的感官 / 结构要点 / 弱点侦察 / 收割 | 刺客 | 低序列感知与开窗口同源 |
| 操纵天气 | 刺客 | 刺客序列2 灾难=同权柄两名字，共用 ZoneDef 母版 |
| 钢铁勇气 | 刺客 | 同需"不被恐惧击倒" |
| **集众·兽群** | **母巢 药师/耕种者** | 跨系 combo：读 `beast_swarm` 升级集众（兽群枢纽） |
| **地狱之火·亡者** | **永暗之河 收尸人** | 跨系 combo：读 `亡灵/奴役` 升级火焰为燃灵（见 §三 登记） |

> **枢纽状态（落地优先级最高）**：`集众(massing)` / `替身` / `混乱` / `恶欲值` / `命运` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单（见《九大源质总览》§3）。`替身` 由刺客【镜面替身·改】与占卜家【纸人替身】、律师【替身定义】共写；`集众` 由猎人写入、母巢兽群可读。
