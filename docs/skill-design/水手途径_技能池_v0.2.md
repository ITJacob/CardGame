> **本版定位**：v0.2 是**原著校准版**。v0.1 把这条途径翻译成了一套"通用物理近战 + 通用回血 + 通用群体洗地"，与原著差距大——原著白纸黑字的招牌（幻鳞、愤怒爆发 / 暴怒一击、天文地理直觉、风之掌控三件套、闪电掌控与克亡灵、歌唱三义、风刃军团、连环闪电、真正飞行、披甲、海王领域、毁灭水滴、音爆、恐惧之音、天灾降临三灾、天罚、光之化身、暴君权柄三义、物质权柄）**大部分没有落地**，反而塞进了原著根本没有的东西：序列8 放雷电技能（原著序列5 才有闪电掌控）、给一条"风暴、海洋、雷电"的途径做了两发 `heal`（**原著水手途径没有任何治疗能力**）、把核心的"愤怒"机制完全丢掉、只做收益侧不做代价侧。本版做三件事——
> ① 逐序列比对原著能力表，**补回全部被漏掉的招牌能力**；
> ② **删除 v0.1 凭空发明的原著外设计**（序列8 的雷鸣、海洋战歌的 heal、潮汐号令的群体加攻、天候本能的自推条、雷神之权的追伤、暴君之躯的纯数值堆血）；
> ③ 把原著的具体手段还原成可落地机制，而不是抽象成"风暴 → 群体伤害 + 减速"。
>
> **数值纪律**：本文所有数值（能量 / 伤害 / tick / 层数 / 时长、抗性百分比）**一律为占位建议值，统一归类为 ⚠️D 待标**，需过验证脚本后重定。**本版先锁的是"技能效果"**，不是数值。
>
> 「原著」行 = 原著能力依据（引用自上述对照表）；「文案」= 玩家视角描述，肉鸽派发展示用；「序列」= 序列位阶 + 触发点 / 能量消耗；「效果」= 引擎落地表达；「翻译/语义」= 为什么这么映射、绑定了哪个数值锚点。

> **元素口径（三元素分工，全稿统一）**：风 = `physical`、雷 = `shock`（**F63 已否决新增 `lightning`，本稿遵守**）、水 = `water`（**F63 已 ✅ 落地**）。全稿**零 `heal`**（原著水手途径无治疗能力）、**零概率**（原著能力无掷骰成分，符合 R5 精神）、**零 `on_turn_start`**（主动规避 G15）。

### 本途径的两条辨识度机制

**① 愤怒（rage）：越挨打越强，攒够就清算**

这是本途径最有原著味的资源机制（序列8 暴怒之民 → 序列2 愤怒之源 → 序列0 暴君权柄的"愤怒"），也是 v0.1 完全丢掉的东西。

- **写入**：`on_take_damage` → `rage` +1 层（【愤怒爆发】，整场上限 5 ⚠️D）；【暴怒挥击】命中 +1 层；【愤怒之源】把每次受击改为 +2 层、上限 +3。
- **读取**：每层提供 `attack +1` / `gauge_rate +2`（⚠️D）——对应原著"愤怒时**力量和速度**极大提升"。
- **清算**：【暴怒一击】消耗全部层数，把层数换成一击的伤害。
- **⚠️ INV-S5 合规**：改的是 `gauge_rate` 源属性，**不是派生的行动周期**。
- **⚠️ 主依赖**：`rage` 需要"按层数动态提供属性"（本稿新增项 1，已落 ddd：H34 statPerStack）。**退化方案**：`rage` 仅作计数，满 5 层时挂 `frenzy`（`attack +3` / `gauge_rate +8`，duration 3）——零新字段，代价是失去"越叠越强"的连续成长感。

**② 三元素分工 + 水→雷导电联动**

- 风 = `physical`（狂风 / 风刃 / 飓风盘绕 / 风刃军团 / 龙卷风 / 音爆）
- 雷 = `shock`（雷电之矢 / 雷击 / 连环闪电 / 闪电风暴 / 天罚 / 风暴地狱）
- 水 = `water`（海啸 / 毁灭水滴 / 海王领域 / 天灾降临·雪难与海啸）
- **联动**：处于 `drowning`（溺沉，**复用 F13**，已登记）状态的目标受到 `shock` 伤害时追加伤害（【连环闪电】）——原著"水能导电"，让 🜄 与 🜂 两轴能互相喂，而不是各打各的。

## 一、技能池

图例：⚠️ = 需要框架扩展（注明改动记录编号或本稿新增项）；★ = 该轴的旗舰技能；⚠️D = 数值占位待标

### 普通（序列 9–8）

#### 【被动】卓越力量 🜃
- **原著** 序列9 水手 —— "卓越力量：远超常人的力量"
- **文案** 经年累月在甲板上拽缆绳练出来的臂力——战斗一开始，你的力量便压过常人。
- **序列** 9 水手 · **hook** `on_battle_start`（A1 ✅ 已落地）
- **效果** `modify_stat(attack, +2, duration: null)`（⚠️D）
- **翻译/语义** 原著"远超常人的力量"的直译，无翻译损耗。定位是本途径的**输出地基**：让【风刃】【暴怒挥击】这类低费直伤技在后期仍值得占槽。与愚者【灵视】（+5 能量）同量级、方向互补。升级阶梯（B6）：+2 → +3 → +4。

#### 【被动】幻鳞 🜃
- **原著** 序列9 水手 —— "平衡+幻鳞（难以被抓握）"
- **文案** 你身上覆着一层滑腻的幻鳞，谁也抓不牢你——推搡、拖拽、擒抱，都从你身上滑开。
- **序列** 9 水手 · **hook** `on_battle_start`
- **效果** 挂载 `scale_veil`（整场）：`move_immune: true`（难以被抓握）+ `damage_taken_mul: 0.9`（⚠️D，滑不溜手）
- **翻译/语义** 原著这行有两个词，分别落两条：① "平衡 + 难以被抓握" → 免疫位移（抓不住就无从谈起推、拉、擒抱）；② "幻鳞" → 一层轻减伤。减伤刻意低于 `vulnerable` 的反向量级，避免变成免伤板。
- ⚠️ 依赖 `move_immune`（本稿新增项 4，已落 ddd：H27 moveImmune，与愚者途径 v0.2 新增项 6 同源并入；与 F7 `shackle` 的"禁位移"是同一字段的正反两面）。减伤部分建议并入 F 组合并候选 2 的「参数化减伤状态」母版。

#### 【主动】水中灵活 🜄
- **原著** 序列9 水手 —— "水中灵活如海族，无保护下潜 15 米"
- **文案** 你像海族一样滑进浪里，闪到一处更安全的落脚点，只留下一片抓不住的水影。
- **序列** 9 水手 · **能量 2 / cd 3 / 吟唱 0** · `move.param`（目标为**己方半场内**的指定空位）
- **效果** `move(param → 己方半场指定空位)`（G8 合规：同 faction）+ `mount_status(elusive_wake, charges: 1, duration: 3)`：触发器 `on_take_damage` → 该次伤害 ×0.5，消耗一层（C6 ✅ 已落地）
- **翻译/语义** 原著"水中灵活 / 下潜"是**机动性**，不是攻击，故**零直伤**——2 能量的预算全买"自由落点 + 一次闪避"。闪避用 C6 `charges: 1` 表达"一次性的水影"。
- ⚠️ G8：`move.param` 的落点必须限定己方半场（G8③ 建议在 `handleMove` 入口统一加 `to.faction === from.faction` 校验，覆盖全部依赖 `param` 默认分支的技能）。

#### 【被动】愤怒爆发 🜁
- **原著** 序列8 暴怒之民 —— "'愤怒爆发'：愤怒时力量和速度极大提升"
- **文案** 每一次挨打都在你胸腔里添一把火——愤怒越盛，你的力量与出手速度就越惊人。
- **序列** 8 暴怒之民 · **hook** `on_battle_start` + `on_take_damage`（自身）
- **效果** `on_battle_start` → 挂载 `rage`（`category: 'buff'`，`maxStacks: 5` ⚠️D，`duration: null` 整场）；`on_take_damage` → `rage` 层数 **+1**（达上限不再增）；`rage` **每层**提供 `attack +1` / `gauge_rate +2`（⚠️D）
- **翻译/语义** 愤怒轴的**资源引擎**。原著"力量与速度"→ 卡牌里对应 `attack` 与 `gauge_rate`；"越挨打越强" → 由 `on_take_damage` 叠层。**INV-S5 合规**（改的是源属性，不是派生的行动周期）。整场不衰减，是为了让"先挨打攒怒、后清算"的节奏成立。
- ⚠️ 依赖：F51 `mount_status.stacks`（编队上下文 §六）+ **按层数缩放属性 `statPerStack`**（本稿新增项 1，已落 H34）。**退化方案**：`rage` 仅作计数，满 5 层时挂 `frenzy`（`attack +3` / `gauge_rate +8`，duration 3，零新字段，代价是失去连续成长感）。

#### 【主动】暴怒挥击 🜁
- **原著** 序列8 暴怒之民（愤怒积攒机制在低序列的常规表达）
- **文案** 你带着火气抡出一记重击——挨打的人疼，你自己却越打越上头。
- **序列** 8 暴怒之民 · **能量 3 / cd 2 / 吟唱 0** · `reach: melee`
- **效果** `Sequence[ damage(element: physical, 4), mount_status(rage, stacks: +1) ]`（后者作用于自身）
- **翻译/语义** 本途径的「火球术」级基础循环件。3 能量 × 1.2 = 3.6 伤害预算，这里给 4 直伤 + 1 层愤怒（按"1 层 ≈ 1 点后续伤害"折算，略超但层数的兑现依赖后续受击与【暴怒一击】，属延时收益）。cd 2 使其可反复刷层，是愤怒轴的循环件。

#### 【主动】暴怒一击 🜁 ★
- **原著** 序列8 暴怒之民 —— "'暴怒一击'：积攒愤怒后的恐怖一击"
- **文案** 你把积压的怒火一次性倾泻出去——这一击有多重，取决于你挨过多少打。
- **序列** 8 暴怒之民 · **能量 3 / cd 4 / 吟唱 0** · `reach: melee` · Manual（fallbackSort: `hp_desc`）
- **效果** `If(自身 rage 层数 > 0)` → `Sequence[ damage(element: physical, 3 + 2 × 层数), status.consume(rage, all) ]`；`else` → `damage(element: physical, 3)`（⚠️D）
- **翻译/语义** **愤怒轴旗舰**，也是本途径最有味道的一张卡。原著"积攒愤怒后的**恐怖一击**" = 层数换伤害的**清算技**，与【愤怒爆发】（叠层）构成完整回路：先挨打攒怒，再一次性倾泻。刻意做成近战（清算要贴脸），与【风刃】（远程、无附加）形成"风险换爆发"的选择。
- ⚠️ 依赖：`If` 算子（✅）+ **`damage.valueFrom: { statusStacks: 'rage' }` 的跨效果传值**（本稿新增项 2，已落 ddd：效果参数 §1.1 valueFrom statusStacks，H26）+ F48 消耗层数（效果上下文 §2.1）。
- ⚠️ **分档退化方案**（若跨效果传值不落地）：改用条件谓词 `self_status_stacks_range` 分档——0 层 3 伤 / 1–2 层 6 伤 / 3–4 层 9 伤 / 5 层及以上 13 伤（谓词已落：§三 `has_status` 层数比较 cmp/n）。
- ⚠️ **定价红线**：层数上限在【愤怒之源】+3、【暴君权柄】+5 后可达 13 层 → 3 + 2×13 = 29 伤 / 3 能量，**严重越线**。落地前必须在参数层给"每层换算系数"与"层数上限"同时设 clamp（建议系数降到 1.5、上限锁 8），否则本卡不可标定。

### 精良（序列 7–6）

#### 【被动】天文地理直觉 🜂
- **原著** 序列7 航海家 —— "天文地理直觉：对磁场、洋流、风向有直觉，永不迷路"
- **文案** 你读得懂磁场、洋流与风向——战斗一开始就抢到先手，而任何想把你的节奏推离航道的手段都会落空。
- **序列** 7 航海家 · **hook** `on_battle_start`

- **翻译/语义** **权柄轴旗舰**。原著"万王之王"括号里的三个词**逐条落地、一条不落**。这是本稿唯一同时改写三条机制的传说被动，也是 🜃 权柄轴与 🜁 愤怒轴的**交汇点**——它让愤怒轴在传说档仍有成长空间，而不是在序列8 就封顶。

- **退化方案**：若 `statPerStack` 不落地，把"每层 +5% 伤害"改为"层数 ≥5 时挂载 `frenzy`（`damage_mul: 1.25`，duration 3）"，零新字段。

#### 【主动】物质转化 🜃
- **原著** 序列0 暴君 —— "'物质'权柄：物质与能量相互转化，覆盖基本力"
- **文案** 你改写了它护甲的"定义"——那些甲片不再保护它，而是变成了刺向它自己的刀。
- **序列** 0 暴君 · **能量 5 / cd 6 / 吟唱 ⚠️D** · `reach: ranged` · Manual（fallbackSort: `hp_desc`）
- **效果** `Sequence[`
  - `dispel(target, category: ['buff'], count: all)`（读取并清除**护盾**值，计入 N）,
  - `modify_resource(armor, -99, delta)`（清除**护甲**值，计入 N）,
  - `damage(element: physical, N)` `]`，其中 **N = 本次被清除的护盾 + 护甲总量**（⚠️D，建议设上限）
- **翻译/语义** 原著"物质与能量**相互转化**"——本稿对这条权柄最干净的落地是：把对方的**防御性物质转化为攻击性伤害**。与【毁灭水滴】区分见该条。

- **退化方案**：固定 `damage(element: physical, 6)` + 清除防护，强度低一档但仍可用（此时它退化为【毁灭水滴】的 `physical` 版本）。
- ⚠️ 另需新 targetSpec 排序 `armor_desc`（本稿新增项 14，已落 ddd：§一 sort 行含 armor_desc，可选——不做则按 `hp_desc` 兜底，代价是"专打重甲"的语义丢失）。

## 四、本稿遗留

- **数值全档待标**：36 个技能的能量 / 伤害 / tick / 层数 / 时长 / 抗性百分比**全部**为占位建议值，统一 ⚠️D，需过验证脚本重定。
- **群体溢价是最大盲区**：【风刃军团】【海啸】【闪电风暴】【音爆】【天灾降临】【风暴地狱】六张群体卡的定价只做了单体折算，未乘目标数，沿用 D4 盲区；**群体护盾**（【水幕】）与**群体沉默**（【音爆】）完全没有既有锚点（沿用 D3）。
- **`gauge_rate` 类定价无锚点**：【加速与滑翔】(+8)、【光之化身】(+8)、【海王领域】(×1.1 / ×0.9)、【天灾降临·雪难】(×0.85)、【风暴地狱】(×0.9)、`rage` 每层 +2，全部沿用 D2 的 `gauge_rate` 修正定价盲区。
- **【暴怒一击】的数值红线**：【愤怒之源】(+3 上限)、【暴君权柄】(+5 上限) 叠加后层数可达 13，按"3 + 2×层数"折算 = 29 伤 / 3 能量。**落地前必须同时 clamp 换算系数与层数上限**（建议系数降至 1.5、全局上限锁 8），否则本卡不可标定。
- **`rage` 的 `statPerStack` 是本稿最大落地风险**：它同时卡住【愤怒爆发】【暴怒挥击】【愤怒之源】【暴君权柄】四条。退化方案（满层挂 `frenzy`）已在各条内写明，可用但会损失"越叠越强"的连续成长感——这是本途径最核心的手感，建议优先实现主方案。
- **`dread` 的"不可锁定施法者"依赖 C8**（🟢 已登记未实现）；未落地则【恐惧之音】退化为纯削攻 + 输出衰减。
