# 收尸人途径（序列0：死神）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入永暗之河系核心机制 **「隐秘值」战场维度**（secrecy 0–10，主消费方之一）；
> ③ 新增 **跨系 combo 卡**（永暗之河↔源堡 提线木偶、永暗之河↔混沌海 净化克死灵、永暗之河↔灾祸之城 黑焰）；
> ④ 补 1 张主题界域牌（冥界之门）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；序列映射依据《永暗之河系技能设定》《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

> **v2 修订要点**：战士已移入永暗之河系，不眠者/收尸人/战士聚齐为「死亡·黑暗·灵体」承接组；本系是源堡系 `提线木偶 / 灵体之线` 的天然宿主，**提线木偶枢纽在收尸人侧**（奴役轴）。

### 四条构筑轴（新版：轴 = 钩子，非标签）

每条轴有**身份状态**；enabler 卡挂载/累积该状态，payoff 卡读取该状态放大。状态名即轴身份，便于跨系可读。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **灵视** 👁 | `灵视`(spirit_sight, 灵性) | 天然灵视 / 死亡之眼 / 通灵 → 挂 `灵视` | 若\[灵视\] 借灵施法 / 揭示弱点 / 压制具备灵者 | 通灵 |
| ② **尸骸** 🦴 | `尸性`(corpse_trait) | 尸体特质 → 自身挂 `尸性` | 若\[尸性\] 承受死息 / 肉体打击非致命 / 死亡后复活 | 不死者之身 |
| ③ **亡者** ⚰ ★核心·跨组 | `奴役`(puppet_string, 亡者之语) | 亡者标记 / 亡者之语 → 对亡者挂 `奴役` | 若\[奴役\] 唤起活尸骷髅 / 不死生物大军 / 完全死亡 | 亡者之语 |
| ④ **终末** ⚱ | `冥界`(underworld, 死亡·隐秘) | 冥界囚笼 / 冥界之门 → 挂 `冥界` | 若\[冥界\] 囚禁魂体 / 剥夺生命 / 即死 / 苍白世界 | 冥界之门 |

> **隐秘值维度（永暗之河系 §2.3，主消费方之一）**：战场级属性 0–10，独立于力/敏/智/灵/体/魅。收尸人经"灵体之线 / 冥界（隐秘型）"等 +1/次（见【魂枢·隐秘】、【冥界之门】）。层级（照搬总览，与源堡同源）：
> - **≥4**：场上所有 `提线木偶` 每回合 +1 层（收尸人·奴役目标最稳）
> - **≥7**：友方「隐秘 / conceal / 愚弄」类技能 **+50%**
> - **=10**：触发「**源堡共鸣**」——本回合所有带 `提线木偶` 的目标可被任意友方（含跨源质）操控一次（本系可借此操控占卜家秘偶，占卜家也可操控本系亡灵）
>
> **跨源质写入方**：源堡（占卜家·愚弄/隐秘）、永暗之河（不眠者·隐秘 / 收尸人·灵体之线 / 战士·隐蔽）三方共用同一 `secrecy` 维度，收尸人是主消费方之一。

### 普通（序列 9–8）

#### 【被动】尸体特质 🦴 尸骸 · **E**

## 三、跨途径共享（永暗之河三途径 + 跨系 combo）

相邻（不眠者 / 战士）用 `sharedAcross`；跨系 combo 卡通过 **`StatusDef.crossPathway:true`** 实现（枢纽状态白名单）。

| 技能 | 共享/联动给 | 理由 / 介质 |
|---|---|---|
| 尸体特质 / 尸性坚韧 / 不死者之身 | 不眠者 / 战士 | 同源"承受死息""非致命"骨架 |
| 天然灵视 / 灵性亲和 | 不眠者 | 同源"看见灵体"骨架（本系常驻） |
| 冥界之门 / 死亡之国 | 不眠者 | 冥界↔黑夜对冲，已定规则 |
| 灵之线嫁接 | **占卜家（源堡）** | 跨系 combo：读取友方 `puppet_string` 升级为完全秘偶（提线木偶枢纽，对偶愚者【秘偶大师·改】） |
| 亡灵净抗 | **歌颂者（混沌海）** | 跨系 combo：读取友方 `purify` 反制（亡灵↔净化双向克制） |
| 亡灵助燃 | **刺客（灾祸之城）** | 跨系 combo：读取友方 `black_flame` 成燃灵（死灵黑焰） |

> **枢纽状态（落地优先级最高）**：`提线木偶(puppet_string)`、`寄生`、`替身`、`混乱`、`恶欲值`、`命运`、`净化(purify)`、`黑焰(black_flame)` 在 `StatusDef` 标 `crossPathway:true` + 参与途径白名单。本途径接入 **`puppet_string`（占卜家/收尸人/不眠者/囚犯）** 与 **`purify`（歌颂者/收尸人）** / **`black_flame`（刺客/收尸人）** 三条枢纽，白名单见 §六。

## 四、轴引擎 / 隐秘值 / 跨系 自检

- **enabler→payoff 闭环**：灵视=灵视、尸骸=尸性、亡者=奴役、终末=冥界，四轴均显式成链。
- **隐秘值维度**：收尸人经 冥界之门/死亡之国/魂枢·隐秘/灵之线嫁接/亡灵助燃 写入 `secrecy`；≥4 触发己方 `puppet_string`+1层；≥7 隐秘类+50%；=10 源堡共鸣（待引擎 `secrecy_mul` 落点）。
- **跨系 combo（非复刻）**：【灵之线嫁接】读占卜家 `puppet_string`、【亡灵净抗】读歌颂者 `purify`、【亡灵助燃】读刺客 `black_flame`，均为"读取友方别家招牌状态再升级"，符合新方案。
- **界域牌**：【冥界之门】（终末上层 overlay，写隐秘值）、【死亡之国】（终末上层 overlay，即死转化）共 2 张，占总量内。
