# 秘祈人途径（倒吊人）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按 9 大源质系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入混沌海系核心机制 **「放牧」(Grazing)**——本途径即为该签名机制的**写入方**（存储任意途径灵魂→用其能力，全局唯一跨系借技能）；以 **`放牧` 槽（enabler +1 / payoff 释放被放牧单位能力）** 建模；
> ③ 新增 **跨系 combo 卡**（混沌海↔源堡 寄生/血肉寄生：读友方偷盗者 `寄生` → 血肉共生升级）；
> ④ 补 1–3 张主题界域牌（阴影/血肉/堕落类，注意深渊化属暗影世界罪犯，本途径用阴影/血肉领域）。
> 框架依据 `_GENERATION_BRIEF.md` v0.3 §10–§13；源质 / 相邻 / 序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》与《混沌海系技能设定》§7（**v2 修订：秘祈人已由源堡移入混沌海**）；跨系机制依据《九大源质总览》《源堡系技能设定》。
>
> **本版定位**：v0.2/v0.3 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层；并依 v2 把"寄生/血肉寄生"主题从**组内**改判为**跨源质（↔源堡偷盗者）**联动。
> **数值纪律**：全部数值为占位建议值，统一归类 ⚠️D 待标。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

> **v2 修订影响**：秘祈人由源堡移入混沌海，故"寄生/血肉寄生"与源堡偷盗者的同名主题变成**两个不同源质之间的共享**（跨源质联动，见 §三【蔷薇主教·改】）。本途径的「阴影/血肉/堕落」是**跨源质联动**语境（↔源堡偷盗者），而非组内 combo——v0.2 把寄生做成组内复刻是错误的，本版修正。
> **混沌海系签名维度 = 放牧(Grazing)**：见下方维度说明，**秘祈人即该机制的写入方**。

### 本系咬合器维度说明（混沌海系 §2.2 + 九大源质总览 §1 万能接口 ⑥）

**签名机制 = 放牧 (Grazing)**：动态能力槽，存储**任意途径的灵魂** → 用其能力。全局唯一"跨系借技能"机制（归属本途径）。

| 层级 / 效果 | 说明（照搬总览，不另立标准） |
|---|---|
| **enabler（写入方=秘祈人）** | 吞噬单位灵魂入 `放牧` 槽（牧羊人·放牧灵魂），`grazed_soul` +1，并追加自身 `attack/hp_max/energy_max` |
| **容量阈值** | 随序列 5→1 上限 **7→9→13→18→22**，同时驱使数 1→3→全部外放（【灵魂牧场】B6 阶梯） |
| **payoff（跨系借技能）** | 释放被放牧单位的能力（数量随序列升）；放牧源堡系→临时用提线/寄生，放牧永暗之河→临时用亡灵，放牧本系→临时用雷霆/模仿 |
| **本系其他联动切入点** | ① 净化/雷霆 克死灵（↔永暗之河/暗影世界）；② 寄生/血肉寄生↔源堡偷盗者（跨源质，见【蔷薇主教·改】）；③ 放牧是混沌海内部五途径互为相邻的万能桥 |

> 本途径是放牧的**承载者**：`放牧` 槽既是一条身份轴（③），也是全混沌海系跨系联动的地基（§三 枢纽状态 `crossPathway:true`）。

## 四、轴引擎 / 咬合器 / 跨系 自检

- **enabler→payoff 闭环**：阴影（藏入阴影挂`阴影`→掌控阴影/阴影替身术/阴影统治者 payoff）、血肉★核心（祭祀/液化寄生挂`血肉`→血肉治愈/血肉不灭/替罪 payoff）、放牧★跨系（`放牧灵魂` enabler +1 → 驱使灵魂/堕落眷属 payoff 释放被放牧能力）、污秽（倾听挂`污秽`→秽语·诅咒/流逝 payoff）。四轴均显式成链。
- **放牧维度（混沌海签名）**：本途径即写入方。【放牧灵魂】吞灵魂入 `grazed_soul` 槽（enabler），【驱使灵魂】/【堕落眷属】释放其能力（payoff），且 `grazed_soul` 标 `crossPathway:true` 供混沌海其余四途径经 combo 借用。
- **跨系 combo（非复刻）**：【蔷薇主教·改】读友方偷盗者 `寄生` 升级血肉共生——v2 修订后这是两个不同源质（混沌海↔源堡）之间的共享，比原组内复刻更硬核。
