# 窥秘人途径（隐者）· 技能池 v0.3（新版设计方案重构版）

> **版本**：v0.3（新版设计方案重构，2026-09-12）—— 在 v0.3 框架（界域 / 位格 / 性别 / 吟唱）基础上，**按知识荒野系新方案重做**：
> ① 4 个构筑轴从「内容标签」改为 **enabler→payoff 引擎**（轴身份状态 + 挂载卡 / 结算卡）；
> ② 接入本系签名维度：**规律/信息（无独立量表）**——靠 **信息删除改写命运**（↔光之钥怪物）与 **信息修改同源重组**（↔源堡占卜家）两条跨系桥落地；
> ③ 新增 **跨系 combo 卡**（窥秘人信息 ↔ 光之钥命运 / 窥秘人信息 ↔ 源堡占卜家重组 / 窥秘人星象 ↔ 源堡学徒星界锚）；
> ④ 补 1–2 张主题界域牌（星象/信息类）。
> 框架依据 `../meta/GENERATION_BRIEF.md` v0.3 §10–§13；序列映射依据《诡秘之主职业路径与能力对照表（修订版 v2）》；跨系机制依据《九大源质总览》《知识荒野系技能设定》。
>
> **本版定位**：v0.2 已做原著校准，本重构**不改动原著能力映射**，只重做"轴=钩子"与跨系联动两层。
> **数值纪律**：全部数值为占位建议值，统一归类为 ⚠️D 待标；本版先锁"技能效果 + 轴引擎 + 跨系接口"，不锁数值。
> 「原著」= 对照表能力依据；「文案」= 玩家视角；「效果」= 引擎落地。

### 四条构筑轴（新版：轴 = 钩子，非标签）

知识荒野系**无独立战场量表**——其签名是「规律/信息」。窥秘人以四轴**身份状态**做自包含 enabler→payoff 引擎；跨系价值通过 combo 卡（信息删除改写命运 / 信息修改同源重组）外溢。

| 轴 | 身份状态 | enabler（挂载/累积） | payoff（读取放大） | 旗舰卡 |
|---|---|---|---|---|
| ① **窥秘** | `窥秘`(pry, 自身计数) | 窥秘之眼/窥秘权柄 → 累积 `窥秘` | 若\[`窥秘`≥N\] 窥探隐藏秘密/命运、预言最佳选择 | 预言大师 |
| ② **法术** ★核心 | `法术`(spell, 自身计数：解析/创造法术库) | 法术解析/神秘再现 → 存 `法术` 库 | 若\[`法术`≥N\] 常见法术更强、自创法术（神秘再现）爆发 | 巫师 / 神秘学家 |
| ③ **星象** | `星象`(astral, 敌方/区域标记) | 星之巨柱/星桥/本我星象 → 挂 `星象` | 若\[目标带 星象\] 星光囚笼禁锢、星海穿梭位移增益 | 星象师 |
| ④ **信息** ★跨系 | `信息`(info, 自身形态/计数) | 信息化/贤者 → 进入 `信息` 形态 | 若\[`信息` 形态\] 删除/修改目标状态、知识攻击强化 | 贤者 |

> **知识荒野系签名维度（依据《九大源质总览》§5）**：本系**无独立量表**，靠两类跨系桥获得全网价值：
> - **信息删除改写命运**（↔光之钥）：窥秘人「删除/修改信息」直接作用于怪物预知的未来命运——命运总线上唯一能反向编辑命运的节点（§6.5）。见【命运删除】combo 卡。
> - **信息修改同源重组**（↔源堡占卜家）：「删除/修改信息」与「重组/篡改/嫁接定义」是同一类概念层操作（§6.3）。见【篡改·信息】combo 卡。
> 本稿另将 `窥秘`/`法术`/`星象`/`信息` 四状态做成 enabler→payoff 自循环，使本途径在无独立量表时仍有完整构筑引擎。

## 四、轴引擎 / 签名维度 / 跨系 自检

- **enabler→payoff 闭环**：四轴均有 enabler（挂身份状态）与 payoff（读取放大）。窥秘=`窥秘`、法术=`法术`、星象=`星象`、信息=`信息`，均显式成链。
- **无独立量表**：知识荒野系签名「规律/信息」不立自 gauge；窥秘人以四状态自循环成引擎，跨系价值经三张 combo 外溢（命运删除 / 篡改·信息 / 星光囚笼·改）。
- **跨系 combo（非复刻）**：三张 combo 均"读取友方别家招牌状态再升级"——怪物 `命运`、占卜家 `重组`、学徒 `星界锚`。
