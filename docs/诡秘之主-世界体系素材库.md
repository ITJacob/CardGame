# 诡秘之主 · 世界体系素材库（爬塔卡牌游戏向）

> 用途：为肉鸽卡牌爬塔游戏提供「世界 / 维度」层面的素材索引与机制转化建议。
> 配套文档：《诡秘之主职业路径与能力对照表》（22 经典途径 + 10 外神途径）
> 版本：v0.1（素材收集阶段）

---

## 0. 先纠正一个词

你列的「灵境」，原著设定里叫 **灵界**（Spirit World）。「灵境」在设定中不是独立世界，容易被混用。

另外，「现世」的官方叫法是 **现实世界 / 物质世界**（与「灵的世界」「绝对理性世界」并立）。

## 1. 世界骨架：两套分法

**分法 A（隐秘组织的官方三分法）**

| 层 | 名称 | 说明 |
|---|---|---|
| 上 | 绝对理性世界（绝对真理世界） | 生命学派宣扬的概念层。非凡特性是绝对理性世界中某些事物在物质世界、灵魂世界的**投影**，以命运之河为代表 |
| 中 | 灵的世界（灵界） | 灵体、怨魂、低阶非凡者的活动域；信息之海，占卜与预言的根源 |
| 下 | 物质世界（现实世界） | 人类栖居地，规则最稳定 |

**分法 B（实战四层，更适合游戏建模）**

```
星空（外神 / 旧日）          ← 最外层，宇宙尺度
  ↑
星界（真神居所、权柄与象征）
  ↑
灵界（与物质世界完全重叠）
  ↑
现实世界（物质世界）
```

**关系要点**
- 现实世界与灵界、星界的分离，是「堕落母神、欲望母树、混沌之子」三位旧日诞生后才发生的——在此之前宇宙是一体的混沌。
- 灵界**和现实世界完全、全部重叠，却又互不干涉**，必须靠非凡力量打破间隔。这是最好的游戏设定：没有"入口"，只有"穿透"。

## 5. 爬塔机制转化建议

### 5.1 核心模型：世界的双重用法

**纵向 —— 塔层 = 世界（环境规则层）**
每一大层对应一个世界，切换时**改变基础规则**，而不是只换数值。这比"换皮关卡"有辨识度得多。

**横向 —— 卡牌 = 穿梭 / 借力**
卡牌不直接造成伤害，而是把单位、伤害、状态"移到另一个世界"来处理。这正好对应原著：绝大多数强力效果的实质是**跨层操作**。

### 5.2 塔层 × 世界 × 规则草案

| 塔层 | 世界 | 该层基础规则 | 设计意图 |
|---|---|---|---|
| 第 1 层 | 现实世界 | 规则基线，无修正 | 教学层 |
| 第 2 层 | 灵界 | 每回合结算「灵界潮汐」：随机翻转 1 条环境词缀；所有单位获得「意象」标记（可被引动） | 引入不确定性 |
| 第 3 层 | 镜中世界 | 双方出场单位各获得 1 个「镜中人」（复制体，属性减半）；本体死亡时镜中人顶替 | 让"死亡"不再是终点，改变血量估值 |
| 第 4 层 | 梦境 / 心灵之海 | 玩家可在战斗开始时**改写 1 条基础规则**（如"护甲不再衰减""费用上限 +2"） | 高自由度的爽点层 |
| 第 5 层 | 冥界 | 死亡单位不移除，转为「亡者」资源；敌人获得死亡免疫类词条 | 资源循环层 |
| 第 6 层 | 深渊 | 「污染值」每回合 +1，超过阈值卡牌费用增加 / 产生负面效果 | 压力与取舍层 |
| 第 7 层 | 历史 | 消耗堆可被回溯重放；每场战斗限 1 次「历史回响」 | 组合技层 |
| 第 8 层 | 灰雾之上 | 敌人"预知"失效（屏蔽其意图显示）；玩家的效果延迟 1 回合结算但加倍 | 信息战层 |
| 终局 | 星界 / 星空 | 敌人以「象征」而非数值存在，须用对应概念（契约、秩序、衰败）破解 | Boss 层 |

### 5.3 卡牌机制原型（按世界）

| 世界 | 机制原型 | 具体卡面设想 |
|---|---|---|
| **灵界** | 重叠层 / 信息污染 | 「灵视」：查看敌人手牌，但每用一次积累 1 点失控；「灵界穿梭」：本回合不受伤害，下回合受到 150% |
| **星界** | 象征槽 | 卡牌不提供数值，而提供「象征」（契约 / 秩序 / 衰败 / 欺诈），用于破解对应 Boss 的机制锁 |
| **历史** | 回响与借力 | 「古代学者」：复制上一回合打出过的 1 张牌；「历史孔隙」：召唤本局已死亡英雄的影像（属性 50%） |
| **镜中世界** | 映射与替身 | 「镜子替身」：本回合受到的伤害转给镜像分身；「强制入镜」：将 1 名敌人封入镜中，跳过其 2 回合 |
| **心灵之海** | 意图篡改 | 「潜意识篡改」：直接修改敌人下回合的行动意图；「心灵风暴」：全场共享伤害（打谁都溅射） |
| **梦境** | 规则改写 | 「织梦」：本场战斗改写 1 条规则；「梦魇」：敌人被迫重放上回合行动 |
| **冥界** | 死亡转化 | 「亡者之语」：把敌方死亡单位转为己方随从；「看门人」：以自身为囚笼，收纳并延迟一次致命伤害 |
| **深渊** | 递增代价 | 「深渊契约」：立刻获得强力效果，污染值 +3；「恶意感知」：预知并免疫下一次致命伤害 |
| **画中世界** | 高维封印 | 「入画」：将敌人封入画中，其效果全部无效化，但每回合需支付维持费；「降维」：把敌人从高维打落，属性大幅削弱 |
| **灰雾之上** | 遮蔽与延迟 | 「灰雾」：屏蔽敌人所有预知 / 追踪类效果；「时间差」：本回合效果延迟到下一回合结算，数值翻倍 |
| **命运长河** | 命运织造 | 「命运之轮」：概率化（伤害随机 0~200%）；「重启循环」：状态回到 3 回合前（水银之蛇） |
| **绝对理性世界** | 投影/实体双形态 | 卡牌有「投影态」（低费低效果，不可被针对）和「实体态」（高费高效果，可被针对）两种形态，可切换 |

### 5.4 与「愚者途径」已有设计的对齐

你之前做的「预知」（开局 +5 费用）属于**命运长河 / 历史**层的能力。建议把它归入同一机制族，与「命运之轮」的概率化、水银之蛇的重启循环共享一套「命运点数」资源，避免能力散成孤岛。

## 6. 设定存疑 / 待核实

1. ~~「心灵之海」与「集体潜意识之海」是否为同一层的深浅两级，原著未给出严格拓扑~~ —— **已核实（v0.2 修正）**：原著拓扑是「**心灵岛屿**（个人心智）漂浮于**集体潜意识大海**（连接介质）之上，**梦境 = 心灵最深处 / 梦境最底层**，且梦境有多层」。不是简单的深浅两级。另外「心灵之海」并非原著标准名词，标准是「**集体潜意识大海**」。
   - 补充：掌握集体潜意识大海即可掌握「**巧合**」（作家序列1）。心魇蜡烛可让人直达"心灵最深处/梦境最底层"，把场景实质化，在其中杀死目标的负面人格即永久消灭；但**心灵/梦境有许多层，敌人可反过来欺骗甚至猎杀**，超时 5 分钟使用者彻底迷失成植物人。
2. 「历史」在原著中更多表现为「可被回溯的影像与回响」，是否构成一个独立"世界"存在争议；游戏里按独立层处理更好玩。
3. 「绝对理性世界」与「灵魂世界」并立，但「灵魂世界」是否等同于灵界，设定中未严格区分。建议游戏中回避「灵魂世界」这个名词，统一用「灵界」。

## 7. 一句话结论

你的清单缺的不是一两个名字，而是**整个上位层**：

> 现实世界 → 灵界 → **星界** → **星空** 是纵向主干；
> **历史、梦境/心灵之海、镜中、画中、冥界、深渊、灰雾之上** 是横向支线；
> **神国、封印物内部世界、异度空间** 是可复用的关卡模板。

做爬塔游戏时，**让每层塔 = 一个世界 + 一套规则改写**，会比"换数值换皮"的方案高一个档次，而且天然贴合原著——因为诡秘里所有高位能力的本质，都是跨层操作。
