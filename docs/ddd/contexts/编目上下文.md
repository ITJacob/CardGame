# 编目上下文（Catalog）

## 一、职责定位

编目上下文是**定义态的唯一居所**，是一个与战斗运行时完全解耦的独立聚合。它持有所有 `*Def`（EffectDef / TermDef / BehaviorTemplate / SkillDef / StatusDef / ZoneDef / ClassDef），不可变、可全局缓存、可共享。

战斗创建时，把所引用的全部 Def 快照进战斗实例——之后配置变更不影响进行中的战斗，这是回放与验证可复现的基础。Catalog 加载时做全量引用完整性校验，失败即拒绝启动。

## 二、各 Def 的结构

| Def | 关键字段 | 角色 |
|---|---|---|
| EffectDef | id, type, element, 默认参数, 元标记 | 效果原语；行为/技能/状态三方共享的词汇表 |
| TermDef | id, displayName, category, description, composition, overridable, tags | 术语本体；命名的效果参数组合，编目期展开 |
| BehaviorTemplate | id, key, trigger, 默认 cost, castTime, cooldown, targetSpec, effects | 行为壳模板 |
| SkillDef | id, init{cost,castTime,cooldown,targetSpec}, effects | 行为的初始化参数集 + 效果组合 |
| StatusDef | id, category, triggers, behaviorModifiers, redirect, defaultDuration, maxStacks, stackPolicy, dispelable | 状态本体 |
| ZoneDef | id, kind, 默认 ZoneGrant 模板, 生命周期上限 | 区域本体 |
| ClassDef | id, kitOps（增/删/改）, knownSkills | 职业 → 套件 + 技能 |

## 三、SkillDef 的模板优先 + 逃生舱

技能默认填 `templateRef` 只覆写数值与效果；允许 `templateRef` 为空、由 SkillDef 自带完整行为定义。90% 走模板享复用，10% 的特异技能有出路。

## 四、术语的编目期展开

术语是给人理解的命名效果组合，运行期引擎零感知。展开时机在编目期（战斗启动前一次性完成）：`BehaviorTemplate.effects` 中的 TermRef 被递归展开为扁平 `EffectRef[]`，每个产出的 EffectRef 烙印 `originTerm`（完整引用路径，支持嵌套）。运行期 Action 只见 EffectRef，溯源痕迹只供战报/UI/流派统计。

术语引用图必须无环，catalog 加载时静态校验。术语展示文案由实际生效参数渲染，禁止与实参脱节。

## 五、不变量（编目 · 7 条）

| 编号 | 名称 | 规则 |
|---|---|---|
| INV-C1 | 引用完整 | 所有 ref 必须可解析；Catalog 加载时做全量引用完整性校验，失败即拒绝启动 |
| INV-C2 | 数值单点 | 默认值与上下限只在 Def，实例值只在 Grant/params。任何重复定义视为配置错误 |
| INV-C3 | 启动时快照 | 战斗启动时快照所引用的全部 Def 进战斗实例，之后配置变更不影响进行中的战斗 |
| INV-C4 | 展开一次性 | 术语展开与环路/白名单校验在 Catalog 加载时一次性完成，运行期不再解析 TermRef |
| INV-T1 | 术语展开 | 术语在编目期展开为扁平 EffectRef 序列；运行期引擎零感知 |
| INV-T2 | 术语无环 | 术语引用图无环，Catalog 加载时静态校验 |
| INV-T3 | 覆写白名单 | TermGrant.overrides 的键必须是 TermDef.overridable 的子集 |
| INV-T4 | 文案同步 | 术语展示文案由实际生效参数渲染，禁止与实参脱节 |
| INV-T5 | 多段共享坐标 | 术语内多段默认共享同一冻结坐标，段间不重新解析目标；目标死亡则后续段落空 |

> 注：INV-T1~T5 归属编目上下文，因术语是编目期概念；此处一并列出以便查阅。
