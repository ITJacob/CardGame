# 共享内核（Shared Kernel）

## 一、职责定位

共享内核是跨多个上下文复用的**值对象与规约**：它们没有自己的聚合，被战场、编队、执行、效果各层共同引用。把它们单独抽出来，是为了避免"同一个概念在多个上下文里各写一遍、最终漂移不一致"。

## 二、TargetSpec（目标规格）

技能的绝大部分表达力来自 TargetSpec 的四个正交维度——它们可以任意组合。

```
TargetSpec {
    request       : TargetRequest   // 查询：阵营 / 路线 / 锚点 / 范围 / 排序 / 数量 / 扩散
    mode          : Unit | Area     // 点目标 / 区域目标
    consumption   : Instant | Zone | Summon
    selectionMode : Auto | Manual   // 自动选目标 / 玩家手动选目标
    fallbackSort  : SortRule        // Manual 时必填的确定性兜底
}
```

- `mode == Unit` 时 `consumption` 强制为 Instant；`mode == Area` 时 `consumption` 必填（无默认值）。
- `selectionMode == Manual` 时 `fallbackSort` 必填。

| 维度 | Auto | Manual |
|---|---|---|
| 含义 | 系统按 sort 规则定目标，玩家不介入 | 系统圈出候选池，玩家从中选 |
| 典型 | 绝大多数普攻与单体技能（打最前排、打最低血） | 需要玩家决策的技能（打谁由我定，而非规则定） |

## 三、EffectRef（效果引用）

```
EffectRef { ref, params?, condition, target? }
```

- `ref` 指向 EffectDef.id；`params` 覆写默认参数；`condition` 决定对谁生效；`target` 覆盖行为级目标（状态触发常用）。

## 四、EffectCondition（规约）

组合式谓词，判定上下文是单个最终目标：

```
Always | Chance(via RandomSource) | TargetHpBelow | TargetHpAbove
| CasterHasStatus | TargetHasStatus | Not(of) | And(of[]) | Or(of[])
```

`Chance` 是唯一允许引入随机的条件，且必须满足随机性治理规则（见[随机性治理](./随机性治理.md)）。

## 五、RandomSource（随机源）

```
RandomSource {
    seed        // 战斗创建时确定，写入战斗记录
    next()      // 唯一抽样入口
    snapshot()  // 供回放/验证读取
}
```

## 六、领域事件字典（节选）

领域事件在战斗 → 外部（UI / 回放 / 统计）之间提供最终一致的广播通道，不参与战斗内部一致性。

| 事件 | 载荷 | 来源 |
|---|---|---|
| TickAdvanced | tickIndex | 调度 |
| GaugeCrossed | unitId, gaugeKey | 调度（授予机会） |
| ActionOpportunityGranted | opportunity | 执行 |
| BehaviorCommitted | actionId, caster, cost | 审计、回放 |
| ChannelStarted / Interrupted / Completed | channel | 执行、UI |
| TargetsResolved | actionId, resolvedTargets | 审计 |
| ActionRedirected | actionId, redirectStep | 审计、回放 |
| EffectApplied | actionId, effectRef, target, outcome | 状态（受击触发）、UI |
| OccupancyChanged | diff（进入/离开坐标的单位集合） | Zone（唯一触发入口） |
| StatusMounted / Refreshed / Expired / Dispelled | instanceId, defId | 溯源账本、UI |
| ZonePlaced / Triggered / Expired | zoneId, coord | 战场、UI |
| UnitSpawned / UnitDied | unitId | 状态（登场/亡语）、战场（离场坍缩） |

## 七、元素与术语（共享值对象速查）

```
Element        : fire | ice | poison | shock | mental | physical | none   // 值对象，无实例态
DamageCategory : physical | magic | true                                  // 由 Element 派生（只读）
TermRef        : { termRef, overrides?, originPath? }                     // 只存在于定义态
EffectRef      : { ref, params?, condition, target?, originTerm? }        // originTerm 只读烙印
```

| 值对象 | 归属上下文 | 运行期是否读取 |
|---|---|---|
| Element | 共享内核（结算在效果上下文） | 是（作为 EffectRef 的字段被读取） |
| ResistanceSet | 编队 | 是（逐元素一槽，走溯源账本） |
| TermDef / TermGrant / TermRef | 编目 | 否（编目期展开后消失） |
| originTerm | 执行 | 是（只读审计字段，不参与结算） |
