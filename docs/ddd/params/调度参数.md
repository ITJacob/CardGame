# 调度参数与取值域

本文件收容调度上下文的全部枚举取值域与数值。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、枚举取值域

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| Gauge 触发条件 | 严格越过阈值（>） | 引擎常量 | 已定（INV-S1） |
| overflowPolicy | Keep（越界留存） | Gauge | 当前仅一种，预留 Reset |
| 先手交替模式 | [己,敌,敌,己] 循环 | 参数层 | 已定（INV-S2），禁止改为按位置分层 |
| 冷却起点 | 提交时刻 | 引擎常量 | 已定 |
| 打断 | 资源不退 | 引擎常量 | 已定 |
| Gauge 可被效果修改 | 经 modify_resource 的 gauge.current / gauge.rate / gauge.threshold | 引擎常量 | 行动周期是派生值，不可直接修正（INV-S5） |

## 二、数值清单

| 参数 | 值 | 原出处 | 归属 | 标记 |
|---|---|---|---|---|
| 精力阈值 | 75 | 总览 §4 | Gauge.threshold + cost.gaugeAmount 默认值 | 重定位 |
| 主动行为的精力成本 | 75 | 总览 §4 | BehaviorTemplate.cost.gaugeAmount 默认 | 重定位 |
| 先手偏差量级 | 0.001 tick | 总览 §4 | 删除（由 INV-S2 的交替合并取代） | 重定位 |

重定位说明（行动机会拆分相关）：原设计里"精力成本 75"同时承担了时间成本与行动资格两重语义。拆分后：
- `Gauge.threshold = 75`（何时获得机会）
- `BehaviorTemplate.cost.gaugeAmount = 75`（执行一次消耗多少进度条）
- `ActionOpportunity`（资格，独立于数值）

三者当前数值相同，因此默认行为完全不变；但从此可以表达"消耗 0 进度条但仍占回合"这类需求。
