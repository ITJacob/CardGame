# 战场参数与取值域

本文件收容战场上下文的全部枚举取值域与数值。所有数值在骨架落地后需重新过一遍平衡评审——本文只负责不让它们丢失、不让它们错位。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、枚举取值域

### 1.1 区域（Zone）

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| ZoneDef.kind | trap / blessing / hazard / mark | ZoneDef | 区域类型 |
| ZoneGrant.trigger | on_enter / on_exit / on_occupy_tick | ZoneGrant | 默认 on_enter |
| ZoneGrant.affects | enemy_of_owner / ally_of_owner / any | ZoneGrant | 由 request.faction 推导 |
| ZoneGrant.effects | EffectRef[]（多条、逐条独立判定） | ZoneGrant | 由单条 effect 扩为清单，与状态载荷对齐；整次触发只消耗一次 uses |

区域不是"特殊的单位状态"，而是坐标版的状态：占格 / 有血量 / 可被攻击 → summon + spawn；纯坐标效果、不占格 → zone。陷阱/祝福地面都属于 Zone。

### 1.2 界域（Domain）

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| DomainDef.tier | base / hero / overlay | DomainDef | 底层（CombatSetup 注入，不可驱散）/ 英雄域（被动常驻，优先级最高）/ 上层（卡牌打出，压制栈） |
| DomainDef.dispelable | boolean | DomainDef | base 恒 false（INV-B11）；hero / overlay 按设计 |
| DomainDef.triggers | TriggerDef[]（战场级） | DomainDef | 走「全局第三方监听」通道，挂 on_tick / on_turn_start 等触发点结算载荷 |
| DomainGrant.duration | 正整数（tick）/ -1（常驻） | DomainGrant | 被压制的上层界域 duration 暂停递减；放逐 ≤ 20 tick、置换 ≤ 24 tick 为原著参考上限（⚠️D 内容侧纪律） |
| DomainGrant.priority | 整数（默认打出序号递增） | DomainGrant | 上层栈排序键：后打出者压顶 |

**RulePatch（规则改写补丁）**：`DomainDef.rulePatches: RulePatch[]`，tagged union，由既定流水线节点被动读取（INV-D6）。初批 kind：

| kind | 字段 | 读取节点 | 说明 |
|---|---|---|---|
| `seal_effect` | effectType | I 节点候选池 | 禁用指定效果类型（如 `seal: [translocate]`） |
| `disable_effect` | side, effectType 或 tag | I 节点 | 指定阵营的指定类型/标签效果失效（如「替身类能力失效」） |
| `cost_mod` | effectType 或 tag, delta | commit 成本校验 | 指定类型/标签技能的能量成本增减（如「暗影系卡费用 +1」） |
| `empower` | side, stat, mul, tag? | O 节点 | 指定阵营的属性/伤害乘区，可按标签过滤（如「光/净化标签效果 +50%」） |

纪律：补丁纯声明——新 kind 必须绑定既有节点，不得新增流水线节点、不得直接改写状态。「全场每回合腐蚀」类周期性效果不走补丁，走 `DomainDef.triggers`（战场级触发器 + EffectRef 载荷）。交互规则（界域 × 卡标签）统一为带 tag 过滤的补丁，标签取值由 `SkillDef.tags` 供给（见编目参数 §二）。

### 1.3 战场时钟（BattleClock）

战场级时间轴。**1 tick = 20 分钟，一天 72 tick**。时钟只进不退（裁定见 `docs/meta/proposals/战场时间-昼夜时钟.md` §一.3）。

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| `board.clock` | `int[0, 71]` | 战场 | **唯一可写源**：每 tick +1，到 71 后归 0（跨日环绕）。起始值在 CombatSetup 由 RandomSource 抽样一次（R3 登记 / R4 单次抽样） |
| `board.luminance` | `int[0, 10]` | 战场（只读派生） | 光照度。由 `clock` 查 §1.3b 表派生，**不双写**（INV-C2） |
| `board.phase` | `midnight` / `dawn` / `day` / `dusk` / `night` | 战场（只读派生） | 相位。由 `clock` 查表派生，与 `luminance` 同为只读视图 |
| `board.lumOverride` | `{ value: int[0,10], duration: int, sourceId }` | 战场 | 覆写层：权柄卡写入，**优先级高于派生值**；多个按打出序号压栈（复用 `DomainGrant.priority` 口径），到期回落 L2 |

> ⚠️ **档位与相位不严格同构**：黎明前段（tick 12–15，04:00–05:00）光照度 ≤2，落在暗夜档——符合「黎明前最暗」，但会让黎明轴卡片在此窗口吃到暗夜档乘区。**需要精确判定的卡走 `phase_is` 谓词，不要只靠阈值。**

**月夜**：不单列相位，定义为 `phase ∈ {night, midnight}` ∧ 月相可见（药师 `moon_cycle` 在场或己方持有）。与既有月相节拍器衔接，不新增量表。

#### 1.3c 进入战斗的时间（按塔层定窗口 + 种子抖动）

| 塔层类型 | 基础窗口（clock） | 抖动 | 等价区间 |
|---|---|---|---|
| 常规层 | 24–47（白昼） | ±6 tick | 08:00–16:00 ±2 小时 |
| 夜战层 | 54–71 ∪ 0–11（夜/午夜） | ±6 tick | 18:00–04:00 ±2 小时 |
| 晨昏层 | 12–23 ∪ 48–59（黎明/黄昏） | ±3 tick | ±1 小时 |
| 首领层 | 48–59（黄昏） | ±3 tick | 16:00–20:00 ±1 小时 |

随机性合规（见 `../contexts/随机性治理.md`）：时钟影响的是**状态挂载与乘区**，非伤害数值 / 资源 / 目标选择 → 落在 R5 建议边界内；须 R3 登记、R4 单次抽样，起始 clock 随 seed 固定以满足 R6 回放契约。
