# 编队参数与取值域

本文件收容编队上下文的全部枚举取值域与数值。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、枚举取值域

### 1.1 状态（Status）

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| StatusDef.category | dot / hot / buff / debuff / control / reactive / aura / stance | StatusDef | hot/debuff 与 dot/buff 语义有重叠，建议精简；stance 受 INV-P5 硬控清除规则约束 |
| trigger.event | on_apply / on_tick / on_take_damage / on_deal_damage / on_death / on_spawn / on_turn_start / on_remove / on_battle_start / on_kill | StatusDef | on_remove 用于配合溯源撤销 |
| stackPolicy | refresh / reject / stack | StatusDef | 已定 refresh |
| modifierRevert | on_expire_or_dispel | 引擎常量 | 已定 |
| source_filter | melee / ranged / skill / … | TriggerDef | 触发来源过滤 |

### 1.1b 状态可选能力（扩展字段）

StatusDef / 死亡结算 / UnitDef 的可选字段与能力。多数带默认值或为空，不破坏既有状态行为。

| 字段 | 取值 / 形态 | 归属 | 说明 |
|---|---|---|---|
| charges | 正整数 | StatusDef | 次数型状态：每响应式派发 −1，归零卸载（C6） |
| immune | StatusCategory[] / { categories?, sourcePathways? } | StatusDef | 阻挡指定类别/来源的状态被施加（G12）；sourcePathways 支持按途径过滤 |
| lethalProtect | boolean + hpRatio | StatusDef/死亡结算 | 阻止本次死亡并按比例恢复（H7） |
| damage_mul / damage_taken_mul | 数值 / 可求值对象 | StatusDef | H4 升级为 `{ filter, dynamic }`（按途径/元素/状态/血量/caster 过滤、按层数/计数动态）；与 `vulnerable` 同乘区加算 |
| heal_received_mul | 数值（支持 0 与 >1） | StatusDef | 治疗修正（H21）；0 = 禁疗 |
| heal_output_mul | 数值 | StatusDef | 治疗输出乘区（施法者侧，handleHeal 读取） |
| durationModifier | { scope, mode, value, filter } | StatusDef | outgoing/incoming 的 duration 加成（H14） |
| moveImmune / gaugeReductionImmune | boolean（+ scope） | StatusDef | 免疫位移 / 免疫推条（H27/H31） |
| neverMiss | boolean | StatusDef | 必定命中（H35） |
| buffBlocked | boolean / { categories } | StatusDef | 禁止获得增益（H38） |
| statPerStack | Partial<Record<StatKey, number>> | StatusDef | 按层数线性修正属性（H34） |
| formGroup / nextPhase / cycleTicks / phases | — | StatusDef | 形态组互斥轮转 / 按 duration 进度切换（H50） |
| thresholdTrigger | { metric, cmp, value, effects } | StatusDef | 阈值触发（猎人） |
| slots | Record<string, number\|string> | StatusDef | 状态数据槽，承载 element/tier/unitDef 等（H33） |
| casterId / payload 寻址 | — | StatusDef | 状态持有施法者引用，载荷可寻址施法者（F56） |
| contagious / spread / ramp / stackThreshold | — | StatusDef | 复合 debuff 扩展：传染/扩散/dot 递增/叠满触发（H2） |
| transferStatus(…) | mode: move/copy/rewrite/rotate | EffectDef 算子 | 状态搬运/复制/改写/重排（H32，复用 F50） |
| suppress / untransferable | boolean | StatusDef | 生效抑制（偷盗者）/ 不可搬运（刺客），与 immune 同层 |
| silent_immune / ignoreDispelable | boolean | StatusDef | 卷轴不受沉默影响 / 驱散无视不可驱散（反向开关） |
| immune_stat_reduction | StatKey[] | StatusDef | 免疫指定属性被削减（罪犯） |
| revive_blocked / dot_cannot_kill / damage_cap | — | 死亡结算 | 死亡结算点分支（H23/C-7）；damage_cap 为截断非免死 |
| summon_cap | number | UnitDef/运行时 | 每施法者召唤位上限（H39） |
| maxTriggersPerBattle / oncePerBattle | number / boolean | TriggerDef/EffectDef | 每场限次（通识者/G4） |
| on_remove reason 过滤 | expired/dispel/consumed/overwritten | TriggerDef | on_remove 按卸载原因过滤（H29） |
| StatusCategory 增补 | fear / retarget / link / contract / conceal / seal | 枚举 | 配合 G12 immune / C2 dispel.category 数组（H40） |

### 1.2 攻击类型（reach）

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| reach | melee / ranged / none | BehaviorTemplate | 攻击类行为的属性；与站位、与 targetSpec 正交（INV-P6）；非攻击类为 none |
| protectedSelector.kind | unit_ref / coordinate_relation | StatusDef.RedirectRule | unit_ref = 守护指定单位；coordinate_relation = 守卫姿态（同路且 index 更大者） |
| coordinate_relation.relation | same_lane_behind / … | 同上 | 取值域待扩，首批只需 same_lane_behind |
| sourceFilter | melee / ranged / skill / any | StatusDef.RedirectRule | 守卫姿态填 ranged；守护填 any |
| stance 清除规则 | 硬控（stun）清除全部 category == stance | 引擎常量 | 分类驱动，不在眩晕里枚举状态（INV-P5） |

### 1.2b 单位类型标签体系

`UnitDef` 统一一组标签，支撑「定向检索/克制/增益」类技能，避免为每个类型写死负抗性：

| 字段 | 取值 | 说明 |
|---|---|---|
| unitType | 主类（SPIRIT / UNDEAD / MACHINE / PLANT / VERMIN / CONSTRUCT / FLESH / DEMON / ABERRATION / ITEM …） | 主分类 |
| tags | string[] | 细分类（shadow / spirit / flesh / beast / relic …） |
| 谓词 | target_has_tag / target_unit_type / target_is_summoned | EffectCondition 配套 |
| 乘区/过滤 | 按 tag 的伤害/受伤乘区 + targetSpec 的 tag 过滤 | 与 H18 统一过滤器共用 |

退化方案：给不死/污秽/黑暗单位预置负 `resist:holy` / 负 `resist:shock`（零新字段），代价是无法做定向检索与减伤条款。

### 1.3 元素抗性（逐元素）

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| ResistanceSet 槽位 | fire / ice / poison / shock / mental / physical | BaseProfile + ModifierLayer | 逐元素一槽，走 sourceId 撤销；基线建议全 0 |
| 抗性在 DamageChain 的位置 | 减免型之后、乘区型之前 | 引擎常量 | 与"防御线性减伤"是两笔账，不合并 |
| EffectCondition 元素谓词 | ElementIs(e) / ElementIn([...]) | 共享内核 | 供状态触发与流派判定 |

### 2.1b 技能定价纪律

| 参数 | 值 | 说明 |
|---|---|---|
| 标准单体技能 | 3 能量 → 5 伤害 | 单卡换算基准 |
| 一张卡预算 | ≈ 3 能量 ≈ 6 伤害 ≈ 10% 最大生命 | 三种口径等价；任一口径超标须在其他维度补偿 |
| 攻防修正 | ±1 ~ ±2 | 单卡面板修正幅度 |
| 护甲 | 5 一档 | 护甲按 5 为最小档位增减 |
| 抗性修正 | ±10% ~ ±20% | 单卡抗性修正幅度 |

定价规则：

- 伤害技能按"能量 × 1.2"折算为伤害。
- 位移 / 控制 / 资源类技能须压低直伤——位移在"双路各 4 格 + 坍缩 + 插队"的战场结构里本身即硬资源，不可与纯伤害同价。

### 2.3 元素抗性数值

| 参数 | 值 | 归属 | 标记 |
|---|---|---|---|
| 基础抗性 | 基线全 0 | BaseProfile | 已裁定 |
| 抗性投放档位 | 10% 为一档，单卡 ±10~±20% | 参数层 | 已裁定；与「防御 ±1 为档、护甲 5 为档」同构 |
| 抗性口径 | 百分比乘区 | 参数层 | 已裁定 |
| 抗性上下限 | 钳制 [-50%, +75%] | 引擎常量 | 已裁定：负抗最多增伤 50%（防爆发翻倍）；正抗最多减伤 75%（留一线） |
| 抗性与乘区关系 | 与易伤/坚守同乘区加算，统一乘一次 | 引擎常量 | 已裁定；避免乘区数量爆炸 |
| 抗性撤销 | 按 sourceId | StatProvenance | 复用既有机制，零新增逻辑 |

抗性不是特殊属性：它和攻击、防御走同一套三层模型与同一份溯源账本，只是按元素分槽。

### 2.4 参数化状态母版

状态 / 单位 / 算子按底层机制归并为以下母版族。各途径只填参数与外观，避免状态 / 单位表随途径数线性膨胀。具体状态实例落在编目数据（catalog），不在本设计稿。

| 母版 | 覆盖机制 | 关键参数 |
|---|---|---|
| H1 召唤物基线 | hpRatio/atkRatio/reach/亡语载荷 四参 | 一条模板，各途径填数值 |
| H2 参数化复合 debuff | dot×乘区×时长×属性 的排列 | on_tick 载荷 / damage_taken_mul / heal_received_mul / maxStacks / ramp / stackThreshold / on_remove 载荷 / contagious / spread |
| H3 参数化减伤/免伤 | 次数型免伤 | damage_taken_mul（支持 0）× charges × 触发点 × 消耗后载荷 |
| H4 过滤/条件伤害乘区 | 按途径/元素/状态/血量/caster 过滤 | filter + dynamic（按层数/计数） |
| H5 潜行/不可锁定/虚化 | 候选池过滤 | untargetable_by_targeted × damage_taken_mul × charges × 破除条件 × damage_immune |
| H7 致死保护 | 死亡结算点中断 | lethalProtect + hpRatio；与 dot_cannot_kill / damage_cap 同点分支 |
| H8 运行时覆写 dispelable | 权柄决定可驱散性 | 挂载方声明指定类别 dispelable:false |
| H9 Zone 母版 | 区域载荷承载 | 载荷原语 + 阵营分支 + 落点 |
| H10 参数化增益/形态 | buff/debuff/form | modify_stat 组 × damage_mul × 代价段 × on_deal_damage 附加 |
| H11 计数型状态 | 默记/层数 | maxStacks（可覆盖）× duration:null × status.consume 读写 |
| H12 target_override 族 | 锚点 × 存续 | first_empty/self/manual/nearest_any/any_lowest_hp/<单位>/<阵营hp_desc>/<分身> + charges/duration + target_override_immune |
| H16 damage.pierce | 破甲/穿透 | pierce[] + armorPierceRatio |
| H21 heal_received_mul | 治疗修正 | 字段复用，支持 0 与 >1 |
| H24 参数化减速 | 禁位移+速率+dot | gaugeRateMul × moveImmune × attackMod × dotOnTick（冻结=0） |
| H27/H31 moveImmune / gaugeReductionImmune | 免疫位移/推条 | 布尔 + scope |
| H28 伤害转嫁/分摊/链接 | 链/分摊/分享 | ratio × direction × split × selfKeep × linkedTo（内置防循环） |
| H32 状态搬运 | move/copy/rewrite/rotate | filter × keepDuration × ratio × direction |
| H34 statPerStack | 按层数修正 | Partial<Record<StatKey, number>> |
| H35 neverMiss | 必定命中 | 布尔 |
| H36 execute | 处决 | damage.lethal:true，直达死亡结算 |
| H38 buffBlocked | 禁增益 | 布尔 / { categories } |
| H40 StatusCategory 增补 | 6 新值 | fear/retarget/link/contract/conceal/seal |
| H42 光环/常驻模板 | duration:null + 群体双向乘区 | scope + 同向乘区取最高/叠乘（待拍板） |
| H48 modify_stat.mode | set / to_at_least | 直接置值/取上限 |
| H50 形态组/阶段切换 | formGroup 互斥轮转 / phases 进度切换 | nextPhase / cycleTicks |
