# 执行参数与取值域

本文件收容执行上下文（含行为/状态交互）的枚举取值域。技能示例值（火球术、旋风斩、烈焰风暴等）属示例，已从参数层剥离，不在此列出。

## 一、行为枚举

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| Behavior.trigger | active / passive | BehaviorTemplate | 主动 / 被动 |
| passive_hook | on_apply / on_remove / on_tick / on_turn_start / on_battle_start / on_spawn / on_death / on_kill / on_attack / on_active_skill / on_take_damage / on_deal_damage / on_phase_change / on_status_gain | BehaviorTemplate | 被动触发钩子，共 14 个，取值域与语义见 §2.1 |
| BehaviorTemplate.castTime | 非负整数（tick） | BehaviorTemplate / SkillDef.init | 吟唱时长，0 = 瞬发；>0 时提交后进入 Channel（引导），引导期可被带 `interrupt` 标志的状态打断——技能作废、资源不退（提交即承诺）；`cast_time_set` 修正聚合取最小（「免吟唱」= cast_time_set: 0） |
| BehaviorModifier.op | disable / force / energy_cost_mul / energy_cost_add / cast_time_set / cooldown_mul / target_override | StatusDef | 决策期约束算子；disable 的作用域可按行为过滤（全部 / 攻击 / 技能 / 按 consumption 类型——如禁止 domain 类技能，「回归现实」的界域锁定） |
| 聚合规则 | disable 并集 / force 并集 / mul 乘积 / add 求和 / cast_time_set 取最小 / cooldown_mul 乘积 / target_override 覆盖 | 引擎常量 | 已定；disable 优先于 force |
| RedirectRule.to | self / attacker / transfer_target / first_empty | StatusDef | 转向目标；`first_empty` = 转向至最近空坐标（occupant 为空即落空）——入射侧「闪避型转向」（怪物·水银之躯、反占卜类确定性落空）与 C7 目标改写共用同一锚点 |
| 转向优先级 | 守护 10 > 自转移 5 | 参数层 | 已定；单跳防环 |

## 二、转向（RedirectRule）说明

转向是执行期 R 节点的核心机制。守卫与守护同属一条 RedirectRule，只是选择器与来源过滤不同：

| 维度 | 守护 | 守卫姿态 |
|---|---|---|
| 受保护对象 | 一个指定单位（protectedSelector.kind = unit_ref） | 同路且 index 大于自己的全部单位（coordinate_relation） |
| 拦截来源 | 全部（sourceFilter: any） | 仅远程（sourceFilter: ranged） |

两个能力因此统一为一条机制，不必为"守卫"另造一套拦截系统。转向单跳（visited 集防环），伤害随转向走最终目标的防御，状态类效果留原目标。

**绕过转向**：`EffectRef.params.ignore_redirect: true` 时，本 Action 跳过 R 节点的转向收集（不被守护 / 守卫姿态 / 伤害转移拦截）——律师「踏月」、猎人「精准」的"必中"语义由此承载。与 `neverMiss`（H35，命中判定层面）是两个层面：一个绕过拦截，一个保证命中。

### 2.1 触发点（passive_hook）取值域

触发点是状态与被动挂载的 fire 时机。取值域封闭，共 14 个：

| 触发点 | fire 时机 | 说明 |
|---|---|---|
| `on_apply` | 状态挂载到单位时 | 生命周期钩子；挂载期扣次数不在此计 |
| `on_remove` | 状态从单位卸载时 | 生命周期钩子；携带卸载原因 |
| `on_tick` | 每个 tick | 对全体持状态单位 fire；持续伤害/回复的承载点 |
| `on_turn_start` | 该单位**行动开始**时 | 只 fire 给即将行动的单位，语义=自身回合开始 |
| `on_battle_start` | 战斗开始时，一次性 | 全局开局；不能用 `on_spawn` 表达 |
| `on_spawn` | 单位登场时 | 召唤物/增援登场会重复 fire |
| `on_death` | 单位死亡时 | fire 给死者自身 |
| `on_kill` | 击杀发生时 | fire 给**击杀者**，与 `on_death` 的接收方不同 |
| `on_attack` | 单位**发起攻击**时 | 含落空与被免疫；区别于 `on_deal_damage` |
| `on_active_skill` | 单位发动**主动技能**（`trigger: active` 且非 `basic_attack` 的行为）提交时 | fire 给技能发动者；攻击类主动技能同时 fire `on_attack`。仲裁人 decree「禁止使用技能」判定、窥秘人知识回层的承载点（2026-09-04 拍板：独立第 12 触发点，取代待拍板清单 H22 的 `on_attack + kind` 方案） |
| `on_deal_damage` | 单位造成伤害时 | 仅在真正造成 damage 后 fire |
| `on_take_damage` | 单位受到伤害时 | 被击侧钩子 |
| `on_phase_change` | 战场相位跃迁时 | 2026-09-21 新增：`clock` 跨越相位边界、或 `set_luminance` 写入覆写层时 fire。战场级监听（不隶属单位），载荷携带 `fromPhase` / `toPhase` / `cause`(advance/override)。时钟只进不退，故不存在「回退相位」事件 |
| `on_status_gain` | 单位获得状态时 | fire 给**获得者**；语义层强制 frameworkFlag 登记制（2026-09-29 采纳为封闭集第 14 成员，怪物·意外之财首个消费方） |

两条语义纪律：
触发器载荷内的 `move` 与其他 move 同纪律：一律过 G8 faction 校验（2026-09-29 裁定，刺客·羽毛般轻盈）。`on_remove` 在自然到期（reason=expired）、驱散、消耗、被顶掉时均 fire，卸载原因四值 expired / dispel / consumed / overwritten（窥秘人·末日预言的到期爆发成立）。触发器 `condition` 用既有谓词族过滤事件（如 on_deal_damage + element_is = 仅某元素伤害时 fire，观众·细微观察）。


- `on_tick` 与 `on_turn_start` 的时间尺度不同：前者每 tick，后者约每 5 tick（敏捷 0）。状态内触发器用 `on_turn_start` 时，其 `duration` 必须 ≥ 该单位行动周期，否则改用 `on_tick`。
- `on_spawn` 会在召唤物/增援登场时重复 fire，凡"战斗开始时生效"一律用 `on_battle_start`。
- `on_attack` 与 `on_active_skill` 的分工：普攻只 fire `on_attack`；非攻击主动技能只 fire `on_active_skill`；攻击类主动技能**两者都 fire**（一次行为两条事件，各自独立判定）。需要「任何主动行为」语义的订阅方同时挂两者。

**全局第三方监听：** 触发点除挂载于单位自身外，还支持不隶属于特定单位的全局监听者（战场级规则、第三方触发）。其 fire 与结算独立于任何单位的生命周期；`on_death` 的全局监听会向**持有该被动的单位** fire，与 fire 给击杀者的 `on_kill` 分属两条路径。

> 🔴 **G15（引擎依赖，设计已闭环）**：`on_turn_start` 在引擎侧**从未 fire**，当前所有依赖它的技能与界域触发器**不生效**。它是触发点封闭集的正式成员、语义完整（见上表）——**引擎实现缺口，不是设计缺口**（2026-09-29 内核裁定销账：设计侧 frameworkFlags 全部落地，补 fire 点为主项目义务）。原 12 触发点表述已随 on_active_skill / on_phase_change / on_status_gain 扩为封闭集现值
>
> **影响面（2026-09-15 统计，共 19 处）**
>
> - 被动 `passive_hook` 4 处：`chanter/skill_chanter_s9_spirit_recovery`（灵性恢复）、`seer/skill_seer_s9_divination`（占卜）、`seer/skill_seer_s8_premonition`（直觉预感）、`savant/skill_savant_s5_star_deduction`（星轨推演）。

### 2.3 同标签连击计数器（cast_chain，2026-10-02 拍板）

施法者级计数 `caster.chain {tag, count}`：一次技能成功进入结算时，若其 `SkillDef.tags` 与施法者上一张已结算技能存在交集，则对应 tag 计数 +1；无交集（或跨回合/换 tag）则全部计数归零。计数被条件谓词 `tag_chain(tag, cmp, n)` 读取，承载同标签连击降费/增效（歌颂者圣咏连唱、猎人战阵号令、罪犯污秽连锁——机制所有权矩阵）。纯计数器、不改写行为本身；与 BehaviorModifier 的 energy_cost_mul 配合生效。

### 2.2 目标改写（target_override）

效果结算前可改写最终目标锚点。**锚点枚举同共享内核 anchor 全集（16 关键字 + <指定单位>，absolute 配 fixedIndex），不再有可用子集**（2026-10-01 补齐：原清单 7 值漏列 taunt_source 等，与总枚举漂移）。

改写为 `BehaviorModifier` 的 `target_override` 算子，聚合规则为覆盖（后者胜），单跳不递归。**层级：target_override（含嘲讽强制）> 行为显式 targetSpec > 缺省目标基准**（同路排首，见 `../params/共享内核参数.md` §一）；反制开关 = `target_override_immune`（H12 族）。

**嘲讽细则（2026-10-01 拍板）**：

- **force 语义 = 行为白名单**：被嘲讽期间仅可执行普攻，攻击类主动技能与其余技能全禁（聚合规则「disable 优先于 force」不变）。
- **嘲讽强制免疫转向**：I 节点对 taunt-forced Action 打标记，R 节点跳过转向收集——守护 / 守卫姿态 / 自转移均不可拆嘲讽（与 `ignore_redirect` 同出口）。
- **嘲讽与隐匿互斥**：嘲讽生效期间，嘲讽来源单位的 untargetable 类修饰符不生效（嘲讽 = 吸引注意，藏不住）。
- **多嘲讽源**沿用聚合规则「覆盖，后者胜」= 最近施加者胜出（施加时序在战斗记录内，确定性可复现）。
