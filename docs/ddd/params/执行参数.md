# 执行参数与取值域

本文件收容执行上下文（含行为/状态交互）的枚举取值域。技能示例值（火球术、旋风斩、烈焰风暴等）属示例，已从参数层剥离，不在此列出。

## 一、行为枚举

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| Behavior.trigger | active / passive | BehaviorTemplate | 主动 / 被动 |
| passive_hook | on_take_damage / on_death / on_turn_start / on_spawn / on_battle_start / on_kill / on_attack / … | BehaviorTemplate | 被动触发钩子 |
| BehaviorModifier.op | disable / force / energy_cost_mul / energy_cost_add / cast_time_set / cooldown_mul / target_override | StatusDef | 决策期约束算子 |
| 聚合规则 | disable 并集 / force 并集 / mul 乘积 / add 求和 / cast_time_set 取最小 / cooldown_mul 乘积 / target_override 覆盖 | 引擎常量 | 已定；disable 优先于 force |
| RedirectRule.to | self / attacker / transfer_target | StatusDef | 转向目标 |
| 转向优先级 | 守护 10 > 自转移 5 | 参数层 | 已定；单跳防环 |

## 二、转向（RedirectRule）说明

转向是执行期 R 节点的核心机制。守卫与守护同属一条 RedirectRule，只是选择器与来源过滤不同：

| 维度 | 守护 | 守卫姿态 |
|---|---|---|
| 受保护对象 | 一个指定单位（protectedSelector.kind = unit_ref） | 同路且 index 大于自己的全部单位（coordinate_relation） |
| 拦截来源 | 全部（sourceFilter: any） | 仅远程（sourceFilter: ranged） |

两个能力因此统一为一条机制，不必为"守卫"另造一套拦截系统。转向单跳（visited 集防环），伤害随转向走最终目标的防御，状态类效果留原目标。

### 2.1 v0.2 触发点与目标改写扩展

**被动触发点 `passive_hook` 取值（v0.2 扩展）：**
`on_take_damage / on_death / on_turn_start / on_spawn / on_battle_start / on_kill / on_attack / …`

新增 `on_attack`（H22）：持有者**发起攻击**时 fire，区别于 `on_take_damage`（被击时）。用于"攻击时附带额外效果"类状态，避免与受击逻辑耦合。

**目标改写 `target_override`（H12）：** 效果结算前可改写最终目标锚点，锚点枚举同共享内核 `anchor`（详见 `../params/共享内核参数.md`）：
`manual / nearest_any / any_lowest_hp / self_faction_hp_desc / spawned_unit / empty_ally_slot / <指定单位> / …`

**全局第三方监听（H20）：** 支持不挂载于特定单位的全局监听者（如战场级规则、第三方触发陷阱），其触发与结算独立于任何单位的生命周期，避免把"全局规则"伪装成"状态实例"。
