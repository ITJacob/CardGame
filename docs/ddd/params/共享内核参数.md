# 共享内核参数与取值域

本文件收容共享内核的枚举取值域（目标系统、元素）。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、目标系统（TargetRequest / TargetSpec）

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| faction | enemy / ally / self / self_or_ally | 共享内核 | 敌方默认取对位阵营 |
| laneRef | same_lane / cross_lane / all_lanes / auto | 共享内核 | auto 在 I 节点之前由施法者上下文预处理为具体值（same_lane / all_lanes），保持流水线纯函数 |
| anchor | front_line / self / front_of_self / behind_self / cross_same_index / absolute / first_empty / taunt_source | 共享内核 | absolute 需配 fixedIndex |
| scope | single_point / whole_lane / adjacent | 共享内核 | radius 已从取值域删除，改用 adjacent + spread 组合 |
| sort | none / hp_asc / hp_desc / atk_desc / index_asc | 共享内核 | 空坐标排序的兜底值需明确 |
| spread | none / lane_line / splash_adjacent / splash_behind / cross_same_index | 共享内核 | —— |
| mode | unit / area | 共享内核 | —— |
| consumption | instant / zone / summon | 共享内核 | mode=unit 时强制 instant |
| selectionMode | auto / manual | 共享内核 | 候选数 ≤ pickCount 时不触发玩家选择 |
| fallbackSort | 同 sort 取值域 | 共享内核 | manual 时必填（INV-E6），用于 AI / 状态触发 / 超时 |

## 二、元素属性

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| EffectDef.element | fire / ice / poison / shock / mental / physical / none | EffectDef | 六个元素 + none；纯标签 |
| DamageCategory | physical / magic / true | 派生（编目映射表） | 只读，服务于 UI 分组与流派规约；默认不参与结算（INV-EL3） |
| element → damageCategory 映射 | physical → physical；fire/ice/poison/shock/mental → magic；none → none | 参数层 | 待确认，映射表单点定义 |
| ResistanceSet 槽位 | fire / ice / poison / shock / mental / physical | BaseProfile + ModifierLayer | 逐元素一槽，走 sourceId 撤销；基线建议全 0（详见编队参数） |
| EffectCondition 元素谓词 | ElementIs(e) / ElementIn([...]) | 共享内核 | 供状态触发与流派判定 |

元素挂在 EffectDef（可被 EffectRef.params 覆写），不挂在 BehaviorTemplate 上。一次行动可产出多段不同元素的伤害；技能的"这是个火系技能"是派生：`derivedElements = union(全部 effect 的 element)`，只读、缓存、不双写。

element = poison 与"中毒"状态互不隐含：毒元素伤害不必然施加中毒状态，中毒状态的跳伤通常带 poison 元素，但那由状态本体声明。桥接一律走状态本体的触发表声明——是数据，不是代码。
