# 共享内核参数与取值域

本文件收容共享内核的枚举取值域（目标系统、元素）。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、目标系统（TargetRequest / TargetSpec）

|---|---|---|---|

## 二、元素属性

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| EffectDef.element | fire / ice / poison / lightning / mental / physical / holy / dark / none | EffectDef | 八元素 + none；纯标签（shock 退役→lightning；water 退役→tag，2026-09-13 裁定） |
| DamageCategory | physical / magic / true | 派生（编目映射表） | 只读，服务于 UI 分组与流派规约；默认不参与结算（INV-EL3） |
| element → damageCategory 映射 | physical → physical；fire/ice/poison/lightning/mental/holy/dark → magic；none → none | 参数层 | 映射表单点定义（shock 退役→lightning；water 退役→tag，不进映射；dark→magic） |
| ResistanceSet 槽位 | fire / ice / poison / lightning / mental / physical / holy / dark | BaseProfile + ModifierLayer | 逐元素一槽，走 sourceId 撤销；基线建议全 0（详见编队参数）；`resist:*` 通配见编目参数 §1.3 |
| EffectCondition 元素谓词 | ElementIs(e) / ElementIn([...]) | 共享内核 | 供状态触发与流派判定 |

元素挂在 EffectDef（可被 EffectRef.params 覆写），不挂在 BehaviorTemplate 上。一次行动可产出多段不同元素的伤害；技能的"这是个火系技能"是派生：`derivedElements = union(全部 effect 的 element)`，只读、缓存、不双写。

element = poison 与"中毒"状态互不隐含：毒元素伤害不必然施加中毒状态，中毒状态的跳伤通常带 poison 元素，但那由状态本体声明。桥接一律走状态本体的触发表声明——是数据，不是代码。

> **闭集裁定（2026-09-13）**：元素枚举封闭为**八元素 + none**。`water` 已退役为开放 tag（水不算伤害类型，退出枚举）；`shock` 已退役，雷电统一为 `lightning`。光 / 暗以 **`holy` / `dark` 成对**存在：`holy` 兼「光 + 净化」语义，`dark` 为独立抗性槽，二者可对称设置弱点（暗系单位负 `resist:holy`、光系单位负 `resist:dark`），不再用「负 `resist:holy`」单向 hack。
>
> 新风味（暗 / 黑焰 / 污秽 / 净化 / 亡灵 / 命运 / 月相 / 空间 / 风 / 血 / 自然等）**一律走 `tags`**（开放枚举，供 RulePatch `empower` 与流派过滤）、源质维度、显式状态或 `unitType`；需要抗性关系时**复用现有槽**，不新开元素。
>
> 新增第 9 元素须同时满足三重判据：**① 需要独立抗性槽 ② 需要独立状态触发 ③ 机制中心化且高频**。否则折叠进现有枚举或改走 tag。

## 三、效果条件谓词（EffectCondition）

条件判定统一为**带参谓词族**，不为每种比较新开一个 ID。

| 谓词 | 参数 | 语义 |
|---|---|---|
| `has_status` | `side, id, cmp, n` | 指定方是否持有某状态，且层数满足比较 |
| `has_category` | `side, categories` | 指定方是否持有指定类别的状态 |
| `hp_percent` | `side, cmp, n` | 指定方生命百分比比较 |
| `stat_compare` | `aUnit, bUnit, key, cmp` | 两名单位的指定属性相互比较 |
| `caster_has_summon` | `tag?, unitId?` | 施法者是否持有召唤物 |
| `caster_status_exists` | `id` | 施法者是否持有指定状态 |
| `zone_active` | `zoneId` | 场上是否存在指定区域 |
| `gauge_above` | `n` | 行动条进度高于阈值 |
| `dispelled_count` | `cmp, n` | 本次驱散数量比较 |
| `target_has_tag` / `target_unit_type` / `target_is_summoned` | tag / type / — | 单位标签体系谓词；type 值域 = unitType 12 值（权威见 `召唤物参数.md` §一） |
| `dead_count` | `side, cmp, n` | 指定方已死亡单位数比较（死者存在 = `cmp: '>=', n: 1`；通识者毁灭新生、耕种者最后回归之地的条件面） |
| `field_status_count` | `id, cmp, n` | 全场（不分敌我）指定状态实例数比较（存在性 = `cmp: '>=', n: 1`；耕种者枯荣循环、罪犯恶意化身的「场上仍有人带着我的污染」） |
| `hp_percent_compare` | `aSide, bSide, cmp` | 两名单位的生命**百分比**相互比较（歌颂者：目标 HP% < 自身 HP%；与 `stat_compare` 的绝对值比较互补） |
| `gender_is` | `side, value(male/female)` | 指定方性别判定（性别约束技能的条件面） |
| `faction_is` | `side, value(ally/enemy)` | 指定方阵营判定（相对施法者；怪物·精神洗礼的条件面）。2026-09-29 裁定转正：schema 枚举中的 `unit_faction` / `target_faction_is` 为同义稿面名，统一归并本行 |
| `phase_is` | `phases[]` | **战场相位判定**：当前 `board.phase` 属于集合之一即成立。取值域 `midnight / dawn / day / dusk / night`（见 `战场参数.md` §1.3）。月夜 = `phases:[night, midnight]` + 月相条件（2026-09-21 落地） |
| `luminance_compare` | `cmp, n` | **光照度比较**：`board.luminance` 与阈值比较（暗夜档 `cmp:'<=', n:2`；白昼档 `cmp:'>=', n:8`）。取值域 `int[0,10]`，官方档位 2 / 5 / 8（2026-09-21 落地） |
| `resource_compare` | `side, key, cmp, n[, aggregate]` | **单位 Pool 现值比较**：指定方指定 Pool（hp / energy / shield / armor / lost / lust）与常数比较（恶欲值档位判定：罪犯掌控欲望升级链读 `lust >= 1`）。Pool 枚举见 `效果参数.md` modify_resource.resource。**聚合读法（2026-09-26 裁定）**：可选 `aggregate:'sum'`——对 `side` 范围内全部单位的该 Pool 现值**求和后**与 n 比较（`side:'all'` 即双方全场∑；首个消费方【深渊即我】∑恶欲值≥15 免疫失控）。缺省 = 单单位现值 |

> ⚠️ **相位与光照度档位不严格同构**：黎明前段（tick 12–15，04:00–05:00）光照度 ≤2 会落在暗夜档。凡「必须是黎明/黄昏才算」的卡一律走 `phase_is`，**不要用 `luminance_compare` 近似**——2026-09-21 裁定。

> 位格**绝对值**比较走既有 `stat_compare(aUnit, bUnit, key: 'rank', cmp)`；**位格差**比较走新谓词 `rank_gap`（2026-10-02 拍板）——stat_compare 比较两名单位的值，表达不了「差 ≥N」的缺口语义（观众位格压制体系的地基）。

| `rank_gap` | `aUnit, bUnit, cmp, n` | 两名单位**位格之差**（a−b）与 n 比较——观众控制/读心的位格前提与差值缩放（如「位格高于目标 ≥2 则强制必中」）。 |
| `damage_source_is` | `sources[]` | **伤害来源类别判定**：本次伤害的来源属于集合之一即成立。取值域 `behavior`（行为伤害：攻击/技能/对撞/反击，进通用乘区）/ `status`（状态来源伤害：DoT 等持续伤害，不进乘区）——二分语义见执行上下文 §六；首个消费方为沉眠受击苏醒（只被行为伤害打醒，DoT 不醒） |
| `tag_chain` | `tag, cmp, n` | 施法者**同标签连击计数**比较：连续施放的技能与上一张同 tag 则计数 +1、断链归零（计数器规则见 `../params/执行参数.md` §2.3）；「已连唱 N 张圣咏」式降费/增效的条件面。 |

### 组合子（2026-09-14 落地）

谓词可嵌套组合。**不为每种复合条件新开谓词**，只用这三个组合子：

| 组合子 | 参数 | 语义 |
|---|---|---|
| `any_of` | `conditions[]` | 任一子条件成立即成立（OR） |
| `all_of` | `conditions[]` | 全部子条件成立才成立（AND，多条件并列时的显式写法） |
| `not` | `condition` | 取反 |

> - 可任意嵌套（如 `any_of` 内嵌 `all_of`）。
> - 概率条件（`chance`）作为子条件时仍受 R3 登记制与 R4 单次抽样约束：**组合子本身不抽样**，抽样只发生在被组合的叶子条件上。
> - 用量依据：技能库中 `any_of` 出现 27 处，此前 ddd 无组合子，稿面只能靠重复分支凑合。

## 四、候选池过滤器

目标系统级过滤器，供 `untargetable` / `untargetable_by_targeted` / 「识破」等候选池排除机制共用：

| 字段 | 取值 | 语义 |
|---|---|---|
| `direction` | `inbound` / `outbound` / `both` | 过滤方向：仅 inbound = 敌方不可选中；both = 双向；outbound = 不可选中全向排除 |
| `effectCategories` | `buff` / `heal` / `guard` / `damage` | 按效果类别分流，实现「不可被增益但可被伤害」这类非对称排除 |
| `weight` | int（默认 100） | 候选池加权：目标选择 / 召唤落位的倾向权重（收尸人·灵之同类减伤分支）；与 modify_targetability 同出口，2026-09-29 落地 |

**识破分支**：反向开关，参数 = 忽略隐匿 / 不可选中 × 对隐匿目标的伤害乘区。与候选池过滤器同出口，不另立机制。
