# 效果参数与取值域

本文件收容效果上下文的全部枚举取值域与数值。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、效果枚举

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| EffectDef.element | fire / ice / poison / lightning / mental / physical / holy / dark / none | EffectDef（可被 EffectRef.params 覆写） | 纯标签无内建数值语义（INV-EL1）。伤害类必填，其余填 none（shock 退役→lightning，water 退役→tag，2026-09-13） |
| Effect.type | damage / heal / mount_status / modify_stat / modify_resource / move / spawn / dispel / drain / domain / translocate / **snapshot** / **restore_snapshot** / **modify_damage** | EffectDef | 14 个（domain / translocate 于 2026-09-06 拍板新增；snapshot / restore_snapshot / modify_damage 于 2026-09-14 拍板新增）。⚠️ 后三者 schema 早有分支、技能库已在用，此前 ddd 只缺语义定义 |
| 扩展效果类型（语义暂缓） | gauge_shuffle / status_shuffle | EffectDef | 2026-09-14 裁定：**暂不落入 ddd**。schema 已预留分支，但当前仅服务单张传说卡（律师·秩序崩坏），为避免为极少数卡扩张原语集，语义与结算规则暂缓；技能稿维持 🟡 标记，待该卡进入实现阶段再定 |
| heal.mode | delta（默认）\| setHp \| hpMaxRatio \| to_ratio | EffectRef.params | delta = 按 value 回复；setHp = 直接置为 value；hpMaxRatio = 按最大生命比例置血；to_ratio = 回复至目标比例（配 `healToRatio`）。承载「复活 / 血肉不灭」类**置血**语义（秘祈人·血肉不灭等）。⚠️ 2026-09-13 登记：schema 早已允许，ddd 此前漏登 |
| snapshot | scope（快照字段范围，见下方 snapshot 字段范围行） | EffectDef | 保存目标单位当前状态快照（hp / pools / stats / statuses / gauge / coords 的子集），供后续 `restore_snapshot` 回滚。承载「保存 / 重启 / 备份」类能力（怪物·保存·重启、窥秘人·备份）。不进伤害链；同一单位默认只保留最近一张快照（多槽位暂不开） |
| restore_snapshot | snapshotId?（默认最近一张）、scope? | EffectDef | 按快照回滚目标单位状态。⚠️ 回滚**只恢复声明范围内的字段**，不返还已消耗资源、不重放已触发的一次性效果；与 `lethalProtect` 组合可实现「死亡回滚至 25% 血」（窥秘人·备份） |
| modify_damage | scope: dealt \| taken；mode: mul \| delta；value | EffectRef.params | **伤害链内的一次性修正**：在触发器载荷里改本次即将结算的伤害（如 `on_take_damage` 时 ×0.5）。⚠️ 与状态上的持续乘区 `damage_taken_mul` / `damage_mul` **是两回事**——本原语一次性、作用于单次伤害事件；持续减伤仍走状态修饰符（H4） |
| damage.source | attack / skill_formula / value | EffectDef | value 用于 DoT 等固定值 |
| modify_stat.duration | null（永久）/ 正整数（回合） | EffectRef.params | 带值时由账本条目自带 remaining 计时，到期 revertBySource；不产生 StatusInstance，不可被驱散（INV-P7） |
| modify_stat.stat | 战斗属性：attack / defense / armor（容量）/ rank（位格）/ summon_cap（召唤位上限）；资源上限：hp_max / energy_max；恢复速率与行动条源属性：energy_regen / gauge.rate / gauge.threshold；抗性槽：resist:fire / resist:ice / resist:poison / resist:lightning / resist:mental / resist:physical / resist:holy / resist:dark / resist:* | EffectRef.params | ⛔ 禁止修正派生值——但**「行动周期」才是派生值**（= threshold / rate），`gauge.rate` / `gauge.threshold` **本身是源属性，允许修正**：改速率或阈值就是改周期的正当方式（INV-S5 合规，2026-09-13 澄清，终结「改 gauge_threshold 是否触 INV-S5」悬案）。有效攻防（base+modifiers）同理只能改源属性。⚠️ `stamina_rate` / `stamina_threshold` 为**废弃旧名**，一律以 `gauge.rate` / `gauge.threshold` 为准（schema 与引擎同口径）。技能侧 gauge.rate 用量最高（76 处），此前本表漏登是框架待落地项的最大单一来源。抗性钳制 [-50%, +75%]、档位 10%；`resist:*` 为全元素通配（water 退役→tag，无 resist:water 槽）；`$` 前缀为**变量键**（如 `resist:$buildElement`——元素在派发 / 构筑时选定，取值由战外 Draft 层注入，本仓库不定义具体值；schema 已允许 `resist:$<key>`） |
| modify_stat.mode | delta（默认）\| set \| mul \| to_at_least \| to_at_most | EffectRef.params | set = 直接置值；mul = 乘性缩放（如 gauge.rate ×1.1 / ×0.85，与 delta 互斥）；to_at_least = 取不低于目标值；to_at_most = 取不高于目标值（封顶，如投影力量不超过序列 4 强度）。⚠️ 2026-09-13 双向补齐：卡面早有 `mul` 在用但本表漏登，schema 侧则漏了 `to_at_most` |

| snapshot 字段范围 | `hp` / `pools` / `stats` / `statuses` / `gauge` / `coords` | EffectDef | 快照与回滚的字段范围，逐字段显式声明；回滚只恢复声明范围内的字段 |
| dispel.target | unit / coordinate / domain | EffectRef.params | coordinate = 拆陷阱（移除 Zone）；domain = 解除上层/英雄界域（base 不可驱散，INV-B11） |
| dispel.filter | { dispelable?, category?: string[], statusId?, tier?, count? } | EffectRef.params | `category` / `statusId` / `count` 只对 unit 目标生效；`category` 扩为数组（可同时清 debuff+control）；`statusId` 精确点名（如「护盾」）；`tier` 只对 domain 目标生效（hero / overlay 按层过滤）；count 省略 = 全部清除 |
| drain.ratio / drain.healRatio | 伤害系数 / 回复系数（相对实际结算伤害） | EffectRef.params | 引擎内部闭环，只发一条 EffectApplied |
| drain.resource | 'hp' \| 'energy' | EffectRef.params | 搬运目标资源（默认 hp）；能量不足按实际值结算，不产生负数 |

### 1.1 补充效果参数

| 原语 | 参数 | 取值 | 说明 |
|---|---|---|---|
| damage | pierce | ('armor'\|'shield'\|'resist')[] | 跳过整层（枚举层） |
| damage | armorPierceRatio | 0~1 | 按比例破甲（与 pierce 并存，按强度分级） |
| damage | lethal | true | 处决：直达死亡结算，不吃 armor/减伤/抗性（H36） |
| damage | damageElementOverride | element | 施法者伤害元素覆写（如强制 mental） |
| spawn | hpRatio / position / reviveOf / oncePerBattle | 见下 | C5 通用 spawn 扩展 |
| spawn | template / count / variant / lifetime | 见下 | H17 召唤物参数族 |
| spawn | companionBuff | EffectRef[] | 召唤物自带增益（F54） |
| valueFrom | statusStacks / targetStat / maxStatThisBattle / battleStats / lastEffectReturn / dispelledAmount | 跨效果传值枚举 | 伤害/修正值取自运行时状态或战斗统计（H26）；`dispelledAmount` = 本次效果链中 dispel / modify_resource 清除掉的总量（护盾+护甲+状态数），供后续段引用（水手·物质转化：N = 被清除的防护总量） |
| domain | op / def / duration / priority | op: overlay / swap / hero | 降临压栈 / 置换对换底层（INV-B11 唯一出口）/ 英雄域挂载；duration -1 = 常驻；priority 默认按打出序号递增（后打出者压顶） |
| translocate | op / duration / returnPayload | op: pull_into / banish | 拉入 / 放逐：目标 detached N tick 后于己方队尾回归；banish 可带回归载荷 `returnPayload: EffectRef[]`（时空乱流，Chance 走 R3/R4）；放逐 ≤ 20 tick 为原著参考上限（⚠️D 内容侧纪律） |

- **spawn 参数**：`hpRatio`（按 hpMax 设初始血）、`position: 'tail' \| 'at_unit' \| 'original'`（重生落位）、`reviveOf`（指向某死亡单位复用其 def+坐标，实现复活语义，不新增第 10 原语；寻址死者用锚点 `last_dead_ally`，见共享内核参数 §一）、`oncePerBattle`（每场一次）、`template`（源单位+继承比例；**继承内容 = 属性按比例 + 完整技能组**（skillSlots / behaviorSlots 快照复制），除非显式覆写——观众·身份分离「继承施法者已装配技能组」依此语义，2026-09-04 确认）、`count`（一次多只）、`variant`（按条件选 unitId 表）、`lifetime`（到期自动消散，走 on_remove 消散路径）。
- **跨阵营 spawn**：把敌方死亡单位转为己方单位属**新建单位**，非 relocate 敌方单位，因此不违反位移铁律；落点恒为 `position: 'tail'`（己方半场队尾）。
- **damage.pierce 三种写法强度不同**（pierce 全跳 > ignore_armor 布尔 > armorPierceRatio 比例），归并时保留比例参数，不取最强。
- **跨效果传值 `valueFrom`**：统一取值来源枚举，避免把"吸血/按攻击力加成/本场峰值"等塞进术语；同族的 `status.consume`（读取并扣减指定状态层数）在状态/主动技能上下文均可引用。
- **hp_max 削减截断**：`modify_stat(hp_max, -N)` 生效时，若当前 hp 高于新上限则**立即截断**至新上限（不超额保留）；修正到期或按 sourceId 撤销回滚 hp_max 时**不回补**已截断部分（2026-09-04 确认；药师 / 通识者的生命上限削减技能依此语义）。

### Gauge 三维度（A24 开放）

| 键 | 语义 | 典型用法 | 钳制下限 |
|---|---|---|---|
| gauge.current | 行动条当前进度 | 击退 = modify_resource(gauge.current, -KNOCKBACK_DISTANCE) | 0（不得为负），KNOCKBACK_DISTANCE=50 |
| gauge.rate | 每 tick 累积速率 | 加速 / 减速（"敏捷 -50%"的原生表达） | 0 |
| gauge.threshold | 触发阈值 | 需要更多累积才能行动 | 1 |

⚠️ 行动周期 = threshold / rate 是派生值，⛔ 禁止被 modify_stat 直接修正（INV-S5）——要改周期，改上面两个源属性之一。

击退距离完整口径：击退不是引擎术语/算子，只是 `modify_resource(gauge.current, -KNOCKBACK_DISTANCE)` 的命名封装；距离固定为 50（一次性推后 50 点，阈值 75 → 推后约 2/3 行动周期），gauge.current 钳制下限 0 保持。该常量单一来源、可调，归属效果上下文而非战场结构（详见 `战场参数.md` §二 数值清单的指针行）。

### armor 的双重身份（易错点）

护甲既是吸收型 Pool（§8.2），又是可修正属性。两个 type 都能动它，但语义不同、不可互换：
- `modify_resource(armor, -3)` = 消耗当前值（打穿护甲，一次性）
- `modify_stat(stat: armor, -5, duration: 4)` = 降低容量持续 4 回合（破甲，到期回滚，INV-P7 不可驱散）
