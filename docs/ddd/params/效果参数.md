# 效果参数与取值域

本文件收容效果上下文的全部枚举取值域与数值。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、效果枚举

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| EffectDef.element | fire / ice / poison / shock / mental / physical / water / holy / none | EffectDef（可被 EffectRef.params 覆写） | 纯标签无内建数值语义（INV-EL1）。伤害类必填，其余填 none |
| Effect.type | damage / heal / mount_status / modify_stat / modify_resource / move / spawn / dispel / drain | EffectDef | 9 个 |
| damage.source | attack / skill_formula / value | EffectDef | value 用于 DoT 等固定值 |
| modify_stat.duration | null（永久）/ 正整数（回合） | EffectRef.params | 带值时由账本条目自带 remaining 计时，到期 revertBySource；不产生 StatusInstance，不可被驱散（INV-P7） |
| modify_stat.stat | 战斗属性：attack / defense / armor（容量）；资源上限：hp_max / energy_max；恢复速率：energy_regen / stamina_rate / stamina_threshold；抗性槽：resist:fire / resist:ice / resist:poison / resist:shock / resist:mental / resist:physical / resist:water / resist:holy / resist:* | EffectRef.params | ⛔ 禁止修正派生值——行动周期（threshold/rate）、有效攻防（base+modifiers）都只能改源属性（INV-S5）。抗性钳制 [-50%, +75%]、档位 10%；`resist:*` 为全元素通配 |
| modify_stat.mode | delta（默认）\| set \| to_at_least | EffectRef.params | set = 直接置值；to_at_least = 取不低于目标值（不足则补足，超出不动） |
| modify_stat.sourceRef | `<单位>` \| `'field_average'` | EffectRef.params | 配合 set / to_at_least 取参照值；field_average = 全场均值（实现「拉平」语义） |
| snapshot 字段范围 | `hp` / `pools` / `stats` / `statuses` / `gauge` / `coords` | EffectDef | 快照与回滚的字段范围，逐字段显式声明；回滚只恢复声明范围内的字段 |
| dispel.target | unit / coordinate | EffectRef.params | coordinate = 拆陷阱（移除 Zone） |
| dispel.filter | { dispelable?, category?: string[], statusId?, count? } | EffectRef.params | 只对 unit 目标生效；`category` 扩为数组（可同时清 debuff+dot+control）；`statusId` 精确点名（如「护盾」）；count 省略 = 全部清除 |
| drain.ratio / drain.healRatio | 伤害系数 / 回复系数（相对实际结算伤害） | EffectRef.params | 引擎内部闭环，只发一条 EffectApplied |
| drain.resource | 'hp' \| 'energy' | EffectRef.params | 搬运目标资源（默认 hp）；能量不足按实际值结算，不产生负数 |
| drain.category | 'buff' | EffectRef.params | 从目标转移可驱散增益到施法者（保留剩余 duration），区别于 dispel 销毁语义 |
| move.op | swap_neighbor / insert_tail_cross_lane / swap_ally / param / pull_forward / push_back / charge_forward | EffectRef.params | 全部是占位变更（pull_forward/push_back 已落地，锁定 from.faction 合规；charge_forward 为扩展候选）。击退不在这里——它改的是 Gauge，走 modify_resource(gauge.current, -KNOCKBACK_DISTANCE) |
| modify_resource.resource | Pool：hp / energy / shield / armor（当前值）；Gauge：gauge.current / gauge.rate / gauge.threshold | EffectDef | ⚠️ 加血请用 heal，这里只用于直接扣除；可作用于敌方单位，下限截断为 0（不进负值） |
| modify_resource.mode | delta（默认）\| set | EffectDef | set = 直接置值（配合 sourceRef 实现「拉平/等于」语义），下限截断 |

### 1.1 补充效果参数

| 原语 | 参数 | 取值 | 说明 |
|---|---|---|---|
| damage | pierce | ('armor'\|'shield'\|'resist')[] | 跳过整层（枚举层） |
| damage | armorPierceRatio | 0~1 | 按比例破甲（与 pierce 并存，按强度分级） |
| damage | lethal | true | 处决：直达死亡结算，不吃 armor/减伤/抗性（H36） |
| damage | damageElementOverride | element | 施法者伤害元素覆写（如强制 mental） |
| spawn | hpRatio / position / reviveOf / oncePerBattle | 见下 | C5 通用 spawn 扩展 |
| spawn | template / count / variant / lifetime | 见下 | H17 召唤物参数族 |
| spawn | companionBuff | EffectRef[] | 召唤物自带增益（F54） |
| valueFrom | statusStacks / targetStat / maxStatThisBattle / battleStats / lastEffectReturn | 跨效果传值枚举 | 伤害/修正值取自运行时状态或战斗统计（H26） |

- **spawn 参数**：`hpRatio`（按 hpMax 设初始血）、`position: 'tail' \| 'at_unit' \| 'original'`（重生落位）、`reviveOf`（指向某死亡单位复用其 def+坐标，实现复活语义，不新增第 10 原语）、`oncePerBattle`（每场一次）、`template`（源单位+继承比例）、`count`（一次多只）、`variant`（按条件选 unitId 表）、`lifetime`（到期自动消散，走 on_remove 消散路径）。
- **跨阵营 spawn**：把敌方死亡单位转为己方单位属**新建单位**，非 relocate 敌方单位，因此不违反位移铁律；落点恒为 `position: 'tail'`（己方半场队尾）。
- **damage.pierce 三种写法强度不同**（pierce 全跳 > ignore_armor 布尔 > armorPierceRatio 比例），归并时保留比例参数，不取最强。
- **跨效果传值 `valueFrom`**：统一取值来源枚举，避免把"吸血/按攻击力加成/本场峰值"等塞进术语；同族的 `status.consume`（读取并扣减指定状态层数）在状态/主动技能上下文均可引用。

### Gauge 三维度（A24 开放）

| 键 | 语义 | 典型用法 | 钳制下限 |
|---|---|---|---|
| gauge.current | 行动条当前进度 | 击退 = modify_resource(gauge.current, -KNOCKBACK_DISTANCE) | 0（不得为负），KNOCKBACK_DISTANCE=50 |
| gauge.rate | 每 tick 累积速率 | 加速 / 减速（"敏捷 -50%"的原生表达） | 0 |
| gauge.threshold | 触发阈值 | 需要更多累积才能行动 | 1 |

⚠️ 行动周期 = threshold / rate 是派生值，⛔ 禁止被 modify_stat 直接修正（INV-S5）——要改周期，改上面两个源属性之一。

### armor 的双重身份（易错点）

护甲既是吸收型 Pool（§8.2），又是可修正属性。两个 type 都能动它，但语义不同、不可互换：
- `modify_resource(armor, -3)` = 消耗当前值（打穿护甲，一次性）
- `modify_stat(stat: armor, -5, duration: 4)` = 降低容量持续 4 回合（破甲，到期回滚，INV-P7 不可驱散）
