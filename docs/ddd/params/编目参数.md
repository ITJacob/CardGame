# 编目参数与取值域

本文件收容编目上下文（术语）的枚举取值域。默认值与上下限只写在 Def，实例值只写在 Grant/params（INV-C2）。

## 一、术语（Term）枚举

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| TermDef.category | attack_shape / rider / trigger / mobility / guard / … | TermDef | 取值域开放，服务于 UI 分组与流派检索 |
| TermComposition 算子 | Sequence / Repeat / If | TermDef | 首批三个算子。If.cond 复用 EffectCondition 谓词。跨效果传值（吸血等）不进术语，做成独立 EffectDef(drain) |
| Repeat.shareTarget | true（默认）/ false | TermDef | true = 多段共享同一冻结坐标（INV-T5） |
| TermDef.overridable | 参数名白名单，默认空 = 完全固定 | TermDef | Grant 覆写越界即编目期报错（INV-T3） |
| TermGrant.overrides | { 参数名: 值 } | TermGrant | 键必须是 overridable 子集 |
| originTerm | 术语 id 的完整引用路径（支持嵌套） | EffectRef（只读） | 烙印于编目期展开；不参与结算，供战报/UI/流派统计 |
| 术语引用图 | 必须无环 | 引擎常量 | Catalog 加载时静态校验（INV-T2） |
| 术语文案占位符 | {count} / {element} / {ratio} / {threshold} / {duration} / {stacks} / {armor_delta} / {status_name} | 参数层 | INV-T4 要求文案由实参渲染 |

## 二、术语展开要点

- 术语 = 命名的效果参数组合，服务于人而非引擎；编目期展开为扁平 EffectRef + originTerm 溯源烙印，运行期零感知。
- 术语内多段默认共享同一冻结坐标，段间不重新解析目标；目标死亡则后续段落空（INV-T5）。
- 术语展示文案由实际生效参数渲染，不允许与实参脱节——"风怒"真打三下就必须显示三下，或改名（INV-T4）。
- 流派 = 基于术语与元素的规约（如「风怒流 = 含 wind_fury 的技能 ≥ 2」），是纯查询，不进战斗。
