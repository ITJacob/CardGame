# 肉鸽派发参数（Progression）

本篇定义派发层的取值域与参数约束。所有字段只在局外构筑 / 抽取阶段消费，不进入战斗结算（见 `../contexts/肉鸽派发上下文.md`）。

## 一、派发元信息（SkillDef 候选定义）

| 参数 | 类型 | 取值域 / 约束 | 说明 |
|---|---|---|---|
| `rarity` | enum | `common` / `uncommon` / `rare` / `epic` / `legendary` | 稀有度分级，见 §1.1 序列位阶映射 |
| `weight` | number | `≥ 0` | 同池内相对抽取权重，0 表示本池不出现 |
| `pool` | poolId | 抽取池标识 | 按 run / 章节切换候选集 |
| `pathway` | pathwayId | 途径标识 | 职业过滤维度 |
| `buildAxis` | axisId | 本途径构筑轴标识，见 §二 | 技能在构筑轴上的归属 |
| `sharedAcross` | pathwayId[] | 途径标识列表（可空） | 跨途径共享，见 §1.2 |
| `desc` | string | 非空 | 玩家视角文案，派发展示用 |
| `modes` | modeId[] | 多选一 / 变体档（可空） | 数据层，与升级阶梯同族实现，不进引擎 |

### 1.1 稀有度 = 序列位阶映射

稀有度不另设维度，由途径序列位阶自然映射：

| rarity | 序列位阶 | 权重档 | 定位 |
|---|---|---|---|
| `common` | 9–8 | 高 | 骨架，构筑基底 |
| `uncommon` | 7–6 | 中 | —— |
| `rare` | 5–4 | 低 | 构筑核心 |
| `epic` | 3–2 | 很低 | 大招 |
| `legendary` | 1–0 | 极低 | 一局 ≤ 1 |

### 1.2 跨途径共享（sharedAcross）

共享沿**相邻途径**生效：同一源质分组内、序列位阶相邻的途径可重复抽到同一技能。取值域为途径标识列表，空表示本途径独占。

## 二、构筑轴（buildAxis）

每条途径定义 4 条构筑轴，用于把技能池按玩法维度分组，使派发与构筑有可辨识的方向。

| 参数 | 类型 | 约束 |
|---|---|---|
| `axisId` | id | 途径内唯一 |
| `pathwayId` | id | 所属途径 |
| `keyword` | string | 轴的关键词 |
| `playstyle` | string | 玩法定位 |

- 每途径固定 4 轴，且 4 轴须覆盖该途径全部序列的能力谱系。
- 技能池内每个技能归属且仅归属一条构筑轴；每轴挑一个旗舰技能作为该轴的强度锚点。
- 构筑轴只影响派发展示与分组，不进入战斗结算。

## 三、槽位约束（UnitDef）

| 参数 | 类型 | 默认值 | 约束 |
|---|---|---|---|
| `activeSlots` | integer | 4 | `≥ 1`，主动技能槽位数 |
| `passiveSlots` | integer | 4 | `≥ 1`，被动技能槽位数 |

## 四、重复获得规则（duplicatePolicy）

| 取值 | 类型（枚举） | 语义 | 关联 |
|---|---|---|---|
| `upgrade` | `'upgrade'` | 重复抽到 → 走 UpgradeTrack 升一档 | 配合升级阶梯 |
| `reject` | `'reject'` | 重复抽到 → 丢弃，补抽 | —— |
| `stack` | `'stack'` | 重复抽到 → 叠加实例 | 多层 Grant |

## 五、升级阶梯（UpgradeTrack）

| 参数 | 类型 | 说明 |
|---|---|---|
| `skillDefId` | id | 所属候选技能 |
| `tiers` | tier[] | 每档 = 参数增量集 或 形态选择（modeId）；`tiers[0]` 为基准档 |
| `tier.delta` | 参数增量 | 升档时叠加 / 覆盖的数值（具体口径由数值层标定） |
| `tier.mode` | modeId? | 升档时切换的形态档 |

## 六、构筑快照（BuildSnapshot）

| 参数 | 类型 | 约束 |
|---|---|---|
| `unitId` | id | 目标单位 |
| `slots` | BuildSlot[] | 长度 = activeSlots + passiveSlots，每槽一填充技能 |
| `BuildSlot.kind` | `'active'` \| `'passive'` | 槽位类型 |
| `BuildSlot.filledSkillDefId` | id | 填充的候选技能定义 |

## 七、取值范围纪律

- 派发层所有 `weight` / 档位增量属**数值层标定项**，本篇只固定类型与 `≥ 0` / 非空等结构性约束，不给具体数值。
- `modes` 与 UpgradeTrack 的 `tier.mode` 共享同一 modeId 命名空间，二者是同一"变体档"概念的数据层与升级层两面。
