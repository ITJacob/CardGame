# 律师 lawyer 重设计日志

## 玩法蓝图（2026-10-23 C3 判例制重构 · 环节⑥拍板）

### 命题
| 一句话命题 | 可操作变量 | 变量代价/输面 |
|---|---|---|
| 判例制——不写新规，只引用本场已经发生过的事：被驱散过、死过、被消耗过的东西都会成为先例；先例一旦成立不可撤销，你和对手都能引用它 | 先制造哪种先例（驱散/死亡/消耗）、何时援引、先例被对手共享时如何取舍 | 先例未发生则判例空转；先例被对手援引；先例类型与局面不匹配；立案本身花掉行动机会 |

**模型落点**（阴阳师式进度条回合制，无手牌）：`precedent`（先例，duration null 永续）由立案·侵蚀/立案·死亡施加，params 记录 erosion / consumption / death；判例卡用 `recorded_has` 读键，并配合 `dispelled_count` / `dead_count` 等既有事件计数谓词确认「先例已发生」。计数只增不减——先例不可撤销。
