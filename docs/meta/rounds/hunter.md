# 猎人 hunter 重设计日志

## 玩法蓝图（2026-10-23 A 骨架重构 · 环节⑥拍板 P1 集众围猎）

### 命题
| 一句话命题 | 可操作变量 | 变量代价/输面 |
|---|---|---|
| 集众围猎——先标定猎物，再用集众层数指挥全队把火力收拢到它身上；层数来自全队的协同行动，花在改指、集火与分担上 | 标谁（weak_point 弱点对象 / prey_mark 猎物对象）、集众层数怎么花（集结 / 改指 / 集火 / 分担） | 标记被驱散或猎物被换走则层数空转；减员压低产层速度，指挥断档；把层花错对象则输出断档 |

**模型落点**（阴阳师式进度条回合制，无手牌）：集众层数 = 指挥容量，上限 3（内核 maxStacks 静态，人数通过产层速度约束：存活友军 ≥2 每回合 +1、≥4 每回合 +2）；弱点 weak_point = 公开易伤（受伤 ×1.3），只由弱点侦察/羞辱施加；猎物 prey_mark = 集火信号（全队对猎物额外段），由标定猎物单卡主授予。三者分工不混：弱点放大伤害、猎物决定打谁、集众决定能指挥几次。
