## 2026-10-20 通灵之眼 ↔ 灵体灵性权柄（0.0612）

- **根因**：两张被动都只 `mount_status` 一个状态，旧指纹只看卡面节点，看不到状态自身的 modifiers / immune / 触发器——卡面双方都退化成一个挂载节点。
- **口径修复（SCORING 2.9）**：卡面挂载状态 def 的形态与 `triggers[].effects` 并入卡级效果空间与 `sshape`；未改卡面。
- 结果：0.0612 → **0.2322**；不眠者最近对 0.0612 → **0.127**（入梦 ↔ 强制入梦），<0.20 对数 12 → 3；总分 89.4 → 90.8。

## 2026-10-20 入梦 ↔ 强制入梦（0.127）

- **分化**：强制入梦追加「梦滞」——对**已入梦**的敌人行动条 -10（该段放在伤害前，读取命中前的 dream 状态）；与入梦形成「先入梦、再强制」的追击，而不是两张同机制的单击/群发副本。
- 结果：0.127 → **0.2282**；不眠者最近对 0.127 → **0.1421**（午夜武艺 ↔ 守夜人体质），<0.20 对数 3 → 2；总分 90.8 → 90.9。

## 2026-10-20 午夜武艺 ↔ 守夜人体质（0.1421）

- 结果：0.1421 → **0.2096**；不眠者最近对 0.1421 → **0.1546**（不眠之躯 ↔ 夜视），<0.20 对数 2 → 1；总分 90.9 → 91.2。

## 2026-10-20 午夜武艺 ↔ 守夜人体质（0.2096，第二轮）

- **显式目标**：两张卡的机制已不同（午夜武艺=受击反挂恐惧，守夜人=相位光环+白昼惩罚+迎夜），但午夜回击的恐惧目标在 AST 里是隐式的，指纹只看到 `eff:self`。把 `target:"attacker"` 显式写出（与卡面「反挂攻击者」一致，触发语境不变）。
- 结果：0.2096 → **0.2514**；不眠者最近对 0.2114（通灵之眼 ↔ 一心多用），<0.20 仍为 0；总分 91.3 不变。
