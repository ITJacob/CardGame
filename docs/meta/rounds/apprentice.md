# 学徒 apprentice 重设计日志

## 玩法蓝图（2026-10-23 E2 同时结算重构 · 环节⑥拍板）

### 命题
| 一句话命题 | 可操作变量 | 变量代价/输面 |
|---|---|---|
| 预排时空——先把几式动作排进时空里，最后一次同时打出；排在里面的内容和顺序不能再改，预判错就落空 | 预排哪几式（攻势/身法）、何时同时结算、预判对手是否位移或免疫 | 对手位移/免疫则对应段落空；预排类型与局面不匹配则收益低；结算前预排被驱散则整段作废 |

**模型落点**（阴阳师式进度条回合制，无手牌）：`staged_scene`（预排场景）记录动作类型（params kind_attack / kind_move），由预排·攻势/预排·身法施加；同时结算卡用 `recorded_has` 读 params 键，按固定顺序（攻势→身法）在同一个 Action 内连续执行，然后清空。顺序不可改，预判错误由段落空承担。
