## 格① 命题

> **战士玩家在局内主动改变「场上谁是那个被宣判的将死之人」**，它由 2 张卡写入（处决登记 / 迟暮），8 张卡读取，代价是**下一次自己行动结束前未斩杀 → 撤销标记 + 目标护盾 + 自伤 + 该单位本场不可再宣判**。

- 选 A（宣判者）：三候选中唯一有输面（没死挨罚 / 被队友抢杀白花 Action）。
- B 相位切换降级不做（无输面）；⑯伪装 / ㉛战斗权柄的 then/else 绑定保留。
- 私有「将死」标记路线，**不写 `death_tally`**（避免跨途径污染与虚假联动分）。
