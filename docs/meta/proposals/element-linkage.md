# 元素联动与标签玩法（设计箱①）

> 状态：**首批已拍板并落地（2026-10-24）**；第二批（共鸣 3/4 档、标签联动）待排期。
> 范围：`docs/json/` 状态层 + 游戏内核伤害链；不动原语枚举。

## 一、拍板（2026-10-24）

- **承载方向：混合**——common 元素状态自带共鸣触发器（全局跨途径）；升阶/私有化写途径卡面读段。
- **相消形式：每命中削 1 层**；削到 0 正常卸载（on_remove 照常 fire）。
- **相消成本：本次伤害 ×0.85**（「用力驱寒，火势便弱」）。
- **对立表：稀疏**——火×冰、圣×暗；毒/精神/雷不入表。
- **首批范围**：共鸣 1/2 档 + 相消；共鸣 3/4 档与标签联动排后。

## 二、首批落地

- `StatusDef.element`（schema + 内核）：burn=fire、poison=poison、blood_chill=ice、sacred_flame=holy、black_flame=dark。
- 共鸣（状态端触发器）：
  - burn：火伤 → 灼烧 +1 层（增效档，maxStacks 封顶）。
  - poison / blood_chill / sacred_flame：同元素伤害 → +2tick（续态档，固定小增量非满刷新）。
- 相消（伤害链前置）：对立元素可驱散状态每命中削 1 层；命中时本次伤害 ×0.85。只削状态层，不改抗性。
- 单测 `game/tests/elementLinkage.test.ts`。

## 三、第二批（2026-10-24）

- 共鸣 3 档（计数爆发）：灼烧的火伤计数载体 `burn_resonance`（3 次→3 点火伤并清零）。
- 共鸣 4 档（升阶转化）：灼烧 3 层→燃焚；中毒 3 层→疾病（原状态移除）。
- 燃焚标记 fire、疾病标记 poison，继续参与相消/共鸣判定。

## 四、残留
