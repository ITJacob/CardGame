# 骨架重议（SKELETON REVIEW）

> 环节⑥常驻议事文档（定义见 `WORKFLOW.md`）。输入 = 蓝图命题三格 + 可操作变量列 + `playable_scan` 2×2；
> 输出 = 撞车簇裁定、候选新骨架、机制扩容请求、拍板记录。
> 纪律：AI 只出候选、主人拍板；命题聚簇**不进** `score.py` 100 分（只作议事输入）；未过 Gate 不动卡池。

## 一、盘点方法（2026-10-23 首轮）

- 数据源：`docs/meta/rounds/*.md` 的 `### 命题` 表（一句话命题 / 可操作变量 / 变量代价/输面），22/22 齐备。
- 判定依据：三格合读，不只看一句话命题；重点看「可操作变量」列写的是**玩家做什么决定**。
- 本轮为一次性人工聚簇，不新增脚本、不新增评分指标。后续轮次沿用同一口径，可再议是否脚本化。

## 二、撞车簇

| 簇 | 骨架 | 途径 | 数量 |
|---|---|---|---:|
| A | **前置门槛**：先垫一个量，量不够收益打折/失效 | reader、pryer、spectator、seer、hunter、warrior、apothecary | 7 |
| B | **累积—择时兑现**：量自然/投入增长，玩家挑引爆时点 | corpse_collector、criminal、planter、savant、monster、thief | 6 |
| C | **规则层收租**：写规则/誓约/篡改，靠对手违例进账 | arbiter、chanter、lawyer | 3 |
| D | **自反代价**：自己先吃亏再转嫁/回流 | prisoner、supplicant | 2 |
| E | **编排顺序**：位移链、换位次序、元素轮转是主动作 | assassin、apprentice、sailor | 3 |
| F | **独立**：全局时间通道推进税 | sleepless | 1 |

**结论**：A+B = 13/22 ≈ 59%，骨架都是「建一个量 → 量决定收益 → 择时兑现」，差异主要在**通货名字**与**量从哪来**，不在玩家做的决定。输面更同质：空窗被滚雪球 / 对手不配合 / 资产被清 / 付过头反噬 / 概率落空，五类覆盖全部 22 条；C 组三条的输面是同一句「对手不配合则空转」。

判据：**决策类型相同**才算撞车；只共享输面或只共享措辞不算。

**warrior × hunter 划界红线（2026-10-23 拍板 R1–R4，照准）**

- **R1 契约独占**：`doom_mark` / `doom_debt` / `doom_sealed` 为 warrior 私有，不跨途径共享；他途径不得复制「限期未达成 → 违约惩罚」结构。
- **R2 标记性质不可互换**：hunter 的 `weak_point` 保持公开易伤（可驱散、自然过期、无惩罚），不得升级为契约；warrior 的 `doom_mark` 不得做成对全队生效的公开易伤。
- **R3 兑现形态分叉**：hunter 的终局是「标记存在 → 直接致死」（毁灭之矛 / 毁灭权柄）；warrior 不获得 lethal 型标记处决，兑现靠读层集火 + 限期压力。
- **R4 模板去重**：hunter 停止「标记 → 追加 N 伤害」通用模板，收割轴改「标记 × 集众」复合兑现；warrior 读层额外段保留，但不得给将死目标附加公开易伤状态。

### 7.2 新划界候选（待主人拍）

**thief × assassin(E3)「借」字同形不同义**

- thief「有借有还」：借的是**资产 / 身份 / 时间**，带时限归还，借来之物可被驱散、到期强制还回。
- assassin「镜映借序」：借的是**对手最近一次动作**，在己方序列重放，不承所有权、无归还结算。

| 编号 | 红线候选 |
|---|---|
| T1 | thief 的借物必须保留归还 / 时限结构，不得升级为「把对手动作纳入己方序列」 |
| T2 | assassin 的借序不得承接财产 / 状态所有权，不产生归还结算 |
| T3 | 两者不共用正主状态：`deep_parasitized` 归偷盗者寄生轴，`borrowed_step` 归刺客借序轴 |

**apothecary × planter（母巢同源）**：非撞车——决策不同（预服剂量窗口 vs 接受/拒绝催熟），
但指纹距离 0.147 为全库第二近；处置走差异化整理，不换骨架。

**spectator × apprentice**：非撞车（位格压制 vs 预排同时结算）；0.179 属指纹趋同，整理即可。
