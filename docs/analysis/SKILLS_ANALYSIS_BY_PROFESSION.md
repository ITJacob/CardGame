## 七、结论与观察

1. **原语总量**：全库共 2714 个原语节点 + 889 个算子节点；`mount_status`(32%) 与 `damage`(18%) 仍是绝对主力，状态驱动风格延续。
2. **modify_stat 最常被改的属性**：`attack`(111)、`defense`(97)、`gauge.rate`(40) —— 敏捷原生的 `gauge.rate`、攻防 `attack/defense`、资源速率与独立资源槽是首选。
3. **modify_resource 最常被改的资源**：`gauge.current`(119)、`lost`(78)、`energy`(54) —— `energy` 是第一杠杆，`lost`（迷失租金）已随界域/跨层普及成为常态成本，`gauge.current`（推条）用量高于直接 hp/shield。
4. **参数使用**：modify_stat 中带 `duration` 的占 66%（持续型修正为主），带 `condition` 的仅 1%（绝大多数无条件是确定性修正，符合 B1 铁律）；`sourceRef`/`valueFrom` 动态取值共 14 处，属「按参照源缩放」的高级表达。
5. **职业差异**：详见 §二/§2.2 矩阵与 §3.4/§4.4。各职业 Top 原语（§2.3）显示签名表达——召唤系（不眠者/收尸人/秘祈人）`spawn` 偏高，控制系（刺客/囚犯）`move`+`dispel` 偏高，能量系（愚者/阅读者）`modify_resource(energy)` 偏高。
6. **数据质量**：见 §五。未发现问题。
