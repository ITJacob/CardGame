# 参数层 · 枚举取值域与数值清单 v1.5


本文件的定位：《领域模型详细设计 v1.1》刻意剥离了全部枚举取值与数值，本文是那些内容的集中收容处。
v1.1 新增维度：reach / selectionMode / protectedSelector / sourceFilter / stance（见 §1.1、§1.3、§1.7）。
它不是设计稿，而是一份"待回填清单"：每个条目都标注了在新模型下的归属位置、当前值出处、以及状态（沿用 / 待评审 / 冲突待裁定）。
所有数值在骨架落地后需要重新过一遍平衡评审，本文只负责不让它丢失、不让它错位。

## 0. 三条归属原则

|||
|---|---|
|单点定义|默认值与上下限只写 Def；实例值只写 Grant / params。任何一处重复定义都是配置错误（INV-C2）|
|上下文归属|数值放在它所约束的上下文里：调度数值归调度，战场结构数值归战场，平衡数值归参数层|
|可审计|凡影响 TTK / 胜率的数值，必须能被平衡审计工具单独筛出|

#### 1.2.1 Gauge 三维度（A24 新增）

||||
|---|---|---|---|
|gauge.current|行动条当前进度|击退 = modify_resource(gauge.current, -50/n)|0（不得为负）|
|gauge.rate|每 tick 累积速率|加速 / 减速（"敏捷 -50%"的原生表达）|0|
|gauge.threshold|触发阈值|需要更多累积才能行动|1|


⚠️ 行动周期 = threshold / rate 是派生值，⛔ 禁止被 modify_stat 直接修正（INV-S5）——要改周期，改上面两个源属性之一。

击退终于落地：§2.3 已标定的锚点「击退收益 50/n tick」此前无 effect 承载（move.op 全是占位变更、modify_resource 碰不到 Gauge），现在有解了。
n 的含义待确认（推测为"所在路单位数"或"击退距离"），见 §4 第 31 项。

顺带解锁：gauge.rate 开放后，总览 v6 那套"眩晕 = 精力恢复归零"的老实现也可表达——但 v1.3 已裁定眩晕走 disable（§3.7），此路不再推荐。
