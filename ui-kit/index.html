选中提示按钮 .cg-select

默认空环；选中变黄铜实心环 + 对勾 + 发光（不靠颜色辨识，带图标与文案）。点下方可切换。

返回箭头 .cg-back

内联胶囊与悬浮圆形（.cg-back--fab）两种；左下角即一个悬浮实例。

关闭按钮 .cg-close

圆形黄铜描边 X，hover 提亮；弹窗标题栏右侧即其实例。

弹窗 .cg-modal

遮罩模糊 + 入场淡入放大；顶部黄铜细线；含标题 / 正文 / 操作栏 / 关闭按钮。下方为流内静态预览，点「打开弹窗」看真实浮层。

输入框 .cg-input

暗底黄铜描边，聚焦发光；含图标前缀、错误态、禁用、多行（textarea）。

开关 .cg-switch

纯 CSS 切换（隐藏 checkbox），暗轨道 → 黄铜填充 + 圆点发光；含副说明与禁用态。

进度条 .cg-progress

暗轨道 + 黄铜渐变填充 + 发光；含 warn / ok 多色与 lg 尺寸。点「模拟充能」看动画。

Toast 轻提示 .cg-toast

右下角浮层，3.2 秒自动消失（或手动关闭）；含 info / ok / warn 三型，神秘学左线描边。

区域容器 / 面板 .cg-panel

界面上一小块区域的局部背景框，区别于整页 .cg-bg（全屏暗雾）。用于菜单、按钮组、翻页主体等。与「区域卡片 .cg-card」无关——卡片是角色/技能卡面，面板是界面区块的框。
