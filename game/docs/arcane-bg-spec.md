## 1. 概念锚点

### 1.1 意象依据（全部取自 `docs/诡秘之主资料库/` 与 `assets/frames/TAROT_SYMBOLS.md`，无外来设定）

| 锚点 | 出处 | 落到本设计 |

| **灵界「完全重叠、互不干涉」** | `诡秘之主-世界体系素材库.md:43` ——「灵界和现实世界完全、全部重叠，却又互不干涉……没有『入口』，只有『穿透』」 | 本背景的存在方式就是这条设定的复刻：一个与现实层完全重叠、看得见却碰不到、绝不干涉的层。`pointer-events:none` + 装饰性低不透明，是把设定翻成 CSS。 |
| **灵界七光** | 同表第 2 层 ——「七道净光……活着的高位存在，位格仅在神灵之下」 | R1 上 **7 枚符文**。数量是灵界的主位序列，不是为美学凑的。光是「活着」的 → 明灭而不只是旋转。 |

| **灰雾之上 / 源堡** | 素材库第 14 层 | 现有 `.cg-bg--fog` 的双团暗雾已经是灰雾。新层不是画在灰雾上，是画在**灰雾之中**——这也是新层位于暗雾之下的叙事原因。 |

### 1.2 符文选字：为什么是这 7 枚

`ui-kit.svg` 现有 `cg-sigil-*` 精灵恰好 **7 枚**：愚者 / 隐者 / 命运之轮 / 塔 / 星星 / 月亮 / 太阳。选它们的理由：

1. **已经存在** —— `<use href="#cg-sigil-…">` 直接引用，新增 bit 为 0。
2. **覆盖全套牌序的两端与中段**（0 / IX / X / XVI–XIX）。
3. **数量刚好对上七光**。免责：这 7 枚是「途径徽记」，**不是**七光的本体，只在**数量**上与七光共振——借用口彩，不是设定宣告。

> 扩展路径（非本轮）：补满 22 枚进 `ui-kit.svg` 后，R1 可升级为完整途径环。仍是矢量。

### 1.3 为什么它适合「首页主菜单」这个门面位置

1. **首页是全站唯一不需要信息密度的地方**——只有标题 + 6 个按钮，剩下的空间与时间是留白。
2. **它是「入站」而非「出站」的符号**：给的是「这是什么世界的暗示」，不含进度/数值/具体信息，语义上不可能误导。
3. **它是一枚「角落徽记」，不压内容**（**口径已变**）：早期设计让罗盘居中、给标题做框；改版后**罗盘锚在左上、部分出屏**，退成一枚偏置的世界观徽记——视线仍以居中的标题与按钮为主。
4. **它可持续存在而不疲劳**：换气节奏仍在 **49s 以上**，用户 3–8 秒的停留期内看到的是缓慢漂移 + 一次不完整的亮度涨落。

## 2. 分层与 3D 结构

### 2.1 与现有分层的插入位置

```
┌─ html                                      canvas 背景 = var(--bg) #1d2026
└─ body.cg-kit.cg-bg.cg-bg--fog  ← 必须加 isolation: isolate（见 §2.2）
   ├─ body 自身 background-image（现有，不改）
   │     径向亮晕 · 径向暗角 · 160px 八芒环 tile(soft-light)
   │
   ├─ ★ .cg-arcane-field  z-index:-1   ← 【本规格新增】
   │    ├─ .af-stage  perspective 场景内的 3D 舞台（rotateX/Y/Z）
   │    │    ├─ .af-layer--ticks      translateZ(-90px)  → R2 廿二刻度环（自转）
   │    │    ├─ .af-layer--enneagram  translateZ(0)      → S0 九芒内阵（静止）
   │    │    └─ .af-layer--runes      translateZ(+90px)  → R1 七光符文环（自转）
   │    └─ （layer 内：<svg class="af-array"> 承载几何；旋转挂在 svg 上）
   │
   ├─ main.menu / nav.cg-nav / #app 内容     z-index:auto（正常流）
   └─ body::after 暗雾(screen)  z-index:auto  ← 现有，不改，仍在内容之上
```

- 现有底图在最底；新层在其上；内容在新层之上；暗雾仍按现有规则叠在内容之上（观感零变化）；`.cg-nav` 的 `z-index:40` 与毛玻璃采样照旧。
- **3D 场景**：`perspective` 挂在 `.cg-arcane-field` 上，`.af-stage` 做整体倾斜，`.af-layer` 用 `translateZ` 拉开纵深。旋转（`rotateZ` 闭环）挂在每层的 `<svg>` 上，与层自身的 `translateZ` 互不打架。
- `perspective-origin` 取罗盘圆心（`--af-cx --af-cy`）→ 3D 收敛方向朝罗盘，画面其它处不畸变。

### 2.2 一个必须写进实现的坑（高优先级）

`isolation` 是**必需的，不是可选的**：

- 现状 `body` 只有 `position:relative; z-index:auto` → **不构成 stacking context**。
- 此时 `z-index:-1` 的子元素会逃逸到 html 的根堆叠上下文，落在**步骤 2**（负 z-index），而 `body` 自身背景在**步骤 3**绘制 → **新层会被 `.cg-bg` 的背景图整个盖住，现场表现为「写了没效果」**。
- 一旦 `body { isolation: isolate }`，body 自成 stacking context：背景降为步骤 1，负 z-index 子层成为步骤 2 → **正确落在背景之上、内容之下**。

> 验收第一件事：确认 `getComputedStyle(document.body).isolation === 'isolate'`。漏掉这步，后面所有视觉调试都是白调。
>
> 副作用已核无：`#app` 内部 `z-index 2…80` 的相对次序不变，`body::after` 与它们的相对次序也不变。

| # | 层名 | 元素 | 用途 | 技术 | 3D |

## 3. 每层参数

> 单位：`u` = SVG `viewBox="0 0 1000 1000"` 内的用户单位，圆心 (500,500)。
> 换算：`px = u × --af-size ÷ 1000`。
>
> **`vector-effect: non-scaling-stroke` 是硬要求**：`--af-size` 在手机上只有几百 px，1u 线宽会掉到亚像素。锁定后线宽恒等于设备 px（再由 `--af-sw` 按断点补偿），跨断点观感一致。

### 3.1 公共 token

```css
.cg-arcane-field{
  --af-size:  min(150vmin, 140vw, 1600px);
  --af-cx: 34vw;   --af-cy: 26vh;   /* 罗盘圆心在视口里的落点（桌面；竖屏另给一组） */
  --af-tilt: 30deg; --af-yaw: -16deg; --af-roll: -6deg;  /* 3D 姿态 */
  --af-depth: 90px;                 /* 每环纵深 */
  --af-op-r1: 0.40; --af-op-r2: 0.35; --af-op-s0: 0.10;  /* 层不透明度 */
  --af-sw: 1;                       /* 线宽系数，按断点 1 / 1.15 / 1.40 / 2.20 */
  --af-glow: #e6a23c;               /* 暖琥珀辉光色（新色号） */
  --af-breath: cubic-bezier(0.37, 0, 0.63, 1);  /* sine-in-out 近似 */
}
```

### 3.5 「明灭」的实现：把亮度梯度烘进几何 ★

约束：**不在每个 rune 上创建独立 DOM/合成层、不做逐符文 DOM 动画**。而需求要「旋转 + 明灭」。解法：

**把亮度梯度烘进几何，让「波」由旋转自己带出来。**

- 给 7 枚符文烘上**静态**、不对称的 `stroke-opacity` 梯度（0.92 / 0.64 / 0.44 / 0.36 / 0.36 / 0.44 / 0.64，见 §3.3）。
- R1 整体旋转 → 亮度分布跟着转 → 「一道光缓慢绕环游走」，**等价于逐符文动画**。
- 成本：**0 个额外 DOM、0 个额外合成层、0 次 repaint**。
- 再叠一层 R1 整体 49s 呼吸（opacity 0.72↔1.00），让峰谷本身也缓慢涨落。

> 梯度必须刻意不对称（以 i=0 为峰、向两翼衰减），否则旋转起来只是明暗杂点，读不出「一道光在走」。

### 3.6 双色调：S0 用 `--text-dim` 而不是黄铜

- 品牌调性是「**黄铜 + 暗雾**」，从来不是单一色。`--text-dim` `#9aa1ad` 是 token 内**唯一的冷调**，用它当最内层，等于在纪律内合法借用出「雾」的冷调层。
- 空间上：**外暖内冷** → 黄铜在外围做框、冷灰在阵眼做空。

### 3.7 混合模式与辉光的落点

- **根层 `.cg-arcane-field` 用 `mix-blend-mode: normal`**：在本底图亮度（`--bg` #1d2026）下，低-中 alpha 源 `screen` 与 `normal` 的视觉差值可忽略，`normal` 免掉 blend 相关的 paint 风险。
- **「光晕」= 笔画上的 `drop-shadow`，不是底色盘**：4 层同色 `--af-glow`、半径由 3px 到 52px，叠加出由线芯到外围的**渐变衰减**。三层宽 blur 已实测：半径再往 84px 走会把整片泛白、线芯对比掉没，故停在 52。
- 曾试验过的「高光点/耀斑」已**撤除**（过小仍嫌大、且引入边缘压暗/光球问题，收益不抵成本）。

## 4. 动效编排

### 4.1 相位关系

| 层 | 旋转方向 | 周期 | 角速度 | 明灭周期 |
|---|---|---|---|---|
| R1 七光符文环 | **正转 CW** | 120s | +3.000 °/s | 49s |
| R2 廿二刻度环 | **反转 CCW** | 170s | −2.118 °/s | 67s |
| S0 九芒内阵 | — | ∞ | 0 | — |

**为什么用 `linear`**：旋转是 360° 闭环。任何 ease-in-out 都会让每圈出现「加速—减速」的呼吸感，读成「卡顿/喘息」。**闭环 tiling 动画必须线性**；`cubic-bezier` 体现在**明灭**上（§4.2）。

**为什么 R1/R2 反向**：同心环同向旋转会读成「一个刚体在转」；反向让 22 刻度与 7 符文**持续错位**，任一瞬间都独一无二。

**去同步**：120s / 170s 与 49s / 67s 均不成简单整数比 → 无可感知的循环感。

### 4.2 明灭 easing

```
cubic-bezier(0.37, 0, 0.63, 1)   →   sine-ease-in-out 的标准近似
```
速度在两端连续地归于 0，周期性往复时没有可听见的「顿」；对 0.72↔1.00 这种窄幅是**唯一不会在端点产生可见台阶**的选择。

## 5. 减动效降级（`prefers-reduced-motion: reduce`）

### 5.1 最终静态形态

保留**三层全部几何**，取消全部 animation 与 transition：

- R1 / R2 冻结在**几何烘入的初始相位**（θ₀=−90°，顶点朝正上方），轮辐对称站在中轴上，视觉稳定。
- S0 本就静态，不变。
- 每层不透明度取**动效区间的中值**：

| 层 | 动效区间 | reduce 静态值 |
|---|---|---|
| R1 | 0.288 – 0.400 | **0.344**（= ×0.86） |
| R2 | 0.280 – 0.350 | **0.315**（= ×0.90） |
| S0 | 0.10（静态） | **0.10** |

- 符文那道「游走光」不再游走，但梯度仍在 → 保留「某一侧稍亮」的明暗暗示。
- **3D 姿态与辉光照旧保留**（它们不随时间变化，不属「动效」）。

### 5.2 具体 CSS

```css
.af-array--runes{ animation: af-spin-cw  120s linear infinite,
                             af-breathe-r1 49s var(--af-breath) infinite; }
.af-array--ticks{ animation: af-spin-ccw 170s linear infinite,
                             af-breathe-r2 67s var(--af-breath) infinite; }

@keyframes af-spin-cw  { from{ transform: rotate(0deg);}   to{ transform: rotate(360deg);} }
@keyframes af-spin-ccw { from{ transform: rotate(0deg);}   to{ transform: rotate(-360deg);} }
@keyframes af-breathe-r1 { 0%,100%{ opacity: calc(var(--af-op-r1) * 0.72);} 50%{ opacity: var(--af-op-r1);} }
@keyframes af-breathe-r2 { 0%,100%{ opacity: calc(var(--af-op-r2) * 0.80);} 50%{ opacity: var(--af-op-r2);} }

@media (prefers-reduced-motion: reduce){
  .af-array--runes,
  .af-array--ticks{ animation: none; }
  .af-array--runes{ opacity: calc(var(--af-op-r1) * 0.86); }  /* = 0.344 */
  .af-array--ticks{ opacity: calc(var(--af-op-r2) * 0.90); }  /* = 0.315 */
}
```

> reduce 用 `animation: none` 而非 `paused`——paused 会冻在任意中间相位（可能是歪的），`none` 才确保回到 θ₀=−90° 的正位。BG-02 §3.1 的 `paused`（`document.hidden`）是**不同场景**，不要合并。

## 6. 移动端 / 低端档位

### 6.1 触发条件与降级参数

触发以 BG-02 §3.2 的能力探测为先（Save-Data / `deviceMemory` / `hardwareConcurrency` / reduce），此处只给**视口断点**，二者取更严的一档。

| 档 | 触发 | S0 九芒 | R1 七光 | R2 廿二刻度 | 不透明度系数 | 线宽 `--af-sw` |
|---|---|---|---|---|---|---|
| **A 全档** | 宽 ≥1200px | 显示 | 旋转+明灭 | 旋转+明灭 | ×1.00 | 1 |
| **B 窄桌面** | 900–1199px | **隐藏** | 旋转+明灭 | 旋转+明灭 | ×0.92 | 1.15 |
| **C 平板** | 640–899px | **隐藏** | 旋转+明灭 | 旋转+明灭 | ×0.85 | 1.40 |
| **D 手机** | <640px | **隐藏** | 旋转（**关明灭**） | 旋转+明灭 | ×0.85 | 2.20 |
| **L0 静态** | BG-02 判 low / reduce | 隐藏 | 静态 §5 | 静态 §5 | §5.1 中值 | — |

断点逻辑：

- **为什么第一个砍 S0**：九芒星在改版后位于罗盘内圈，而罗盘锚在左上、S0 常被推到屏外或被刻度环压住，叙事收益最低，先砍。
- **为什么手机保留 R1**：它是唯一有叙事内容的层（7 枚符文），砍掉就只剩一圈刻度，毫无辨识度。宁可压到 ×0.85 并关掉明灭（少一层 opacity 动画）。
- **竖屏单独锚点**：`@media (orientation: portrait)` → `--af-cx: 15vw / --af-cy: 13vh`。`34vw/26vh` 那套是视口比例锚点，窄屏下会落到偏中上；竖屏另给一组，确保仍贴左上出屏（**2026-10-13 新增**）。

| 视口 | 150vmin | 140vw | `--af-size` | R2 半径(470u) | R1 半径(412u) | S0 半径(236u) |
|---|---|---|---|---|---|---|
| 1920×1080 | 1620 | 2688 | **1600px**（触上限） | 752px | 659px | 378px |
| 1440×900 | 1350 | 2016 | **1350px** | 635px | 556px | 319px |

### 6.3 性能预算

| 项目 | 预算 |
|---|---|
| 合成层 | **≤ 3 个**（R1 / R2 两个运动层 + 1 个 `drop-shadow` 滤镜层；S0 静态不建层） |
| 每帧主线程 | **0 scripting**（无 rAF、无 JS 循环） |
| Layout | **0**（只动 transform / opacity） |
| Paint | 首次显示与 route/viewport 变化时；稳态 0 paint（`drop-shadow` 结果被缓存，只有 `transform` 在动） |
| `filter` | **新增 2 处 `drop-shadow`**（R1/R2 各一组 4 层）——旧版禁 filter，改版有意放宽；若低端掉帧可减到 2 层 |
| `mix-blend-mode` | 根层 **normal**（§3.7） |
| CPU 增量（桌面首页空闲 30s） | 平均 **<3%**；4× CPU 节流 **<6%**（较旧版略高，因辉光） |
| 帧率 | 60Hz 下 >16.7ms 帧占比 **<2%**；>50ms 帧 **0** |
| CLS 增量 | **0**（fixed + overflow:hidden，不参与文档流） |

**禁用清单**（违反即打回）：逐帧修改 path 数据 / 大量 `stroke-dashoffset` 动画 / `background-position` 动画 / 每个符文一个 DOM 层 / 任何 velum 式 `blur` / 任何在动画周期内的 `mask` 变动。

## 7. 可访问性与对比度自检清单

> **基准**：现有 `.cg-bg--fog::after` 本来就在给全站加亮度（screen 混合的两团蓝紫），所以「现状 baseline」不是 `#1d2026`，而是被雾抬高之后的值。下表以此为基准。

### 7.1 对比度表（按新不透明度重算）

`#e6e8ec` 正文 / `#9aa1ad` menu-sub·menu-status，在三档雾浓度下叠加 `#c8a24a` 动态层：

| 雾浓度 | 现状 baseline 正文 / 次要 | +α0.10（S0） | +α0.35（R2） | +α0.40（R1） |
|---|---|---|---|---|
| 雾最浓（理论上限） | 11.28 **/ 5.32** | 9.47 /**4.47** | 5.92 /**2.79** ⚠ | 5.37 /**2.53** ⚠ |
| 菜单列实测估算 | 12.06 **/ 5.69** | 10.17 /**4.80** | 6.20 /**2.93** ⚠ | 5.60 /**2.64** ⚠ |
| 雾稀薄处 | 12.66 **/ 5.97** | 10.60 /**5.00** | 6.47 /**3.05** ⚠ | 5.85 /**2.76** ⚠ |

**结论（口径与旧版不同，须明说）：**

- 绑定约束仍是 `--text-dim`。**当一条 1px 铜线正好穿过某个 `--text-dim` 像素时**，该像素对比度按上表降到 **2.5–3.0:1**（低于 AA 4.5:1）。
- 这与旧版「内容区有效 alpha ≤0.10」的纪律**不再兼容**——新版线不透明度 0.35/0.40 是**主理人有意调高**的结果（旧值在 1px 细线上肉眼看不见）。
- **缓解**：① 线是 1px 且稀疏，绝大多数文字像素落在暗底而非线上，**整段文字的可读性**不受影响；② 罗盘**已锚到左上出屏**，最密的弧段落在标题外侧之上，正中按钮区被 `.cg-btn` 的不透明面板遮住；③ 未受线覆盖的 `--text-dim` 仍达 baseline 的 5.3–6.0:1。
- **接受这条偏离**：作为装饰性、非正文的首页氛围层，判定为可接受。若日后要回守严格 AA，下调 `--af-op-r1/r2` 或再改锚点即可。

## 8. 验收标准（客观判据）

1. **姿态 / 摆位**——`getComputedStyle` 上 `.af-stage` 的 `transform` 含 `rotateX/rotateY/rotateZ`；`.af-layer--runes` 的 `translateZ` = `+90px`（其绝对值等于 `--af-depth`）；桌面圆心落在 `34vw/26vh`、竖屏 `15vw/13vh`，左上角切出屏外。
2. **辉光**——R1/R2 的 `filter` 为 4 层 `drop-shadow`，色 = `--af-glow`；实测一条线的横剖面：线芯比局部背景高 **≥ 15/255**，外围有 ≥10px 的渐变衰减带，且**不出现整片泛白**（远离线的背景亮度不随辉光显著抬升）。
3. **对比度**——按 §7.1：未受线覆盖的 `--text-dim` ≥ 4.5:1；「线穿文字」为已知接受项（§7.1 结论）。
4. **互动**——自动化断言 6 个按钮中心 `elementFromPoint()` 返回按钮或其后代；根层 `pointer-events:none`、`aria-hidden=true`；Tab 序不含新节点。
5. **性能**——沿用 BG-02 §3.4 全表；附加：稳态 30s 录制中 **Layout = 0**、稳态 **Paint 仅出现在首帧**；DevTools Layers 新增持续合成层 **≤ 3**。
6. **减动效**——强制 reduce 后相隔 3s 两图 **PNG diff = 0**；非首页路由下本层 `display:none`。
7. **共存**——仅切本层 CSS 开关，`#/settings` 页与首页无内容区域像素一致；不得出现暗角变浅、暗雾被冲淡、八芒 tile 消失。
8. **资产**——`git status --porcelain assets/` 为空；改动仅限 BG-02 §5.1 清单。
