# 职业框 · 塔罗抽象符号系统（设计提案 v1）

> 目的：用**塔罗牌自身的符号**替代具象母题（不眠者星图铺满卡面的教训），把所有图形锁死在边条（border strip），卡面内部恒为纯黑。
> 映射权威源：罗塞尔「亵渎之牌」体系（每张大阿尔卡纳封印一条神之途径），非塔罗俱乐部代号。
> 配套样板见同目录可视化（卡框塔罗符号系统样板）。

## 放置规则（三处落点）

| 落点 | 内容 | 尺寸（卡宽占比） | 编码含义 |
|---|---|---|---|
| 上边中央 | 途径塔罗**主徽记** | ~20px / 约 13% | 区分 22 途径 |
| 四角 | 同徽记**缩小回声** | ~9px / 约 6% | 「角饰加图形」 |
| 下边中央 | 牌序**罗马数字** | 字号 12 | 塔罗牌序 0–XXI |
| 细线本身 | 颜色/条数 | — | 编码稀有度（common 1银 / uncommon 2铜绿 / rare 3金） |

卡面内部：**绝对纯黑，不画任何图形**（这是绕开之前职业框失败的根本约束）。

## 接入方式（落地步骤，遵循出图纪律）

1. **数据源**：在 `manifest.json` 或各 `*.skills.json` 增 `tarotSigil` 字段（牌序 + 符号描述 + 罗马数字）。
2. **prompt 模板**：职业框 prompt = `artFrameFormat`（大画布·边条结构） + 「上边中央一个小 <SIGIL>，四角同 <SIGIL> 缩小回声，下边中央罗马数字 <NUM>，卡面内部纯黑无图」。
3. **先验证再出图**：改完数据 → 跑 `tools/build_frame_prompts.py` 刷新 `PROMPTS.md` → **确认 PROMPTS.md 已含新描述** → 才出图。
4. **限频**：内置 ImageGen 限频 `2026-09-24 08:00 UTC+8` 才恢复；此前只做设计，不烧积分。
5. **建议首验途径**：`sleepless`（不眠者）— 之前具象星图失败，正好用「星星=八芒星」验证抽象路线。

## 备注
- 同形卡片区分：Fool(圆+杖) / Sun(圆+芒) / Star(八芒) / Moon(弯月) / Wheel(八辐) / Hermit(圆+六角) 轮廓各异，缩到 9px 仍可辨。
- Magician 与 Strength 都用 ∞：Strength 额外带「下方放射小圆」以区分。
- Empress ♀ 与 Emperor 王冠均为单色细线，配罗马数字 III / IV 不会混淆。
